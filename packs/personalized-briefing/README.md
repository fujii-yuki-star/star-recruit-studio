# 拡張パック「あなた向け会社説明」（社内配布用）

ADR-0060（拡張パック）・ADR-0061（あなた向け会社説明）。**機能の鍵だけ**のパック（プログラムも動画の中身も入っていない）。
入れた人のすたりおにだけ、左のメニューに「あなた向け会社説明」が出る。入れていない人のアプリでは一切動かない（ADR-0061 決定1）。

## 作り方（開発側）

```bash
npm run pack:briefing
```

→ `release/personalized_briefing_<版>.starpack`（中身は `pack/` の下だけ＝この README は入らない。`manifest.json` の `files` は道具が埋める＝`scripts/make-starpack.mjs`）。

- ⚠️ `minAppVersion` は**この機能が入ったアプリの版**（β＝0.7.0）。それより古いすたりおには入らない（入れる前に断る）。
- 版（`version`）を上げると、入っている古い版と入れ替えられる。

## 使い方（担当者向け）

1. すたりおの「設定」→「拡張パック」→「拡張パックを入れる…」で `.starpack` を選び、中身を確かめて「入れる」。
2. 左のメニューの「あなた向け会社説明」で**登録**する：
   - 興味の項目（例が入っている・名前を変える／足す／消す）
   - 使う動画（場面編集で作った動画）と、場面ごとの「見せる興味」「優先度」「必ず入れる」「使わない」
   - 最後の場面の文と、会社のロゴを置くか（ロゴは「設定」の「会社の見た目」）
   - **学生の画面から抜ける 4 桁の番号**（決めるまで学生の画面は始められない）
3. 説明会の場で「**学生の画面を始める**」。学生が知りたいこと・長さ・話す声を選ぶ → 組む → 並べ替え・外す・声を変える → 作る → 見る → 終わる。
4. 抜けるときは右上の「担当の人へ」→ 番号。番号を忘れたら、アプリを閉じれば通常の画面から始まる。

- 学生の名前などは入力させない・保存しない。作った動画は「終わる」で消え、残っても 24 時間で消える。
- 同梱の AI が使えないパソコンでも、ルールだけで組める（そのとき最後の場面の一言に「AI が」は出ない）。
