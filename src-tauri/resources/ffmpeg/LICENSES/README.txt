同梱の FFmpeg（動画の書き出しに使う部品）に関するライセンス本文です。

- ../LICENSE.txt
    FFmpeg 本体のライセンス（GNU LGPL v3）。FFmpeg のソースは https://ffmpeg.org/releases/ から入手できます
    （このアプリが使っている版と入手方法は、ソースコードの FFmpeg_SOURCE.md に記録しています）。
- GPL-3.0.txt
    GNU GPL v3 の本文。LGPL v3 は GPL v3 に追加の許可を足したものなので、GPL v3 の本文もあわせて添えます。
- OpenH264-BSD-2-Clause.txt
    同梱の FFmpeg の中に組み込まれている OpenH264（Cisco Systems のソースから組み立てられたもの）のライセンス
    （BSD-2-Clause）。通常の書き出しでは Windows の機能（Media Foundation）を使い、OpenH264 はその機能が無い
    パソコン（Windows N/KN 等）での予備の方式としてだけ使われます。
    ⚠️ これは Cisco が配布しているバイナリではありません。
