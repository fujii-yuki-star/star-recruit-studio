## なぜ2か所あるのか

⚠️ **原本を全部 `public/` に置くと、使っていない絵まで配布物に入ります**（インストーラが太る）。
逆に原本を持たないと、**使うのをやめた絵が消えて戻せなく**なります。
だから **原本は全部ここ・配るのは使うぶんだけ** に分けています。

⚠️ **`public/yuko/` を直接増やさないこと。** 原本をここへ置いてから、使うものを複製してください。
使う絵の一覧は **`src/app/data/yukoImages.ts` の1か所**にあります（そこに書いていない絵は誰も使いません）。

## 名前の付け方（`17_YUKO_CHARACTER_SPEC.md` §3）

`yuko_{poseTag}_{NNN}.png`。`poseTag` の正典は7つ＝
`normal` / `smile` / `guide` / `bow` / `surprise` / `think` / `cheer`。
⚠️ **自由文字列なので足してよい**（`17 §3`）＝いまは `thanks` / `sad` / `angry` / `sleepy` / `run` を足しています。

### そろい具合（2026-09-25）

**正典の7つはすべてあります**（`normal` / `smile` / `guide` / `bow` / `surprise` / `think` / `cheer`）。
既定（解決に失敗したときの顔）は **`normal`**＝`17 §3` の約束どおり。

原本にはこのほかに、**同じ顔の別案**（`normal_002`＝座り・`smile_002`＝控えめな挨拶）と、
**正典外の演出用**（`thanks` / `sad` / `angry` / `sleepy` / `run` / `worry` / `idea`）があります。
使いたくなったら `public/yuko/` へ複製して `yukoImages.ts` に1行足してください。

## 形について

⚠️ **いまの絵は正方形（1254×1254）**ですが、`17 §2` は「**縦長 720×1280 目安・全表情で同一カンバス**」と
書いています（動画の中に立ち絵として置く前提）。**実態と仕様が食い違っています**。
シール調の絵はアプリの画面では正方形が自然なので、**動画に使うぶんを作るときに改めて決める**話です
（このことは `17` 側にも注記してあります）。
