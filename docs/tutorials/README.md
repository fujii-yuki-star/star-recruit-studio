## お願いしたい素材

1. **短い実写の動画を 2〜3 本**（各 10〜20 秒・社内の風景や作業の様子・フリー素材で可）
   ＝ 05・07・08 で「動画の部品」と「元の音」を見せるため。写真だけだと、分ける・詰めるの見せ場が弱い。
2. **人が話している短い音か動画**（20〜40 秒・日本語・はっきりした声）
   ＝ 07 の「声を文字にする」。⚠️ 利用者の声で録ったものでも、フリー素材でも可。**声の同梱素材（ずんだもん）で作った音でも撮れる**ので、無ければそれで撮る。
3. **架空の会社ロゴ**（透過 PNG・正方形に近い形）
   ＝ 09 の「いつものロゴ」。実在の会社のロゴは使わない。
4. （任意）**ゆうこの表情の差分**が足りているかの確認
   ＝ 掛け合いで「驚く」「困る」を使う段がある（04・05 の掛け合い台本）。足りなければ笑顔で代える。

## 決めてほしいこと

- **01 を延ばすか**＝今は入口（4段）だけ。「写真を取り込んで 30 秒の動画を書き出す」まで1本で見せる案（ADR-0046 の当初の想定）と、02・03 に分けたままにする案。
- **画面での呼び名**（ADR-0046 未解決の論点2）＝「使い方の動画」「チュートリアル」など。`06 §3` に定着語が無い。
- **配る解像度と、インストーラをどこまで大きくしてよいか**（論点3・4）＝ 10 本・各 2〜4 分を 1280×800 で入れると、数百 MB 増える見込み（実測は撮ってから）。

## 台本の書き方（共通）

- 段の `say` は**録画の目印**（短く・事実だけ）。解説は掛け合い（`*.dialogue.json`）で重ねる。**笑いのために手順の正確さを曲げない**（ADR-0046 ⑥）。
- `clickText` などのボタン名は**画面の文字そのまま**。🆕 の下書きは、撮る前に `--下見` で通して直す（名前が変わっていたら台本の側を直す）。
