## 撮り方と仕上げ方（2026-10-15 に 10 本を撮り、01・04・06 を仕上げた）

- ⚠️ **アプリは Claude（など MSIX で動くもの）の中から起動しない**＝その中で起動したアプリが書いたファイルは別の置き場（`Packages\Claude_…\LocalCache`）へ回され、**画面に絵を出す WebView2 からは見えない**＝取り込んだ写真や、よく使う素材の小さな絵が「絵が出ない印」で写る（書き出しは正しいので気づきにくい）。
  **エクスプローラー経由で起動する**（環境変数 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` を付けた .cmd を `explorer.exe` で開く）→ `tutorialRecord.mjs --attach` で撮る。回ごとにアプリと部品を止め、撮影で作られた動画を片づけてから起動し直す。
- 撮る → `tutorialCursor.mjs`（カーソルを焼き、中身だけに切る）→ **`tutorialCompose.mjs`**（掛け合いの声を同梱の音声ソフトで作り、段ごとに切った映像・声が長い段は止めたコマ・連動する字幕・ゆうこの立ち絵〔ゆうこの声で動く〕・BGM・題字をタイムライン形式の動画に組む）→ `--import` → `--export`（`18` の口）。
- 掛け合い台本＝`<番号>-<名前>.dialogue.json`（`at` は `opening`／`ending`／段の `say`・`reading` は声に渡す文）。01・04・06 にある。
- 大きさ＝書き出し「きれい（1920×1080）」で 1 分あたり約 14MB（01＝56 秒 13.5MB・04＝119 秒 31.4MB）。10 本を同じ作りにすると 300MB に近い＝「ふつう」で書き出すかは要相談。

## 撮る前の準備（下見で確かめた手順）

- **見本の拡張パック**（10）＝`docs/tutorials/prep/sample_office/` に manifest と見た目パターンがある。文字の形と曲は同梱物から写して組む：
  `f/kaitou.ttf`＝`public/fonts/KaitouYokokuGothic.ttf`・`b/cruise.mp3`＝`public/bgm/limousine-cruise.mp3` を置いて
  `node scripts/make-starpack.mjs docs/tutorials/prep/sample_office <出力>.starpack` → アプリの設定から入れる（撮ったら外す）。
- **架空の会社ロゴ**（09）＝`docs/tutorials/prep/sample_logo.png`（丸と三角・透過・利用者の案 2026-10-14）を、よく使う素材に名前「会社ロゴ（見本）」・種類「写真」・タグ「見本」で置く（撮ったら外す）。
- **話し声の見本**（07）＝声のソフトで作った話し声（青山龍星・約 9 秒・「みなさん、こんにちは。今日は、すたりおで字幕をつける方法をご紹介します。話している声を、そのまま文字にできます。」）を、よく使う素材に名前「話し声の見本」・タグ「見本」で置く（撮ったら外す）。
- **下見は実際に操作する**＝動画が作られ、設定も変わる。終わったら作られた動画をごみ箱へ移し、06・09 の注記のとおり設定を戻す。
- ⚠️ **このパソコンの中の AI を使う 03 は、CPU が空いているときに撮る**＝2026-10-15 は他の作業で CPU が 7 割ほど埋まっていて、たたき台が 4 分を過ぎてもできなかった（前日は 95 秒）。待つ段は `untilHeadingMs`（見出しが変わるまで・上限つき）で待つ。
- 道具は終わるときに**アプリの部品（AI・声・文字起こし）も一緒に止める**（`scripts/lib/appTree.mjs`）＝以前はアプリだけを止めていて、AI の部品が丸1日残った。
- 録画の道具は**スクロールをゆっくり滑らせる**（`scripts/lib/glideScroll.mjs`・0.6〜1.4 秒）＝押す相手を画面へ入れるとき一瞬で飛ぶと、見ている人にはスクロールしたことが分からない（利用者の指摘 2026-10-16）。見えている相手は動かさない。滑らせた長さは記録（`.steps.json` の `glidedMs`）に残る。
- 録画の道具は**文字の無いボタン（絵だけ）も名前で押せる**（`scripts/lib/cdp.mjs` の `FIND_BY_TEXT`＝08 の「縦の版を作る」で要った）。

## お願いしたい素材

1. **短い実写の動画を 2〜3 本**（各 10〜20 秒・社内の風景や作業の様子・フリー素材で可）
   ＝ 05・07・08 で「動画の部品」と「元の音」を見せるため。写真だけだと、分ける・詰めるの見せ場が弱い。
2. **人が話している短い音か動画**（20〜40 秒・日本語・はっきりした声）
   ＝ 07 の「声を文字にする」。⚠️ **無くても撮れる**（声のソフトで作った話し声で下見済み）。人の声のほうが「聞き違いを直す」を見せやすいので、あれば差し替える。

## 台本の書き方（共通）

- 段の `say` は**録画の目印**（短く・事実だけ）。解説は掛け合い（`*.dialogue.json`）で重ねる。**笑いのために手順の正確さを曲げない**（ADR-0046 ⑥）。
- `clickText` などのボタン名は**画面の文字そのまま**。🆕 の下書きは、撮る前に `--下見` で通して直す（名前が変わっていたら台本の側を直す）。
