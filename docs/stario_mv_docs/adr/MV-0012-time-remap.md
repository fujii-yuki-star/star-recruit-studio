# MV-0012: 速度変更・タイムリマップ

- **状態**: Accepted（2026-11-27・γ0.2 の段階③。業界の型＝After Effects の約束に合わせる＝MV-0003・α の ADR-0034 と同じ考え方）
- **日付**: 2026-11-27
- **関連**: MV-0010（γ0.2 の段階）／MV-0001（形＝`timeRemap` は秒の数値のキーフレーム）／MV-0003（描画の約束）／MV-0006（映像のコマの選び方）／MV-0011（入れ子の時刻）／MV-0004・MV-0007（音）／MV-0009（取引と履歴）

## コンテキスト

正典の形には、映像・音・入れ子のレイヤーに `timeRemap`（そのフレームで見せる素材の時刻＝秒・数値のキーフレームも可）がある。速度を持つ欄は無い。描画の核はまだ `timeRemap` を読まず、検査は「まだ描けない（γ0.2）」と知らせている。

## 決定

### 決定1：タイムリマップ＝そのフレームで見せる素材の秒（AE と同じ）

- `timeRemap` があるレイヤーは、コンポジションのフレーム `f` で素材の `timeRemap(f)` 秒を見せる（キーフレームの時刻は他の項目と同じコンポジションのフレーム＝MV-0001）。`startFrame` からの進みは使わない。
- 映像：その秒 × 素材の fps を切り捨てたコマ（MV-0006 と同じ選び方）。**素材の範囲の外は端のコマで止める**（AE のタイムリマップと同じ＝0 秒より前は最初のコマ・終わりより後は最後のコマ）。
- 入れ子：その秒 × 中の fps を切り捨てたフレーム。範囲の外は端のフレームで止める（同上）。
- 連番の映像も同じ（端で止める）。
- `timeRemap` が無いときは今まで通り（`startFrame` から進む・範囲の外は描かない）。

### 決定2：音もタイムリマップに沿って鳴らす（音の高さも変わる＝AE と同じ）

- 音のレイヤー・音を持つ映像・入れ子の中の音は、見える範囲の各時刻で `timeRemap` の秒の音を鳴らす。速くすれば高く、遅くすれば低く、逆向きなら逆に鳴る（AE と同じ＝音の高さを保つ伸縮はしない）。素材の範囲の外は無音。
- 作り方：素材の音を一度ほどいて（48kHz ステレオ）、コンポジションの各標本の時刻で素材の位置を求めて間を直線で補い、一時の音のファイルにしてから混ぜる。**書き出しとプレビューは同じ関数**（MV-0007 決定6）。一時のファイルは中身（素材・リマップ・範囲）で名前を決めて使い回す。
- 入れ子のレイヤーの `timeRemap` は中の音にも効く（中の音をまず中の時刻で混ぜた音にして、それを外の時刻へリマップする）。

### 決定3：速度変更はタイムリマップのキーフレーム2つで表す（欄を増やさない）

- 正典の形に速度の欄を足さない（schema を変えない）。速度は「見える範囲の始めと終わりに置いた直線のキーフレーム2つ」で表す（傾き＝速度）。
- 取引の編集 `setSpeed`（`layerId`・`percent`＝100 で等速・負で逆再生・0 は断る）：
  - 今の見える範囲の始め `inFrame` で見せている素材の秒（`timeRemap` があればその値・無ければ `startFrame` からの進み）を起点にする。逆再生のときは、今の見える範囲の終わりで見せている秒を起点にする（見えていた区間を逆向きに見せる＝AE の伸縮 −100% と同じ見え方）。
  - 見える範囲の長さを `今の長さ × 100 / |percent|` に直す（`outFrame` を動かす＝AE の伸縮と同じく遅くすれば長くなる）。
  - `timeRemap` を、始めと終わりの直線のキーフレーム2つで置き換える。
  - ⚠️ AE の「時間伸縮」は他の項目のキーフレームも伸び縮みさせるが、ここでは**動かさない**（速度の欄が無い＝他のキーフレームはコンポジションの時刻のまま）。知らせる（キーフレームのある項目があれば warnings）。
- 取引の編集 `enableTimeRemap`（`layerId`・`enabled`）：
  - 入れる＝今の見え方のまま、見える範囲の始めと終わりに直線のキーフレーム2つを置く（AE の「タイムリマップ使用可能」＝`Ctrl+Alt+T`）。
  - 外す＝`timeRemap` を消す（`startFrame` からの進みに戻る＝見え方が変わりうる・AE と同じ）。
- 映像・音・入れ子のレイヤーだけ（他は断る＝正典の形が許さない）。

### 決定4：画面

- 項目の欄（PropsPanel）に「速度（%）」：映像・音・入れ子のレイヤーで出す。今の値は `timeRemap` が直線の2つなら傾き・無ければ 100・それ以外（キーフレームが3つ以上・直線でない）は「タイムリマップ」と表示して数値は空。変えると `setSpeed`。
- 「タイムリマップ」の入り切り（`Ctrl+Alt+T`＝AE と同じ）。キーフレームの細かい編集は段階⑤（キーフレームの画面）・⑥（グラフ）。

## 結果・影響

- `mv-core`：「まだ描けない」からタイムリマップを外す。素材の秒を求める関数（`source_sec`）。
- `mv-render`：映像・連番・入れ子の時刻をタイムリマップで決める。
- `mv-export`：タイムリマップのある音を一時の音にする（純粋な標本の補い `remap_pcm` と、その WAV 書き出し）。
- `mv-ops`：`setSpeed`・`enableTimeRemap`・操作の一覧・履歴の名前。
- 画面：速度の欄・タイムリマップの入り切り。

## 未解決の論点

- 音の高さを保つ伸縮（AE には無い・要るなら別の項目）。
- フレームの混ぜ合わせ（AE のフレームブレンド・ピクセルモーション）＝遅くしたときにコマの間を混ぜる。段階④のモーションブラーの後に検討。

## 追補（2026-11-27）＝実装の記録

- **芯**：`source_sec`（そのフレームで見せる素材の秒＝リマップの値か startFrame からの進み）を `mv-core` の1か所に置き、描画・音・取引が同じものを使う。範囲の外の扱いは素材の長さを知っている所で決める（`mv-render` の `hold_index`＝端で止める・コマ数がわからなければ 0 より前だけ）。
- **描画**：映像（コマ数は FFmpeg の調べた値）・連番（取り込みのときのコマ数）・入れ子（`nested_frame` が `Result` になった）。
- **音**：`remapped_wav` が素材を書き出しと同じ混ぜ方（`mix_args`）で 48kHz ステレオにほどき、`remap_pcm`（純粋）で外の時刻へ並べ直して浮動小数の WAV（`wav_f32`）にする。置き場所は一時フォルダの `stario-mv-audio`（中身で名前を決めて使い回す・24 時間より前のものは次に作るときに消す＝`sweep_old`）。入れ子は中の音をまず中の時刻で混ぜてから並べ直す。
- **取引**：`setSpeed`・`enableTimeRemap`・履歴の名前「速度を変える」「タイムリマップ」。速度は「見せていた素材の区間」を保つ（倍速→等速で長さが戻る・止まっていたら見える範囲の長さ）。
- **画面**：項目の欄の「時間」（速度＝直線のキー2つなら傾き・細かいリマップは「タイムリマップ」と表示・タイムリマップの入り切り）・`Ctrl+Alt+T`（選んだ時刻を持つレイヤーごとに今と逆へ）。⚠️ 帯を掴んでずらすと、タイムリマップのキーも一緒にずらす（他のキーフレームと同じ＝同じ時刻に同じ素材の秒を見せる）。
- ⚠️ 変形の「式」で知らせる分岐（`moving_transform` の expression）は、式が γ0.7 まで検査で断られるので今は届かない（γ0.7 で式を入れるときに検査を足す）。
- **実機で確かめたこと（2026-11-27・開発版＋CDP＋画面の撮影）**：入れ子のレイヤーを選んで項目の欄の「速度」に 200 を入れる → 見える範囲が 150 → 75・リマップは (0, 0 秒)〜(75, 5 秒)・30 フレーム目の入れ子の中身が等速の 60 フレーム目と同じ／−100 → (0, 5 秒)〜(150, 0 秒)・欄に −100／`Ctrl+Alt+T` でリマップが外れ、欄のチェックも外れる。⚠️ 音は耳では確かめていない（高さと時刻は検査で確かめた）。映像の素材（FFmpeg でほどく方）の端で止める動きは、検査で映像の素材を使っていない（連番と入れ子で確かめた）。
