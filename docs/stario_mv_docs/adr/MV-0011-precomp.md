# MV-0011: 入れ子のコンポジション（プリコンポーズ）

- **状態**: Accepted（2026-11-27・γ0.2 の段階②。業界の型＝After Effects の約束に合わせる＝MV-0003・α の ADR-0034 と同じ考え方）
- **日付**: 2026-11-27
- **関連**: MV-0010（γ0.2 の段階）／MV-0001（形＝`type: precomp`・`compositionId`・入れ子の循環の検査）／MV-0003（描画の約束）／MV-0004（書き出しの音）／MV-0007（プレビューの音）／MV-0008（編集画面）／MV-0009（取引と履歴）

## コンテキスト

正典の形には入れ子の入れ物（レイヤーの `type: precomp` と `compositionId`）があり、2段目の検査は入れ子の循環も見ている。描画の核はまだ描けず、検査は「まだ描けない（γ0.2）」と知らせている。

## 決定

### 決定1：入れ子の中を同じ描画の核で描き、その絵を1枚のレイヤーとして重ねる

- 入れ子のコンポジションを、外と同じ描画の核で描く（中のレイヤー・親子・描画モードもそのまま）。**地は透明**（AE と同じ＝入れ子の背景の色は、そのコンポジションを開いて見るときだけ）。
- 描いた絵は GPU に置いたまま、**作業の色空間のまま**外の合成に渡す（一度 sRGB の 8bit に落とさない＝往復で劣化しない）。
- 外では1枚のレイヤーとして、変形（親子付けも）・不透明度・描画モードを掛ける。中身の大きさ＝入れ子のコンポジションの大きさ（1倍で描く＝拡大すると粗くなるのは AE の既定と同じ。「コラップス」は γ0.2 では入れない）。
- 入れ子の深さは 16 まで（循環は2段目の検査で断る。深すぎるときは描かずに知らせる）。

### 決定2：入れ子の中の時刻

- 中の時刻（秒）＝（外のフレーム − レイヤーの `startFrame`）÷ 外の fps。中のフレーム＝その秒 × 中の fps を切り捨て（映像の素材と同じ選び方＝MV-0006）。
- 中のフレームが 0〜長さの外なら描かない（AE と同じ）。

### 決定3：入れ子のレイヤーの既定（`addLayer`）

- アンカーは中身の中心（入れ子のコンポジションの中心＝AE）。位置はコンポジションの中心。
- 長さは入れ子の長さ（外の fps に直す・外の終わりで止める＝素材と同じ）。

### 決定4：入れ子の中の音も鳴らす・書き出す

- 入れ子の中の音（音のレイヤー・音を持つ映像）を、外の時刻へずらし、入れ子のレイヤーの見える範囲で切って混ぜる。入れ子のレイヤーを消音・ソロの外・表示を切っていれば鳴らさない（AE と同じ）。
- プレビューと書き出しは同じ混ぜ方（MV-0007 決定6）。

### 決定5：プリコンポーズ（取引の編集 `precompose`）

- 選んだレイヤーを新しいコンポジションへ移し、外ではその入れ子のレイヤー1つに置き換える（AE の「すべての属性を新規コンポジションに移動」）。
  - 新しいコンポジションは、外と同じ大きさ・fps・長さ・背景。中のレイヤーは並び・時刻・変形をそのまま（見た目が変わらない）。
  - 入れ子のレイヤーは、選んだうちいちばん手前の位置に置く。見える範囲は外の全体・`startFrame` 0・アンカーと位置は中心（＝そのまま重なる）。
  - **親子付けが外と中にまたがるときは切る**（中へ移したレイヤーの親が外に残る・外のレイヤーの親が中へ移る）。切ったことは知らせる（見た目が変わりうる＝黙らない）。
- 画面：`Ctrl+Shift+C`（AE と同じ）・タイムラインの帯の「プリコンポーズ」。入れ子の帯をダブルクリックで、その中を開く（上のコンポジションの選択が切り替わる）。

## 結果・影響

- `mv-render`：コンポジションを作業の色空間の絵として描く段（入れ子でも使う）・合成で「作業の色空間の中身」を受ける印。
- `mv-core`：「まだ描けない」から入れ子を外す。
- `mv-export`：入れ子の中の音を集める。
- `mv-ops`：`addLayer` の入れ子の既定・`precompose`・操作の一覧・履歴の名前。
- 画面：プリコンポーズ・ダブルクリックで開く・入れ子の帯の色。

## 未解決の論点

- コラップス（入れ子の中を外の解像度で描く・描画モードを外へ通す）。
- 入れ子の時間を伸び縮みさせる（タイムリマップ＝段階③）。
