# MV-0013: モーションブラー

- **状態**: Accepted（2026-11-27・γ0.2 の段階④。AE と同じ＝MV-0010 決定4・利用者判断 2026-11-27）
- **日付**: 2026-11-27
- **関連**: MV-0010 決定4／MV-0001（形・schemaVersion）／MV-0003（描画の約束＝小数のフレームの値）／MV-0011（入れ子）／MV-0012（タイムリマップ）／MV-0009（取引と履歴）

## コンテキスト

MV-0010 決定4 で「AE と同じ（レイヤーとコンポジションの両方のスイッチ・シャッター角 180°・サンプル 16）」と決め、形に足すものはこの ADR で決めることにした。描画の核は値を小数のフレームでも求められる（MV-0003）。

## 決定

### 決定1：形に足すもの（足すだけ＝今の動画はそのまま読める）

- レイヤー：`motionBlur`（真偽・無ければ切）。AE のレイヤーの「モーションブラー」スイッチ。
- コンポジション：`motionBlur`（無ければ切）＝`enabled`（真偽・AE のコンポジションの「モーションブラーを有効」）・`shutterAngle`（0〜720 度・既定 180）・`shutterPhase`（−360〜360 度・既定 −90）・`samples`（2〜64・既定 16）。AE のコンポジション設定の「高度」と同じ意味。
- schemaVersion は 0.2.0 に上げる（項目を足しただけ＝移し替えは要らない。0.1.0 の動画もそのまま読む）。

### 決定2：かかる条件と時刻（AE と同じ）

- レイヤーのスイッチと、そのレイヤーがあるコンポジションのスイッチの**両方が入ったときだけ**かかる。
- 1コマの中で、時刻 `frame + (shutterPhase + shutterAngle × (i + 0.5) ÷ samples) ÷ 360`（i = 0〜samples−1）の変形で描いた絵を平均する（既定＝そのコマの前後 1/4 コマ）。
- ぼかすのは**変形**（位置・アンカー・大きさ・回転・不透明度・親の変形）。中身（文字・図形の大きさ・映像のコマ・入れ子の中の時刻）はそのコマのものを使う。
- 動いていない（全部の時刻の変形と不透明度が同じ）なら、ぼかさずに1回で描く（同じ絵・速い）。

### 決定3：描き方（プレビュー＝書き出し）

- 描画の核の中で、そのレイヤーだけを透明な地に各時刻で描いて平均し（作業の色空間・乗算済み）、その絵をレイヤーの描画モードで1回重ねる（描画モードは平均した絵に1回だけ掛ける＝重ねるたびに掛けない）。
- 入れ子のレイヤーは、入れ子の変形でぼかす（中のレイヤーは、中のコンポジションのスイッチに従う＝それぞれのコンポジションのスイッチが自分のレイヤーに効く）。
- 外部 AI の「1コマ描く」・プレビュー・書き出しは同じ描画の核を通るので、同じ絵になる。

### 決定4：画面と取引

- タイムラインの行に、レイヤーのスイッチ（AE の「M」の印）。タイムラインの上に、コンポジションのスイッチ。
- 取引は今の `updateLayer`・`updateComposition` で書く（新しい編集は足さない）。

## 結果・影響

- 正典：`mv-project.schema.json`（項目・schemaVersion 0.2.0）・見本。
- `mv-core`：形・既定の値・ぼかす時刻を求める純粋な関数。
- `mv-render`：レイヤーを透明な地に描く段・平均する段・平均した絵を重ねる段。
- 画面：2つのスイッチ。

## 未解決の論点

- 適応サンプル（AE の「適応サンプル数の上限」）。
- 遅いときに、プレビューだけサンプルを減らすか（今は減らさない＝プレビュー＝書き出し）。
