# MV-0008: 編集画面（タイムライン・値の欄・プレビューで掴む・キーフレームを打つ）

- **状態**: Accepted（2026-11-26・γ0.1 の段階⑧・利用者判断＝4点ともおすすめどおり＋キーフレームを打つのを前倒し）
- **日付**: 2026-11-26
- **関連**: ADR-0074 決定3（C-2 取引・C-3 開いていても閉じていても）・決定6（版の割り振り）／MV-0001（形）・MV-0005（操作口）・MV-0006（素材）・MV-0007（プレビュー）／α の ADR-0034（業界の型に合わせる）

## コンテキスト

段階⑦まで、アプリは読むだけだった（外部 AI が書き、アプリが映す）。段階⑧で、**利用者が画面で編集できる**ようにする。
版の割り振りでは、γ0.1 は「置く・切る・詰める・ずらす・吸着」、γ0.2 は「レイヤー＋キーフレームの画面」。
利用者の判断で、**キーフレームを今の時刻に打つことだけ**を γ0.1 へ前倒しした（グラフ・動きの道筋は γ0.2 のまま）。

## 決定

### 決定1：画面の変更も、外部 AI と同じ取引を通す

- 画面の操作は全部、`mv-ops` の `applyTransaction`（MV-0005）を**アプリの中から同じ関数で**呼ぶ。検査も保存も AI と同じ道。
- **掴んで動かしている間は保存しない**。動かしている途中の編集を、プレビューの糸に「試し」として渡す。糸は写しに当てて描くだけ。離したときに1つの取引として保存する。
- 1つの操作（1回のドラッグ・1回の値の確定・1つのキー操作）＝1つの取引＝後で「元に戻す」1回（段階⑨）。
- 検査が通らない操作は保存せず、理由を出す（例：コンポジションより前へ動かした）。

### 決定2：アプリと AI が同時に触るときは、錠と版で並べ、画面は当て直す

- 画面の取引には、そのとき見ていた版（`baseRevision`）を付ける。
- 版が違う（その間に AI が書いた）ときは、**最新の中身に同じ操作を当て直す**。画面の操作は「どのレイヤーを」と ID で指しているので、当て直せることが多い。当て直して検査が通れば保存し、通らなければ理由を出す。
- 錠がかかっている（AI が反映中）ときは、少し待って（最大2秒）送り直す。
- AI をアプリ経由で操作させる（MCP がアプリにつながる）のは後の版。
- **素材の取り込みの許可**（MV-0005 決定4 の許したフォルダ）は AI のための決まり。利用者が画面で選んだファイルは許したフォルダの外でも取り込める（呼ぶ側を「利用者」として区別する）。

### 決定3：画面の構成（AE の型）

- 上段：左に**素材の一覧**、真ん中に**プレビュー**、右に**値の欄**（選んだレイヤー）。
- 下段：**タイムライン**（左にレイヤーの名前と切り替え、右に時間の目盛りとレイヤーの帯・今の時刻の線）。
- 欄の大きさは境目を掴んで変えられる（大きさは画面の好みとして手元に覚える＝プロジェクトには書かない）。

### 決定4：タイムラインの操作（γ0.1）

| 操作 | やり方（業界の型） | 取引の中身 |
|---|---|---|
| 置く | 素材の一覧からタイムラインへ運ぶ（落とした時刻から始まる） | `addLayer` |
| ずらす | 帯を掴んで左右へ | `updateLayer`（`inFrame`・`outFrame`・`startFrame` を同じだけ） |
| 端を切る | 帯の左右の端を掴む／`Alt+[`・`Alt+]`＝今の時刻で切る | `updateLayer`（`inFrame` か `outFrame`） |
| 今の時刻へ動かす | `[`・`]`＝始まり／終わりを今の時刻へ | `updateLayer` |
| 分割 | `Ctrl+Shift+D`＝今の時刻で2つに分ける（AE と同じ＝元は今の時刻で終わり、写しが今の時刻から始まり、元の上に置く） | `splitLayer`（新しい編集） |
| 詰める | 選んだレイヤーを、時間の順に隙間なく並べ直す（AE の「シーケンスレイヤー」） | `updateLayer` を並べる |
| 消して詰める | `Shift+Delete`＝消して、後ろのレイヤーをその長さだけ前へ | `removeLayer`＋`updateLayer` |
| 消す | `Delete` | `removeLayer` |
| 重なりの順 | 名前の列を掴んで上下へ／`Ctrl+]`・`Ctrl+[` | `moveLayer` |
| 切り替え | 目（表示）・ソロ・錠・名前の変更 | `updateLayer` |
| 吸着 | **既定で入（Premiere の型）**。`S` で切り替え。吸い付く先＝今の時刻・コンポジションの始まりと終わり・ほかのレイヤーの始まりと終わり・マーカー。8 画素以内 | ― |
| 選ぶ | クリック・`Ctrl` で足す・`Shift` で範囲・`Ctrl+A` | ― |

- 時間の目盛り：今の時刻の線を掴んで動かす（動かしている間もプレビューが追う）。`Alt＋ホイール`＝拡大・縮小、ホイール＝上下、`Shift＋ホイール`＝左右。
- 帯は見えている行だけ描く（**画面の部品＝DOM**。重くなったら帯の部分だけ Canvas に替える）。
- `splitLayer` は外部 AI にも使える編集として、操作の一覧（`mv-operations.json`）に足す。

### 決定5：値の欄（固定値）と、キーフレームを打つ（前倒し）

- 選んだレイヤーの値を数値で直す：位置・アンカー・大きさ・回転・不透明度・描画モード。種類ごとの中身（文字・単色・図形）も直せる。
  - 文字：文と大きさと色。単色：色と大きさ。図形：大きさ・角の丸み・塗り。
- 数値は**左右に掴んで動かせる**（AE の型）。クリックで打ち込み、`Enter` で確定、`Esc` で取り消す。
- **キーフレームを打つ（AE の型）**：
  - 値の左のストップウォッチを押すと、その値はキーフレームになり、今の時刻にキーを1つ打つ。
  - キーフレームになっている値を変えると、今の時刻にキーを打つ（あれば置き換える）。
  - ◀◆▶ で前と次のキーへ移り、◆で今の時刻のキーを足す・消す。
  - ストップウォッチを外すと、今の時刻の値の固定値に戻る（キーは消える）。
  - 補間は直線（AE の既定の時間補間）。イージング・グラフ・動きの道筋は γ0.2。
  - タイムラインの帯の下に、キーの位置を小さな◆で出す（掴んで動かすのは γ0.2）。

### 決定6：プレビューで掴んで動かす

- プレビューでクリックすると、その場所にある**いちばん手前のレイヤー**を選ぶ。選んだレイヤーの枠（四隅）を画面の上に重ねて描く。
- 掴んで動かすと、位置（`position`）が動く。`Shift` で縦か横だけに動かす。キーフレームになっていれば、今の時刻のキーを打つ（決定5 と同じ）。
- 枠の計算は Rust（描画の核と同じ中身の大きさ・変形）で行い、画面は受け取って描くだけ（近似で描き写さない）。
- 拡大・縮小・回転の取っ手は γ0.2。

### 決定7：素材の一覧

- 取り込んだ素材を、種類・大きさ・長さ・指紋の有無とともに並べる。「取り込む…」（ファイルを選ぶ）で `importAsset` する（コピーが標準）。
- タイムラインへ運ぶと置ける（決定4）。

## 結果・影響

- 操作の一覧に `splitLayer` が増える（外部 AI も使える）。
- `mv-ops` の呼ぶ側に「利用者」と「AI」の区別が増える（決定2 の取り込みの許可）。
- 実装は3つに分ける：
  - ⑧-1：取引の道（試し・当て直し）とタイムラインの基本
  - ⑧-2：値の欄とキーフレームを打つ
  - ⑧-3：プレビューで掴むことと素材の一覧

## 未解決の論点

- 作業範囲（`B`・`N`）と、その範囲の繰り返し再生（MV-0007 から持ち越し）。
- 複数のレイヤーを掴んでまとめて動かすときの吸着（いちばん近いものだけに吸い付く、で始める）。
- AI をアプリ経由で操作させる（MCP がアプリにつながる）・反映の前に利用者に見せる設定。

## 追補（2026-11-27）＝⑧-1 の実装

- **取引の道**：アプリの `src-tauri/src/edit.rs`。画面の取引は `mv_ops::Ops` の `applyTransaction` をそのまま呼ぶ（引数の形の検査・形と中身の検査・保存まで AI と同じ）。
  - 版が違う（`conflict`）＝版を外して同じ操作をもう1回だけ当て直す（結果に `reapplied: true`・画面は「当て直しました」と知らせる）。
  - 錠（`locked`）＝100 ミリ秒ごとに見直して最大2秒待つ。外れなければ断る。
  - 検査に問題が残る＝最初の問題を添えて断る（何も変えていない）。
  - 保存したらプレビューの糸へ「すぐ読み直す」（`Cmd::Reload`）。⚠️ 更新時刻だけで見ると同じ秒の中の保存を取りこぼすので、読み直しは時刻を見ずに行う。
- **試し**：掴んでいる途中は `Cmd::Trial(ops)`＝糸が開いている動画の写しに当てて描くだけ（保存しない）。外の変更を読み直したときも試しを当て直す。離したら1つの取引で保存し、断られたら試しをやめる。
- **`splitLayer`**：`mv-operations.json` と `mv-ops` の `tx.rs`（写しは元と同じ中身で ID だけ新しい・元の1つ上）。
- **画面**：`src/edit/`（`layerOps.ts`＝操作→取引の中身・`timelineMath.ts`＝時刻と位置・吸着・`editKeys.ts`＝キー・`Timeline.tsx`・`useEditor.ts`・`layout.ts`＋`Splitter.tsx`＝欄の大きさを `localStorage` に覚える）。
  - 終わりは含まない（`outFrame`）ので、`]`・`Alt+]` は今の時刻のコマを**最後に見えるコマ**にする（AE と同じ見え方＝`outFrame = 今の時刻 + 1`）。分割は今の時刻のコマから写しが始まる。
  - 錠のかかったレイヤーは、掴んでもキーでも動かさない・消さない。
  - 帯は見えている行だけ描く（上下に 6 行の余裕）。
  - **掴んでいる途中は帯も試しの位置に描く**（プレビューだけが動いて帯が止まって見えた＝実機で見つけた）。離してから読み直しが届くまでも離した位置のまま・断られたら元の位置へ戻す。
  - 選んでいるものの1つを押しても、押した瞬間には選択を縮めない（そのまままとめて動かせる）。動かさずに離したら、それだけを選び直す（AE の型）。
- **実機で確かめたこと（2026-11-27・開発版・CDP で操作）**：掴んでいる間はプレビューが試しを描き `project.json` は変わらない／離すと保存され、すぐ読み直される／帯が掴んだまま動く／選んで今の時刻を目盛りで動かし `Ctrl+Shift+D` で分割（写しが上・素材の時刻はそのまま）。
- ⑧-2（値の欄とキーフレームを打つ）・⑧-3（プレビューで掴む・素材の一覧から置く・取り込みの「利用者」の区別）は未着手。左の素材の一覧と右の値の欄は、⑧-1 では読むだけ（素材の名前・選んだレイヤーの名前と範囲）。

## 追補（2026-11-27）＝⑧-2 の実装

- **今の時刻の値は Rust に求めてもらう**（`edit_eval`＝`mv_core::eval::value_at`＝描画の核と同じ計算）。画面で補間を書き写さない。
  求める場所は `edit.rs` の `ANIM_PATHS` と画面の `props.ts` の `ANIM_PATHS`（同じ並び＝検査で突き合わせる）。式で動く値は求めない（画面では直せない＝「（式）」と出す）。
  求めた値は「どのレイヤー・どの時刻の値か」と一緒に持つ＝時刻を動かした直後に前の時刻の値を出さない（届くまでは直せない）。
- **値の欄**（`PropsPanel.tsx`・`NumberScrub.tsx`・`props.ts`）：変形（アンカー・位置・大きさ〔%〕・回転〔°〕・不透明度〔%・0〜100 に収める〕）・描画モード／文字（文・大きさ・色）／単色（色・幅・高さ）／図形（四角は大きさと角の丸み・楕円は大きさ・塗り）。
  数は左右に掴む（`Shift` 10 倍・`Ctrl` 1/10）・押して離すと打ち込み・`Enter` 確定・`Esc` 取り消し。錠のかかったレイヤーは見るだけ。
- **キーフレームを打つ**：ストップウォッチ（入れる＝今の時刻に今の値のキーを1つ・外す＝今の時刻の値の固定値）／キーフレームの値を変える＝今の時刻にキーを打つ（同じ時刻にあれば値だけ置き換え・補間はそのまま・無ければ直線）／◀◆▶（◆の最後の1つを消すとその値の固定値＝キーの無いキーフレームは形として置けない）。
- **レイヤーをずらすとキーも一緒にずらす**（キーの frame はコンポジションの時刻なので、ずらさないと動きだけ元の時刻に残る＝AE の型）。`[` `]`・消して詰める・詰めるも同じ（`shiftPatch` が全部を通る）。分割と端を切るはキーを動かさない。
- 帯の下にキーのある時刻の◆（掴んで動かすのは γ0.2）。掴んでいる途中の帯の見え方は JSON Merge Patch で当てる（◆も一緒に動く）。
- **実機で確かめたこと（2026-11-27・開発版＋CDP）**：位置を掴んで動かすと途中も値が追い、離すと保存／ストップウォッチでキー・30 フレーム先で値を変えるとキーが2つ（帯の下に◆2つ）／間の時刻（15）は直線の中間（Rust が求めた値）。

## 追補（2026-11-27）＝⑧-3 の実装（これで段階⑧は全部）

- **枠は描画の核が求める**：`mv-render` の `layer_quads`（描くときと同じ `layer_content`＝中身の大きさと変形で四隅・見えるかとソロは描画と同じ `shown_layers`）。プレビューの糸が窓へ写すときと同じ `present::fit` で窓の画素へ写して返す（`preview_bounds`）。⚠️ 中身は縁をなめらかにする余白を持つので、枠は描いた絵の外枠（1画素ほど広いことがある）。⚠️ 保存の直後に頼まれても古い枠を返さないよう、読み直しのあとに答える。
- **プレビューで掴む**（`PreviewOverlay.tsx`・`overlay.ts`）：押した所のいちばん手前（錠は飛ばす・何も無ければ選択を外す）・選んだものの枠と四隅を描く・掴んで位置を動かす（欄の画素×画素比÷倍率＝コンポジションの画素・`Shift` で縦か横の大きいほうだけ・キーフレームなら今の時刻のキー）・再生中は出さない。掴んだときの位置は Rust に求めてもらう（`edit_eval`）。
  - ⚠️ 親（`parentId`）の変形は描画の核がまだ当てていないので、位置の差はコンポジションの画素のまま足す（親を描くようになったら、ここも親の逆変換を通す）。
- **素材の一覧**（`AssetsPanel.tsx`）：種類・大きさ・長さ（無ければコマ数）・透過・指紋の有無。「取り込む…」は利用者が選んだファイルを写して取り込む（連番は γ0.1 では AI の口から）。タイムラインへ運ぶと落とした時刻からいちばん手前に置く（落とす所を線で見せる・Pointer Events）。「置く」は今の時刻に置く。
- **取り込みの「利用者」**（決定2）：アプリの操作口は `Ops::for_user`＝利用者が選んだ素材は許したフォルダの外でも取り込める。AI の口（`Ops::new`＝MCP・コマンド）は今までどおり。書き出しの許しは利用者の口でも緩めない。
- **`addLayer` の既定**：`inFrame` を書けばそこから始まり、素材の時刻 0（`startFrame`）もそこ・終わりは素材の長さの分だけ後（コンポジションの終わりで止める・終わりより後に始めたら素材の長さだけ）。操作の一覧の説明も同じ。
- **実機で確かめたこと（2026-11-27・開発版＋CDP）**：プレビューの真ん中を押すと手前の青が選ばれ枠が出る／掴んで 60×30 動かすと枠が追い、位置が 320,180 → 352.9,196.5（欄の倍率どおり）・離したあと Rust が求め直した枠も同じ所／「取り込む…」で本物のファイルを選ぶ窓から、許したフォルダの外の PNG を取り込めた（写して指紋あり）／素材をタイムラインの 60 フレームへ運ぶと、そこから終わりまでの画像のレイヤーがいちばん手前にできた。
