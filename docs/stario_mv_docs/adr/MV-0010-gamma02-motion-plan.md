# MV-0010: γ0.2（動き）の段階と、親子付け・ヌルの約束

- **状態**: Accepted（2026-11-27・利用者判断＝4点ともおすすめどおり）
- **日付**: 2026-11-27
- **関連**: ADR-0074 決定6（版の割り振り）／MV-0001（形＝`parentId`・`null`・`precomp`・`timeRemap`・`threeD`・`camera` の入れ物）／MV-0003（描画の約束＝AE と同じ変形の順）／MV-0008（編集画面）／MV-0009（取引と履歴）

## コンテキスト

γ0.1（土台）がそろった（段階①〜⑨・#1553〜#1570）。γ0.2 は「動き」＝モーショングラフィックスを作れる版。
ADR-0074 の表の中身：全数値のキーフレーム・イージングのグラフ・動きの道筋・親子付け／ヌル・レイヤー＋キーフレームの画面・入れ子・速度変更／タイムリマップ・モーションブラー・動きのプリセット。

⚠️ **食い違い**：正典の schema（`threeD`・`camera`）と2段目の検査は、2.5D（奥行き・カメラ）を「γ0.2 から」と書いているが、ADR-0074 の表には無い。

## 決定

### 決定1：描画の核から作り、画面はそのあと（利用者判断 2026-11-27）

| 段階 | 中身 |
|---|---|
| ① | 親子付け・ヌル（描画の核に親の変形・ヌル・見た目を保って親を付ける操作・画面で親を選ぶ） |
| ② | 入れ子（`precomp` のレイヤーを描く・入れ子の中の時刻） |
| ③ | 速度変更・タイムリマップ（映像・入れ子の時刻） |
| ④ | モーションブラー（決定4） |
| ⑤ | レイヤー＋キーフレームの画面（全数値のキーフレーム・キーを掴んで動かす・補間の切り替え） |
| ⑥ | イージングのグラフ（決定3） |
| ⑦ | 動きの道筋（プレビューに軌跡と空間のハンドル）＋拡大・回転の取っ手（MV-0008 で後回しにした分） |
| ⑧ | 動きのプリセット（保存と適用） |
| ⑨ | 2.5D（決定2） |

- 先に外部 AI から動きを作って書き出せるようにし（①〜④）、画面で作り込むのはそのあと（⑤〜⑧）。
- 段階ごとに、必要なら ADR（MV-0011〜）を足してから書く。

### 決定2：2.5D は γ0.2 の最後に入れる（利用者判断 2026-11-27）

- AE の基本だけ＝奥行き（z）・X/Y の回転・カメラ。**光と影は入れない**。
- ADR-0074 の表に追補する（schema と検査の「γ0.2」はそのまま正しくなる）。

### 決定3：イージングのグラフは値と速さの両方（利用者判断 2026-11-27）

- AE と同じく切り替えて使う。速さのグラフで「ゆっくり始まり・止まる」、値のグラフで行き過ぎて戻る動きを作る。
- 書くのは今の形（キーの `easeOut`・`easeIn`＝cubic-bezier のハンドル）。速さのグラフはその見せ方の1つ（形は増やさない）。

### 決定4：モーションブラーは AE と同じ（利用者判断 2026-11-27）

- レイヤーごとのスイッチと、コンポジションのスイッチの**両方が入ったときだけ**かかる。シャッター角 180°・サンプル 16。
- プレビューと書き出しは同じ計算（描画の核で1コマの中の時刻を重ねる）。
- 形に足すもの（レイヤーのスイッチ・コンポジションの設定）は段階④の ADR で決める。

### 決定5：親子付けとヌルの約束（段階①・AE の型）

- **親の変形を子に掛ける**：子のレイヤーの座標 → 子の変形 → 親の変形 → …（親の親まで）→ コンポジションの座標。
  親の**不透明度は引き継がない**（AE と同じ）。親が見える範囲の外でも、表示を切っていても、変形は効く。
- **ヌル**：描かない（書き出しにも出ない）。親にするための入れ物。画面では 100×100 の枠で見せ、選べる・掴める（アンカーの既定は (0,0)＝AE のヌルと同じ）。
- 親は同じコンポジションのレイヤー。自分・循環は検査で断る（今の2段目の検査のまま）。
- **見た目を保って親を付ける**（AE で親を選んだときと同じ）：取引の編集 `setParent` を足す。今の時刻で、子の変形を「新しい親の逆の変形 × 今の見た目」に直してから親を付ける（外すときは今の見た目へ戻す）。
  - 子の位置・大きさ・回転がキーフレームのときは、見た目を保てない（時刻ごとに違う）＝**見た目を保たずに付けて、そう知らせる**（AE も同じ扱い）。
  - 親の大きさが縦横で違い、さらに回転していると、子の見た目は傾き（ゆがみ）なしには保てない＝近い形にして、そう知らせる。
  - `updateLayer` で `parentId` だけを変えるのは、見た目を保たない付け方（AI がわかって使う）。
- **プレビューで掴んで動かす**（MV-0008 決定6）は、親があれば親の逆の変形（向きと大きさ）を通して位置の差にする。

## 結果・影響

- ADR-0074 決定6 の表に追補（γ0.2 に 2.5D）。
- 段階①：`mv-render`（親の変形・ヌル）・`mv-core`（検査の「まだ描けない」から親子付けとヌルを外す）・`mv-ops`（`setParent`）・操作の一覧・画面（タイムラインの名前の列に親を選ぶ欄・ヌルの枠・掴むときの逆の変形）。

## 未解決の論点

- ヌルを画面から足す入口（新しいレイヤーを足す画面は γ0.1 に無い）＝段階①では AI の口と、画面の「ヌルを足す」1つで始める。
- 2.5D の範囲の細部（被写界深度・カメラの種類）は段階⑨の ADR で。

## 追補（2026-11-27）＝段階①（親子付け・ヌル）の実装

- **描画の核**：`mv_core::eval::world_matrix`（子 → 親 → 親の親…・不透明度は掛けない・循環は検査で断るのでここは数えて抜けるだけ）を、描くときと枠を求めるとき（`layer_quads`）の両方で使う。ヌルは描かない（不透明度に関係なく）・枠は 100×100 を親まで掛けて返す。枠に「親の向きと大きさ」（`parentLinear`）を添える。
- **検査**：「まだ描けない」から親子付けとヌルを外した（自分・見つからない・循環の検査はそのまま）。
- **`setParent`**（取引の編集・操作の一覧）：既定は見た目を保つ＝今の時刻で `新しい親の逆 × 今の見た目` を位置・大きさ・回転に分け直す（アンカーはそのまま）。位置・大きさ・回転・アンカーのどれかがキーフレームか式なら保たずに付けて知らせる。ゆがむ（親が縦横別の大きさで回転）ときは近い形にして知らせる。自分・循環・別のコンポジションは断る。`keepAppearance: false`＝保たない。
- **画面**：タイムラインの名前の列に「親」（自分と子孫は出さない・付け替えは今の時刻で見た目を保つ）・帯の「ヌルを足す」（いちばん手前）・ヌルの帯は点線。プレビューで親のある子を掴むと、位置の差は親の向きと大きさの逆を通す。
- **反映の知らせを画面に出す**：取引の `warnings`（見た目を保てなかった など）をタイムラインの帯に出す。⚠️ 実機で、キーフレームのレイヤーに親を付けたら**黙って画面の外へずれた**ので足した。
- **実機で確かめたこと（2026-11-27・開発版＋CDP）**：「ヌルを足す」→ 赤の親をヌルに → プレビューでヌルを 80 画素動かすと赤の枠も 80 画素動く／動かない緑の親をヌルにすると、枠は付ける前とまったく同じ（見た目を保つ）・知らせは出ない。
