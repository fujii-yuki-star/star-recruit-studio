# MV-0003: 描画の核の約束（時刻の値・座標・合成・文字）

- **状態**: Accepted（2026-11-26・γ0.1 の段階③。業界の型＝After Effects の約束に合わせた技術の決定）
- **日付**: 2026-11-26
- **関連**: MV-0001（プロジェクトの形）・MV-0002（プレビューもネイティブで描く）・ADR-0074 決定2

## コンテキスト

γ0.1 の段階③で、ある時刻の1コマを描く核（`crates/mv-core` の `eval`・`crates/mv-render`）を作った。
外部 AI もこの約束どおりに値を書くので、**曖昧さを残さない**（座標の原点・補間の式・色の扱い）。
迷ったところは**業界の型（After Effects）**に合わせた（α の ADR-0034 と同じ考え方＝独自の約束を発明しない）。

## 決定

### 決定1：時刻の値（`mv-core::eval`）

- 最初のキーより前＝最初のキーの値／最後のキーより後＝最後のキーの値。
- 区間の進み方は**区間の始まりのキーの `interpolation`** で決まる：`hold`＝次のキーまで止める／`linear`＝まっすぐ／`bezier`＝ CSS の cubic-bezier と同じ式（`P1`＝始まりのキーの `easeOut`、`P2`＝終わりのキーの `easeIn`。無ければ直線と同じハンドル `[1/3,1/3]`・`[2/3,2/3]`）。
- 位置の動きの道筋（`spatialOut`・`spatialIn`）があれば3次ベジェの道筋を通り、**道のりで等速**に進む（AE と同じ）。進み具合（上の補間）は道のりの割合に当てる。
- 値は小数のフレームでも求められる（モーションブラー・タイムリマップのため）。

### 決定2：変形の順番

- レイヤーの座標 → コンポジションの座標＝ **T(位置)・R(回転・時計回り)・S(縦横の大きさ)・T(−アンカー)**（AE と同じ）。
- 不透明度は 0〜1 に丸める。

### 決定3：レイヤーの中身の原点（AE と同じ）

| 種類 | レイヤーの (0,0) |
|---|---|
| 単色・画像 | 中身の**左上** |
| 図形（四角・楕円） | 中身の**中心** |
| 図形（自由な形） | 頂点の座標がそのままレイヤーの座標 |
| 文字 | **1行目のベースライン**の、揃えの点（左揃え＝行の左端・中央＝行の中央・右＝行の右端） |

### 決定4：合成

- レイヤーの中身は CPU で画素にする（図形＝tiny-skia・文字＝cosmic-text・画像＝image）。拡大されても粗くならないよう、大きさの倍率ぶん細かく描く（1〜8 倍）。
- GPU で、**末尾のレイヤーから順に**1枚ずつ混ぜる（先頭が最前面＝MV-0001 決定6）。合成は 16 ビット浮動小数。
- 作業の色空間が `linear` のときは、中身の sRGB を linear に直してから混ぜ、最後に sRGB へ戻す（`srgb` のときはそのまま）。
- 描画モードは W3C（Compositing and Blending Level 1）の式。⚠️ `add` だけは上限なしの足し算（16 ビット浮動小数の中では 1 を超えてよい＝発光を重ねても白く潰れない。書き出しで丸める）。
- 書き出しの1コマ＝乗算していない sRGB の RGBA8。

### 決定5：描けないものは黙って描かない

- 指定のフォントが読み込んだフォントに無い → **知らせる**（別のフォントで描かない）。
- 文字は**読み込んだフォントだけ**を使う（パソコンに入っているフォントは見ない＝どのパソコンでも同じ絵）。今は α の同梱フォント（`public/fonts`）を参照する（`apps/stario-mv/COPIED_FROM.md`）。
- 描画の核がまだ描けない項目（文字の縁取り・字の間など）は、2段目の検査（`NOT_YET`）でも知らせる＝描くときに黙って無視しない。
- 映像のレイヤーは素材の取り込み（γ0.1 の段階⑥）から。それまでは描こうとすると知らせる。
  - ⚠️ **追補（2026-11-26・MV-0006）**：映像・連番・SVG を描けるようになった（描き方は MV-0006 決定4）。

## 結果・影響

- 検査：`mv-core` の `eval` に 11 本、`mv-render` に 12 本（位置とアンカー・重なりの順・見える範囲・不透明度×色空間・中間色の往復・描画モード6種・図形の原点・キーフレーム・文字と無いフォント・画像・まだ描けないレイヤー・見本の正解画像）。
- 正解画像（golden）＝`crates/mv-render/tests/golden/`。CI はソフトウェアの GPU で描くので、画素の値で ±3・ずれた画素 0.5% までを同じとみなす。作り直しは `UPDATE_GOLDEN=1`。

## 未解決の論点

- 縮小したときのちらつき（ミップマップ）・モーションブラー・2.5D（γ0.2）。
- 文字の縁取り・字の間・縦書き・ルビ・1文字ずつの動き（γ0.4）。
- 合成の速さ（1レイヤー＝画面全体を1回描く方式。上位 PC で測って必要なら最適化）。
