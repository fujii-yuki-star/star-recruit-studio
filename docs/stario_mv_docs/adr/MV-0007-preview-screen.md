# MV-0007: プレビュー画面（開く・再生・コマ送り・外の変更を映す）

- **状態**: Accepted（2026-11-26・γ0.1 の段階⑦）
- **日付**: 2026-11-26
- **関連**: MV-0002（ネイティブの窓に描き、画面を重ねる）・MV-0003（描画の核）・MV-0005（外部 AI の操作口）・MV-0006（素材）・ADR-0074 決定3（C-3 アプリが開いていれば即座に映る）

## コンテキスト

段階⑥までで、外部 AI が動画を組み立てて書き出せるようになった。段階⑦では、アプリの窓でその動画を**見て確かめる**。
編集の操作は段階⑧、元に戻す・自動保存は段階⑨で扱う。
方式は MV-0002 で決めた：描画の核（`mv-render`）で窓に直接描き、透明にした画面（React）を上に重ねる。

## 決定

### 決定1：描くのは書き出しと同じ核、窓へは「出来た絵を写すだけ」

- 描画の核に `render_texture` を足す（書き出しの `render` は、これに GPU からの読み戻しを足したもの）。プレビューは出来た絵を GPU に置いたまま、窓のプレビューの欄へ写す（`mv-render::present`）。
  - ⚠️ 写す段では色も形も変えない。欄の大きさに合わせて、縦横の比を保って縮める（余りは帯）。
  - 窓の画素の形は sRGB の印が付かないもの（`Bgra8Unorm` など）を選ぶ。描画の核の出力は、すでに sRGB の値を持っているため（二重に変換しない）。
- GPU は窓に描ける GPU を選び、描画の核と窓の両方で同じものを使う（`Gpu::for_surface`）。

### 決定2：描くのは専用の1本の糸、画面は命令を送るだけ

- プレビューの糸が持つもの：窓・GPU・描画の核・開いている動画。
- 画面から送る命令：開く・欄の位置・再生・止める・コマへ移る・コマ送り・コンポジションの切り替え。
- 糸からは今の状態（コマ・再生中か・実際のコマの速さ・落としたコマの数）を画面へ知らせる。
- 欄の位置は、画面が欄の矩形（物理の画素）を測って送る。欄の大きさが変わるたびと、窓の大きさが変わるたびに送る。

### 決定3：再生は時計に合わせ、間に合わなかったコマは数えて見せる

- 再生は「再生を始めた時刻からの経過 × fps」のコマを描く。描くのが間に合わなければ、そのコマを飛ばして次に間に合うコマを描く。
  - 飛ばしたコマの数を画面に出す（MV-0002 の判断軸＝黙って間引かない）。
- 最後のコマまで来たら止める（繰り返しは段階⑧の作業範囲と一緒に）。
- 描けないコマ（まだ描けない機能・素材が無い など）は、再生を止めて理由を欄の上に出す。黙って飛ばさない。

### 決定4：外の変更をすぐ映す（C-3 の読む側）

- 開いている `project.json` が変わったら（外部 AI の取引・別の道具）、読み直して描き直す。0.5 秒ごとに更新の時刻を見る。
- 読み直せない形になっていたら、前に描けていた状態のまま理由を出す（壊れたものを描かない）。
- ⚠️ アプリが**書く**側（画面と AI の変更を1本の列に並べる）は段階⑧⑨で扱う。段階⑦のアプリは読むだけ。

### 決定5：起動のしかたと、フォント・FFmpeg の場所

- 「動画を開く」でフォルダを選ぶ。起動の引数 `--project <フォルダ>` でも開ける（外部 AI・確認の道具から開くため）。
- フォントと FFmpeg の場所は外部 AI の操作口と同じ設定（`ai-settings.json` の `fontDirs`・`ffmpeg`）を使う。無ければ、次の順に探す。
  1. 環境変数
  2. アプリに同梱したもの
  3. 開発中は α の同梱物（`COPIED_FROM.md`）
- 操作：Space＝再生／止める、←・→（PageUp・PageDown も）＝1コマ、Home・End＝最初・最後。AE と Premiere の型に合わせる。

### 決定6：プレビューの音（追補・2026-11-26）

- **混ぜ方は書き出しと同じ関数**（`mv-export` の音の filter を1か所にまとめ、書き出しとプレビューの両方が通す）。
  - 違うのは出し方だけ。書き出しは AAC へ、プレビューは生の音で機器へ流す。機器の速さが 48kHz でなければ、混ぜたあとに機器の速さへ変える。
- 再生を押したとき、コンポジション全体を一度に混ぜる。動画が変わる（開く・外の変更・コンポジションの切り替え）までは混ぜた結果を使い回す。
- **再生の時計は「鳴らした量」**（cpal で既定の出力の機器へ流す）。絵を音に合わせる（音は飛ばさない・絵は間に合わなければ飛ばして数える）。
- 次のときは絵だけで再生する。どれも、その旨を知らせる（黙って音を消さない）。
  - 音を消すボタンで消したとき
  - 音のレイヤーが無いとき
  - 機器が無いとき
  - 混ぜられないとき
  - 機器が途中で止まったとき（音の時計が 0.5 秒進まなければ、時計へ切り替える）

## 結果・影響

- `mv-render` に `render_texture`・`Gpu::for_surface`・`present` が増える。書き出しの絵は変わらない（正解画像の検査で確かめる）。
- アプリ（`src-tauri`）が `mv-ops`・`mv-export` を使う（設定と FFmpeg の探し方を共有する）。
- 窓を透明にした（`transparent: true`）。
