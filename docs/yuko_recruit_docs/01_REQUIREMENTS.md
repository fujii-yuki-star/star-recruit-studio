# ゆうこ採用ムービーメーカー 要件定義書 v0.1

## 1. 概要

### 1.1 プロダクト名

**すたりお（stario）**

正式名称（2026-06-17 決定）。会社名 star にあやかった呼称。マスコット／ナレーターの「ゆうこ」は継続使用する。
旧称：ゆうこ採用ムービーメーカー（採用専用時代の名称）。英語表記の別名：Stario / Yuko Recruit Studio（リポジトリ名は当面据え置き＝ADR-0011 未解決#9）。

### 1.2 目的

本ソフトは、**採用・会社紹介動画に加え、社内発表など一般用途の動画**を簡単に作成できるようにするPC向け動画制作支援ソフトである。用途は **採用（recruit）／一般・社内発表（general）の2系統**で、最初に種類を選んで以降の入力・AIプロンプトが分岐する（`videoKind`・ADR-0011）。

利用者が自分でナレーションを録音したり、本格的な動画編集ソフトを操作したりしなくても、マスコット「ゆうこ」がナレーションを担当する動画を作成できることを目的とする。

### 1.3 基本コンセプト

本ソフトは、AIが動画そのものを生成するツールではない。

AIは以下を担当する。

- 動画構成案の作成
- パート構成の作成
- シーン構成の作成
- 使用素材案の選定
- テンプレート選択案の作成
- ゆうこのナレーション生成
- 字幕文生成
- 表現チェック（採用向け等。用途に応じた注意喚起）

動画の実生成は、ソフトウェアがテンプレート定義に基づいて、画像・動画・テキスト・ゆうこ素材・音声・BGM・装飾アセットを機械的に配置・合成することで行う。

### 1.4 一言での説明

> 写真・動画と、会社情報や発表内容を入力すると、AIが構成案とゆうこのセリフを作成し、ソフトがテンプレートに沿って自動で動画を組み立て、プレビューとMP4出力ができるPC向け動画制作支援ツール「すたりお（stario）」。採用・会社紹介に加え、社内発表など一般動画も作れる（ADR-0011）。

## 2. 想定ユーザー

### 2.1 主利用者

- 採用担当者
- 人事担当者
- 会社説明会資料を作成する担当者
- 採用広報担当者

### 2.2 利用者の前提

主利用者は技術者ではないことを前提とする。

そのため、通常画面では以下のような技術用語を極力表示しない。

- JSON
- レンダリング
- アセット
- スロット
- templateId
- assetId
- FFmpeg
- Provider
- LLM
- APIレスポンス

ユーザー向けには、以下のような言葉に置き換える。

| 技術者向け表現 | ユーザー向け表現 |
|---|---|
| レンダリング | 動画を書き出す |
| テンプレート | 見た目パターン |
| アセット | 素材 |
| バリデーション | 内容チェック |
| トランジション | 画面切り替え |
| ナレーション生成 | ゆうこの声を作る |
| プレビュー | 仕上がり確認 |
| エクスポート | 保存する |
| スロット | 表示場所 |

### 2.3 操作方針

通常操作は、ウィザード形式・シーンカード形式を中心とする。

ユーザーは座標調整や複雑なタイムライン編集を行わず、以下の操作だけで動画を作れることを目指す。

1. 動画の目的を選ぶ
2. 会社情報を入力する
3. 写真・動画を追加する
4. ゆうこに動画案を作ってもらう
5. 出てきた構成案を確認する
6. 必要なセリフや素材を修正する
7. プレビューする
8. MP4として保存する

## 3. システムの基本方針

### 3.1 AIとソフトの役割分担

| 担当 | 役割 |
|---|---|
| AI | 動画構成案、パート構成、シーン構成、ナレーション、字幕、素材割り当て案、表現チェック |
| ソフト | テンプレート選択、素材配置、音声生成、動画合成、プレビュー、MP4出力 |
| ユーザー | 構成案確認、セリフ修正、素材差し替え、見た目パターン選択、最終確認 |
| ゆうこ | 会社紹介役、採用動画のナレーション役、画面内マスコット |

### 3.2 AIは動画を直接生成しない

本ソフトでは、AI動画生成モデルによる映像生成は初期対象外とする。

AIは動画の設計情報をJSON形式で返す。

ソフトはそのJSONを検証し、テンプレート・素材・音声・BGM・装飾アセットを用いて動画を自動構築する。

### 3.3 テンプレート駆動の動画生成

動画の見た目は、事前定義されたテンプレートによって決定する。

各テンプレートには以下を定義する。

- 画像・動画の表示領域
- テキスト表示領域
- 字幕表示領域
- ゆうこ表示領域
- ロゴ表示領域
- 装飾アセット配置
- 背景色・背景画像
- 初期表示秒数
- 文字サイズ
- 文字数制限
- 画面切り替え効果

ユーザーが毎回文字位置や画像位置を調整しなくても、テンプレートに沿って自動配置されることを重視する。

### 3.4 かんたん操作とこだわり編集の両立

通常は簡単に操作できることを最優先とする。

一方で、生成された動画案を細かく調整したいユーザー向けに、こだわり編集モードを用意する。

こだわり編集モードでは以下を調整可能とする。

- シーン順序
- シーン追加・削除・複製
- シーン表示秒数
- 素材差し替え
- 画像表示範囲
- 動画開始秒・終了秒
- 動画内音声ON/OFF
- ゆうこ素材
- 字幕
- BGM音量
- ナレーション音量
- 画面切り替え効果

ただし、Premiere ProやDaVinci Resolveのような本格動画編集ソフトは目指さない。

## 4. 動画仕様

### 4.1 初期対応

| 項目 | 初期仕様 |
|---|---|
| 画面比率 | 16:9 |
| 解像度 | 1920×1080 |
| 出力形式 | MP4 |
| フレームレート | 30fps |
| 用途 | 採用サイト、会社説明会、YouTube、社内共有 |

### 4.2 将来対応

- 9:16 縦動画
- 1:1 正方形動画
- SNSショート動画向け出力
- 1080×1920
- 1080×1080

### 4.3 動画尺

初期MVPでは最大5分程度を想定する。

将来的には最大10分程度の会社紹介・採用説明動画の作成も対象とする。

長尺動画では、動画全体を「パート」と「シーン」に分割して管理する。

例：

```text
動画
  ├─ パート1：オープニング
  │   ├─ シーン1
  │   └─ シーン2
  ├─ パート2：会社概要
  │   ├─ シーン3
  │   └─ シーン4
  ├─ パート3：仕事内容
  │   ├─ シーン5
  │   └─ シーン6
  └─ パート4：応募メッセージ
      ├─ シーン7
      └─ シーン8
```

### 4.4 長尺動画対応方針

10分程度の動画まで将来対応できるよう、以下の設計を初期段階から考慮する。

- パート単位での管理
- パート単位でのプレビュー
- シーン単位での音声生成
- 修正したシーンのみ音声再生成
- 全体尺の自動見積もり
- 長すぎる場合の警告表示
- 全体プレビューだけでなく、シーン単位・パート単位プレビューに対応

## 5. 素材管理要件

### 5.1 対応素材

MVPで対応する素材は以下とする。

| 種別 | 対応形式候補 |
|---|---|
| 画像 | PNG / JPG / JPEG / WEBP |
| 動画 | MP4 |
| BGM | MP3 / WAV |
| ゆうこ素材 | PNG推奨 |
| 装飾アセット | PNG / SVG候補 |

将来的には以下も検討する。

- MOV
- WEBM
- OGG
- M4A
- PDF
- PowerPoint
- Word
- Excel
- 採用ページURL読み込み

### 5.2 素材カテゴリ

素材は用途ごとに分類する。

| カテゴリ | 用途 |
|---|---|
| 動画素材 | 実際のシーンに使う動画 |
| 画像素材 | 写真・会社外観・社員写真など |
| ゆうこ素材 | 立ち絵・表情差分 |
| BGM素材 | 背景音楽 |
| 効果音素材 | 将来対応 |
| 装飾アセット | 半透明パネル・帯・フレーム |
| ブランド素材 | ロゴ・QRコード・会社カラー背景 |
| テンプレート | 見た目パターン |

### 5.3 素材情報

各素材には以下の情報を持たせる。

- 素材ID
- ファイル名
- ファイルパス
- 素材種別
- サムネイル
- 説明文
- タグ
- 使用シーン
- 公開チェック済みフラグ
- AI解析結果

例：

```json
{
  "assetId": "asset_office_01",
  "type": "image",
  "filePath": "assets/office_01.jpg",
  "tags": ["office", "workplace"],
  "description": "若手社員が作業しているオフィス写真"
}
```

### 5.4 動画素材の設定

動画素材をシーンで使用する場合、以下を設定できること。

- 開始秒
- 終了秒
- 動画内音声を使用するか
- 動画内音声の音量
- フェードイン
- フェードアウト

動画内音声は、シーン単位でON/OFFを選択可能とする。

採用動画では、基本的にゆうこのナレーションとBGMを優先するが、素材動画の音声を残したい場面にも対応できるようにする。

## 6. AI機能要件

### 6.1 AI利用方針

外部AI APIの利用を前提に設計する。

ただし、将来的にローカルAIや他のAI Providerへ切り替えられるよう、AI Providerを抽象化する。

初期候補：

- OpenAI API
- Claude API
- Gemini API

ローカル候補：

- Ollama + Qwen系軽量モデル

### 6.2 AIに送信する情報

AIには以下の情報を送信できる。

- 会社名
- 業種
- 事業内容
- 募集職種
- 採用対象
- 会社の強み
- 職場の雰囲気
- 求める人物像
- 動画の目的
- 希望尺
- トーン
- 素材説明
- 画像サムネイル
- 動画代表フレーム
- 利用可能な見た目パターン一覧

画像サムネイルは送信可能とする。

理由は、AIの素材理解精度が上がることで、生成される動画構成案・素材割り当て案の品質向上が期待できるため。

### 6.3 送信前確認

外部AIに情報を送信する場合は、送信前確認画面を表示する。

表示例：

```text
AIが動画案を作るために、以下の情報を送信します。

・会社情報
・動画の目的
・素材の説明
・画像サムネイル
・動画の代表フレーム

元の動画ファイルは送信しません。
送信してもよろしいですか？
```

### 6.4 AIが生成する内容

AIは以下を生成する。

- 動画タイトル案
- パート構成
- シーン構成
- 各シーンのテンプレート案
- 各シーンの使用素材案
- ゆうこのセリフ
- 字幕文
- タイトル文
- 本文テキスト
- ゆうこ素材・表情候補
- BGM雰囲気候補
- 採用向け表現チェック結果

### 6.5 AI出力形式

AIは動画構成JSONを返す。

例：

```json
{
  "schemaVersion": "1.0",
  "video": {
    "title": "会社紹介動画",
    "purpose": "new_graduate_recruit",
    "aspectRatio": "16:9",
    "resolution": "1920x1080",
    "totalDurationSec": 180
  },
  "parts": [
    {
      "id": "part_001",
      "title": "オープニング",
      "scenes": [
        {
          "id": "scene_001",
          "templateId": "opening_yuko_right_v1",
          "durationSec": 8,
          "assetRefs": {
            "background": "asset_company_entrance_01"
          },
          "character": {
            "characterId": "yuko",
            "poseId": "yuko_smile_01"
          },
          "texts": {
            "title": "株式会社〇〇へようこそ",
            "main": "若手が活躍できる職場です",
            "subtitle": "今日は株式会社〇〇の魅力を紹介します。"
          },
          "narration": {
            "text": "こんにちは、ゆうこです。今日は株式会社〇〇の魅力を紹介します。",
            "voice": "yuko_default",
            "speed": 1.0
          },
          "transition": {
            "in": "fade",
            "out": "fade"
          }
        }
      ]
    }
  ]
}
```

### 6.6 AI JSONの検証

AIが返したJSONは、動画化前に必ず検証する。

検証項目：

- JSON形式が正しいか
- schemaVersionが対応範囲か
- 存在するtemplateIdか
- 存在するassetIdか
- 必須テキストが存在するか
- durationSecが異常値でないか
- 文字数がテンプレート上限を超えていないか
- ゆうこ素材IDが存在するか
- シーン数が極端に多すぎないか
- 合計尺が指定範囲内か

### 6.7 自動補正

AI出力に軽微な問題がある場合、ソフト側で自動補正する。

| 問題 | 補正 |
|---|---|
| 存在しないテンプレートID | 同カテゴリの既定テンプレートに置換 |
| 存在しない素材ID | 未使用素材から候補提示 |
| 秒数が短すぎる | 最小秒数に補正 |
| 秒数が長すぎる | 最大秒数に補正 |
| 文字が長すぎる | 警告＋短縮ボタン |
| ゆうこ素材がない | default_yukoに置換 |

ユーザーには技術的なエラーではなく、対応内容を分かりやすく表示する。

例：

```text
3件の項目を自動で調整しました。
1件は確認が必要です。
```

## 7. テンプレート要件

### 7.1 テンプレートの役割

テンプレートは、動画内の素材・文字・ゆうこ・装飾アセットの表示場所を定義する見た目パターンである。

ユーザー向けには「テンプレート」または「見た目パターン」と表現する。

### 7.2 初期テンプレート候補

MVPでは以下のテンプレートを用意する。

| テンプレート | 用途 |
|---|---|
| オープニング | 会社名・タイトル表示 |
| 写真紹介 | オフィス・社員・イベント紹介 |
| 動画紹介 | 会議風景・作業風景紹介 |
| ポイント紹介 | 会社の強み・制度紹介 |
| メッセージ | 求める人物像・応募メッセージ |
| クロージング | 採用ページ案内・締め |
| ゆうこなし全面写真 | 写真や映像を大きく見せたい場面 |
| 半透明パネル付き | 写真背景にテキストを載せる場面 |

### 7.3 ゆうこ表示はテンプレート依存

ゆうこは常時表示ではない。

ゆうこの表示有無、位置、大きさ、使用素材はテンプレートによって決まる。

テンプレートによって以下を定義できる。

- ゆうこを表示する
- ゆうこを表示しない
- 右下に表示
- 左下に表示
- 大きめに表示
- 小さめに表示
- お辞儀素材を使う
- 案内ポーズを使う

### 7.4 テンプレート定義

テンプレートは内部的にJSONで管理する。

レイヤー式の定義を採用し、装飾アセットや半透明パネルも扱えるようにする。

例：

      "id": "background",
      "type": "asset",
      "assetRole": "background",

      "y": 0,
      "w": 1920,
      "h": 1080

    {
      "id": "mainVisual",

    {

## 8. ゆうこ機能要件

### 8.1 ゆうこの役割

ゆうこは会社マスコットとして、採用動画内で会社紹介・ナレーションを担当する。

### 8.2 ゆうこ素材

ゆうこは静止画素材を複数持つ想定とする。

例：

- 通常
- 笑顔
- 案内
- お辞儀
- びっくり
- 考える
- 元気

各ゆうこ素材にはタグを設定する。

例：

```json
{
  "id": "yuko_smile_01",
  "name": "ゆうこ_笑顔",
  "filePath": "characters/yuko_smile.png",
  "tags": ["smile", "guide", "opening"]
}
```

### 8.3 ゆうこの声

ナレーション音声は「ゆうこの声」として設定できること。

初期設定では、ずんだもん系の音声をデフォルトとする。

将来的に以下も選択できる余地を持たせる。

- ゆっくりボイス
- VOICEVOX内の別話者
- 外部TTS
- 社内専用ボイス

### 8.4 声の調整項目

ユーザーは以下を調整できること。

| 項目 | 内容 |
|---|---|
| 声の種類 | ずんだもん、ゆっくりボイス等 |
| 話速 | 遅い / 標準 / 速い |
| 高さ | 低め / 標準 / 高め |
| 抑揚 | 控えめ / 標準 / 元気 |
| 音量 | 小 / 標準 / 大 |
| 間の長さ | 短め / 標準 / 長め |

設定はプロジェクト全体、および必要に応じてシーン単位で上書きできること。

### 8.5 音声生成

音声はシーン単位で生成する。

セリフを修正した場合、該当シーンのみ再生成できること。

## 9. BGM要件

### 9.1 標準BGM

本ソフトは標準BGMを複数同梱する。

標準BGM候補：

- 明るい
- 落ち着いた
- さわやか
- 会社紹介向け
- 若手向け
- しっとり

標準BGMは、利用規約・ライセンス上、採用動画で利用可能なもののみ同梱する。

### 9.2 ユーザー持ち込みBGM

ユーザーが任意のBGMファイルを追加できること。

対応形式候補：

- MP3
- WAV
- OGG
- M4A

### 9.3 BGM設定

BGMに対して以下を設定できること。

- BGM選択
- 音量
- ループ
- フェードイン
- フェードアウト
- 全体共通BGM
- 将来的には、複数のBGM素材を登録し、パート／場面ごとに切り替えて使い分け

MVPでは、**全体共通BGM（1プロジェクト1曲・動画全体に流す）**・音量調整・ループ対応を優先する。複数BGM素材の登録と場面ごとの使い分けは v0.2 以降（§17.1）。実装には scene へのBGM指定フィールド追加（スキーマ拡張＝ADR）が必要で、本格的なタイムライン編集には踏み込まない（§16.2）。

## 15. 非機能要件

### 15.1 対応環境

初期はWindows PCを主対象とする。

理由：

- 採用担当者の業務PC利用を想定
- Tauri等でのPCアプリ化を想定
- VOICEVOXやFFmpegとの連携を想定

### 15.2 PCスペック想定

採用担当者のPCはグラボなしの一般業務PCを想定する。

そのため、重いローカルAI推論を必須としない。

外部AI APIを利用することで、グラボなしPCでも高品質な動画構成案生成を可能にする。

### 15.3 セキュリティ・情報送信

外部AI APIへ送信する情報は、ユーザー確認後に送信する。

原則として、元動画ファイルそのものは送信せず、動画代表フレームを送信する。

画像はサムネイル化して送信可能とする。

### 15.4 ライセンス注意

以下のライセンス確認が必要。

- VOICEVOX本体
- 使用するVOICEVOX話者
- ずんだもん等のキャラクター利用規約
- ゆっくりボイスの利用条件
- 標準BGMのライセンス
- 標準装飾アセットのライセンス
- ゆうこ素材の権利
- ユーザーが持ち込む素材の権利
- 採用動画に映る人物の肖像権

### 15.5 エラー表示

採用担当者向けに、エラーは原因よりも対応方法を中心に表示する。

悪い例：

```text
Invalid templateId: photo_left_text_right_yuko_v1
```

良い例：

```text
この場面で使う見た目パターンが見つかりませんでした。
代わりに「写真紹介」の見た目を使います。
```

## 20. 現時点の結論

本ソフトは、採用担当者が非技術者であることを前提に、簡単な操作で採用動画を作成できることを重視する。

一方で、AIが返した動画構成JSONをテンプレートエンジンで機械的に動画化する構造により、開発者視点でも拡張しやすい設計とする。

重要な中核方針は以下である。

- AIは動画を直接生成しない
- AIは動画構成案を生成する
- ソフトがテンプレートに沿って動画を組み立てる
- 採用担当者にはJSONや技術用語を見せない
- 通常操作はかんたんにする
- 必要に応じてこだわり編集を用意する
- ゆうこはテンプレート内で自然に表示する
- ゆうこの声を設定・調整できる
- 標準BGMと持ち込みBGMに対応する
- 半透明パネル等の標準アセットを用意する
- ユーザー素材もテンプレート用アセットとして登録できる
- 将来的に最大10分程度の会社紹介動画にも対応する

以上。
