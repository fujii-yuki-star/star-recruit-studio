# ADR-0068: 部品の音のノイズを減らす（タイムライン形式）

- **状態**: Accepted
- **日付**: 2026-10-20
- **関連**: [`ADR-0001`](0001-rendering-parity.md)（プレビュー＝書き出し）／[`ADR-0024`](0024-non-destructive-editing-model.md)（自己完結）／[`ADR-0034`](0034-timeline-interaction-model.md)（業界の型）／[`ADR-0043`](0043-alpha-beta-scope-and-general-backlog.md) ⑤（α-8）／#1479／`src/domain/timeline/audio.ts`・`export.ts`

## コンテキスト

録った声・取材の動画の音に入る**さーっという雑音**を減らす手段が無い（どの編集ソフトにもある＝Premiere の「ノイズを軽減」・Clipchamp の「ノイズ抑制」）。
プレビューの音はブラウザ（`HTMLAudioElement`／`<video>`）が鳴らし、書き出しは FFmpeg が混ぜる。FFmpeg のノイズ除去（`afftdn`）を書き出しだけに掛けると、
**聞いた音と書き出した音が違う**（ADR-0001・ADR-0026③）。音を切り離す機能は無いので、**動画の元の音**にも効かせる必要がある（取材の動画が主な使い道）。

## 判断軸

- 業界の型＝部品ごとの切り替え（壊さない・いつでも外せる）。
- **プレビュー＝書き出し**＝同じ音を聞く。
- 自己完結（ADR-0024）＝作り置きは作り直せるものだけ。

## 検討した選択肢

| 選択肢 | 評価 |
|---|---|
| (A) **ノイズを減らした音を一度だけ作り置き（`cache/`）し、プレビューも書き出しもそれを鳴らす** | 同じファイルを聞く＝一致する。部品の切り替えだけなので元の素材は変わらない（壊さない）。**採用** |
| (B) 書き出しだけ FFmpeg で掛ける | 聞いた音と書き出した音が違う。不採用 |
| (C) ノイズを減らした音を**新しい素材**として作り、部品の音を差し替える | 動画の元の音は差し替え先が無い（音を切り離す機能が無い）・ファイルが増えて戻すと残る（ADR-0064 の発端と同じ）。不採用 |

## 決定

1. **欄**＝`TimelineClip.denoise?: boolean`（timeline schema 1.21→1.22・任意・未指定＝しない）。効くのは
   **持ち込みの音の部品**（`kind:'audio'` で `assetId` を持つ）と、**直接置いた動画の元の音**（`useOriginalAudio`）。
   同梱 BGM・読み上げ（もともと雑音が無い）・見た目パターンの差し込み口には効かない（欄を出さない）。
2. **作り置き**＝素材ごとに1つ、`cache/denoise/<素材のファイル名>.flac`（**場所は素材のパスから決まる**＝`denoisedCachePath`）。
   Rust の `ensure_denoised_audio` が FFmpeg の `afftdn=nf=-25`（強さは固定）で作る。**元より新しければ作り直さない**（素材を差し替えたら作り直す）。
   FLAC＝劣化しない・WAV より小さい。`cache/` は運ばない・作り直せる（#332 と同じ扱い＝焼き出し・複製でも作り直す）。
3. **プレビュー＝書き出し**＝どちらも作り置きを鳴らす。
   - プレビュー：音の出どころの鍵を `denoise:<素材 id>` に替える（`audioSourceKeyOfClip`）。動画の元の音は `<video>` を黙らせ、
     同じ時刻・速さで作り置きを鳴らす（`audioCuesAt` が並べる）。
   - 書き出し：作り置きの**パス**を渡す（`assetPath`＝動画の元の音と同じ渡し方・中身を文字列にしない）。書き出す前に作り置きをそろえる。
4. **画面**＝「音量」（音の部品）・「この動画の音」（動画）の欄に「ノイズを減らす」の切り替え。作っている間は「ノイズを減らした音を用意しています」。

## 結果・影響

- schema（timeline 1.22）・`11 §7.6`・`06`（選んだ部品の欄）・Rust（コマンド1つ）。
- 無音探し・文字起こし（ADR-0058）は元の素材を見る（雑音の有無で区切りが大きく変わらない・作り置きを待たない）。

## 未解決の論点

- 強さを選べるようにするか（いまは固定）＝使われ方を見てから。
- 差し込み口の動画の元の音にも効かせるか。
