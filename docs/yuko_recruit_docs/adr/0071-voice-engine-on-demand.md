# ADR-0071: 声のエンジンは使うときに起動し、しばらく使わなければ止める

- **状態**: Accepted
- **日付**: 2026-11-04
- **関連**: [ADR-0005](0005-voicevox-bundling.md)（同梱と自動起動）／[ADR-0051](0051-local-llm-primary.md)（同梱の AI＝同じ「使うときに起動・10分で止める」）／[ADR-0070](0070-export-parallel-render-windows.md)（書き出しの窓の数をメモリで決める）／[ADR-0042](0042-agent-entrypoints.md)（起動の引数）

## コンテキスト

同梱の VOICEVOX ENGINE は、ADR-0005 以来**アプリの起動と同時に**起こしていた（`lib.rs` の setup → `start_bundled_engine`）。
動いている間は**約 0.5GB**のメモリを握り続ける。声を作らない間も、書き出しの間も、起動の引数で書き出しだけを頼まれた回（ADR-0042）もそうだった。

2026-11-04 の負荷確認で、**利用者がふだん使うパソコンはメモリに余裕がない**ことが分かった（空き 0.4〜1GB 台）。
ADR-0070 の追補で書き出しの窓の数を「積んでいるメモリ」で決めるようにしたが、エンジンの 0.5GB は**使っていなくても毎回引かれていた**。

同梱の AI（ADR-0051）は最初から「使うときに起動し、10分使わなければ止める」形になっている。

## 判断軸

- 使っていないものにメモリを持たせない（書き出しの速さに直接効く）。
- 声を作るときの待ちを、利用者に見えるところで増やさない。
- 同梱の AI と同じ動き方にそろえる（2つの常駐の仕方を覚えさせない・コードの型も同じ）。

## 検討した選択肢

| 選択肢 | 評価 |
|---|---|
| (A) 使うまで起動しない（一度起動したらアプリを閉じるまで動かす） | 起動直後と書き出しだけの回は 0.5GB 浮く。声を作った後はずっと握る。 |
| (B) (A) に加え、しばらく使わなければ止める | 声を作り終えた後の編集・書き出しでも 0.5GB を返す。長く触らなかった後の最初の1回だけ起動を待つ。**採用**（利用者判断 2026-11-04） |
| (C) 今のまま起動時に起こす | 待ちは無いが、メモリの少ない環境で書き出しが遅いまま。 |
| 「省エネ状態」で待たせる | エンジンにその仕組みが無い（動いているか止まっているかの二択）。 |

## 決定

1. **アプリの起動時には起動しない。** 起動は次のどれかが起きたとき。
   - 声を作る・読み方を確かめる・読み方辞書を読む／直す（エンジンへ頼むすべての口）＝**起動して応えるまで待ってから頼む**（上限 120 秒）。
   - 声を使う画面（たたき台・場面編集・タイムライン編集・公開前チェック）を開いたとき＝**裏で起動だけしておく**（待たない）。最初の1回の待ちをほぼ隠すため。
   - 起動の引数の仕事が「用意ができたか」を尋ねたとき（`voicevox_ready`）＝起動を始めて「まだ」と答える（尋ねる側が待つ・#1204 のまま）。
2. **最後に使ってから 10 分たったら止める**（同梱の AI と同じ値・同じ純粋関数 `should_stop_idle`）。**頼みごとが走っている間は止めない**。止める判断と「使い始め」の数え上げは**同じ錠の中**で行う（数え始めた直後に止めて、その頼みが失敗する、を作らない）。
3. **上級者が接続先を設定しているときは、同梱のエンジンを起こさない**（その接続先へ頼む＝今までどおり）。
4. **エンジンが落ちていたら次に使うとき起こし直す**（持っているプロセスが終わっていたら「動いていない」と扱う）。
5. 止めても**読み方辞書は消えない**（辞書はエンジンの外＝OS 上の決まった場所にある・ADR-0037）。

## 結果・影響

- アプリを起動しただけ・書き出しだけの回は、エンジンの約 0.5GB を使わない。声を作り終えて 10 分たてば返る。
- 長く声を触らなかった後の最初の1回は、エンジンの起動（数秒〜十数秒）を待つ。声を使う画面を開いた時点で裏で起こすので、多くの場合は見えない。
- 書き出しは声を作り直さない限りエンジンを使わない＝書き出しの間に止まっても影響は無い。
- コード：`src-tauri/src/voicevox_engine.rs`（起動・使用の数え上げ・止める見張り）／`src-tauri/src/voicevox.rs`（各口で起動して待つ）／`src-tauri/src/lib.rs`（起動時の起動をやめる）／`src/infrastructure/voiceFs.ts` と `src/App.tsx`（声を使う画面で裏で起こす）。
- 正典（schemas/11/12）は変わらない。

## 未解決の論点

- 10 分が長すぎる／短すぎるか（実際の使われ方を見て決め直す）。
