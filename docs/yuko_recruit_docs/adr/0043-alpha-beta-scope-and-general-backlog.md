# ADR-0043: α と β の線引きと、「一般機能の将来枠」を作る（孤児を二度と作らない）

- **状態**: Accepted
- **日付**: 2026-09-17（利用者判断）
- **関連**: [`ADR-0032`](0032-timeline-project-format.md)・[`ADR-0034`](0034-timeline-interaction-model.md)・[`ADR-0041`](0041-external-agent-operability.md)・[#1192](https://github.com/fujii-yuki-star/star-recruit-studio/issues/1192)

## 背景

2026-09-17 の棚卸し（[`audits/2026-09-17-video-editing-maturity.md`](../audits/2026-09-17-video-editing-maturity.md)）で、
**行き先が無くなっている決定が2つ**見つかった。

| 浮いたもの | どこに書いてあったか | どうなったか |
|---|---|---|
| カラー補正・クロマキー・マスク・描画モード | ADR-0032 の射程「**α-6 以降**」／#634 の「対象外」 | α-6（#857）にも α-7（#958）にも open な Issue にも**1文字も無い** |
| 「間を詰める」 | ADR-0034 決定11「**α-6 候補**」 | 同じく**どこにも無い** |

⚠️ **原因は「α-6 以降」という書き方**＝**当時のロードマップの区切りを行き先に使った**。
α-6 の中身を組み直したときに、その区切りは**消えた**。**消える名前を行き先にすると、中身ごと消える。**

## 決定

### ① α と β の意味を固定する

| | 意味 |
|---|---|
| **α** | **一般向け「すたりお」本体として、リリース前に要る機能と品質** |
> ⚠️ **「一般」が二重の意味を持つ**（PR #1196 レビュー ℹ️）＝ここで言う「一般向け」は
> **製品の射程**（会社固有でない）の話。[`ADR-0011`](0011-video-kinds-and-stario.md) の
> `videoKind`（`recruit` / `general`＝**動画の種類**としての「一般・社内発表」）とは**別の話**。
| **β** | **会社・採用の用途に固有の機能**を主に足す段階 |

⚠️ **β は「後でやること置き場」ではない**＝汎用の機能を「β」とだけ書いて送らない。
（送ると、β のロードマップを作るときに「これは会社固有か？」で弾かれ、**また浮く**。）

### ② 一般機能の将来枠を、**実在する箱**として作る

- **ラベル `general-backlog`** ＋ **マイルストーン「一般機能バックログ（α後）」**。
- ⚠️ **新しい概念を足したのではない**＝このリポジトリは既に `alpha-N` ラベルと α-N マイルストーンで
  行き先を表している。**同じ仕組みの続き**にした（管理体系を増やさない）。

### ③ 「行き先の無い決定」を残さない

**ADR や Issue で何かを「後回し」にするときは、必ず次の2つを同時に書く。**

1. **どの箱へ入れたか**（α-N マイルストーン／`general-backlog`／「やらない」）
2. ⚠️ **α へ上げる条件**（何が起きたら前倒すか）

⚠️ **「α-6 以降」「将来」「後で」だけの書き方を禁じる**＝それは箱ではない。

### ③-2 ⚠️ **規則だけでは止まらないので、機械で拾う**（PR #1196 レビュー 🔴）

**この ADR の PR 自身で、規則が守られなかった。** 同じファイルの長い追補（497 行目）は直したのに、
**読者が最初に見る決定表（86 行目）を見落とした**。レビューの言うとおり、
**行き先の記述が長大な地の文の中に散らばっていて、目で拾える形になっていない**のが原因で、
注意力の問題ではない。

→ **門番を作った**＝`src/test/orphanDestinationGuard.test.ts`。
走査するのは `docs` の中の Markdown 全部で、**`α-N 以降` / `α-N 候補` が、行き先を与え直した注記（ADR-0043 か `general-backlog`）
なしで書かれている行**を落とす。

⚠️ **作った直後に、さらに3件見つかった**（合計5件）＝
`ADR-0032` の決定表・`ADR-0024` の未決定事項4・`ADR-0034` の**作業範囲（ループ・範囲書き出し）**。
**規則を知っていても目視では拾いきれない**ことの実証。

⚠️ **見ない資料は2つだけ**＝この ADR 自身と、棚卸しの記録（どちらも「そう書いてあった」ことを
**説明するために引用している**ので、赤くすると説明が書けなくなる）。数は門番自身の検査で留めてある。

### ④-2 追補（2026-10-19・α 残件の洗い直しで見つけた「行き先の無い」もの）

閉じた Issue のコメントや資料にだけ書かれ、`general-backlog` の箱に入っていなかったものを、ここへ入れる（③）。
⚠️ **Issue（`general-backlog` ラベル）はまだ起こしていない**＝中身の判断は利用者が「詳しく見ていない」（2026-10-19）ので、まずこの表を行き先とする。α へ上げるときに Issue を起こす。

| もの | 出どころ | α へ上げる条件 |
|---|---|---|
| **ノイズ低減**（声・環境音） | #1379 の D（閉じたときに「general-backlog」と書いたが箱が無かった） | 実写の動画素材で「ノイズが気になる」が実際に出たとき |
| **レビュー補助**（見る人の書き込みを受ける等） | #1379 の F | 社内で「動画を見てもらって直す」流れが実際に要るとき |
| **ブランドルール**（会社の色・字体を外れたら知らせる） | #1379 の G | 会社の見た目（ADR-0036）だけでは揃わないと実際に分かったとき |
| **列をまたぐ縦の自動送り**（掴んで画面の上下端へ運ぶと列が送られる） | `06_UI_SPEC.md`（運んでいる間の送り・#714 は閉じている） | 列が多く「置く列」の欄では間に合わないと実際に分かったとき |

⚠️ **タイムライン形式で置いた「（ゆうこ）」の見た目パターンに立ち絵を入れる欄は「やらない」**（利用者判断 2026-10-19）＝
立ち絵は別の部品として置けば出せる。場面形式から作り直した動画は立ち絵を持ったまま（`bake.ts`）。

### ⑤ 追補（2026-10-20・利用者判断）＝**α でソフトとして完成させる／β 以降は外付けの追加機能だけ**

利用者の方針（2026-10-20）：**α でソフトとして完成させ、β 以降は完全に外付けの追加機能しか扱わない**。

- ⚠️ **①の β の意味を改める**＝β は「会社・採用に固有の機能」ではなく、**拡張パック（ADR-0060）で足す外付けの追加**（見た目パターン・BGM・声・字体・機能の鍵＝データ）だけ。会社固有の β 機能（ADR-0061 あなた向け会社説明）も拡張パックの鍵で出す外付けとして扱う。
- ⚠️ **②の「一般機能バックログ（α後）」は廃止する**＝本体の機能は「α でやる」か「やらない」のどちらか。後でやる置き場を残さない（③の「行き先の無い決定を残さない」をこの形で守る）。
- 行き先は次の表（2026-10-20 の α 残件の精査で、ADR と資料の未解決 107 件・開いている Issue 11 件を洗った結果。利用者が「推奨どおり」で承認）。

**α でやる（マイルストーン「α-8（ソフトの完成）」）**

| もの | 出どころ |
|---|---|
| 止めた絵をファイルにしない（部品の設定で止める） | ADR-0065 |
| 場面の切り替えの「ワイプ」「ズーム」を実際に描く（いまは選べるのにフェードで描かれる） | ADR-0009 未解決・ADR-0032 決定19 |
| 反転・縦横の大きさを変えた部品の選択枠と取っ手・その場で直している間の姿 | #1416・ADR-0059 未解決 |
| 列ごとの音量・ソロ | ADR-0034 未解決5・④-2 |
| 掴んで上下の端へ運ぶと列が縦に送られる | ④-2・`06` |
| 列の外へ落としたとき列を自動で足す | ADR-0034 未解決 |
| ノイズ低減（声・環境音） | ④-2 |
| 素材の一覧にあるがどこにも使っていない素材の片づけ（タイムライン形式） | ADR-0064 未解決 |
| 窓が狭いときの欄の振る舞い | ADR-0033 未解決 |
| 動きのある部品を掴んだときの大きさ・回転の取っ手・道筋の見せ方 | ADR-0054 未解決 |
| 持ち込んだ字体で太字が効かないことを画面で示す | ADR-0038 未解決 |
| 編集中の AI 補助を、掛け合いの各行・見出しへ広げる | ADR-0053 未解決 |
| 読み込んだ字幕から読み上げの声も作る | ADR-0055 未解決 |

**やらない（閉じる）**

| もの | なぜ |
|---|---|
| 場面形式とタイムライン形式の行き来 | ADR-0032 の片道の設計と食い違う |
| セリフ1行ごとに字幕ボックスを選ぶ（場面形式） | 場面形式は凍結（ADR-0032） |
| レビュー補助（見る人の書き込み等） | 製品の種類が違う |
| ブランドルール（会社の色から外れたら知らせる） | 会社の見た目（ADR-0036）で足りる |
| 外部 AI の OpenAI 対応・混雑時の待ち直しの作り込み | 同梱の AI が主軸（ADR-0051） |
| 欄を別の窓に浮かせる | 仕上がり確認の別窓（ADR-0050）で足りる |
| 拡張パックを利用者が自分で作れるようにする | 配る側（こちら）が作る（ADR-0060） |
| 文字起こしを語単位で消す | 文単位で消せる。語の時刻が実録音で確かめられていない（ADR-0058） |
| 素材ライブラリを別の PC へまとめて渡す | フォルダごと写せば足りる |
| サムネイルの自動生成・採用媒体ごとのプリセット | 一覧の絵（`projectThumbnail`）と縦横・長さの選択で足りる |

**外付け（β 以降・拡張パック）**：見た目パターンを増やす（#1187）・声の追加・ゆうこの絵の追加・ゆっくりボイス。

**本体の作業ではないもの**：法務・配布の確認（`13 §9`）と、利用者の環境が要る実機確認（MSI・Windows N/KN）は α の出口の条件として残す。
同梱 AI の追加学習（#1294）は利用者判断（2026-10-01）どおり「必要と分かったときに再開」のまま。

## 結果

- **ADR-0032 と ADR-0034 の「α-6 以降／α-6 候補」は、本 ADR で行き先を与えた**（下の追記で本文にも書き戻す）。
- 今後「後でやる」と書くときは**箱と昇格条件**を同時に書く。

## 採らなかった案

| 案 | なぜ採らないか |
|---|---|
| **β へまとめて送る** | β は**会社固有**の段。汎用機能を混ぜると、β の計画で弾かれて**また浮く** |
| **「やらない」と決めてしまう** | 基本カラー補正は**普通の動画編集で使う**。試験の前に切ると、必要と分かったとき戻す道が無い |
| **新しい管理の仕組みを作る**（別リポジトリのロードマップ等） | 既存のラベル＋マイルストーンで足りる。増やすと**そこがまた見られなくなる** |
