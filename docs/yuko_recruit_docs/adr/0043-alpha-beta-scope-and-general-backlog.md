# ADR-0043: α と β の線引きと、「一般機能の将来枠」を作る（孤児を二度と作らない）

- **状態**: Accepted
- **日付**: 2026-09-17（利用者判断）
- **関連**: [`ADR-0032`](0032-timeline-project-format.md)・[`ADR-0034`](0034-timeline-interaction-model.md)・[`ADR-0041`](0041-external-agent-operability.md)・[#1192](https://github.com/fujii-yuki-star/star-recruit-studio/issues/1192)

## 背景

2026-09-17 の棚卸し（[`audits/2026-09-17-video-editing-maturity.md`](../audits/2026-09-17-video-editing-maturity.md)）で、
**行き先が無くなっている決定が2つ**見つかった。

| 浮いたもの | どこに書いてあったか | どうなったか |
|---|---|---|
| カラー補正・クロマキー・マスク・描画モード | ADR-0032 の射程「**α-6 以降**」／#634 の「対象外」 | α-6（#857）にも α-7（#958）にも open な Issue にも**1文字も無い** |
| 「間を詰める」 | ADR-0034 決定11「**α-6 候補**」 | 同じく**どこにも無い** |

⚠️ **原因は「α-6 以降」という書き方**＝**当時のロードマップの区切りを行き先に使った**。
α-6 の中身を組み直したときに、その区切りは**消えた**。**消える名前を行き先にすると、中身ごと消える。**

## 決定

### ① α と β の意味を固定する

| | 意味 |
|---|---|
| **α** | **一般向け「すたりお」本体として、リリース前に要る機能と品質** |
> ⚠️ **「一般」が二重の意味を持つ**（PR #1196 レビュー ℹ️）＝ここで言う「一般向け」は
> **製品の射程**（会社固有でない）の話。[`ADR-0011`](0011-video-kinds-and-stario.md) の
> `videoKind`（`recruit` / `general`＝**動画の種類**としての「一般・社内発表」）とは**別の話**。
| **β** | **会社・採用の用途に固有の機能**を主に足す段階 |

⚠️ **β は「後でやること置き場」ではない**＝汎用の機能を「β」とだけ書いて送らない。
（送ると、β のロードマップを作るときに「これは会社固有か？」で弾かれ、**また浮く**。）

### ② 一般機能の将来枠を、**実在する箱**として作る

- **ラベル `general-backlog`** ＋ **マイルストーン「一般機能バックログ（α後）」**。
- ⚠️ **新しい概念を足したのではない**＝このリポジトリは既に `alpha-N` ラベルと α-N マイルストーンで
  行き先を表している。**同じ仕組みの続き**にした（管理体系を増やさない）。

### ③ 「行き先の無い決定」を残さない

**ADR や Issue で何かを「後回し」にするときは、必ず次の2つを同時に書く。**

1. **どの箱へ入れたか**（α-N マイルストーン／`general-backlog`／「やらない」）
2. ⚠️ **α へ上げる条件**（何が起きたら前倒すか）

⚠️ **「α-6 以降」「将来」「後で」だけの書き方を禁じる**＝それは箱ではない。

### ③-2 ⚠️ **規則だけでは止まらないので、機械で拾う**（PR #1196 レビュー 🔴）

**この ADR の PR 自身で、規則が守られなかった。** 同じファイルの長い追補（497 行目）は直したのに、
**読者が最初に見る決定表（86 行目）を見落とした**。レビューの言うとおり、
**行き先の記述が長大な地の文の中に散らばっていて、目で拾える形になっていない**のが原因で、
注意力の問題ではない。

→ **門番を作った**＝`src/test/orphanDestinationGuard.test.ts`。
走査するのは `docs` の中の Markdown 全部で、**`α-N 以降` / `α-N 候補` が、行き先を与え直した注記（ADR-0043 か `general-backlog`）
なしで書かれている行**を落とす。

⚠️ **作った直後に、さらに3件見つかった**（合計5件）＝
`ADR-0032` の決定表・`ADR-0024` の未決定事項4・`ADR-0034` の**作業範囲（ループ・範囲書き出し）**。
**規則を知っていても目視では拾いきれない**ことの実証。

⚠️ **見ない資料は2つだけ**＝この ADR 自身と、棚卸しの記録（どちらも「そう書いてあった」ことを
**説明するために引用している**ので、赤くすると説明が書けなくなる）。数は門番自身の検査で留めてある。

### ④ 今回の仕分け（利用者判断・2026-09-17）

| 機能 | 行き先 | α へ上げる条件 |
|---|---|---|
| **基本カラー補正**（明るさ/露出・コントラスト・彩度・必要なら色温度） | `general-backlog` | **#1194（長尺の実地試験）で「普通の動画編集として明確に不足」と確認されたときだけ** |
| **クロマキー** | `general-backlog`（高度編集） | 現時点では無し |
| **マスク** | `general-backlog`（高度編集の基盤） | 現時点では無し。⚠️ **通常の編集と高度合成/MV 制作の境目**を検討する段で扱う |
| **描画モード（Blend Mode）** | `general-backlog`（高度合成） | 現時点では無し |
| **[#1186](https://github.com/fujii-yuki-star/star-recruit-studio/issues/1186)** 非一様スケール・反転・回転の軸 | `general-backlog` | **#1135 / #1194 で「これが無いと品質目標を満たせない」と実証されたとき** |
| **[#1187](https://github.com/fujii-yuki-star/star-recruit-studio/issues/1187)** テンプレートを増やす | `general-backlog` | **既存テンプレ不足が #1135 / #1194 の成立を妨げるとき**（その場合は**必要最小限だけ** α で足す） |
| **[#1193](https://github.com/fujii-yuki-star/star-recruit-studio/issues/1193)** 範囲削除・間を詰める | **α** | — |
| **[#1194](https://github.com/fujii-yuki-star/star-recruit-studio/issues/1194)** 長尺の通し試験 | **α** | — |

## 結果

- **ADR-0032 と ADR-0034 の「α-6 以降／α-6 候補」は、本 ADR で行き先を与えた**（下の追記で本文にも書き戻す）。
- 今後「後でやる」と書くときは**箱と昇格条件**を同時に書く。

## 採らなかった案

| 案 | なぜ採らないか |
|---|---|
| **β へまとめて送る** | β は**会社固有**の段。汎用機能を混ぜると、β の計画で弾かれて**また浮く** |
| **「やらない」と決めてしまう** | 基本カラー補正は**普通の動画編集で使う**。試験の前に切ると、必要と分かったとき戻す道が無い |
| **新しい管理の仕組みを作る**（別リポジトリのロードマップ等） | 既存のラベル＋マイルストーンで足りる。増やすと**そこがまた見られなくなる** |
