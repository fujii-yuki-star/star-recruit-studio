# ADR-0073: 単独の語り（ナレーション）にも、場面ごとの話者を持たせる

- **状態**: Accepted（2026-11-05・利用者判断＝案 A）
- **日付**: 2026-11-05
- **関連**: ADR-0061（あなた向け会社説明＝学生が声を選ぶ）／ADR-0015（掛け合いの行の話者 `speaker`）／ADR-0003・0025（クレジット）／ADR-0032（場面形式は凍結＝続けてよいのは「素材と声」）／`11 §6`（声の解決順序）・`11 §7.4`／`schemas/project.schema.json`

## コンテキスト

ADR-0061 の学生の画面で「声を選ぶ」を作ろうとして分かった（2026-11-05）：

- **単独の語りの声は、アプリ全体の設定**（`getVoicevoxSpeaker`）で決まる。`scene.narration.voiceId`（文字列）は正典（`11 §6`）では場面の上書きだが、
  `voicevoxProvider` は**設定の話者を先に見る**ので、実際には効かない（対応表も既定の1つしか無い）。
- 掛け合いの行は数値の `speaker` を持ち、こちらは設定より優先される（ADR-0015）。
- そのため「この場面だけ別の声」は、**掛け合いにしない限りできない**。学生の選んだ声で語りを作り直すには、場面ごとに話者を持つ道が要る。

検討した案（利用者に示した A〜C）から **A＝データの形を広げる** を選んだ（2026-11-05）。

## 判断軸

- **設定した意味どおり**（ADR-0026①）＝場面に書いた声が、作る声にもクレジットにも効く。
- **掛け合いと同じ概念を割らない**（ADR-0026②）＝話者は行と同じ「数値の `speaker`」。
- **既存の動画を変えない**＝持っていない場面は今までどおり（アプリの設定の声）。

## 検討した選択肢

| 選択肢 | 評価 |
|---|---|
| (A) `narration.speaker`（数値・任意）を足す | 行の `speaker` と同じ形・同じ優先順。既存の動画は欄が無い＝出力不変。**採用** |
| (B) 単独の語りを「1行だけの掛け合い」に写す | 字幕の出る長さ（声の長さで区切る）が変わる＝絵が変わる。不採用 |
| (C) その回だけアプリ全体の設定を差し替える | 落ちると他の動画へ漏れる・クレジットも食い違う。不採用 |
| (D) `voiceId` の対応表を育てる | 文字列と数値の二重管理（ADR-0015 は数値に寄せた）。不採用 |

## 決定

1. **`Narration.speaker`**（整数・任意・null＝継承）を `project.schema` に足す（**1.34 → 1.35**・欄を足すだけ＝古い動画はそのまま読める）。
   値の意味は掛け合いの行の `speaker` と同じ（`voiceCatalog` の VOICEVOX の話者番号）。カタログに無い番号は既定の声へ（V19 と同じ）。
2. **解決順序**＝`narration.speaker` → アプリの設定の話者 → `voiceId` の対応 → 既定（掛け合いの行と同じ）。
3. **入口は1つ**＝単独の語りを1行に写す `lineFromNarration` が `speaker` も写す。これで**掛け合いの行と同じ道**（作る声の入力・同じ入力かの判定・クレジット・行の字幕の話者・タイムラインへの焼き出し）に乗る。
   単独の語りの合成の入力は `resolveNarrationInput`（`voiceProvider.ts`）に1つ。
4. **クレジット**＝単独の語りの場面も、その場面の話者で名乗る（`sceneVoiceCredits`・「ずっと表示」の場面ごとの名乗り）。
5. **画面**：段階1では**場面編集に欄を出さない**（ADR-0061 の学生の声だけが書く）。段階2で場面編集の「声」に出す（掛け合いの行の声の選び方と同じ部品）。
   ⚠️ 段階1の間に一時の動画を「残す」道は無い（ADR-0061 の「残す」は未実装）＝**画面に出ない値を利用者が持つ動画は、まだできない**。

## 結果・影響

- schema：`project.schema.json` の `Narration.speaker`・`schemaVersion` 1.35（読み込みの対応範囲を広げる）。正典 `11 §6`・`11 §7.4`。
- コード：`types.ts`・`narrationLines.ts`（`lineFromNarration`）・`voiceProvider.ts`（`resolveNarrationInput`）・`projectStore`（単独の語りの合成と照合）・`restoreVoices.ts`・`narratorCredit.ts`・書き出し／仕上がり確認のクレジット・`briefing/build.ts`（学生の声）。
- タイムライン形式：声のクリップは既に `speaker` を持つ＝焼き出しは `lineFromNarration` 経由で写る。

## 未解決の論点

- 段階2（場面編集の「声」の欄）の置き場所と、アプリ全体の設定との見せ分け（UI/UX）。
- `narration.voiceId`（文字列）の扱い＝いまも効いていない。整理するなら別の ADR。
