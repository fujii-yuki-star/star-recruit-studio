# ADR-0064: 使っていないファイルの片づけは、利用者が選んで「ごみ箱へ移す」

- **状態**: Accepted
- **日付**: 2026-10-20
- **関連**: [`ADR-0020`](0020-undo-redo-model.md)（取り消しの履歴に素材は載らない＝場面形式）／[`ADR-0024`](0024-non-destructive-editing-model.md)（素材込みで自己完結）／[`ADR-0032`](0032-timeline-project-format.md)（タイムライン形式の履歴は素材も含む）／[`ADR-0065`](0065-freeze-frame-without-file.md)（止めた絵をファイルにしない＝検討）／`15 §6`

## コンテキスト

2026-10-19 の実機確認で、**動画のフォルダに、どこからも使われていないファイルが溜まる**ことが分かった。

- タイムライン形式で「この瞬間で絵を止める」を取り消すと、切り出した写真のファイルが `assets/` に残る（やり直しで戻すために、わざと残す作り）。
- 取り込みを取り消した場合も同じ（大きな動画なら数百MB）。
- 画面からこれを片づける道が無い（素材の一覧にも出ない）。

一方、場面形式で素材を削除すると、ファイルを**ごみ箱を経由せずにすぐ消している**（`delete_project_files`＝`fs::remove_file`）。

最初の案は「開いたときに、どこからも参照されないファイルを自動で消す」だったが、利用者の指摘（2026-10-20）で**世の中のソフトの挙動**を調べ直した。

| ソフト | 使っていない素材の扱い |
|---|---|
| Final Cut Pro | クリップを消すと元ファイルを**ゴミ箱へ**（ほかで使っているものは残す）。自動で消すのは作り直せる生成物（レンダリング・代理）だけ |
| DaVinci Resolve | 「Remove Unused Clips」はプロジェクトの一覧から外すだけ（ファイルは消さない）。ディスクを減らすのは別の明示操作 |
| Premiere Pro | 「Remove Unused」・Project Manager の「未使用を除外」＝どれも利用者が実行 |
| Logic Pro | 「Clean Up」は**消す前に対象の一覧を出し、チェックを外して残せる** |

⇒ **素材ファイルを黙って消すソフトは無い**。片づけは**利用者が実行するコマンド**で、**消す前に見せる**・**ごみ箱を経由する**のが常識。

## 判断軸

- **黙って消さない**（§2-5・ADR-0026④）＝消えたことに気づけない操作を作らない。
- **戻せる**＝誤って消しても取り戻せる（ごみ箱）。
- **戻し先を壊さない**＝「前の状態に戻す」の時点・控え（`project.json` の1つ前）・開いている動画の取り消し／やり直しが指すファイルは消さない。
- 業界の型に合わせる（ADR-0034 の流儀）。

## 検討した選択肢

| 選択肢 | 評価 |
|---|---|
| (A) 開いたときに自動で消す | 業界の型に反する（黙って消す）。**不採用**（最初の案を取り下げた） |
| (B) **利用者が実行する「使っていないファイルを片づける」＋ごみ箱へ移す** | Logic Pro・Final Cut Pro と同じ形。**採用** |
| (C) 何もしない | ファイルが溜まり続け、画面から片づける道が無い。不採用 |

## 決定

1. **「使っていないファイルを片づける」**を動画ごとの操作として置く（動画の一覧の、その動画のメニュー）。
   - 押すと、**どこからも使われていないファイルの一覧**（名前・種類・大きさ・合計）を見せる。既定は全部選択、チェックを外せば残せる。
   - 「選んだファイルをごみ箱へ移す」で実行する。**ごみ箱から戻せる**と画面に書く。
   - 1つも無ければ「使っていないファイルはありません」と出す。
2. **「使っている」の判定**＝次のどれかに書かれている相対パスは使っている。
   - いまの `project.json`・1つ前の控え（`project.json` の控え）・「前の状態に戻す」の全時点（`restore/`）。
   - **開いている動画なら、画面が持っている内容**（保存前の変更・取り消し／やり直しの履歴を含む）。
   - 調べるのは**文書の中の全部の文字列**（欄の名前で拾わない）＝新しい欄を足しても、見落として消す側に倒れない。
3. **対象は `assets/` と `voices/` の中のファイルだけ**（`project.json`・控え・`restore/` 等には触れない）。
4. **場面形式で素材を削除したときも、ファイルはごみ箱へ移す**（いまはすぐ消している）＝Final Cut Pro と同じ。
   - 取り込みの途中で失敗したときの後片づけ（作りかけの1ファイル）は、利用者が作ったものではないので、従来どおりすぐ消す。
5. **ごみ箱へ移せなかったら、消さずに残す**（すぐ消すへ切り替えない）＝知らせて終える。
   - ⚠️ **ごみ箱に入らないファイル**（ごみ箱の上限より大きい・ごみ箱を使わない設定・ごみ箱の無いドライブ）は、Windows が**黙って完全に消す**ことがある。完全に消すことになるときだけ Windows に確認を出させ（`FOF_WANTNUKEWARNING`）、断られたら失敗として残す（PR #1472 レビュー）。
6. **道の書き方の揺れをそろえて比べる**（区切り `\`／先頭の `./`／重なった `/`／大文字小文字）＝Windows は同じファイルとして開くので、そのまま比べると使っているファイルを「使っていない」と取り違える（持ち込みの AI がフォルダから取り込んだ文書で起きうる）。
7. **開けなかった版（`project.broken.json`）が読めるなら、そこが使うファイルも残す**（手がかりとして残してある版）。
8. **走っている間は調べない**＝取り込み・書き出し・一括の声づくりに加え、1場面・1行だけの声づくり（準備中）・タイムラインの読み上げの声づくりも。

## 結果・影響

- Rust：一覧を作る口（`list_unused_project_files`）と、ごみ箱へ移す口（`trash_project_files`）を足す。Windows はシェルの「ごみ箱へ移す」（`SHFileOperationW`＋`FOF_ALLOWUNDO`）を使う。
- 画面：動画の一覧のメニューに1項目と、確認の欄。
- 文言：`15 §6` に一覧が空・移せなかった、を足す。
- schema・データは変えない（移行なし）。

## 未解決の論点

- タイムライン形式の「素材の一覧にはあるが、どの部品も使っていない素材」（Resolve の Remove Unused Clips に当たる）の片づけ。この ADR は**一覧にも無いファイル**だけを扱う。
- 止めた絵がそもそもファイルを作らない作り（[`ADR-0065`](0065-freeze-frame-without-file.md)・検討）。
