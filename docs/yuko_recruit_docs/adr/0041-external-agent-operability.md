# ADR-0041: 外に持ち込む AI に、ソフトそのものを動かさせる（同梱 AI とは別枠）

- **状態**: Proposed
- **日付**: 2026-09-16
- **関連**: [ADR-0032](0032-timeline-project-format.md)（場面形式の凍結・タイムライン形式の新設）・[ADR-0007](0007-detailed-edit-mode.md)・[ADR-0001](0001-rendering-parity.md)・[#1184](https://github.com/fujii-yuki-star/star-recruit-studio/issues/1184)

## 背景

ADR-0032 は「**AI が触るのは場面形式まで**（タイムライン形式へは片道で焼き出す）」と決めた。
一方で、**利用者が自分で持っている AI**（Claude・Codex 等）に**ソフトそのものを操作させて**動画を作りたい、
という要望が出た。このままだと前者の線引きが後者まで縛ってしまう。

⚠️ **2026-09-16 に実地で確かめた**：`project.json` を直接書いて 33 秒・28 部品・キーフレーム 33 点の
タイムライン動画を組み、同梱 VOICEVOX で声 13 本を作り、**アプリ自身の読み込みと正典 schema の両方を通した**。
**書き出しの保存ダイアログを押す以外は、人が画面を触らずに到達できている。**

## 決定

**「AI」をひとくくりにせず、2つの枠に分ける。**

| 枠 | 誰 | 触れる範囲 | 根拠 |
|---|---|---|---|
| **① 同梱の AI** | こちらが配る **Gemini API キーの無料枠**で動く、ソフトに内蔵された生成 | **場面形式まで**（`ai-video-plan` → 検証 → 変換）。**タイムライン形式は書かない** | ADR-0032 のまま。無料枠＝**量と品質を我々が保証する範囲**なので、テンプレート駆動に収める |
| **② 利用者の AI** | 利用者が自分で持ち込む Claude・Codex 等。**ソフトを操作する側** | **タイムライン形式を直接書いてよい**（時間も空間も自由） | 質が明らかに上がる。費用と責任は利用者側にあり、**テンプレートに収める理由がない** |

⚠️ **ADR-0032 の線引きは①にだけ掛かる**＝本 ADR は 0032 を**否定せず、適用範囲を明示する**。

### ②に掛ける条件

1. **検証を必ず通す**（原則§2-2）。②が書いたものも**生のまま内部データにしない**＝アプリの読み込み（`parseTimelineProjectDoc`）と正典 schema を通ったものだけを受け取る。
   ⚠️ **検証は二段**（PR #1185 レビュー ℹ️）＝読み込みで見るのは**形**だけで、**相互参照（V22〜V33）は
   書き出しのところで断る**（`validateTimelineDoc`・読み込みは止めない）。②のために**新しい検証を作らず**、
   この既存の仕組みにそのまま乗る。
2. **描画核は共有したまま**（ADR-0001）。②のために別の書き出し経路を作らない。
3. **失敗は「次の行動」で返す**（原則§2-5）。②が読むのは人ではないが、**人が後で読む**。
4. **外へ送るのはこのソフトの仕事ではない**（原則§2-6・PR #1185 レビュー ℹ️）。②は**利用者の側で動く AI**
   なので、素材や動画をどこへ見せるかは**利用者と、その AI の間の話**＝**アプリは代わりに送らない**。
   ⚠️ **原則§2-6 は緩めない**＝アプリ自身が外部へ出すとき（同梱の生成・①）は、今までどおり
   **元動画は送らず代表フレームだけ・送信前の確認画面を必ず通す**。②を許すことは、その口を開けない。

## 結果

- ②を成立させるために要るもの＝**#1184 の①〜③**（書き出しの出口・置き場・書く側の契約）。
- 段取りは **α の最後に契約と本 ADR、β の最初に出口と置き場**。
- ⚠️ **Accepted になったら、同じ PR で直す所が3つある**（PR #1185 レビュー 🟡）＝
  ① `CLAUDE.md §2 絶対原則4 の注記`（「AI が触るのは場面形式まで」）
  ② `CLAUDE.md §11`（ADR-0032 の行の「AI が触るのは変換前まで」）
  ③ [`ADR-0032`](0032-timeline-project-format.md) の**判断軸2と決定文**に入れた「提案中」の注記を「書き直しました」へ改める。
  ⚠️ **①を落としやすい**＝§11 だけ直して終わりにすると、**絶対原則の側に無条件の断定が残る**
  （そちらの方が強い拘束なので、残ると実質的に矛盾したまま）。

## 採らなかった案

- **線引きを一律に広げる**＝同梱 AI にもタイムラインを書かせる。却下＝無料枠の生成物の品質を我々が抱えることになり、テンプレート駆動（原則§4）の利点を捨てる。
- **線引きを守り、②も場面形式まで**。却下＝②の価値（時間の自由）がほぼ消える。
