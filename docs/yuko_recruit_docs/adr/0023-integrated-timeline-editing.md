## コンテキスト

利用者要望（2026-07-02）：「**プレビュー画面を見ながら随時再生しながら、複数トラックを用いて本格的に動画編集**をしたい」。α-5 で完全実装の想定か確認があり、**現行計画には未起票**だったため、本 ADR で計画へ組み込む（α-5 の主軸に据える＝利用者合意）。

### 現状（α-4 ③(6) 時点）
- タイムライン編集（ADR-0018 ③(3)〜(6)）＝テロップ overlay の追加/移動/トリミング/吸着まで。**再生ヘッド・同期プレビューは無い**（③(6) の吸着先にも「再生ヘッド」は入っていない＝概念自体が未計画だった）。
- プレビュー画面（仕上がり確認）は**場面単位**の静止画＋音声タイマーで逐次再生する方式。**グローバル時間 t を指定して任意時刻の絵を出す再生エンジンは無い**。
- ④（ADR-0019・α-4 実装予定）で `layoutScene(scene, template, t)` が入る＝「時間 t の絵」を作る**技術的土台**はできる。ただし④の目的はキーフレーム確認で、タイムライン画面への統合UIは範囲外。
- α-5 起票済み（#257-262）は素材と音まわりの拡充で、統合編集は含まれていない。

## 判断軸

1. **パリティ最優先**（ADR-0001/0019）：再生で見た絵＝書き出しの絵（フレーム単位）。統合再生は同一の `compileTimeline`＋`layoutScene(t)` を共有して初めて意味を持つ。
2. **2モデル維持**（ADR-0018/0007）：場面ベース正準・AI 親和性は不変。統合編集は「射影の上の編集面」を豊かにするだけで、データモデルは変えない。
3. **非力PC**（`01 §15.2`）：再生/スクラブはオンデマンド描画＋キャッシュ＋間引きで成立させる。
4. **§2-3/§2-4**：技術用語を出さない・時間軸の自由編集は専用画面に隔離（本ADRはその専用画面を「統合編集面」へ育てる）。
5. **段階出荷**：各段が単独で価値を持つ（再生ヘッド→再生→スクラブ→吸着→…）。

## 検討した選択肢

| 選択肢 | 評価 |
|---|---|
| (A) 統合編集を作らない（現状のタイムライン補助編集で完結） | 実装ゼロだが利用者要望に反する。タイムライン編集が「見えない結果を数値で editing」に留まり UX 上限が低い。**不採用** |
| (B) 完全 NLE へ再設計（時間軸ネイティブ・トラック中心のデータモデル） | ADR-0018 選択肢(A)で不採用済みの方向。場面正準・AI 親和性・後方互換を壊す。**不採用** |
| **(C) 既存2モデルの上に「グローバル時間の再生エンジン＋再生ヘッド＋同期プレビュー」を載せ、タイムライン編集画面を統合編集面へ育てる【採用】** | `compileTimeline`（射影）と `layoutScene(t)`（④）を共有＝**パリティ構造を保ったまま**統合体験に到達。データモデル不変・段階出荷可能。α-5 の音まわり issues が部品として合流。 |

## 決定（Proposed）

> **グローバル秒 t を入力に「その時刻の絵と音」を返す再生エンジン（globalPlayback）を `compileTimeline`＋`layoutScene(t)` の共有で新設し、タイムライン編集画面に同期プレビュー窓＋再生ヘッドを統合する。再生・一時停止・シーク・スクラブを備え、再生しながらのクリップ編集を可能にする。データモデル（場面正準＋overlay）は不変。α-5 の主軸 EPIC（#329）として段階出荷する。**

### 役割分担（利用者合意 2026-07-02・ブラッシュアップ反映）
- **場面編集画面＝簡易編集面**：スライド動画を**手早く作る**（AI たたき台→場面単位の修正）。`scene.lines` はここの正準（ADR-0015・不変）。
- **統合タイムライン編集＝上位の仕上げ編集面**：音声・映像・文字・SE・BGM を時間軸で調整し**完成度を2〜3段引き上げる**。既存のセリフ/字幕は**射影＋導線**で接続（正準は場面側のまま）＝両面の体験を分断しない（どちらで直しても同じデータ）。
- 素材の扱い（同じ動画から複数範囲・非破壊トリム・解析キャッシュ）は **ADR-0024** に従う。

### 差別化軸（強み）と守り手（2026-07-02 整理）
機能追加はこの7軸を**弱めない方向**で判断する（守り手＝違反を検出する正典）。

| 強み | 守る正典 |
|---|---|
| 二層構造（簡易＝場面編集／本格＝統合タイムライン） | 本ADR 役割分担 |
| 声を中心に字幕・テロップ・テキスト・SE・素材を紐付けて編集 | ADR-0015・ADR-0024(5)・#329(3) |
| AI が下書き→人間が本格タイムラインで仕上げ | ADR-0007/0018（場面正準・単一パイプライン） |
| テンプレで崩れない＋FREE/テンプレ作成/KF で作り込める | `§2-4`・ADR-0016/0017/0019/0022 |
| プレビュー＝書き出しの一致 | ADR-0001/0004 |
| ローカル素材を外部送信しにくい安心（事前確認・元動画は送らない） | `§2-6` |
| 日本語ナレーション・字幕に強い | ADR-0003/0005・同梱フォント（#161）・折返し計測（`§7`） |

### lines 接続（α-5 最小到達点の中核）
射影（`compileTimeline`・sceneId/lineId 付きの行クリップ・`origin` による自由テロップとの区別）は**実装済み**。残る導線を α-5 で足す：
1. **セリフ/字幕クリップの選択→編集元へ**（該当 sceneId/lineId の場面編集へジャンプ）。
2. **タイムラインから「声を作成/作り直す」**（未作成行の解消をタイムライン上で）。
3. **再生ヘッド位置→有効セリフ行の解決→同期プレビューへ反映**（`activeLineIndexAt` 流用）。

### α-5 最小到達点（利用者合意 2026-07-02）
**再生ヘッド＋クリック/ドラッグシーク＋同期プレビュー＋上記 lines 導線**まで。スクラブ・ヘッド吸着・SE/平行音声は後続段（下記段階出荷の (4)〜）。

### 段階出荷（EPIC #329 サブPR）
1. **再生ヘッド＋クリックシーク**：タイムラインに再生ヘッドを描画、クリック/ドラッグで移動。その時刻の**静止フレーム**を同期プレビュー窓へ（`activeLineIndexAt`／場面射影から時刻→場面・行を解決・ScenePreview 流用）。**【実装済】** 実装時に決めたこと＝①**時刻→場面の橋渡しは `playheadFrameAt`（domain・射影を読むだけ）**に置き、そこから先（有効行・字幕区間・テロップ・アニメ時刻）は**場面編集/仕上がり確認/書き出しと同じ共有関数**で解決する（画面ごとに見え方をぶらさない・ADR-0026②/③）／②**遷移の重なりでは「あとから始まった場面」**を出す（静止1枚では2場面を混ぜられないため。ヘッドを右へ動かして場面が戻らない＝単調。**実出力はこの区間で2場面を混ぜる**点は近似であり、混ぜた絵は (2) の再生で扱う）／③**シークはルーラー（時間の目盛り）で受ける**（レーンで受けるとクリップの選択・ドラッグと取り合いになる。**ヘッドのドラッグ追従は (4) スクラブ**の範囲）／④**範囲へ収めるのは「時刻を持っている画面」の1か所**（描画のたびに導出。表示部品側でも収めると二重になり、取りこぼしが隠れる＝#561 と同じ轍）。押された素の値は保持し、やり直しで動画が元の長さに戻ればヘッドも元の位置へ帰る／⑤**ルーラーの役割は `slider`**（button ではない＝位置を持つ操作なので読み上げに現在位置が伝わり、←→ で1秒・Home/End で端へ動かせる。**この1秒は秒の入力刻み `SEC_STEP` とは用途が違う**＝あちらは尺を打ち込む刻み、こちらは見たい瞬間を探す粒度）。
2. **連続再生**：グローバル秒の再生ループ（映像フレーム送り＋行音声/BGM/SE のスケジューリング・場面またぎ・遷移重なりの表示）。
3. **lines 導線**（上記＝選択→編集元ジャンプ／声の作成・作り直し／ヘッド→有効行の同期）。**(1)〜(3)＝α-5 最小到達点**。
4. **スクラブ**：ヘッドのドラッグ中に追従描画（オンデマンド＋キャッシュ・間引き＝非力PC）。
5. **再生ヘッド吸着**：③(6) `snapTargetsFor` に再生ヘッド位置を追加（クリップ端をヘッドへ）。
6. **再生中編集の安定化**：編集で射影が変わったときの再スケジュール。
7. **動画スロットの per-use 範囲＋タイムラインからのトリム**（ADR-0024 (1)＝同じMP4を場面ごとに別範囲・schema バンプは実装PRで）。
8. **SE/平行音声トラック**：#258 と合流（overlay `track` enum 拡張＝ADR-0024 (2)・`11 §7.1.4` 追補）。
9. **音まわり統合**：#257/#259 を統合UIから。

### 周辺方針（一般的な動画エディタ要素の扱い・利用者合意 2026-07-02）
**今決める（規範）**：
1. **時間精度/fps**：**秒（実数）＝正準**（`durationSec` 等は既に秒＝schema 変更なし）。**フレーム＝出力時の量子化**とし、描画・書き出し（テロップ `enable`／xfade offset）・④の per-frame・本ADRの再生エンジンは**同一のフレーム格子（既定 30fps）**に丸めて評価する。`videoSettings.fps` は現状 **`const: 30`**（`schemas/project.schema.json`）で固定運用＝UI 非公開。fps の可変化は将来（**`const` を外す＝schema バンプが必要**・`11.1` 破壊的変更ルール）。
2. **トラックのミュート/ソロ**：再生エンジンの**一時状態（正準外・保存しない＝派生状態）**として段階(2)に含める。ロックは将来。
3. **プロジェクト自己完結**：ADR-0024 (6) の原則に従う（素材込み自己完結・例外＝ユーザーテンプレ/同梱物）。
4. **素材欠損**：`15_ERROR_STATE_MODEL` の状態として扱い「次の行動」（差し替え/削除）を提示（`§2-5`）。**再リンク専用UIは α-6 に前倒し**（当初「将来」→α-6/α-7 再編〔2026-07-02 利用者合意〕で解除＝#347。同一 `assetId` のままファイル差し替え＝紐付け全維持・ADR-0024 の Asset=源泉が根拠）。

**計画済み（参照）**：自動保存＝#256（α-4）／復元ポイント＝#263（**α-7 へ移動**・α-6/α-7 再編）／波形・サムネイル列＝#332（α-5・ADR-0024(4)）。

### 対象外（将来・§10 と同旨）
音声認識による自動字幕・自動シーン検出・複数ナレーショントラックの完全実装（方向は ADR-0024 (5)）・波形の高度編集・カラー補正・クロマキー・マルチカメラ・破壊的な素材分割。**周辺整理（2026-07-02）で将来送り**：プロジェクトの素材込みアーカイブ（ADR-0021 の将来 bundle と合流）・書き出しカスタムプリセット・トラックロック・字幕ファイル入出力（**SRT 書き出しは `compileTimeline` から機械生成可能**な将来小機能・取り込みは対象外）・素材クリップ単位のクロップ/リフレーム（ADR-0024 per-use 上書きの将来フィールド・**α-6/α-7 再編でも将来のまま**＝描画＋FFmpeg 両経路の重量級）。
**α-6/α-7 再編（2026-07-02・利用者合意）での変更**：①**再リンク専用UI＝α-6 へ解除**（#347・上記4）②**タイムラインマーカー・フリーズフレーム専用化＝α-7 の余力バッファ候補**（#356・着手しない判断も正。マーカーは `timelineOverlay` への任意追加＝schema マイナーバンプの枠を維持）。α-7＝β前の締め・安定化フェーズ（機能追加は原則なし：検証マトリクス #352／性能 #353／文言監査 #354／配布前確認 #355）。

### ④（ADR-0019）との連結
④の未解決2「プレビューのパリティ戦略」は、**本ADRの統合再生を見込んで決定**する：正本プレビュー（再生/最終確認）は export と同じ per-frame 描画に寄せ、編集中の追従（スクラブ）は間引き・キャッシュで軽くする——という二層を推奨（数値補間は単一の `layoutScene(t)` を共有＝パリティ担保）。④実装の着手時にこの方針で確認する。

## 結果・影響

- **コード（α-5）**：`renderer/preview` にグローバル再生エンジン（純粋な時刻解決は domain へ・§7 テスト）／`app` のタイムライン編集画面に同期プレビュー窓・再生ヘッド。**動画スロットの同期再生部品は #432【実装済】で先行**＝`ScenePreview` の `SlotVideo`（下SVG/video要素/上SVG の3層・`splitVideoSceneSvgMulti` 共有・clipStart/speed/clipEnd/元音声を反映）。α-5 の同期プレビューはこの video 同期をグローバル時刻 t に載せて流用する。
- **正典**：schema への影響は原則なし（再生は派生状態）。段階6の SE トラックのみ overlay `track` enum 拡張＝**schema マイナーバンプ＋無変換移行＋`11 §7.1.4`/`§8` 追補**（実装PRで）。`CLAUDE.md §10`「本格タイムライン編集」の注記を α-5 実装着手時に段階解除へ更新。`§11` には本ADRを Proposed として追記（本PR）。
- **α-5 の編成**：本EPICを主軸とし、#257/#258/#259 は部品/兄弟として合流。#260（素材ライブラリ）/#261（フォント）/#262（カーブ編集）は独立のまま。
