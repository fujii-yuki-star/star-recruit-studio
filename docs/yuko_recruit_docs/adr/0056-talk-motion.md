# ADR-0056: 喋っている間、立ち絵が動く（声の列と立ち絵を結ぶ）

- **状態**: Accepted
- **日付**: 2026-10-07
- **関連**: #1367（#1135 の作例で詰まった所 #2・#1335 提案E＝話者↔立ち絵・利用者判断 2026-10-07＝α に入れる・ADR から）／ADR-0001（描画の核は1つ）／ADR-0019（キーフレーム）／ADR-0032（場面形式は凍結・タイムライン形式は別の文書）／ADR-0034（業界の型）／#1349（動きのひな形）／`11_TIMELINE_REFERENCE §7.6`／`CLAUDE.md §10`（口パクはやらない）

## コンテキスト

漫才・解説系の動画の定番は、**立ち絵が、自分の声が鳴っている間だけ揺れる／はねる**こと（口パクの代わり。
ゆっくり系の「立ち絵が喋ると揺れる」）。いまはそれを**行ごとにキーフレームで手打ち**するしかない。
#1135 の作例（3人・21行）では、弾みのキーフレームを**21行ぶん手で打った**。#1349 の「強調：はねる」は
再生位置で1回ずつ当てるもので、**声の出入りには付いて来ない**（台詞の長さを変えると打ち直し）。

掛け合いの作りやすさ（#1135 の見たいこと③）に直結するので、**声と立ち絵を1か所で結ぶ**道を作る。

## 判断軸

1. **1か所で決めて、台詞を足しても直しても付いて来る**（行ごとに打ち直さない）。
2. **描画の核は1つ**（ADR-0001）＝プレビューと書き出しが同じ関数で動きを出す。
3. **手で打った動きを壊さない**＝キーフレームの上に**足す**（置き換えない）。
4. **場面形式は凍結**（ADR-0032）＝タイムライン形式だけ。
5. **口パクとは別物**（`CLAUDE.md §10`＝MVP でやらない）＝絵は1枚のまま、位置・大きさだけ動かす。

## 検討した選択肢

| 論点 | 選択肢 | 評価 |
|---|---|---|
| 何と結ぶか | (A) **音の列**（その列の声が鳴っている間） | **採用**。掛け合いは話者ごとに列を分けるのが自然（作例も、業界の型も）。台詞を足しても同じ列に置けば付いて来る |
| | (B) 声の**話者**（VOICEVOX の speaker） | 同じ話者を別のキャラに使う／既定の話者を継ぐ、が起きる＝取り違える |
| | (C) 声の部品を1つずつ指す | 台詞を足すたびに結び直す＝手打ちと変わらない |
| | (D) 字幕の部品と結ぶ | 字幕を使わない動画で使えない |
| どちらが持つか | (A) **映像の部品**（立ち絵）が「どの列の声で動くか」を持つ | **採用**。動くのは立ち絵なので、立ち絵の設定欄で決めるのが分かりやすい（1つの声の列で2つの絵を動かすこともできる） |
| | (B) 音の列が「どの絵を動かすか」を持つ | 絵を差し替える（表情）たびに結び直す |
| いつ動くか | (A) **その列の声の部品が生きている間**（時刻だけで決める） | **採用**。声を作る前でもプレビューで動く。隠した部品・隠した列は数えない |
| | (B) 実際に鳴っている音の大きさ（音量）で動かす | 波形の解析が要る・プレビューと書き出しで一致させる手間が大きい＝後で |
| 動き方 | **はねる**（台詞の頭で1回小さく跳ねる）／**ゆらゆら**（喋っている間、上下にゆれる）／**ふくらむ**（喋っている間、少し大きくなったり戻ったり）＋**強さ** | 3つから始める（作例で手打ちしたのは「はねる」）。強さは倍率（既定 1） |
| 重ね方 | (A) **キーフレームの上に足す**（ずれは足し、大きさは掛ける） | **採用**＝飛ぶ・回るなどの手打ちの動きと同時に効く（#1349 の強調と同じ考え） |
| | (B) その間はキーフレームを止める | 手で作った動きが消える |
| 書き出し | (A) **動く部品として扱う**（区間割りでは毎コマ焼く側） | **採用**＝正しい絵が出る。⚠️ 速さは落ちる（下の「未解決」） |

## 決定

1. **タイムライン形式の映像の部品**に **`talkMotion`**（任意）を持たせる：
   - `trackId`＝**音の列**の id（その列の**声の部品**が生きている間に動く）
   - `kind`＝`bounce`（はねる）／`bob`（ゆらゆら）／`pulse`（ふくらむ）
   - `strength`＝強さ（倍率・既定 1・0 より大きい）
2. **いつ**＝その列の声の部品（`kind:'voice'`）が `[startSec, startSec+durationSec)` に入っている時刻。**隠した部品・隠した列は数えない**。声を作ったかどうかは見ない（作る前でもプレビューで動く）。
3. **動きの形**（強さ 1 のとき・数は定数に1か所）：
   - はねる＝声の部品の頭から 0.12 秒で 16px 上がり、0.30 秒で戻る（作例の手打ちと同じ）
   - ゆらゆら＝喋っている間 `y = −A·|sin(2π·f·t)|`（A＝10px・f＝2.5Hz）。頭と終わりは 0.1 秒でなめらかに入る・抜ける
   - ふくらむ＝喋っている間 `scale = 1 + B·|sin(2π·f·t)|`（B＝0.03・f＝2.5Hz）。入り・抜けは同上
   - 同じ時刻に同じ列の声が2つ生きているときは、**先に始まったほう**で数える（重ねて2倍にしない）
4. **重ね方**＝その部品の**キーフレームの結果の上に足す**（縦のずれは足す・大きさは掛ける）。まとまりの動きの後、部品自身の動きと同じ段で効く。
5. **描画の核は1つ**＝`talkMotionAt(doc, clip, t)`（domain・純粋）が足す量を返し、`layoutTimelineAt`（プレビュー＝書き出し）が使う。
6. **書き出し**＝`talkMotion` を持つ部品は**動く部品**として扱う（区間割り `planTimelineExportSegments` の「動きがある」に入れる）。
7. **画面**＝映像の部品の欄に「**喋っている間の動き**」：声の列・動き方（なし／はねる／ゆらゆら／ふくらむ）・強さ。⚠️ 列の名前で選ぶ（技術語を出さない）。
8. **場面形式は対象外**（凍結）。焼き出しでは作らない（場面形式に同じ概念が無い）。
9. **口パクではない**（絵は1枚のまま）。
10. **結びを黙って失くさない・行き先の無い結びを作らない**（PR #1370 レビュー）：
    - 見た目パターンの部品を**バラす**＝はねる・ゆらゆら（縦にずらすだけ）は**全部の部品へ写す**（同じ絵）。**ふくらむはバラさない**（部品ごとの中心でふくらむ＝別の絵・`TIMELINE_EDIT_EXPLODE_TALK_PULSE`）
    - **列を消す**＝その列を指す結びを外す（同じ番号で作り直した列で勝手に動かない）
    - **貼り付け**＝貼る先に声の列が無ければ結びを持ち込まない
    - **検証**＝指す列が無い／音の列でない（外の AI の文書など）は `TIMELINE_TALK_MOTION_TRACK_NOT_FOUND` で知らせる（黙って動かなくしない）

## 結果・影響

- schema：`timeline-project.schema.json` の `TimelineClip` に `talkMotion` を追加＝**timeline 1.15→1.16**（任意追加＝無変換）。場面形式（project）は変えない。
- domain：`talkMotionAt`（新規・§7 テスト対象）・`edit.ts`（設定する編集）・`exportSegments.ts`（動く部品に数える）・`validateTimelineDoc`（指す列が無い／音の列でない＝注意）
- renderer：`layoutTimelineAt` で足す（ADR-0001）
- 画面：`TimelineProjectScreen`（選んだ部品の欄）
- 正典：`11_TIMELINE_REFERENCE §7.6`・`06`・`18`（外の AI も書ける）・`11 §1`（版の表）を実装の PR で直す
- 作例（#1135）で手打ちの弾みを置き換えて比べる

## 未解決の論点

- **書き出しが遅くなる**＝立ち絵は動画の最初から最後まで居ることが多いので、`talkMotion` を持つと**その間ずっと毎コマ焼く**ことになる。喋っていない区間は静止なので、「喋っている区間だけ動く部品」として区間を割れば速くなる＝実装後に実測して決める（#353 と同じ線）。
- 実際の音量で動かす（声の大きさに合わせて揺れる）＝要望が出たら。
- 表情の差し替え（喋るとき口の開いた絵にする＝口パクに近い）＝`CLAUDE.md §10` の除外と関係するので、やるなら別の ADR。
