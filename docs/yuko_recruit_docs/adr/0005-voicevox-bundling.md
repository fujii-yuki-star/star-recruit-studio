# ADR-0005: VOICEVOX エンジンの同梱と自動起動

- **状態**: Accepted（2026-06-13 承認）
- **日付**: 2026-06-13
- **関連**: [`0003-narration-voice.md`](0003-narration-voice.md) / `13_DEPENDENCIES_AND_LICENSING.md §4,§5,§9` / `06_UI_SPEC.md §15` / `CLAUDE.md §3,§11`

---

## コンテキスト

ナレーションは **VOICEVOX:ずんだもん**（ADR-0003）。MVP段階では、ローカルの VOICEVOX エンジンへ `VoiceProvider` 越しに HTTP 接続する実装で進めており、開発者は VOICEVOX を別途起動し、必要に応じて設定画面で接続先URLを指定していた（`13 §4` / `06 §15`）。

しかしエンドユーザーに「VOICEVOX を自分でインストールして起動し、接続先を設定させる」のは受け入れがたい体験であり、リリース後の通常フローにすべきでない。エンジンの**同梱可否・接続方式は `13 §4` / `CLAUDE.md §11` で未決定**として残されていた。

2026-06-13、VOICEVOX ソフトウェア利用規約および各キャラクター（ずんだもん）規約を確認し、**エンジンの同梱・配布とアプリからの自動起動が可能**と判断した（チーム確認）。これを受けて方針を確定する。

## 検討した選択肢

- **(A) エンジンを同梱し、アプリ起動時に自動起動**（ユーザーは導入・起動・接続設定をしない）【採用】
- (B) 別途インストール案内＋接続（ユーザーが VOICEVOX を導入・起動）— MVPの暫定。UXが悪く、リリース向けには不適。
- (C) クラウド音声合成 — ADR-0003（ずんだもん＝ローカル VOICEVOX）と方針不一致。コスト・プライバシー・オフライン性で不利。**不採用**。

## 決定

> **VOICEVOX エンジンをアプリに同梱し、アプリ起動時に自動起動する（A）。** エンドユーザーは VOICEVOX の導入・起動・接続先設定を一切しなくてよい。
> 設定画面の「接続先」は、別ポート／別PC／別途起動したエンジンに繋ぐための**上級者向けフォールバック**として残す（既定＝同梱エンジン）。
> ナレーション音声は ADR-0003 のとおり **VOICEVOX:ずんだもん**。**クレジット常時表示の義務は維持**（`13 §4`・About画面）。

## 結果・影響

- `VoiceProvider`／接続方式の抽象は不変（`infrastructure/voicevox` 越し）。接続先の解決順序は **設定URL ＞ 同梱エンジン（自動起動）＞ 既定 `localhost:50021`**。
- 配布物にエンジンバイナリが含まれ、**インストーラのサイズが増える**。アプリが**エンジンプロセスのライフサイクル**（起動／終了／ポート競合回避／起動完了待ち）を担う。
- クレジット（`VOICEVOX:ずんだもん`）表示は引き続き必須。
- `13 §4` の未決定「同梱可否」をクローズ。`CLAUDE.md §11` を決定済みへ更新。`13 §9` チェックリストの当該項目を反映。

## 規約・ライセンスの根拠（#122・2026-06-22 確認）

「何を同梱するか」で規約・ライセンスが分かれるため、本 ADR が前提とする形態を明記する。

- **同梱するのは VOICEVOX ENGINE（HTTP API サーバ＝裏方）であり、一般向けエディタ（GUI アプリ本体）ではない。**
  - **ENGINE の組み込み再配布は許諾内**：VOICEVOX ENGINE の利用規約・許諾内容に「アプリケーションに組み込んで再配布することができます」と明記。裏方の ENGINE を自社ソフトに同梱・配布することは公式に認められている。
  - **エディタ本体の再配布は禁止**：一般向け配布物（インストーラ等）をそのまま同梱するのは利用規約の禁止事項「本ソフトウェアの全てまたは一部を無断で再配布すること」に該当＝**採用しない**。
- **コードのライセンス**：VOICEVOX ENGINE は **LGPL-3.0 ＋（ソース公開不要の）別ライセンスのデュアル**。本アプリは ENGINE を**独立した HTTP サーバプロセス**として起動・通信し、自社バイナリにリンクしないため、**自社の独自コードは LGPL の copyleft に汚染されない**。LGPL 対応は **FFmpeg と同型**（[`0002-ffmpeg-codec.md`](0002-ffmpeg-codec.md) / [`0013-h264-via-media-foundation.md`](0013-h264-via-media-foundation.md)）＝**ソース入手手段の提示＋使用バージョン pin＋クレジット**で満たす。さらに強化が必要なら ①自前ビルド ②別ライセンスを著作者へ要請 のいずれか。
- **voicevox_core（MIT）も検討したが不採用**：ENGINE 方式で規約・実装とも成立する（HTTP 連携は実装済み）。core 直結は FFI＋ONNX＋モデル/辞書同梱への作り直しを要するため、**規約上 ENGINE 配布が不可と判明した場合のフォールバック**に留める。
- **キャラクター音声モデルは個別規約**（ENGINE/core いずれでも共通）：同梱する全キャラ（既定＝ずんだもん）の**商用利用可否を個別に確認**し、**エンドユーザーにも**各キャラ規約・クレジットの遵守を**自社の利用規約で義務付ける**（ENGINE 規約の許諾条件）。**VOICEVOX クレジット常時表示**は維持（[`0003-narration-voice.md`](0003-narration-voice.md)・About 画面）。

> これにより下記「未解決の論点」3（規約の具体条項の記録）を解消。残る実装詳細（同梱ビルド選定・プロセス管理・動的ポート＝論点1,2）は **#149**（ENGINE 同梱実装）で扱う。

## 未解決の論点（実装・配布の詳細）

1. 同梱するエンジンビルドの選定（CPU/GPU版・対応OS・サイズ最適化）。→ **#149**。
2. 起動方式（sidecar として同梱／初回展開）・**ポート競合時の動的ポート**・起動完了の**ヘルスチェック**・アプリ終了時のプロセス終了。→ **#149**。
3. ~~規約の具体条項の記録~~ ＝ 上記「規約・ライセンスの根拠」節に記録済み（#122）。配布時の**最終法務確認**・エンジンの**バージョン固定**は配布パッケージング時。
4. 既存のインストール済み VOICEVOX を優先利用する余地を持たせるか（任意）。→ #149 の起動失敗フォールバックで考慮。
