# ADR-0067: タイムライン形式の列ごとの音量とソロ

- **状態**: Accepted
- **日付**: 2026-10-20
- **関連**: [`ADR-0034`](0034-timeline-interaction-model.md)（業界の型・未解決5）／[`ADR-0001`](0001-rendering-parity.md)（プレビュー＝書き出し）／[`ADR-0050`](0050-preview-popout-window.md)（別窓の操作の分類）／[`ADR-0043`](0043-alpha-beta-scope-and-general-backlog.md) ⑤（α-8）／#1476／`src/domain/timeline/audio.ts`・`export.ts`

## コンテキスト

どの動画編集ソフトにもある**列（トラック）ごとの音量**と**ソロ（その列だけ聞く）**が無い（ADR-0034 未解決5）。
いまある列の切り替えは「動画に出さない」（`hidden`＝音の列では無音・書き出しにも効く＝業界の「ミュート」）と「固定」だけ。
BGM の列をまとめて下げたい・声の列だけ聞いて確かめたい、ができない（部品を1つずつ直すしかない）。

## 判断軸

- 業界の型（ADR-0034）＝Premiere Pro・DaVinci Resolve の列の頭（M／S／鍵）とミキサーの列の音量。
- **プレビュー＝書き出し**（ADR-0001）＝音量は聞いた音と書き出した音で同じ。
- **書き出しで黙って音が消えない**（§2-5）。

## 検討した選択肢

| 選択肢 | 評価 |
|---|---|
| (A) **音量は文書に持って書き出しにも効かせる・ソロは編集中の聞き方だけ（保存しない）** | 音量＝ミキサーの列の音量（書き出しに出る）。ソロ＝確かめるための道具。ソロを付けたまま書き出して**音が消える**事故が起きない。**採用** |
| (B) ソロも文書に持ち、書き出しにも効かせる | 付けたままにすると書き出しで他の列が無音になる（気づきにくい）。不採用 |
| (C) 列の音量を部品の音量へ書き込む（一括で直す） | 部品の設定を壊す・戻せない・後から足した部品に効かない。不採用 |

## 決定

1. **列の音量**＝`Track.volume`（timeline schema 1.20→1.21・任意・未指定＝1＝100%・値域は部品の音量と同じ 0〜1.5＝`clampVolume`）。
   **音の列だけ**に効く＝その列の音の部品（読み上げ・BGM・持ち込みの音）の実効音量に**掛ける**。
   - 再生＝`audioCuesAt` が掛ける（`trackGainOf`）。書き出し＝`timelineAudioRuns` が一定の音量と音量の変化の点の両方に掛ける。
   - ⚠️ **部品の音量の線（#1266）には入れない**＝線は部品自身の設定（業界の型＝部品の音量とミキサーは別）。
   - ⚠️ 映像の列（動画の元の音）には効かせない＝列の音量は音の列のミキサー（映像の列には出さない）。
2. **ソロ**＝**編集中の聞き方だけ**（文書に持たない・保存しない・取り消しの履歴に載せない・書き出しに効かない）。
   1つでもソロの列があれば、**ソロでない音の列と動画の元の音を鳴らさない**（複数の列をソロにできる＝業界の型）。
3. **画面**＝音の列の頭に「ソロ」の切り替え（いまの「動画に出す／出さない」「固定」の並び）。列の音量は列の「⋮」の
   「この列の音量」から列の頭で直す。**100% でないときは列の頭に値を常に出す**（いまの状態が分かる）。
4. 別窓（ADR-0050）＝音量は本体へ送る（ほかの文書の編集と同じ）。ソロは音を鳴らす本体だけの状態＝受けない。

## 結果・影響

- schema（timeline 1.21）・`11 §7.6`・`06`（列の頭）。`18` は列の欄を並べていない（schema と `11` を見る）ので直さない。
- ⚠️ **部品の音量×列の音量は掛けたあとで値域（1.5）へ収める**（再生・書き出しの一定の音量・音量の変化の点で同じ上限）。
- ⚠️ **消した列のソロは外す**（列の番号は使い回すので、残すと後で足した列が勝手にソロになる）。隠した列だけをソロにすると何も鳴らない＝業界の型（ミュートが優先）。
- 移行なし（任意追加）。

## 未解決の論点

- 列の音量にキーフレーム（ミキサーの自動化）を持たせるか＝使われ方を見てから。
- 映像の列に入っている動画の元の音を列で下げる道（いまは部品ごとの「元の音の音量」）。
