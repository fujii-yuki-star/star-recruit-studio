# ADR-0003: ナレーション音声とゆうこの関係

- **状態**: Accepted（2026-06-10 承認）
- **日付**: 2026-06-10
- **関連**: `13_DEPENDENCIES_AND_LICENSING.md §4,§5` / `17_YUKO_CHARACTER_SPEC.md` / `01 §8.3`

---

## コンテキスト

既定のナレーション音声に **VOICEVOX:ずんだもん** を用いる。画面マスコット「ゆうこ」（**自社保有**）と声の関係が論点だった（`13 §5`：別名キャラの声を“そのキャラの声”として用いると、なりすまし・誤認の懸念がありうる）。

## 検討した選択肢

- (A) ずんだもんの声を「ゆうこ固有の声」として提示 → 別キャラの声を当てる/なりすましの懸念。**不採用**
- (B) **ずんだもんを「ナレーター音声」として用い、ゆうこは画面上の案内役** → 標準的なVOICEVOX利用。**採用**
- (C) 最初からゆうこ専用ボイス → MVPでは過剰。将来の選択肢（`01 §8.3`）

## 決定

> **ずんだもんは「ナレーター音声（VOICEVOX:ずんだもん）」として用いる。** ゆうこは自社マスコット（画面上の案内役）であり、ずんだもんの声を“ゆうこ固有の声”とは称さない。
> **「VOICEVOX:ずんだもん」クレジットを常時表示**（アプリのクレジット画面＋任意で書き出しに焼き込み）。原作者の承認・なりすましを装わない。声は `VoiceProvider` 抽象化で将来差し替え可能にする。

## 結果・影響

- `13 §5` の「別キャラの声を当てる」懸念が解消し、標準的なVOICEVOX利用に整理。
- **クレジット表示が実装要件**（`13 §9`）。
- 声設定UIの表現は「ナレーター音声」を基本とする（`06 §14.2` の文言に反映）。
- ゆうこ専用ボイス等は将来拡張（`17 §7`）。

## 未解決の論点

- ずんだもん（東北ずん子・ずんだもんプロジェクト）規約・VOICEVOX規約の通読。商用配布時の最終確認は継続（規約は変わりうる）。
