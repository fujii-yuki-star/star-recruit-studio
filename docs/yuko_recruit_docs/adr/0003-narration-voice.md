# ADR-0003: ナレーション音声とゆうこの関係

- **状態**: Accepted（2026-06-10 承認・2026-06-25 #177 で複数話者の選択可へ更新＝下記「更新」）／**「常時表示・OFF なし」は [`adr/0025`](0025-credit-display-modes.md) で一部 Superseded**（2026-07-03・表示方式を選べる＋非表示可へ。**About 画面のクレジット必須は不変**）。
- **日付**: 2026-06-10
- **関連**: `13_DEPENDENCIES_AND_LICENSING.md §4,§5` / `17_YUKO_CHARACTER_SPEC.md` / `01 §8.3` / [`adr/0025`](0025-credit-display-modes.md)（クレジット表示方式）

## コンテキスト

既定のナレーション音声に **VOICEVOX:ずんだもん** を用いる。画面マスコット「ゆうこ」（**自社保有**）と声の関係が論点だった（`13 §5`：別名キャラの声を“そのキャラの声”として用いると、なりすまし・誤認の懸念がありうる）。

## 検討した選択肢

- (A) ずんだもんの声を「ゆうこ固有の声」として提示 → 別キャラの声を当てる/なりすましの懸念。**不採用**
- (B) **ずんだもんを「ナレーター音声」として用い、ゆうこは画面上の案内役** → 標準的なVOICEVOX利用。**採用**
- (C) 最初からゆうこ専用ボイス → MVPでは過剰。将来の選択肢（`01 §8.3`）

## 決定

> **ずんだもんは「ナレーター音声（VOICEVOX:ずんだもん）」として用いる。** ゆうこは自社マスコット（画面上の案内役）であり、ずんだもんの声を“ゆうこ固有の声”とは称さない。
> **「VOICEVOX:ずんだもん」クレジットを常時表示**（アプリのクレジット画面＋**書き出し動画への常時焼き込み**＝OFF は設けない＝#153）。原作者の承認・なりすましを装わない。声は `VoiceProvider` 抽象化で将来差し替え可能にする。

## 結果・影響

- `13 §5` の「別キャラの声を当てる」懸念が解消し、標準的なVOICEVOX利用に整理。
- **クレジット表示が実装要件**（`13 §9`）。**書き出し動画には常時クレジットを焼き込む**（renderer 共有＝プレビューにも表示・単一文言 `domain/voice/narratorCredit.ts`・OFF なし）＝#153。
- 声設定UIの利用者向け表現は「**読み上げの声**」を基本とする（当初「ナレーター音声」としていたが、設定・ウィザードUIではより自然な利用者表現へ変更＝PR #106）。**クレジット／帰属の文脈では引き続き「ナレーター音声（VOICEVOX:ずんだもん）」と表記**する（このアプリ画面・書き出し焼き込み）。`06 §14`・各画面の文言に反映。
- ゆうこ専用ボイス等は将来拡張（`17 §7`）。

## 更新（#177・複数話者の選択可）

> **単一キャラ固定（ずんだもん）をやめ、規約確認済みの VOICEVOX 標準キャラから既定ボイスを選べる**ようにする（既定は引き続きずんだもん）。**クレジットは選択キャラに連動して動的に「VOICEVOX:＜キャラクター名＞」を常時表示**（書き出し焼き込み＋プレビュー＋About。OFF なしは不変）。

- 提供するキャラは**規約確認済みの標準キャラに限定**（`domain/voice/voiceCatalog.ts` のカタログで統制）。各キャラの利用規約・クレジット表記義務を満たす（`13 §4,§5`）。
  - **カタログ追加の基準**：VOICEVOX 標準同梱キャラのうち、各権利者規約で「商用利用可・クレジット表記（`VOICEVOX:＜キャラ名＞`）で利用可」を確認できたもののみ。**キャラ規約は VOICEVOX ソフト規約とは別**（権利者規約が優先・`13 §4`）＝追加時は各キャラの権利者規約（配布元）を都度確認する。商用配布前の最終確認は §「未解決の論点」を継続。
- 実装：選択は `voiceCatalog`（`VOICE_CATALOG`／`characterForSpeaker`）→ 設定（appSettings の speaker 番号）。クレジットは `narratorCredit.creditForSpeaker(speaker)`（単一参照元）。書き出し（`buildExportScenes`/`splitVideoSceneSvg`）は `credit` を引数で受け取り焼き込む（renderer は infra 非依存＝app 層で解決して渡す）。
- 複数話者の同時使用（掛け合い＝セリフ別ボイス）は **#180 で導入**し、その際に**使用した全話者を列挙**してクレジットする（本 ADR の「常時クレジット」を踏襲）。

## 未解決の論点

- ずんだもん（東北ずん子・ずんだもんプロジェクト）規約・VOICEVOX規約の通読。商用配布時の最終確認は継続（規約は変わりうる）。
