## コンテキスト

現状は ADR-0003／#153 に従い、選択話者に応じた `VOICEVOX:＜キャラ名＞` を**動画右下に常時焼き込み**（OFF なし）している。完成動画として見ると常時表示が邪魔になるケースがある。

正典の事実（`13 §4`）：VOICEVOX の**必須要件はクレジット表記**（形式 `VOICEVOX:キャラ名`）で、**アプリの場合は紹介・アバウト画面等に記載**する、というもの。**動画への「常時」焼き込みは必須要件ではなく**、ADR-0003／#153 の保守的判断だった（`13 §5`：エンドユーザー〔採用企業〕の商用動画にクレジットを「手順案内」でなく「自動付与」で担保する目的）。

利用者（事業側）判断（2026-07-03）：**社内の採用動画運用が主用途**であり、非表示＋概要欄記載の運用も許容したい（VOICEVOX 公式 Q&A・各キャラ規約の読みでも、動画内に**常時表示し続けることまでは必須でない**と解釈）。道楽以外の目的で「非表示かつ未記載」になる可能性は低いと判断する。

## 判断軸

1. **規約適合**：About 画面のクレジット（必須要件）は不変で維持。動画側は「自動付与されていれば表記義務を満たす」読みに沿う。
2. **エンドユーザー動画へのクレジット担保**（`13 §5`）：始端/末尾でも自動付与なら担保される。非表示を許す場合は概要欄運用の補助を用意する。
3. **パリティ**：プレビュー＝書き出しの表示一致（ADR-0001）。
4. **非技術者UX**（`§2-3`）：技術用語を出さない選択肢文言。
5. **掛け合いの網羅**：複数話者（行ごとの声）を漏れなくクレジット。

## 検討した選択肢

| 選択肢 | 評価 |
|---|---|
| (A) 常時焼き込みのまま（現状・ADR-0003） | 最も保守的だが完成動画で邪魔。利用者要件に合わない。 |
| (B) 表示方式を選べる（常時/最初/最後/両方）・**非表示は不可** | 自動付与を常に担保。当初の推奨。ただし社内運用での柔軟性に欠ける。 |
| (C) **表示方式を選べる＋非表示も許可（概要欄運用の補助つき）【採用】** | 利用者判断に合致。About 必須は維持し、非表示時はコピー導線＋注意で補助。 |

## 決定

> **動画のクレジット表示方式を選べるようにする（既定＝最初と最後）。About 画面のクレジットは必須として不変。非表示も許可し、その際は概要欄運用を補助する。**

1. **表示方式（5種）**：**常時 / 最初の数秒 / 最後の数秒 / 最初と最後 / 非表示**。**既定＝最初と最後**。
2. **About 画面のクレジット**（`VOICEVOX:＜使用キャラ全列挙＞`）は**必須として不変**（`13 §4` の核心要件）。表示方式の設定に依らず常に表示。
3. **非表示を許可**（利用者〔事業側〕判断・社内利用）。緩和策：
   - **注意導線**：非表示を選んだとき「動画にクレジットが入りません。公開時は概要欄などに記載してください」（`15` 準拠・「次の行動」）。
   - **コピー導線**：**そのプロジェクトで使用している VOICEVOX の一覧を文字列でコピーできる**（概要欄へ貼り付け用）。About／設定・書き出し導線に置く。
4. **掛け合いの網羅**：クレジット文言は**場面の話者＋各行の話者（掛け合い）を集約**する（行ごと＝`creditForLine`／プロジェクト横断の全列挙＝`usedVoiceCredits`）。始端/末尾の列挙・About・コピー文字列も同じ集約を使う（単一参照元・`§2-7`）。
5. **preview＝export の一致**：表示区間の定義（**先頭場面の [0,N]／末尾場面の [尺−N,尺]**）を preview/export で共有する。書き出しは既存の**テロップ overlay 機構（`enable='between(t,S,E)'`）を再利用**。プレビューの区間追従は α-5 の再生ヘッド（ADR-0023）があると素直で、α-6 実装時に確定する。

## 結果・影響

- **正典（実装＝α-6 で反映）**：
  - `videoSettings` にクレジット表示設定（表示方式 enum ＋ 秒数 N）を追加＝**schemaVersion マイナーバンプ＋無変換移行**（`§5`/`11 §1`）。既存プロジェクトは無いため既定は「最初と最後」で可（後方互換の懸念なし）。
  - **ADR-0003 の「常時表示・OFF なし」を本ADRが一部 Superseded**（About 必須は維持）。ADR-0003 に追記でリンク。
  - `13 §4/§9` の「書き出し動画に常時焼き込み・OFF なし」記述を「**選べる表示方式・About 必須維持・非表示は概要欄運用＋コピー導線で補助**」へ改訂。
  - `CLAUDE.md §11` に本ADRを追記。
- **実装（α-6・#359）**：クレジットを**時間区間つきの overlay** として扱う（常時＝全区間／最初・最後＝該当区間／非表示＝出さない）。集約ヘルパ（プロジェクト使用 VOICEVOX 全列挙・掛け合い含む）は **#251（About 集約）と共有**。コピー用文字列は同ヘルパから生成。
- **AI（`12`）**：変更なし。

## 未解決の論点（実装 PR で確定）

1. **N（数秒）の既定値・範囲**（例：既定 3 秒・1〜10 秒程度）。
2. **非表示時の注意/確認導線の粒度**（毎回か初回のみか・書き出し前チェック `15` との連携）。
3. **区間表示の実装場所**：書き出しはテロップ overlay 再利用で確定。プレビューの時間区間追従は α-5 再生ヘッドの有無で表現が変わる（α-6 実装時に確定）。
4. **規約適合の最終確認**は事業側判断（`13` 未解決の「規約通読は継続」に沿う。非表示許可の根拠を本ADRに記録済み）。
