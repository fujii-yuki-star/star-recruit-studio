# ADR-0031: 同時2ボイス（並行音声・α-4 最小形＝同時開始）

- **状態**: Proposed
- **日付**: 2026-07-14
- **関連**: [`ADR-0015`](0015-dialogue-timeline-model.md)（掛け合い＝逐次のセリフ列） / [`ADR-0024`](0024-non-destructive-editing-model.md)（「並行音声は amix パス新設が前提」） / [`ADR-0023`](0023-integrated-timeline-editing.md)（統合タイムライン・α-5・#258 SE/平行音声） / [`ADR-0029`](0029-free-subtitle-multi-and-binding.md)（字幕ボックス→話者紐づけ） / `ADR-0001`/`ADR-0026`（パリティ） / `CLAUDE.md §10/§11`

## コンテキスト
スモークで「**2人を同時にしゃべらせたい**（同時に2つの別々のボイスを流す）」要望（利用者・2026-07-14）。現状の掛け合い（ADR-0015）は `scene.lines[]` を**逐次**再生する（`sceneSegmentSpecs` が区間を順に連結＝単一音声トラック）。並行（重なる）音声は ADR-0024 が「**グローバル音声 amix パス新設が前提**」とし α-5（統合タイムライン・ADR-0023／#258）想定だった。

利用者方針＝「**プレビュータイムライン編集が絡まない改善は α-4 で全体的に終わらせたい**」→ 並行音声の**最小形（同時開始）**を 0.4.2 へ前倒し（利用者決定 **A**・2026-07-14）。開始オフセット等の時間軸編集は α-5 に残す。

## 判断軸
- §2-4 テンプレ駆動維持・非技術者 UX（簡易トグルで足りること）。
- パリティ（ADR-0001/0026）：プレビュー=書き出し=静止画=compileTimeline を同じ区間モデルで駆動。
- 既存正準経路（`sceneLines()`／`sceneSegmentSpecs`）を壊さない（additive）。
- α-4/α-5 境界：**時間軸編集（再生ヘッド/スクラブ/多トラックドラッグ）は α-5**（ADR-0023）。同時開始は α-4。

## 検討した選択肢（スコープ）
| 選択肢 | 評価 |
|---|---|
| **A 最小形・同時開始（採用）** | 2人同時「開始」＋amix＋字幕2段。編集は簡易トグル＝タイムライン非依存。α-4 で完結。 |
| B フル（開始オフセットも） | 「2つ目を◯秒ずらす」等。時間軸編集＝α-5 に一部踏み込む。0.4.2 が重い。 |
| C α-5 へ | 統合タイムライン（ADR-0023・#258）と一緒に。0.4.2 に含めない。 |

## 決定（Proposed・scope A・利用者決定 2026-07-14）
1. **モデル（additive）**：掛け合いの行に「**前のセリフと同時に開始**」を表す指定を足す（正確な形は未解決＝`NarrationLine.startWithPrevious?: boolean` か「同時グループ」か lane・要確認）。2行が同じ開始で並行。**開始オフセットは持たない**（同時のみ・α-4）。`project.schema` マイナーバンプ（additive・移行不要）。
2. **音声（核心・新設）**：並行する行を **amix でミックス**する書き出し経路を新設（現状の逐次単一トラックに対し、重なり区間は2ボイスを重ねる）。プレビューは2音を同時再生。ADR-0024 の「amix パス新設が前提」を α-4 で実装。音量は §6 のミックス規約＋（将来 #259 ノーマライズと整合）。
3. **字幕（ADR-0029 活用）**：2話者に**2つの字幕ボックスを紐づけ**（`subtitleSource={kind:'speaker'}`）、**既定字幕の上/下に重ならないよう自動配置（2段）**。自動字幕もこの2段で表示。
4. **正準経路の拡張**：`sceneSegmentSpecs`（現状「区間の列」＝逐次前提）を**重なりを表せる形**へ拡張し、プレビュー/書き出し/静止画/`compileTimeline` の4者が同じ拡張区間で駆動＝パリティ維持。**同時開始は正典 11 の検証ルール V18（`scene.lines[]` は `startSec` 昇順・時間重複なし＝警告/補正）と矛盾する**ため、V18 を「同時開始として明示された行の重複は許容」へ改める（実装PRで 11 §8・下記「未解決」）。
5. **編集UI**：簡易トグル（例「このセリフを前と同時に流す」）＝**タイムライン非依存**。再生ヘッド/スクラブ/多トラックは α-5（ADR-0023）。

## 結果・影響（実装は #524 マージ後・承認後）
- `schemas/project.schema.json`＋`11`：`NarrationLine` に同時開始指定を追加（版バンプ）。
- `domain`：`lineTimeline`（区間モデルを並行対応へ拡張）・音量ミックス（純粋関数・テスト対象＝§7）。
- `renderer/export`＋Rust：**amix 音声経路**（重なり区間の2ボイス合成）。preview：2音同時再生。
- `subtitle`：2段レイアウト（ADR-0029 連携・自動配置）。
- `SceneEditScreen`：同時開始トグル（簡易・§2-4）。
- 正典：**`11` の検証ルール V18（`scene.lines[]` は時間重複なし・§8/§9）を「同時開始の重複は許容」へ改定**（実装PRで・下記未解決）。並行音声は ADR-0024 で α-5（amix パス新設が前提）に位置づけていたのを A の範囲で α-4 へ前倒し（実装時に `§10`/`§11` へ具体を追記）。

## 未解決の論点（承認/実装時に確定）
- **正典 11 の V18（`scene.lines[]` は `startSec` 昇順・時間重複なし＝警告/補正・§9）をどう改定するか**（🔴 レビュー指摘）：同時開始として**明示された**行の重複だけを許容し、それ以外の（意図しない）重複は従来どおり警告/補正する条件を定める。**既存プロジェクトの補正誤爆を防ぐ**（同時開始指定の無い重複は補正・ありは温存＝「同時開始のはずが自動補正でずらされる」正典違反を作らない）。実装PRで `11 §8`/V18 を改定する。
- モデルの正確な形（フラグ／同時グループ／lane）＝**要ユーザー確認**（ADR 承認時）。
- 同時発話の**上限**（2人固定 or N人）。
- `sceneSegmentSpecs` 拡張が既存消費者（字幕解決・動画区間・`compileTimeline`）へ与える影響の洗い出し（パリティ回帰の防止）。
- 字幕2段の自動配置ルール（既定字幕の上/下・重なり回避・縦型での収まり）。
- amix 実装（FFmpeg amix・音量正規化・#259 との関係）。
