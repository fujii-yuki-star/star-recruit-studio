# ADR-0061: あなた向け会社説明（学生が選んだ興味から、登録済みの動画の場面で一時の説明動画を組む・β）

- **状態**: Proposed
- **日付**: 2026-10-13
- **関連**: #1336（要望と仕様）／ADR-0060（拡張パック＝この機能を有効にする道）／ADR-0043（β＝会社・採用に固有の機能）／ADR-0001・0007（描画と書き出しの道は1つ）／ADR-0024（自己完結）／ADR-0025（クレジットの表示）／ADR-0051・0053（同梱の AI）／`CLAUDE.md §2-6`（外部送信）／`11 §2`（採番）

## コンテキスト

社内の採用活動の責任者から：インターン・説明会・社内見学で、**学生が知りたいことを選ぶと**、会社が用意してある説明動画（場面形式）から
関係する場面を集めて、**その学生向けの一時の会社説明動画**をその場で組んで見せたい（#1336）。

利用者判断（2026-10-13）：
1. 24 時間で消すのは **一時の動画と書き出した MP4 の両方**（残したいときだけ明示の操作で通常の動画へ）。
2. 声の差し替えは **単独のナレーションだけ**（掛け合いの場面は元の声のまま）。
3. 「自社開発のすたりおで作った」ことを示す必須の場面は **最後**（文言・ロゴは管理者が変えられる）。
4. 学生の手直しは **場面の ON/OFF だけ**（並べ替えはしない）。
5. どの場面をどの興味に使うかの登録は **すたりおの画面で行う**（設定ファイルを手で書かせない）。
6. 機能の出し方は **拡張パック**（ADR-0060）で有効にする。
7. 学生向けは **全画面の専用モード**（担当者が決めた 4 桁の番号で抜ける）。

## 判断軸

- **原本を書き換えない**・**描画と書き出しの道を複製しない**（ADR-0001・0007）＝β は「何を選び、どう組むか」と専用の画面だけを持つ。
- **本体の形式を汚さない**＝β の登録情報は project.json に入れない（β を外しても α の動画はそのまま開ける）。
- **採用の判断をしない・個人情報を持たない**（#1336 §5・§11）。
- **AI は単一障害点にしない**（ルールだけでも組める）・**外へ送らない**（同梱の AI だけ）。
- 学生の画面に**編集ソフトの言葉を出さない**（§2-3）。

## 決定（Proposed）

### 決定1：有効にする道＝拡張パックの鍵 `personalized-briefing`
- アプリには組み込んであり、鍵を持つパック（ADR-0060）が入っているときだけ、左の帯に「**あなた向け会社説明**」が出る。

### 決定2：登録（管理者の画面）
- 登録の中身は `appData/extensions/personalized-briefing/catalog.json`（正典は新しい schema `schemas/briefing-catalog.schema.json`・独立した版）。
  - **興味の項目**（名前・並び）＝会社が決める（コードに決め打ちしない）。
  - **使う動画**＝場面形式の動画（`projectId`）・有効／無効。
  - **場面ごと**＝興味の項目（複数）・優先度・必須・除外。⚠️ 声の差し替えは「単独のナレーションか」で**自動で決まる**（掛け合いは元の声のまま＝判断2）ので、場面ごとの声の設定は持たない。
  - **最後の場面**（必須）＝文言・ロゴ（ブランドキットのロゴを既定）・見た目パターン。
  - **抜ける番号**（4 桁）。
- 登録は**動画と場面の id を指すだけ**＝原本の動画を消した・場面を消したときは、登録の画面で「見つかりません」と知らせる（黙って飛ばさない）。

### 決定3：学生の画面（全画面の専用モード）
1. **興味を選ぶ**（カード・複数）→ 2. **長さ**（短め／ふつう／しっかり）と**声** → 3. **組む**（下の決定4）→
4. **確かめる**（組んだ場面の一覧・**ON/OFF だけ**・おおよその長さ・「別の案を作る」）→ 5. **見る**（書き出した動画をその場で再生）→ 6. **終わる**（この回のデータを消す）。
- 左の帯・ほかの画面は出さない。抜けるには担当者の 4 桁の番号。
- 文言は**会社説明の言葉**で書く（「場面」「書き出し」「見た目パターン」を学生には出さない）。

### 決定4：組み方＝ルールで絞る → 同梱の AI が選んで並べる → ルールで確かめる（ダメならルールだけで組む）
1. **絞る**（コード）＝選んだ興味の場面・有効・除外でないもの。必須の場面は必ず入れる。
2. **選んで並べる**（同梱の AI・ADR-0051）＝渡すのは**場面の名前・セリフ・興味の項目・長さだけ**（素材のファイルは渡さない）。
   出力は**候補の場面 id の並び**（schema で縛る）。
3. **確かめる**（コード）＝id が候補の中か・重なりが無いか・長さが希望の範囲か・必須が入っているか。
4. **ダメなら**＝優先度順に長さまで詰める（AI 無しでも必ず完成する）。AI が使えない環境でも同じ。
- ⚠️ **外の AI（Gemini）は使わない**＝学生の前で送信前確認を出す流れが不自然で、§2-6 を緩めない。

### 決定5：一時の動画（セッション）
- 組んだ結果は**場面形式の新しい動画**として作る（＝今の場面編集・仕上がり確認・書き出しの道をそのまま通る）。置き場所は
  `appData/temporary-sessions/<projectId>/`（**通常の動画の一覧に出さない**）。id は通常と同じ `proj_YYYYMMDD_NNN` を、両方の置き場所を見て採る（重ならない）。
- **場面の取り込み**＝原本から場面をコピーし、**id を全部付け替える**（`scene_NNN`・`asset_NNN`・`line_NNN`・`anim_NNN`・`group_NNN`・要素 id）。
  参照（`assetRefs`・`character.poseAssetId`・`freeLayout` の素材・動き・声のファイル）を付け替え、ファイルは**名前を変えてコピー**
  （今の `copy_project_files` は名前を変えられない＝変えてコピーする口を足す）。同じ素材は1回だけコピーする。
  ⚠️ **取り込む前と後で絵と声が同じ**ことを検査する（#1336 §7）。
- **声**＝単独のナレーションの場面だけ、選んだ声で作り直す（掛け合いは元の声とファイルのまま）。
- **最後の場面**＝登録の文言・ロゴで組み、最後に足す（学生は外せない）。
- **見る**＝ 1080p で書き出し、その MP4 をアプリの中で再生する（プレビューではなく**書き出した物**を見せる＝見た物と残る物が同じ）。
- **消す**＝作ってから **24 時間**で、一時の動画も MP4 も消す（アプリの起動時・この機能を開いた時・1 時間ごと）。
  「この回のデータを消す」で**すぐ**消す。⚠️ 消すのは `temporary-sessions/` の中だけ（原本・素材ライブラリ・見た目パターン・登録は触らない）。
- **残す**（任意・管理者だけ）＝明示の操作で、通常の動画へ移す。

### 決定6：持たないもの・しないこと
- 学生の名前・属性は**入力させない・保存しない**。セッションに残るのは選んだ興味・長さ・声・組んだ結果・作った物だけ（24 時間で消える）。
- 合否・ランキング・適性の判断はしない（AI にもさせない）。

## 結果・影響

- 正典：`schemas/briefing-catalog.schema.json`（新設）・`11`（一時の動画の置き場所と id の採り方）・`06`（管理者の画面・学生の画面）・`12`（場面を選んで並べる指示と出力の形）・`15`（文言）。
  ⚠️ **project.schema は変えない**（β の情報は catalog 側）。
- コード：拡張の登録表（ADR-0060）・管理者の画面・学生の全画面モード・組み方（絞る／AI／確かめる／ルール）・場面の取り込み（id の付け替え＋名前を変えてコピー）・セッションの置き場所と 24 時間の片づけ（Rust・`cleanup_stale_export_dirs` と同じ起動時の片づけに並べる）。
- 試験：場面の取り込みの付け替え（参照が全部移る・取り込み前後で絵が同じ）・組み方の確かめとルールだけの組み方・24 時間の片づけが `temporary-sessions/` の外を消さない・学生の画面に技術用語が出ない。
- E2E：実際の動画 2〜3 本から 1 本を組んで、書き出して見る（#1336 完了条件）。

## 未解決の論点

- **最後の場面の既定の見た目**＝同梱の締めの見た目パターンを使うか、専用の見た目を作るか（実装時に見本を作って利用者に見てもらう）。
- **興味の項目の初期値**＝空から始めるか、例（仕事内容・研修・若手社員・福利厚生…）を入れておくか。
- **担当者の番号を忘れたとき**の戻し方（アプリを閉じれば抜けられる、で足りるか）。
- 書き出しにかかる時間（場面数×声の作り直し）＝説明会で待てる長さかを実機で測る。
