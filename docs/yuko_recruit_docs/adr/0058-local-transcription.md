# ADR-0058: このパソコンの中で声を文字にする（字幕の候補・文章から範囲を消す）

- **状態**: Accepted（2026-10-08・利用者判断＝α に入れる・ADR から・**同梱する部品の大きさは慎重に**＝#1387。部品の候補はこの PC で実測し、**small〔約200MB 増〕の同梱を利用者が選んだ**）
- **日付**: 2026-10-08
- **関連**: [`ADR-0051`](0051-local-llm-primary.md)（同梱の AI＝このパソコンの中で動かす・外へ送らない・黙って外部へ落とさない）／[`ADR-0055`](0055-subtitle-srt-vtt-exchange.md)（字幕を時刻と文字で交換＝`importSubtitleCues`）／[`ADR-0053`](0053-editing-ai-assist.md)（編集中の AI 補助は候補を出して利用者が選ぶ）／#1385（無音を詰める＝`silenceSourceOf`・範囲を消して詰める）／[`ADR-0032`](0032-timeline-project-format.md)（場面形式は凍結）／`CLAUDE.md §2-6`（外部送信）・`§2-5`／`13_DEPENDENCIES_AND_LICENSING`／#1379 候補A・#1384（容量の最適化）

## コンテキスト

録った話し声・取り込んだ動画の声に字幕を付けるのが、いまは手作業（1文ずつ打つ）か、外で文字起こしして SRT を持ち込む（ADR-0055）しかない。
実況・社内発表・インタビューの動画では、これがいちばん時間を食う（#1379 候補A・利用者判断 2026-10-08＝α）。
業界の型は **「文字にする → 字幕にする → 文章で編集する」**（CapCut の自動字幕・Premiere の「文字起こしベースの編集」・Descript）。

制約：

- **外へ送らない**（§2-6・ADR-0051）＝このパソコンの中で動かす。
- **同梱の大きさに慎重に**（利用者指示）＝#1384 で約 1.37GB 減らしたばかり。いまの同梱物は FFmpeg 136MB・VOICEVOX 713MB・ローカル LLM 1.3GB（＋写真を読む部品 365MB）。
- **非力なパソコンで動く**＝このプロジェクトの基準機はこの PC（Core Ultra 5 125U・メモリ 15.5GB・GPU なし扱い）。

## 判断軸

1. **外へ送らない・黙って別の道へ落とさない**（ADR-0051 と同じ）。
2. **大きさ**（同梱に足す量）と**速さ**（非力な PC で待てる時間）を、精度と同じ重さで見る。
3. **認識の結果は正解扱いしない**＝字幕の候補として出し、利用者が直せる（ADR-0053 と同じ「候補を出して選ぶ」）。
4. **既存の道を通す**＝字幕にするのは ADR-0055 の `importSubtitleCues`、消すのは「範囲を消して詰める」（取り消しに載る・元の素材は消さない）。新しい編集の道を作らない。

## 実測（2026-10-08・この PC・whisper.cpp v1.9.4〔b5130〕・CPU・日本語指定）

試験の音声＝同梱の VOICEVOX で作った**正解つきの話し声**（3人の声・8文・64秒＝会社紹介の文・数字と固有名詞を含む）と、同じ音声に **BGM と雑音を重ねたもの**。

|---|---|---|

## 決定

1. **whisper.cpp の `whisper-cli`（v1.9.4・b5130・MIT）と small（q5_1・190MB・MIT）を同梱する**。置き場所は `src-tauri/resources/transcribe/`（`runtime/`＝13ファイル・`models/`＝1つ・`LICENSES/`）。**SHA-256 を固定**し、合わなければ使わない（ADR-0051 と同じ）。
   ⚠️ ADR-0051 は「公式の重みから自前で量子化」だが、whisper.cpp は**保守者が量子化済みを公開**しており、追加の学習もしない＝**公開の q5_1 を SHA-256 で固定**する（作り直さない理由をここに残す）。
2. **1回ごとに起こして終わらせる**（常駐しない）。音は FFmpeg で**その部品の使っている範囲だけ**を 16kHz の1チャンネルに切り出して渡す（素材の秒の範囲＝無音を詰めると同じ `silenceSourceOf`）。並列数は **論理コアの半分（2〜8）**・**貪欲**・日本語指定。
3. **対象は1つの部品**（音の入った動画・音の部品）＝無音を詰めると同じ選び方。帯の操作の行と右クリックに「声を文字にする…」。
4. **結果は候補の一覧**（時刻・文）。行を押すとその時刻へ。文は**その場で直せる**。「字幕として並べる」で選んだ文を `importSubtitleCues` へ（素材の秒 → タイムラインの秒は、置いた位置・使い始め・速さで写す）。「この範囲を消して詰める」で選んだ連続する文の範囲を消す（既存の確認・取り消し1回）。
5. **待っている間は進み具合を出し、やめられる**（プロセスを止める）。待っている間に部品が動いた・取り消した・別の動画へ移ったら、結果は使わない（無音を詰めると同じ守り）。
6. **断り**：部品が無い（入れ直す）／声の無い部品（押す前に押せなくする）／読めない素材／書き出し中（FFmpeg を取り合わない）／途中で失敗。**黙って外部の AI や見本へ落とさない**。
7. **場面形式は対象外**（ADR-0032 凍結）。

## 結果・影響

- **同梱物は約 200MB 増える**（190MB＋10.5MB）。書庫に入る。`13_DEPENDENCIES_AND_LICENSING`（MIT の告知・由来・SHA-256）・`src-tauri/resources/README.md`・配布の手順（置くスクリプト）を同じ流れで足す。
- **schema は変えない**（字幕は既存の字幕クリップ・候補は画面の状態で保存しない）。
- コード：Rust に「文字にする」口（切り出し→起動→JSON→区切りを返す・止める）、domain に純粋関数（区切り → 候補・素材の秒 → タイムラインの秒・選んだ文 → 消す範囲）、store に入口（無音を詰めると同じ守り）、画面に候補の欄。
- 正典：`06`（帯の操作・候補の欄）・`11_TIMELINE_REFERENCE`（写し方）・`15 §6`（断り）・`13`。

## 未解決の論点

- **実際の録音での精度**（合成の声は高く出る）＝利用者の録音で確かめる（ユーザー確認）。誤り率が 10% を大きく越えるなら large-v3-turbo を「より正確に（時間がかかる）」の選択肢として**別の書庫**で足すかを決め直す。
- **BGM だけの所・無音の所で出る「でっちあげの文」**（Whisper 系の既知の癖）＝実録音で起きるなら、無音を詰める（#1385）と同じ山の測り方で声の無い所を外してから渡す、または VAD の部品（約 1MB）を足す。
- 語単位で消す（Descript 型）は、実録音で語の時刻を確かめてから。
- 話者の聞き分け（誰の声か）は扱わない。
