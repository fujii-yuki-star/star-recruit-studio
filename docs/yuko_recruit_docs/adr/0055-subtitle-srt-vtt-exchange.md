# ADR-0055: 字幕を SRT / VTT で読み込む・書き出す（時刻と文字の交換だけ）

- **状態**: Accepted
- **日付**: 2026-10-06
- **関連**: #1351（#1335 提案G・利用者判断 2026-10-06＝α に入れる）／ADR-0032（場面形式は凍結・タイムラインは別の文書）／ADR-0041（持ち込みの AI）／ADR-0001（描画の核は1つ）／`11_TIMELINE_REFERENCE §7.6`（字幕クリップ・`subtitleTextOf`）／`CLAUDE.md §2-3`・`§2-5`・`§2-6`

## コンテキスト

字幕を**時刻と文字**のまま外とやり取りする手段が無い。外部の文字起こし・外部 AI・YouTube の字幕・他の編集ソフトと往復できないので、
「声と字幕を外で作って持ち込む」「作った動画の字幕を YouTube に載せる」が、すべて手作業になる（#1335 提案G）。
文字起こしの AI を内蔵するのとは別の話＝**交換の口**だけを持つ（重さはほぼ増えない）。

## 判断軸

1. **時刻と文字だけ**を交換する＝体裁（色・位置・ASS のスタイル）の互換は背負わない（そこへ踏み込むと際限が無い）。
2. **描かれる字幕と同じものを書き出す**＝書き出した字幕と動画の字幕が食い違わない（ADR-0001 の流儀＝見え方を2か所で決めない）。
3. **場面形式は凍結**（ADR-0032）＝場面形式の文書の形を変えない。
4. **黙って別の結果にしない**（§2-5・ADR-0026④）＝読めなかった・はみ出した・切り詰めたは言う。

## 検討した選択肢

| 論点 | 選択肢 | 評価 |
|---|---|---|
| 読み込み先 | (A) タイムライン形式だけ | **採用**。字幕クリップは時刻を自分で持つ＝そのまま並べられる |
| | (B) 場面形式にも（場面の字幕へ割り振る） | 場面の字幕は**場面の時刻**に従う＝時刻を持ち込めない。割り振りは推測になる＋凍結中 |
| 書き出し元 | (A) タイムライン形式だけ | 初心者の主な道（場面形式）で使えない |
| | (B) 両方。場面形式は**焼き出し（`bakeTimelineProject`・純粋）を通して同じ取り出し方**に寄せる | **採用**＝取り出しの規則が1つ（場面形式専用の規則を書かない） |
| 読み込んだ字幕 | (A) 字幕クリップ（自分の文を持つ・読み上げに連動しない） | **採用** |
| | (B) 読み上げクリップも作る | 便利だが別の判断（声の割り当て・長さ）＝後で決める（general-backlog） |
| 保存のしかた | (A) 保存ダイアログ＋拡張子を限った書き込みの口（Rust） | **採用**＝WebView の「ダウンロード」は置き場所が利用者に見えない |
| | (B) ブラウザのダウンロード | 置き場所が読めない・アプリの外では使うがアプリでは使わない |

## 決定

1. **形式**：SRT と WebVTT。**時刻と文字だけ**。読み込みでは体裁の印（`<i>` などのタグ・`{\an8}` など）・VTT のキューの設定・`NOTE`／`STYLE` の塊を捨てる。
2. **文字コード**：読み込みは UTF-8（BOM あり・なし）→ UTF-16（BOM あり）→ **読めなければ Shift_JIS**（日本の古い字幕ファイル）。書き出しは UTF-8（SRT は BOM 付き＝Windows の再生ソフトで文字化けしない／VTT は BOM なし）。
3. **読み込み（タイムライン形式だけ）**：
   - キューごとに**字幕クリップ**（自分の文を持つ・連動なし）を作り、既定の字幕の箱で置く。
   - 置き場所は**新しい映像の列**（既存の部品と重ねない・既存の列を探さない＝読み込んだまとまりが1つの列に揃う）。キューどうしが重なるときは、重なった分だけ列を足す。
   - キューの長さが最小（`TIMELINE_MIN_CLIP_SEC`）より短ければ最小まで伸ばす。動画の上限（`VIDEO_HARD_MAX_SEC`）を越えるキューは置かず、**その数を言う**。
   - **1回の編集**＝取り消し1回で全部消える。
4. **書き出し（両方の形式）**：
   - 取り出し方は1つ（`subtitleCuesOf(doc)`）＝**描かれる字幕**＝隠していない列の、字幕クリップ（`subtitleTextOf`＝自分の文、無ければ連動先の読み上げ文）と、見た目パターンの字幕の層の文。空の文は出さない。時刻順。
   - 場面形式は **`bakeTimelineProject` で焼いてから**同じ取り出し方を通す（取り出しの規則を形式ごとに書かない）。
   - 保存ダイアログで場所を選び、Rust の**書き込みの口**で保存する。口は拡張子 `.srt`／`.vtt` だけを受ける（任意のファイルを書ける口にしない）。
5. **画面**：タイムライン形式＝置く欄（字幕）に「字幕ファイルを読み込む」、書き出しの近くに「字幕ファイルを書き出す」。場面形式＝書き出し画面に「字幕ファイルを書き出す」。⚠️ 技術語（SRT・VTT・エンコード）は画面に出さない＝「字幕ファイル（.srt／.vtt）」の拡張子だけを括弧で添える（選ぶファイルの種類として必要）。
6. **外部送信ではない**（§2-6）＝ファイルを読み書きするだけ。

## 結果・影響

- 新規：`src/domain/subtitle/subtitleFile.ts`（解析・組み立て＝純粋・§7 テスト対象）／`src/domain/timeline/subtitleCues.ts`（描かれる字幕の取り出し）／取り込みの編集（`importSubtitleCues`）／Rust の書き込みの口。
- データの形（schema）は**変えない**＝読み込んだ字幕は既存の字幕クリップ。
- 正典：`06`（両画面）・`11_TIMELINE §7.6`（読み込みは字幕クリップを作るだけ＝新しい項目なし）・`15 §6`（読めない・何も無い・はみ出した の知らせ）を実装の PR で同時に直す。
- 2つの PR に分ける：①解析・読み込み（タイムライン形式）②書き出し（両形式・Rust）。

## 未解決の論点

- 読み込んだ字幕から**読み上げクリップも作る**か（声の割り当て・長さの扱い）＝general-backlog。
- 書き出した字幕の**時刻の丸め**（コマ単位にそろえるか）＝実装で決めて追補。
