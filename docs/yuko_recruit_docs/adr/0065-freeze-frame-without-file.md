# ADR-0065: 止めた絵をファイルにしない（部品の設定で止める）

- **状態**: Accepted（2026-10-20・α-8＝ADR-0043 ⑤・#1473）
- **日付**: 2026-10-20
- **関連**: [`ADR-0064`](0064-unused-file-cleanup.md)（使っていないファイルの片づけ）／[`ADR-0001`](0001-rendering-parity.md)（プレビュー＝書き出し）／[`ADR-0032`](0032-timeline-project-format.md)／[`ADR-0034`](0034-timeline-interaction-model.md)（業界の型）／#356 ②・#1137・`src/domain/timeline/freeze.ts`

## コンテキスト

タイムライン形式の「この瞬間で絵を止める」（#356 ②）は、**再生位置のコマを写真ファイルに切り出し**（`extractVideoFrame`）、分けた後ろ半分を**その写真の部品**に替える。

- 取り消すと部品は消えるが、写真のファイルは残る（やり直しのため）＝[`ADR-0064`](0064-unused-file-cleanup.md) の発端。
- 切り出しは FFmpeg を起こすので待ち時間があり、待っている間の変化を断る仕組み（`FREEZE_BLOCKED.changed`・#1136）や、上書き・取り違えの対策（#1137）が要った。

業界の型を調べると（2026-10-20）、**Premiere Pro の「フレーム保持」は部品の設定で、新しいファイルを作らない**。Final Cut Pro の「フリーズフレームを追加」も、再生位置で静止画にする操作（ファイルを作るかは資料で確かめられなかった）。

## 判断軸

- 業界の型（ADR-0034）。
- プレビュー＝書き出し（ADR-0001）＝止めた絵が両方で同じコマであること。
- ファイルを増やさない（ADR-0064 の発端を元から断つ）。
- 待ち時間と、それに伴う断り（#1136・#1137）を減らす。

## 検討した選択肢

| 選択肢 | 評価 |
|---|---|
| (A) いまのまま（写真ファイルを作る） | 動いている。ファイルが残る・待ち時間・取り違えの対策が要る |
| (B) **動画の部品に「このコマで止める」（元の動画の何秒目か）を持たせる** | ファイルを作らない・待たない。描画は「動画のその秒のコマ」を毎回出すので、プレビュー（動画を止めて表示）と書き出し（FFmpeg でそのコマ）を同じ秒で合わせる必要がある。**有力** |
| (C) 速さ 0 で表す | 速さの意味（音・長さの計算）を壊す。不採用 |

## 決定

**(B) を採る**（2026-10-20・α-8＝ADR-0043 ⑤「α でソフトとして完成させる」・#1473）。詰めた中身：

1. **欄は `holdFrame: boolean`**（timeline schema 1.19→1.20・任意追加＝**無変換**）。止める秒は**新しい欄を作らず
   既存の `sourceStartSec`（使い始め）**を使う＝「使い始めの1コマを、部品の長さいっぱい映す」。
   ⚠️ 秒を別の欄に持つと、使い始めと止める秒の**2つが食い違える**ので持たない。
   既存の「写真になった止めた絵」は**そのまま残す**（普通の写真の部品として描かれる）。
2. **描画は既存の「最後のコマで凍る」を共有**＝`videoPlacementsOfClip` が止めた部品の**使える長さを 0** にするだけ。
   書き出しは1コマだけ焼いて全部それを読み（`stagedIndexCap`＝0）、プレビューは `videoHoldsLastFrameAt` が常に真なので
   動画要素を `sourceStartSec` で止める＝**同じ秒の決め方は1か所**（新しい描画の道を作らない＝ADR-0001）。
3. **見えていたコマで止める**＝分ける（`splitClip`）は使い始めを**生の秒**で進めるので、置いた位置が格子に乗って
   いないと隣のコマになる（#1147 と同じ理由）。押した時に映っていたコマの素材の秒を正準（`freezeSourceSec`＝
   `videoSourceSecAt`＋`frameTimeSec`）で出して、後半の `sourceStartSec` に入れる。
4. **音は鳴らさない**＝止める時に元の音・音量の変化を落とし（`asHeld`）、手で書いた文書で `useOriginalAudio` が
   残っていても `videoPlacementsOfClip` が鳴らさない・欄も出さない（`canUseOriginalAudio`）。**速さと使い始めは残す**
   ＝「止めるのをやめる」（`setClipHoldFrame`）と、そこから同じ速さで流れる。
5. **画面**＝「この動画の使い方」に止めている説明と**「止めるのをやめる」**を出し、止めている間は速さ・使い始めの欄を
   出さない（効かない欄を出さない）。帯の名前に「（止めた絵）」を添える（同じ動画の名前が前後に並ぶため）。
6. **「止めた絵を写真として書き出す」は足さない**＝写真が要るときは、今ある「この瞬間を写真にする」（素材の画面・#349）を使う。

## 結果・影響

- 「この瞬間で絵を止める」は**同期で終わる**＝ファイルを作らず、待ちも取り込みも無い（取り込み中でも押せる）。
- 退役：切り出しの待ち・待っている間の変化の断り（`FREEZE_BLOCKED.changed`・`TIMELINE_EDIT_FREEZE_CHANGED`）・
  切り出しの失敗（`TIMELINE_EDIT_FREEZE_FAILED`）・断ったときの写真の片づけ（#1149 ④）・`freezeSourceFrame`。
  エラーの表は 328→326 行。
- 正典：`timeline-project.schema.json`（`holdFrame`・1.20）／`11 §7.6`（`11_TIMELINE_REFERENCE`）／`06`（この瞬間で絵を止める）。
- ⚠️ 切り出しの命令（`extract_video_frame`）は素材の画面の「この瞬間を写真にする」がまだ使う。コマ番号で頼む引数（#1158）は
  呼び出し元が無くなったが、Rust 側の受け口ごと残してある（害は無い・片づけは別件）。
- ⚠️ **止めた絵は素材の時間を進めない**（PR レビュー由来 🔴）＝分ける・詰める・範囲を消すで使い始めを動かさず
  （`advancedSourceStart`）、素材の終わりを理由に断らない（`usesUpSource`／`sourceLimitIssue`）。押しのけを採らないので、
  **伸ばすのが止めた絵を長くする唯一の道**（ADR-0034 決定11）。書き出しで「そのまま流す動画」に数えない
  （`clipIsPassThroughVideo`＝数えると FFmpeg が動画を流す）。無音探し・文字起こしの相手にしない（鳴っていない音）。
- ⚠️ **書き出しで、切れ目に1コマ跳ぶことがある**（PR レビュー由来 🟡・残す）＝書き出しは止めた部品を
  `-ss 使い始め` で並べ直した**0枚目**で焼くが、押す直前に出していたのは**元の並べ方の N 枚目**。素材と出力の fps が
  違うと、この2つが1コマ食い違うことがある（#1158 の実測で 18/64）。**プレビューと書き出しは止めた部品の中では一致**
  （どちらも同じ秒）で、ずれうるのは「切れ目の直前のコマ」と「止めたコマ」の間だけ。直すなら並べ始めの秒と何枚目かを
  部品に持たせる形になる（欄が2つに増え、使い始めと食い違える）ので、実機で目に付くまで持たない。
- [`ADR-0064`](0064-unused-file-cleanup.md) の片づけは、**以前に作られた**止めた絵の写真と、ほかの残りのために引き続き要る。

## 未解決の論点

- なし（止める秒を利用者が選び直す欄＝「使い始め」を止めている間も出すか、は使われ方を見てから）。
