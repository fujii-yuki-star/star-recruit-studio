# ADR-0042: 持ち込みの AI が使う「口」＝起動の引数で、取り込みと書き出しまで通す

- **状態**: Proposed
- **日付**: 2026-09-17
- **関連**: [`ADR-0041`](0041-external-agent-operability.md)（誰に許すか）／[`ADR-0001`](0001-rendering-parity.md)／[`ADR-0007`](0007-detailed-edit-mode.md)／[`ADR-0024`](0024-non-destructive-editing-model.md)／[#1184](https://github.com/fujii-yuki-star/star-recruit-studio/issues/1184)

## 背景

ADR-0041 で「**利用者が持ち込む AI にソフトを操作させてよい**」と決めた。本 ADR は**その口をどう開けるか**を決める。

⚠️ **α に入れる**（2026-09-17・利用者判断）。

> **β では極力社内専用機能を付け加えるだけにしたいので、書き出し口や取込口は α 内にやっておきたい**

＝**β の性格を「社内向けの積み増し」に保つ**ため、誰でも使う土台は α で閉じる。

### いま、どこまで届いているか（実測・2026-09-16）

| やること | いま |
|---|---|
| プロジェクトを**組み立てる** | **できる**＝`project.json` を書けば、正典 schema もアプリの読み込みも通る |
| **声を入れる** | **できる**＝同梱 VOICEVOX の API を叩き、`voices/clip_NNN.wav` を置く |
| **置き場へ入れる** | ⚠️ `%APPDATA%\…\projects\` に**フォルダを置く**しかない（場所を知っている必要がある） |
| **書き出す** | ❌ **人がダイアログを押さないと終わらない**（`ExportScreen.tsx` が保存先を先に聞く） |

＝**足りないのは最後の2つだけ**。

## 論点

1. **口の形**＝常駐の待ち受け（HTTP/ソケット）か、**起動の引数**か。
2. **画面を出すか**＝見えないところで走らせるか。
3. **二重起動**＝利用者が開いている最中に AI が起動したら。
4. **結果の返し方**＝AI がどうやって成否を知るか。

## 決定

### ① 口は**起動の引数**（待ち受けは作らない）

```
stario.exe --import <フォルダ>            取り込んで、その動画を開く
stario.exe --export <動画のid> --out <道>  その動画を書き出す
stario.exe --quit-when-done                終わったら閉じる（上のどちらかと一緒に）
```

⚠️ **待ち受けを作らない**＝ポートを開けると、**このソフトを入れただけで外から触れる面**ができる。
AI は**同じパソコンでソフトを起こせる**のだから、待ち受けは要らない（§2-6 の精神）。

### ② **画面は出す**（見えないところで走らせない）

絵を作っているのは WebView（ADR-0001＝描画核は1つ）なので**窓は要る**。加えて、
**見えないまま失敗すると人が気づけない**＝「動いているつもりで何も出ていない」を作らない。
→ **窓は出し、自動で進む**。`--quit-when-done` を付けたときだけ、終わったら閉じる。

### ③ **単一インスタンス**にし、動いていれば**引数をそちらへ渡す**

⚠️ **書き出しは `project.json` を保存する**（#256）ので、**2つ動くと後から保存した方が勝つ**。
→ 2つ目は**起こさない**。すでに動いていれば**引数だけ渡す**。
⚠️ **渡された側は、未保存の編集を抱えていたら断る**＝
「いま編集中です。保存してからもう一度お試しください。」（§2-5＝次の行動）。
**黙って上書きしない**（ADR-0026④）。

### ④ 結果は**終了コード**と、**画面に出るのと同じ文**で返す

| 終了コード | 意味 |
|---|---|
| `0` | できた |
| `1` | できなかった（理由は画面の文と、うまくいかないときの記録に出す） |
| `2` | 引数が読めない・足りない |

⚠️ **生の技術語を標準出力へ吐かない**（§2-3 の精神）＝出すのは**画面と同じ文**。

### ⑤ 中身は**画面と同じ道**を通す

- **書き出し**＝`ExportScreen` の `startExport` を**そのまま**使い、**保存先を聞く所だけ**引数で置き換える。
  ⚠️ **別の書き出し経路を作らない**（ADR-0007）。公開前チェックも同じものが効く。
- **取り込み**＝既存の取り込み（素材ごとコピー＝ADR-0024）に載せ、**検証を必ず通す**（ADR-0041 条件1）。
  読み込みは形だけ／相互参照は書き出しのところで断る、という**既存の二段**にそのまま乗る。

## 採らなかった案

| 案 | なぜ採らないか |
|---|---|
| **常駐の待ち受け（HTTP/WebSocket）** | 入れただけで**外から触れる面**ができる。AI は同じ機械でソフトを起こせるので必要が無い |
| **画面を出さない（headless）** | 描画核が WebView にある（ADR-0001）ので窓は要る。加えて**失敗が見えない** |
| **Rust だけで書き出す** | 絵を作るのは WebView＝**描画核の二重化**になる（ADR-0001 が禁じている当のもの） |
| **2つ目を普通に起こす** | 書き出しが保存を伴うので、**後から保存した方が勝つ**（利用者の編集が消える） |
| **AI 専用の簡易フォーマット** | 正典 schema が既に AI 向けの入口になっている（実測済み）。増やすと**二重管理**になる |

## 結果

- **α で入れる**＝①〜⑤。
- **書く側の契約**（置き場・ID 採番・素材の相対パス・声のファイル名と `status`・検証の掛け方・失敗の返り方）を
  1枚にまとめる（[#1184](https://github.com/fujii-yuki-star/star-recruit-studio/issues/1184) ③）。⚠️ **いまはどこにも書いていない**。
- β は**社内向けの積み増し**に専念できる。
