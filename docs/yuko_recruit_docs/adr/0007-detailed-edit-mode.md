# ADR-0007: 詳細編集モードと FREE テンプレート（場面の作り込み）

## コンテキスト

現状の編集面は `SceneEditScreen`（＝実質「簡易編集モード」）で、AIが提案した構成に対し、場面ごとに **タイトル/字幕/セリフ/表示時間/見た目パターン/素材スロット割当/クリップ調整/トランジション/ゆうこ表示** を編集できる。「AIがたたき台 → ほぼ完成まで簡易編集」という主動線には十分。

一方で利用者ヒアリングから次の要望が出た（本ADRの動機）:

1. **AIが構成を提案 → 簡易編集である程度仕上げ → それでも細かく気になる場面を微調整したい。**
2. 汎用動画編集ツールより **直感的**で、かつ **「もしもの時に困らない」程度の編集機能**は揃えたい。
3. （主想定ではないが）**AIを使わず手動で動画を作る**用途も想定。その場合は簡易編集より詳細編集の方が圧倒的に扱いやすい。

ここで本格的な編集機能を入れると `§10`（本格タイムライン編集・キーフレーム・複雑エフェクト・テンプレ作成エディタは MVP 外）と `§2-4`（テンプレ駆動＝座標を毎回触らせない）に抵触し得る。**「どこまでを詳細編集とするか」を先に決める**ためのADR。

### 不変条件（崩さない前提）

- **場面内レイアウトは静止**（ADR-0001）。動くのは動画スロットの中身と音声のみ。詳細編集を入れても**場面内アニメ／キーフレームは持ち込まない**。
- **描画は1経路**（ADR-0004：WebView Canvas で SVG→PNG）。詳細編集の結果も**同じ layout→SVG→PNG→FFmpeg パイプライン**を通す（新しい描画エンジンを作らない）。
- **テンプレ駆動**（§2-4）。通常テンプレの座標は固定のまま。

## 検討した選択肢

### モードの持ち方
- **(M-A) 同一データ・2モード**【採用】: 簡易/詳細は**同じ project.json を編集する2つのUI**。詳細モードは「より多くの操作を露出する編集面」であって、別のデータ形式・別の書き出し経路を持たない。AI→簡易→詳細→書き出しが**単一パイプライン**で繋がる。
- (M-B) 詳細編集専用の別ドキュメント／別データモデル — 二重管理になり、AI出力との往復・書き出しの整合が壊れる。不採用。

### 自由配置とテンプレ駆動の両立
- **(F-A) FREE テンプレートに自由配置を閉じ込める**【採用・利用者提案】: 「自由に置きたい場所」では **`category: free` のテンプレ**を使う。自由配置は**FREEテンプレを選んだ場面に限って**有効化し、通常テンプレは座標固定のまま（§2-4 を維持）。テンプレ作成エディタ（§10外）ではなく、**組み込みのFREEテンプレ**を1つ用意するだけ。
- (F-B) どのテンプレでも座標を直接編集可能にする — §2-4（テンプレ駆動）を実質無効化し、毎回座標を触らせることになる。不採用。
- (F-C) 自由配置を入れない — 要望2/3（もしもの時／手動制作）に応えられない。不採用。

## 決定

> **(M-A) 同一データ・2モード**＋**(F-A) FREEテンプレに自由配置を閉じ込める**を採用する。
> 詳細編集モードは、現行の簡易編集と**同じ project/scene データ**を、より細かく編集する UI とする。自由配置は **`category: free` テンプレを選んだ場面**でのみ有効化し、その場面のレイアウト上書きを **scene 側の新フィールド**に持たせる。場面内は依然「静止レイアウト＋（任意の）動画スロット＋音声」に限り、**タイムライン／キーフレーム／複雑エフェクトは入れない（§10 を維持）**。

### 詳細編集モードに含める機能（利用者の選択：4領域すべて）

1. **場面ごとの音声ミックス**（`scene.audioMix`、正典既設）
   - ナレ音量：**ドメイン・書き出しは既に対応済み**（`resolveNarrationVolume(scene.audioMix, …)`。`ExportScreen` も `scene.audioMix` を渡している）。**UI を足すだけ**で「場面ごと」になる＝**Phase 1**。
   - 元動画音量：クリップ調整で既に場面（素材）単位に編集可。
   - BGM音量（場面ごと）：現状 BGM は1本を全体に重ねる方式（ADR-0006/V-C3）。場面ごとに効かせるには**書き出し側で音量エンベロープ**（`volume=…:enable='between(t,…)'`）が要る＝別途実装（Phase 3-4）。それまで**no-op UI を作らない**（「置いてあるだけ未結線」を避ける）。

2. **場面の並べ替え・複製・分割**（構成編集）
   - 並べ替え（order 再採番）、複製（`createSceneId` で採番しコピー）、分割（1場面を2つに）。**場面リストの操作**でありタイムラインではない＝§10 の範囲内。
   - 既存 `addScene`/`removeScene`/`createSceneId` の延長で実装可。

3. **クリップの詳細調整**
   - トリム（開始/終了）・フィット：**既存**（`asset.clip`）。
   - 再生速度：新規（FFmpeg `setpts`/`atempo`。尺・音声との整合を要設計）。
   - 1場面に複数素材：**§10（複雑化）に近づくため要検討・原則は1スロット**。入れる場合もレイヤー数を絞る。

4. **テキスト/装飾の自由配置（FREE テンプレ）** — 最大の項目
   - `category: free` のテンプレを選んだ場面で、テキスト/画像/図形を**自由な座標・サイズ・色**で配置できる。
   - データ：通常テンプレの座標は固定のまま。**FREE場面のみ** scene 側にレイアウト上書きを持たせる（下記スキーマ案）。
   - 描画：自由配置でも**出力は静止レイアウト**＝既存の layout→SVG→PNG→FFmpeg を通る（ADR-0001/0004）。新しい描画は不要。

### スキーマ案（実装時に確定。本ADRは方針のみ）

- `template.schema.json`：`category` enum に **`free`** を追加（11 §3 と同期）。FREEテンプレは「自由配置の器」を表す組み込みテンプレ。
- `project.schema.json`：FREE場面のレイアウト上書き用に **`scene.freeLayout`（任意）** を新設。要素は `{ kind: 'text'|'image'|'shape', x, y, w, h, zIndex, ...（textはtext/fontSize/color、imageはassetId/fit、shapeはshapeType/fillColor）}` の配列。**通常テンプレ場面は使わない**（後方互換：未設定なら従来どおりテンプレ座標）。
- 値域・座標系はテンプレ canvas（1920×1080）基準。`null=継承`/未設定の規約は §5 を踏襲。

### 簡易/詳細モードの関係（UX・要設計）

- 簡易編集モード＝現行 `SceneEditScreen` 相当（最小操作で仕上げる）。
- 詳細編集モード＝同じ場面に対し上記4領域を露出。**同一画面のトグルか別画面か**は UI 設計で確定（未解決論点）。
- **AIなし制作**：空プロジェクトから手動で場面追加→テンプレ（FREE含む）選択→内容配置で、AI生成工程を**任意**にできる。新しい書き出し経路は不要。

### §10 として入れないもの（線引き）

- タイムライントラックUI／キーフレームアニメ／場面内モーション（動画スロットの中身を除く）／複雑エフェクト・フィルタ合成／テンプレ作成エディタ（FREEは組み込みテンプレで代替）。場面は引き続き「静止レイアウト＋（任意の）動画スロット＋音声」。

## 結果・影響

- **段階実装（ロードマップ）**：
  - **Phase 1**：場面ごとナレ音量の UI（`SceneEdit`/詳細の音声セクション）。書き出し既対応＝小PR・即着手可。
  - **Phase 2**：場面の並べ替え・複製・分割（場面リスト操作）。
  - **Phase 3**：詳細編集モードの UI 骨格（簡易/詳細の切替）＋クリップ詳細（再生速度等）。
  - **Phase 4**：FREEテンプレ＋`scene.freeLayout`＋自由配置エディタ（スキーマ拡張・描画/書き出し結線。最大。**実装前に追補ADR or 本ADR改訂**でスキーマ確定）。
  - （場面ごとBGM音量：書き出しエンベロープ実装後に Phase 3-4 で。）
- スキーマ変更（`category: free`・`scene.freeLayout`）は **Phase 4 で正典（11/schemas）に反映**。それまでは本ADRの提案に留める。
- 書き出し・プレビューは原則無改修（FREE場面は「自由に置かれた静止レイアウト」を同パイプラインで描く）。再生速度・場面ごとBGMのみ FFmpeg 追加。

## 未解決の論点

1. **簡易/詳細の UI 形態**：同一画面トグル／別画面／モード状態の持ち方（プロジェクト保存対象か、表示設定か）。
2. **`scene.freeLayout` の確定スキーマ**：要素型・スタイルの範囲（フォント/枠/影をどこまで）、テンプレ層との関係（FREEテンプレは空の器か、初期要素を持つか）。
3. **FREE テンプレの位置づけ**：`category: free` 追加 vs 既存（full_visual 等）流用。AIの `recommendedSceneTypes` 対象外とするか。
4. **場面ごとBGM音量**の書き出し方式（`volume … enable='between(t,…)'` のエンベロープ）。
5. **再生速度**（`setpts`/`atempo`）と尺・ナレーション・字幕タイミングの整合。
6. **1場面複数素材**を許すか（§10 複雑エフェクトとの線引き）。
7. アクセシビリティ・操作の直感性（要望2）をどう担保するか（ドラッグ配置のキーボード代替等）。
