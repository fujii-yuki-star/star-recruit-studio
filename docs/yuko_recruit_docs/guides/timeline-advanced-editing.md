# タイムライン形式：高度な編集のやり方（実機テスト用）

> 利用者の要望（2026-09-03）＝「想定される最も高度な編集をいくつかやり方を教えてほしい。**特に複数ナレーションの掛け合いや重複ナレーション**。**全てタイムライン編集前提で**」に答える手順書。
> **実機テスト（#352）でそのまま上から順に試せる**ように書いた。
>
> ⚠️ **書いてある手順は、すべて実装で裏取りしてある**（画面の言葉・押す順・できること／できないことを、コードと検査で確かめた）。
> 確かめる過程で見つかった不具合は、その場で起票して直した（#1005・#1006・**#1009＝同時にしゃべる2人の字幕が重なる**）。

---

## 0. 前提：この形式で何が変わるか

| | 場面形式 | **タイムライン形式** |
|---|---|---|
| 画面の置き方 | 見た目パターンが決める | **いつでも自由配置** |
| 時間 | 場面の並び | **秒で自由** |
| 見た目パターン | 動画の「枠」 | **置ける素材のひとつ**（差し込み口は生きている） |
| AI | 使える | **使えない**（AI が触るのは場面形式まで） |
| 行き来 | — | **片道**（場面形式 →「バラす」→ タイムライン形式。戻れない） |

タイムライン形式の動画を作る入口は2つ。

- **ホームの「タイムラインで作る」**＝完全な新規（先に**横／縦**を聞かれる。あとから変える道は無い）。
- **場面形式の「見わたす」画面から焼き出す**＝いま作ってある動画をタイムラインへ持っていく（**元は残る／常に別の新規**）。

**列（トラック）の決まりごと**（これを知らないと後半でつまずく）。

- **重ね順は列の並びだけ**で決まる。**手前が上**。部品ごとの「前へ／奥へ」は無い。
- **同じ列の中では、時間を重ねられない**。**重ねたいなら列を足す**。← 重複ナレーションの鍵。
- 列には**映像の列**と**音の列**があり、置けるものが決まっている。

---

## 1. 基礎（ここが通れば、あとは組み合わせ）

1. 「**読み上げを置く**」の欄で **置く列**を選び、「**読み上げを置く**」を押す（再生位置から入る）。ボタンは**掴んで**帯の上へ直接落とすこともできる。
2. 帯を押して選ぶ。`Shift` で足し、`Ctrl+A` で全部、`Escape` か何もない所で解ける。
3. 「**選んだ部品**」の欄で中身を直す。位置と大きさは**キャンバスを掴んでも**、**数値でも**変えられる。
4. 長さは3通り。**帯の端をドラッグ**／「**ここから始める**」「**ここで終わる**」（再生位置で切る）／「**長さ（秒）**」に打ち込む。
   - ⚠️ **ボタンは「再生位置をまたいでいる帯」しか相手にしない**（またいでいない帯まで動かすと、置いた場所ごと動いてしまうため）。**伸ばしたいときは「長さ（秒）」の欄**を使う。
   - ⚠️ **複数選んだままでも長さをそろえられる**（#1005 で直した）。ボタンに「**（N個）**」と出るので、**押す前に何個変わるかが分かる**。
5. `Ctrl+K`（または右クリック →「**ここで分ける**」）で再生位置に切れ目を入れる。**読み上げは切れない**。
6. `Ctrl+Z` で戻せる（この画面の取り消しは**この動画だけ**に効く）。**編集は自動保存**。

## 2. 掛け合い（2人が**交互に**しゃべる）★要望

**専用の機能は無い。読み上げを並べるだけ**。これが設計どおりの姿（列を分けるだけで足りる、という決め）。

### 手順

1. 「読み上げを置く」で **1本目**を置く。
2. 「選んだ部品」→「**読み上げ**」の節で、
   - **文**を入れる
   - 「**声**」で話者を選ぶ（「動画全体に合わせる」＝既定の声）
   - 「**声を作る**」を押す ← **押すと帯の長さが実際の尺に合う**
3. 「**この読み上げの字幕を置く**」を押す。**同じ時間・連動つき**の字幕が置かれる。
4. **2本目**を、1本目の**すぐ後ろ**に置く。**同じ列でよい**（交互＝時間が重ならないため）。
5. 話者を**別の声**にして「声を作る」→「この読み上げの字幕を置く」。
6. 3本目以降も同じ。

### 覚えておくこと

- **字幕は読み上げに連動する**＝連動先を動かす・伸ばすと、**字幕も同じ区間へついてくる**。**字幕側から時間は変えられない**（列は変えられる）。
- **字幕の文は書き換えられる**。空にすると**読み上げの文に戻る**（言い換えの上書き層）。
- **文や声を変えると、作った声は外れる**（作り直しになる）。作成済みの表示には戻らない。
- **複製した読み上げは、音声を引き継がない**（作り直す）。

## 3. 重複ナレーション（2人が**同時に**しゃべる）★要望

ここが**列の決まりごとが効いてくる**ところ。

> **同じ列では時間を重ねられない。だから、重ねたいぶんだけ音の列を足す。**

### 手順

1. 「**音の列を足す**」を押して、**音の列を2本**にする。
2. 「読み上げを置く」の「**置く列**」で **1本目の音の列**を選び、読み上げを置く。文・声を入れて「声を作る」。
3. 「置く列」を **2本目の音の列**に変えて、**同じ時刻**に読み上げを置く。別の声にして「声を作る」。
   - ⚠️ **同じ列に置こうとすると断られる**（「その場所には先に置いてある部品があります」）。断られたら**列を足す**。
4. それぞれで「**この読み上げの字幕を置く**」を押す。
   - **2人目の字幕は自動で上へ積まれる**（#1009 で直した。以前は**まったく同じ場所に重なって**下が読めなかった）。
5. 再生して、**2人ぶんが重なって鳴る**ことを確かめる。

### 覚えておくこと

- **声の音量は1本ずつ変えられる**（「選んだ部品」→「**音量**」）。同時にしゃべらせると聞き取りにくいので、**片方を少し下げる**と読みやすい。
- **時間の重なり方は自由**＝完全に同時でも、少しずらして**追いかけるように**重ねてもよい（列が別なら制約は無い）。
- **3人以上も同じ**（音の列を3本にする）。字幕もさらに上へ積まれる。
- ⚠️ **積み上げは画面の外へは出ない**（いちばん上で止まる）。人数が多いと止まった所で重なるので、そのときは**字幕の位置や大きさを手で調整**する。

### 掛け合いと重複を混ぜる

同じ動画の中で混ぜてよい。**時間が重なる所だけ列を分ける**。列は「1人1列」に固定する必要は無く、**空いていれば同じ列を使い回せる**（例＝Aさん・Bさんが交互 → 途中だけ同時、なら音の列2本で足りる）。

## 4. 見た目パターンを置いて、中身を差し替える

**見た目パターンはこの形式では「置ける素材」**。差し込み口は生きている。

1. 「**見た目パターンを置く**」の欄から選んで置く（**向きが違うものは置けない**）。
2. 「選んだ部品」→「**この見た目パターンの中身**」で、**差し込み口ごとに素材を選ぶ**。文字の欄も同じ所で直す。
3. **素材が入っていない差し込み口は知らせが出る**（そのままだと**灰色の枠が動画に焼き込まれる**）。

### 中身をバラす（自由に触りたくなったら）

右クリック →「**中身をバラす**」で、見た目パターンの中身が**1つずつの部品**に分かれる。

- ⚠️ **戻せない**（`Ctrl+Z` でだけ戻る）。押す前に確認が出る。
- **前後で絵は変わらない**（下地・字幕・動きもそのまま持っていく）。
- **バラせないことがある**＝切り抜き・素材の寄せ・切り出しの終わりを決めた動画などが入っているとき。**理由がその場に出る**。

---

## 5. 動き（キーフレーム）

**「本来の見た目からのずれ」を、時刻ごとに置く**。2か所に違う値を置くと、その間はなめらかに変わる。

1. 部品を選ぶ。
2. 再生位置を**その部品が出ている時間の中**へ動かす（外にあると理由が出る）。
3. 「選んだ部品」→「**動き**」の節で、変えたい項目に数字を入れて置く。
   - **横のずれ（px）／縦のずれ（px）／大きさ（倍）／傾き（度）／濃さ（0〜1）**
   - **空欄の項目は触らない**（0 や 1 を勝手に入れない）。
4. 別の時刻へ動かして、違う値を置く。

### 例：ゆっくり大きくしながらフェードイン（Ken Burns 風）

| 再生位置 | 大きさ（倍） | 濃さ | 横のずれ |
|---|---|---|---|
| 部品の先頭 | `1` | `0` | `0` |
| 0.5 秒後 | — | `1` | — |
| 部品の終わり | `1.2` | — | `-80` |

> **専用の「Ken Burns」機能は無い**（「位置＋大きさの2点」で書けるので持たない、という決め）。

### 動き方のカーブ

`linear` / `ease-in` / `ease-out` / `ease-in-out` に加えて、**自由なカーブ**（CSS の `cubic-bezier` と同じ4つの数）を入れられる。**行き過ぎて戻る**動きも作れる（`y` は 0〜1 の外に出せる）。

## 6. 切り抜き・素材の寄せ・速さ

- **切り抜き**（「選んだ部品」→「**切り抜き**」）＝**上下左右を%で隠す**。既定は**中身が動かない**隠し方。素材の差し込み口だけ「**残った部分を枠いっぱいに映す**」も選べる。**変形（動き）のあとの箱を基準**に切る。
- **素材の寄せ**＝はみ出したときに**どこを残すか**（既定は中央）。
- **速さ**（音の部品）＝**置いた長さは変わらない**。**その長さぶんに素材のどれだけを流すか**が変わる。
- **音量の変化**（「**音量の変化**」の節）＝時刻ごとに音量の点を置くと、その間はなめらかに変わる。BGM を声の下でだけ下げたい、といったときに使う。
  - **手で置かなくても、自動でやる道がある**＝設定の「**音の自動調整**」→「**セリフが流れている間はBGMを控えめにする**」。⚠️ **これは書き出しのときの処理**なので、**仕上がり確認では効かない**（プレビューと書き出しで音が違って聞こえるのは、ここだけ意図した差）。

---

## 7. 切り替え（トランジション）

**専用の入れ物は無い。動き（濃さ）で書く。**

- 前の部品の終わりで**濃さを 0 へ**、次の部品の先頭で**濃さを 0 → 1** に置く＝クロスフェード。
- **焼き出し（場面形式から持ってきた場合）は、場面の切り替えを自動で動きに落としてある**ので、そのまま調整できる。

---

## 8. 書き出し

1. **再生を止める**（再生中は書き出せない）。
2. 「**動画を書き出す**」を押すと**先に保存先**を聞かれる。走っている間は「**書き出しを中止**」に変わる。
3. **書き出せない理由があるときは、押す前に出て押せなくなる**（見た目パターンが見つからない部品がある、など）。
4. 走っている間は**編集も取り消しもできない／別の動画も開けない**（焼くのは**始めた時点の文書**なので）。

## 9. 実機で見てほしいところ（テスト観点）

- [ ] 掛け合い＝声を作るたびに帯の長さが**実際の尺に合う**か。字幕が**ついてくる**か。
- [ ] 重複ナレーション＝**2人ぶんが重なって鳴る**か。**字幕が重ならず上へ積まれる**か（#1009）。
- [ ] 重複＋音量＝片方を下げると**聞き取りやすくなる**か。
- [ ] 複数選択の長さ＝ボタンの「**（N個）**」が**実際に変わる数**と合っているか（#1005）。
- [ ] サイドバーの「**今の動画**」＝場面形式とタイムライン形式の**両方**へ行けるか（#1006）。
- [ ] 動き＝プレビューで見た動きが、**書き出した動画と同じ**か。
- [ ] バラす＝**前後で絵が変わらない**か。

## 付録：うまくいかないときに出る言葉

| 出る言葉 | 意味 | 次にすること |
|---|---|---|
| その場所には先に置いてある部品があります | 同じ列で時間が重なった | **列を足す**か、ずらす |
| 音の部品は音の列に、絵や文字の部品は映像の列に | 列の種類が違う | 合う列を選ぶ |
| この列は固定されています | 列に鍵がかかっている | 固定を外す |
| 選んだ部品が、いま再生位置にかかっていません | 長さのボタンの相手がいない | 再生位置を部品の上へ移すか、選び直す |
| 再生を止めてから使えます | 再生中 | 止める |
