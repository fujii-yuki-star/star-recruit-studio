# 画面仕様書

## 1. 目的

本資料は、「ゆうこ採用ムービーメーカー」の画面構成、画面遷移、主要UI要素を定義する。

主利用者は非技術者の採用担当者であるため、通常画面では専門用語を避け、直感的な表現を使用する。

---

## 2. UI基本方針

- JSON、FFmpeg、LLM、Providerなどの技術用語を通常画面に出さない。
- 基本操作はウィザード形式にする。
- 編集はシーンカード形式を中心にする。
- 詳細な調整は「こだわり編集」に隠す。
- エラーは原因よりも対応方法を示す。
- AI生成結果は「動画のたたき台」として見せる。

---

## 3. 用語置き換え

| 内部用語 | 画面表示 |
|---|---|
| template | 見た目パターン |
| asset | 素材 |
| render | 動画を書き出す |
| validation | 内容チェック |
| narration | ゆうこのセリフ / ゆうこの声 |
| provider | 使用するAI |
| scene | 場面 |
| part | パート |
| export | 保存 |
| videoKind | 動画の種類 |
| videoKind=recruit | 採用動画 |
| videoKind=general | 一般動画・社内発表 |

---

## 4. 画面一覧

| 画面 | 目的 |
|---|---|
| ホーム画面 | 新規作成・最近のプロジェクトを選ぶ |
| 作成ウィザード | 動画目的、会社情報、素材を入力する |
| 素材管理画面 | 写真・動画・BGM・ゆうこ素材を管理する |
| AI送信確認画面 | 外部AIに送る情報を確認する |
| 動画案確認画面 | AI生成結果を台本表として確認する |
| シーン編集画面 | シーンカードを編集する |
| こだわり編集画面 | 細かい調整を行う |
| プレビュー画面 | 仕上がりを確認する |
| 書き出し画面 | MP4を保存する |
| テンプレート管理画面 | 見た目パターンを追加・確認する |
| 設定画面 | AI、音声、保存先などを設定する |

---

## 5. ホーム画面

### 表示項目

- 新しい動画を作る
- 最近使ったプロジェクト
- プロジェクトを開く
- 見た目パターンを管理
- 設定

### 主ボタン

- `新しい動画を作る`
- `プロジェクトを開く`

---

## 6. 作成ウィザード

### Step 1：動画の目的

選択肢：

- 会社紹介
- 新卒採用
- 中途採用
- 未経験歓迎
- エンジニア採用
- 会社説明会用
- SNS向け短尺

入力：

- 動画タイトル
- 目標の長さ
- 雰囲気

### Step 2：会社情報

入力：

- 会社名
- 業種
- 事業内容
- 募集職種
- 採用対象
- 会社の強み
- 求める人物像
- 採用ページURL

### Step 3：素材追加

入力：

- 写真を追加
- 動画を追加
- BGMを追加
- ロゴを追加

各素材に説明文を付けられる。

### Step 4：ゆうこの声

入力：

- 声の種類
- 話す速さ
- 声の高さ
- 抑揚
- 音量

初期値：ずんだもん

### Step 5：AIでたたき台作成

ボタン：

- `ゆうこに動画案を作ってもらう`

---

## 7. AI送信確認画面

### 表示文言例

```text
AIが動画案を作るために、以下の情報を送信します。

・会社情報
・動画の目的
・素材の説明
・画像サムネイル
・動画の代表フレーム

元の動画ファイルは送信しません。
送信してもよろしいですか？
```

### ボタン

- `送信して動画案を作る`
- `キャンセル`

---

## 8. 動画案確認画面

AI結果を表形式で表示する。

| 順番 | パート | 場面 | 使う素材 | ゆうこのセリフ | 見た目 |
|---:|---|---|---|---|---|
| 1 | はじめに | 挨拶 | 会社外観 | こんにちは、ゆうこです。 | オープニング |

### 操作

- この内容でプレビュー
- セリフを直す
- 素材を変更
- 見た目を変更
- もう一度作り直す
- シーンを追加
- シーンを削除

---

## 9. シーン編集画面

### レイアウト

```text
左：素材一覧
中央：プレビュー
下：シーンカード
右：選択中シーンの編集
```

### シーンカード表示

- サムネイル
- 場面名
- 表示秒数
- 使用素材
- 音声生成状態

### 右パネル基本項目

- 場面名
- 見た目パターン
- 使用素材
- ゆうこのセリフ
- 字幕
- 表示時間
- ゆうこの表示/素材

---

## 10. こだわり編集

通常は閉じておく。

### 編集項目

- 画像の表示位置
- 動画の開始秒・終了秒
- 動画内音声ON/OFF
- 動画内音声音量
- BGM音量
- ナレーション音量
- 画面切り替え
- 字幕表示ON/OFF
- ゆうこ表示ON/OFF

---

## 11. プレビュー画面

### 再生範囲

- この場面だけ
- このパートだけ
- 全体

### 表示

- 動画プレビュー
- 再生/停止
- シークバー
- 現在の場面名
- 音量設定

---

## 12. 書き出し画面

### 設定

- 保存先
- 動画サイズ
- 字幕あり/なし
- BGMあり/なし
- ファイル名

### 進捗表示

```text
動画を書き出しています
場面 3 / 12 を処理中
```

### 完了時

- 保存先を開く
- 動画を再生
- ホームに戻る

---

## 13. テンプレート管理画面

画面表示では「見た目パターン」とする。

### 機能

- 標準見た目パターン一覧
- 追加済み見た目パターン一覧
- 見た目パターンを追加
- サムネイル確認
- サンプル表示
- 削除

MVPではテンプレートパック取り込みを基本とする。

---

## 14. 設定画面

### AI設定

- 使用するAI
- APIキー
- 外部AI送信確認を毎回表示するか

### 音声設定

- VOICEVOX接続先
- ゆうこの標準声
- 話速・高さ・抑揚

### 保存設定

- プロジェクト保存先
- 一時ファイル削除

---

## 15. エラーメッセージ方針

悪い例：

```text
Invalid templateId
```

良い例：

```text
この場面で使う見た目パターンが見つかりませんでした。
代わりに標準の写真紹介パターンを使います。
```

---

## 16. 重要なUX

- 生成中でも完了したシーンから確認できる。
- 長尺動画ではパート単位で確認できる。
- セリフ修正後は該当シーンだけ音声再生成できる。
- AI生成結果は必ずユーザーが確認してから動画化する。
