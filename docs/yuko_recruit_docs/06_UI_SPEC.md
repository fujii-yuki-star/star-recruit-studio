# 画面仕様書

## 1. 目的

本資料は、「ゆうこ採用ムービーメーカー」の画面構成、画面遷移、主要UI要素を定義する。

主利用者は非技術者の採用担当者であるため、通常画面では専門用語を避け、直感的な表現を使用する。

---

## 2. UI基本方針

- JSON、FFmpeg、LLM、Providerなどの技術用語を通常画面に出さない。
- 基本操作はウィザード形式にする。
- 編集はシーンカード形式を中心にする。
- 詳細な調整は「こだわり編集」に隠す。
- エラーは原因よりも対応方法を示す。
- AI生成結果は「動画のたたき台」として見せる。

### 操作の統一規約（#410）

同じ操作は全画面で同じ見た目・位置・語彙にする（実装は共有コンポーネント＋単一参照元。これがその規範の単一参照元）。

1. **削除確認**：破壊的な削除は確認を挟む。並びは【やめる（左・ghost）／削除する（右・`btn-danger`＋TrashIcon）】で固定。復元できないものだけ「元に戻せません」を添える（取り消せるもの＝場面・テロップ・セリフ等には付けない）。共有 `DeleteConfirm`。表の行内など notice が入らない場所は同じ並び・色のインライン確認で代替してよい。編集キャンバス上の単体要素（FREE要素・レイヤー）は即時＋取り消し（Undo／未保存破棄）とし、複数まとめて消すときだけ確認する。
2. **キャンセル語**：はい/いいえの確認ダイアログの取消は「やめる」。並びは【やめる（左）／実行アクション（右）】で削除確認と揃える。※実行中の処理の**中断**は「キャンセル／中止」で別カテゴリ（生成キャンセル・書き出し中止・送信前確認）。
3. **戻る導線**：編集フロー内の戻るは **ghost＋←アイコン＋「◯◯へ戻る」**（行き先名）。仕上がり確認は多入口のため「来た画面へ戻る」。**完了後CTA・空状態の主要CTAは対象外**（例：書き出し完了後の「プロジェクト一覧へ戻る」、編集対象なし警告の「一覧へ戻る」）。
4. **busy 表示**：非同期操作の実行中は**ボタンのラベルを変え**（「保存中…／作成中…／書き出し中…」等）**かつ disabled** にする（disabled のみ・表示なしにしない）。
5. **保存ラベル**：保存ボタンは「保存」1種（状態で「保存中…／保存しました／保存に失敗（もう一度押す）」）。同一画面に保存を2つ置かない（共通トップバーの「保存」に一本化）。文言の単一参照元は `saveButtonLabel`。
6. **未保存インジケータ**：「● 未保存の変更があります」（琥珀）の単一実装 `UnsavedMark` を共有する。
7. **保存の着地は「まだ同じ動画を開いているか」で括る**（#762）：自動保存は書き終わるまでに時間がかかり、**その間に別の動画を開ける**（保存中は「未保存あり」と見なさないため確認も出ない）。括らないと、完了の反映が**いま開いている方**へ前の動画の id を書き込み、以後その動画の自動保存が**前の動画のファイルを上書きする**（作業がディスクごと消える・取り消し不能）。失敗の知らせも同じ＝別の動画へ誤って帰属させない。
   ⚠️ 照合に**動画の id を使わない**＝新規の動画は保存で初めて id を採るので、「どちらも id 無し」で同じものに見え、**採番した id が別の新規へ乗る**。開き直す・新規にする・消すたびに進む**世代**で照合する。
8. **アクションボタンの可視ラベル**：押すと何かが起きるボタンの見える文言は**操作（動詞）**にする（対象を指す名詞だけにしない）。狭い一覧の行内などラベルを置けない所は**操作を表すアイコン**にし、名前（動詞）は `title`/`aria-label` で必ず補う。例＝改名は「名前」（名詞）ではなく**ペンアイコン＋`aria-label="名前を変更"`**（#547 P3-6）。※入力欄の**ラベル**は対象名（名詞）でよい＝これはボタンの規約。
9. **編集画面の共通ツールバー**（#774）：**取り消す／やり直す・保存の状態・保存・戻る**は、3つの編集画面
   （場面編集・タイムライン編集・見た目パターン編集）とも**見出しの行**に置く（共有部品 `EditorToolbar`）。
   ⚠️ 以前は3画面3様で、とくにタイムラインは**画面のいちばん下**にあり、欄が画面の高さを超えると
   **スクロールしないと見えなかった**＝**見えていないボタンは無いのと同じ**（ADR-0034 決定19 が「もう1つの
   入口を残す」と言うとき、その入口は**見えている**必要がある）。場面編集も**欄の中**にあり、欄を閉じたり
   配置を変えると見失えた（ADR-0033 で配置を動かせるようにしたぶん、欄の中に置くほど見失いやすい）。
   ⚠️ **「スクロールしても消えない」ところまでが条件**＝場面編集の見出しはスクロールする側の**外**にあるが、
   他の2画面は**中**にあるので**貼り付ける**（`.editor-header`）。移した先が一緒に流れていくなら直したことにならない。
   ⚠️ **保存の状態と「押せるもの」を同じ行に置く**（「作業が消える不安」への備え）＝知らせだけを移すと、
   欄を閉じた状態で保存に失敗したとき「もう一度お試しください」の行き先が画面から消える（§2-5 が行き止まりになる）。
   置き場を移したので**元の場所からは外す**（同じ操作を2か所に置かない＝上記5の流儀）。
   戻るの言い方は画面ごと（「台本表へ戻る」「一覧へ戻る」）。※ タイムラインの「動画の一覧へ」は上記3 の
   「◯◯へ戻る」書式に**まだ揃っていない**（#629 以来の既存ラベル・#774 では変えていない）。
   ※ **たたき台（台本表）は対象外**＝保存の状態も戻るも持たず、取り消す／やり直すだけを見出しのすぐ下に置く
   （画面の上・欄の外なので「欄を閉じると見失う」は起きない）。

> **動画編集の一般語は置き換えない**（ADR-0034 決定21）。この表が置き換えるのは **JSON・FFmpeg・LLM・templateId のような実装用語**（`§2` の方針）であって、
> **分割・ズーム・吸着・トリム・ドラッグのような動画編集の一般語はそのまま使う**＝分かりやすさを最優先する（利用者判断 2026-08-04）。
> ただし**既に定着した言い換えは変えない**（見た目パターン／素材／部品／欄／差し込み口）。


### 3.1 欄の配置（画面共通・ADR-0033）

編集画面は**欄**（見出しのついた区画）に分かれ、**利用者が配置を組み替えられる**。仕組みはどの画面でも同じ（§6）。

- 画面は**左・中央・右・下**の領域に分かれ、**領域の中は縦にも横にも積める**（欄の数に上限は無い）。
- **境界をドラッグして大きさを変えられる**（領域の外枠も、欄どうしの境目も）。掴んだ2つの間だけが動く。
- 欄の見出しを**つかんで動かす**と、ほかの欄の隣へ移せる（**入る場所を線で示す**）。**少し動かすまでは掴まない**・
  **`Escape` でやめられる**・**自分の上／いま居る場所へ落としても何も変わらない**・**左ボタンでだけ掴む**。
- 見出しの「⋮」または**右クリック**で、**上へ／下へ／左へ／右へ**・**左/真ん中/右/下へ移す**・**この欄を閉じる**。
  **動かせない向きは押せなくして理由を出す**。
- **閉じた欄は必ず戻せる**（「〈欄の名前〉を表示する」）・**「配置を既定に戻す」はいつでも押せる**（戻れない状態を作らない）。
- 配置は**画面ごとに1つ**覚える（**動画ごとには持たない**＝別の動画を開いても崩れない）。
  **利用者が変えたときだけ覚える**＝触っていない画面は、こちらが既定を良くしたときにその既定が届く。
- **欄の中身は欄の中でスクロール**する（欄からはみ出さない）。置くものの一覧は**一度に5件ほど＋絞り込み**。
- **欄の中では折り返す**（#687）＝ボタンや入力が増えても**横スクロールを求めない**（デスクトップでは横に送りにくい）。
- **欄の中の節は畳める**（#550・#687）＝縦に長い欄でも、いま触らない節を閉じて上下スクロールを減らせる。
  **よく触る節は開き、細かい調整の節は畳んで出す**。ただし**設定が入っている節は開いて出す**
  （畳んで隠すと入れた設定を見失う＝場面編集の「上書き設定済みなら開く」と同じ規準）。
  **選ぶ対象を切り替えたら既定を見直す**（最初に選んだものの開閉のまま固まらない）。
  **知らせ（黙って消さないための表示）は畳める場所に置かない**＝一度畳んだ記憶が既定より優先されるので、
  節の中に置くと二度と見えなくなる。
  開閉は**画面ごとに**覚える（別画面の同じ見出しと混ざらない）。**記憶のキーは見出しと別に持つ**
  ＝見出しを言い換えたときに記憶が黙って消えない。
  **利用者が実際に開閉したときだけ覚える**＝触っていない節は、こちらが既定を良くしたときにその既定が届く。
- **空の領域へはドラッグで入れられない**（線を出す相手がいない）＝そこは「〈領域〉へ移す」を使う。

### ナビゲーション（サイドバー・#399 B案）

- 先頭は **「プロジェクト」＝一覧**（新規作成・最近のプロジェクト。旧「ホーム」を統合）。押すと必ず一覧が出る（いきなり1本のたたき台へは飛ばない＝利用者のメンタルモデルに一致）。
- **動画を開いている間だけ「今の動画（プロジェクト名）」**が現れ、工程画面群（ウィザード/確認/生成中/たたき台/場面編集/仕上がり確認/タイムライン/公開前チェック/書き出し）を束ねてアクティブ表示する。未オープン時は出さない（一覧へ誘導）。
  - 押すと**直近に開いていた工程画面へ戻る**（たたき台固定にしない・#547 P3-7）。工程外（素材・見た目・設定・一覧）へ出ても位置を保持するので、後半の工程（例：書き出し）から素材を見に行って戻っても先頭へ飛ばされない。まだ工程画面に入っていなければ入口＝たたき台へ。工程画面か否かの線引きと戻り先の記憶は単一の純粋関数（`app/navigation.ts`）で App とサイドバーが共有する（§6）。
- 以降は **素材／見た目パターン／設定**。工程間の「戻る/進む」導線は各画面内のボタン（サイドバー再構成の影響を受けない）。戻るの見た目・文言は §2「操作の統一規約」に従う（ghost＋←＋「◯◯へ戻る」）。

- ⚠️ **押せないボタンを案内しない**（差分再監査 7巡目 🟡・§2-5）＝動画を開いていないときは「素材を追加」が押せないので、空の一覧の案内も**次の行動**（先に動画を開くか、新しく作る）へ差し替える。押せない理由はボタンに添えるが、**それはホバーにしか出ない**ので、案内文の側でその場に出す。

### レイアウト


**既定の並びはこれまでと同じ**（左＝素材一覧／中央＝仕上がり確認と場面の並び（上下）／右＝選択中の場面を編集）
＝配置を触っていない利用者の画面は、**顔ぶれも並びも変わらない**（欄の幅は割合で決まるので実寸は少し変わる）。

**#276（左パネルの折りたたみ・右パネルの横幅ドラッグ）の専用の操作は無くなった**＝欄を閉じる／境界を

＝あれは欄の**中身**の話で、配置とは別の層。

**仕上がり確認の上には「拡大縮小」と「端の目安」を置く**（#142・#265）＝どちらも `ScenePreview` を使う
画面で共有する部品（場面編集・見た目パターン編集）。

- **端の目安（安全領域）**＝端で切られやすいところに点線の枠を出す。⚠️ **編集を助けるためだけ**で
  **書き出しには焼かない**（`layoutScene` を通らない＝プレビュー＝書き出しの一致には関わらない）。
  ⚠️ **横と縦で厚みが違う**＝横型は四辺 5%（テレビのオーバースキャン由来）、縦型は上下に UI
  （時刻・操作ボタン）が重なるので**上下を厚く**する。⚠️ **仕上がり確認には出さない**＝あそこは
  「出来上がり」を見る場所で、補助線が入ると**動画にも入るのか**が分からなくなる。
  ⚠️ 言い方は**「端の目安」**（「セーフエリア」は一般の利用者に通じない業界語＝§2-3。ADR-0034
  決定21 の「動画編集の一般語」にも当たらない）。
- **出すかどうかは覚える**（ADR-0033・ADR-0034 決定14）＝**画面の好み**（その人の作り方）なので
  `localStorage` に置く。**倍率は覚えない**＝あれは**文書の見え方**なので、別の動画を開いたときに
  前の倍率で始まると「なぜか拡大されている」になる。

### 配置の複製・コピー/貼り付け（#770）

自由配置の要素は**複製**（同じ場面へ）と**コピー→貼り付け**（別の場面へも）ができる。

- **中身ごと運ぶ**＝**その部品に付いた動き**（登場のしかた）と、**画像/動画の設定**（枠への収め方・使う範囲・速度・元音声・再生の開始タイミング）も一緒に付いてくる。⚠️ 形だけ写すと「**動く要素を複製したのに動かない複製**」ができ、設定も既定へ戻る（＝空の複製）。
  ⚠️ **まとまり（グループ）に付いた動きは付いてこない**＝その動きはまとまりのものなので、複製はまとまりに入らない（位置もまとまりの変形が乗らない）。まとまりごと複製したいときは、いまは1つずつ複製してまとめ直す。
- **取り消しは1回**＝複製・貼り付けは1手として戻る（動きだけ戻って要素が残る、を作らない）。
- **コピーは押した時点の控え**＝コピーした後に元を消しても、中身つきで貼れる。

### グループ化（要素をまとめて扱う・ADR-0022）

自由配置（こだわり編集）と見た目パターン作成（§14）で、複数の要素（図形・素材・文字／レイヤー）を**グループ**にまとめ、ひとかたまりとして扱える。

- **グループ化/解除**：2つ以上選んで「グループ化」。選択中グループは「解除」でばらせる。
  **解除するとそのまとまりに付けた動きも消える**（#779）＝まとまりが無くなる以上、その動きの持ち主も居なくなる。
  ⚠️ 残すと、**後から作った別のまとまりが勝手に動く**（まとまりの番号は空いた最小の番号を使い回すため）。
  **メンバーを全部消して空になったとき**も同じ（利用者は解除していないが、まとまりは無くなる）。
- **まとめて変形**：グループの枠をドラッグで移動、角で拡大縮小、上のハンドルで回転。
- **まとめて管理**：グループ単位で「隠す/表示」「ロック」「前面/背面（重ね順）」。
- **ロック中**：移動・拡縮・回転・重ね順・解除はできない（うっかり変更を防止）。**表示/非表示の切替とロック解除は可能**。
- 表示は技術用語を出さない（§3）。「グループ／前面／背面／隠す／ロック」等のユーザー向け表現のみ。

## 12. タイムライン画面 ─「タイムラインで編集する形にする」（ADR-0032・#628）

時間の流れを見わたす読み取り専用の表示に加えて、**タイムライン編集の形式へ作り直す**導線を置く（片道＝決定16）。

- **押す前に出しきる**（押した瞬間に作らない・2段階）：①**新しい動画として作られ、いまの動画はそのまま残る**こと ②**増えるディスク容量**（写真・動画・作成済みの声をコピーするため＝決定13） ③**持っていけないもの**（`15 §6` の `BAKE_*`）。①〜③を見せてから「この内容で作る」。
- **作り直す範囲**は「動画ぜんぶ／パートを選ぶ／場面の範囲を選ぶ」（決定17）。範囲や名前を変えたら**確認をやり直させる**（古い容量・注意書きのまま作らせない）。**場面が1つも入らない範囲では作らせない**（中身の無い動画を作らない）。
- 容量は**目安として丸めて**出す（`formatDiskSize`＝1MB 未満／約 NMB／約 N.NGB）。「0.003MB」のような読みづらい数字を出さない。
- 語彙：`タイムライン形式`/`焼き出し`/`クリップ` などは出さない（§3）。「タイムラインで編集する形にする」「作り直す」で言う。
- **作れなかったときは、理由に合った「次の行動」を出す**（§2-5・ADR-0026④・#811 の追補）。作れない理由は
  **置き場所が足りないだけではない**＝**作った中身の問題**（適合しない・目印が重なる）を「空き容量を確かめて」と
  案内すると、言われたとおりにしても直らない。中身の問題は「元の動画の中身に問題があるようです。作る範囲を狭めるか、
  元の動画を直してから」、ファイルのコピー・保存の失敗は「空き容量を確かめて」。実装は `BakeError`（`message` を
  そのまま出す＝読込の `TimelineLoadError` と同じ流儀）。

**入口は3つ（#635・ADR-0032 決定15）**。ホームの「新しい動画を作る」（AI に任せる）「白紙から作る」に並べて
**「タイムラインで作る」**を置く＝**場面に区切らず、時間の流れの上に自分で並べる**別の作り方（完全新規＝決定7）。
- 場面形式とは**別の動画**になる（あとから行き来はしない）。作った直後は**列が映像・音の2本だけ**で中身は空。
- **押した瞬間には作らず、先に向きを聞く**（横向き／縦向き・#664）＝**あとから変える導線が無い**ので、
  作る前に決めてもらう（「あとから変えられません」と添える・§2-5）。やめる導線も出す。
- 作るのはディスクへの書き込みなので、**作っている間はボタンを押せなくし**、失敗したら**画面を変えずにその場で断る**（§2-5）。
- 既存の動画から作り直す入口（上の「タイムラインで編集する形にする」）へは、**たたき台と仕上がり確認からも
  1回で行ける**（「タイムラインで見る」＝#394 を #635 へ吸収）。

### 12.1 タイムライン編集画面（ADR-0032・#629）

**場面形式とは別の文書**なので、一覧から開いたときに**形式で行き先を分ける**（開いてから「形式が違う」と断らない）。一覧では名前の横に「タイムライン」と出して作り方が分かるようにする。

- **開けなかったときは理由と「一覧へ戻る」導線を出す**（`15 §6`・生のエラーは見せない）。
- 骨格（#629 前半）で出すもの＝**その瞬間の仕上がり**（再生位置のつまみ）・**列とクリップの並び**・**クリップの選択**（Shift で追加選択）。
- **列は手前が上**に並べる（保存の並びは後ろほど手前）＝重なりの見え方と一致させる。
- 語彙：`トラック`/`クリップ`は出さない（§3）。「列」「置いてあるもの」で言う。列の自動名は「映像1」「音2」。
- 見え方（目盛り・レーン・クリップ）は**見わたすタイムラインと同じ CSS を使う**＝2つの一覧で見え方が割れない（§6）。
- **共通トップバーの「保存」「保存状態」は出さない**＝あれは場面形式の文書を保存するもので、見ている文書と違うものが保存される（場面形式を開いていないときは空のプロジェクトが新しく作られる）。
- **見た目パターンが見つからない部品**と**置き場所の取り違え**（`11 §8` V22–V28）は必ず知らせる＝描画から外れるものを黙らせない（`15 §6`）。
- 列の自動名の連番は**種別ごと**（「映像1」「音1」）。並び全体の通し番号にすると「音1」が存在しない動画ができる。
- **編集**（#629 後半）＝部品を1つ選ぶと「前へ／後ろへ／再生位置へ／ここから始める／ここで終わる／**複製／削除**／置く列」。**複数選んだときはまとめて消すだけ**（位置は対象が決まらないので変えない）。**列の操作は下記の右クリックのメニュー**（行にボタンを並べない）。⚠️ **取り消す・やり直すはこの欄ではなく見出しの行**（`§2` 統一規約9・#774）＝欄の中や画面の下に置くと、配置を変えたり欄が伸びたりしたときに見失う。
  - **開始・長さは数値でも入れられる**（#721・ADR-0034 決定6）＝ボタンだけだと 0.5 秒ずつか「再生位置に合わせる」しかなく、
    **「3.0秒から」「5.0秒間」に揃える手段が無い**。刻みは**1フレーム**（出力の格子と同じ＝半端な位置に置いて
    書き出しで黙ってずらさない）。**長さは終わりの端を動かす**（始まりは動かない）。ボタンと同じ入口へ流すので、
    置けない条件も同じ（固定した列・書き出し中は触れない）。
  - **消すのは、単体なら即時＋取り消し・まとめてなら確認**（`§2` 統一規約1・ADR-0034 決定20・#721）。
    **ボタンでもキー（`Delete`）でも同じ**＝キーだけ確認なしで消える、を作らない。
    確認は**聞いた相手を消す**（数だけ覚えない）＝この確認は覆いではなく知らせの段なので、
    出したまま選び直せてしまう。「2個消しますか」と聞いて1個/全部が消える、を作らない。
- **見た目パターンの部品を選ぶと、その中身（差し込み口の素材・文字）を差し替えられる**（#632）。差し込み口の
  名前は**場面編集と同じ言い方**（`slotLabelsFor`＝同じ枠を画面によって別の名で呼ばない）。**入れられる素材の規則も
  場面編集と同じ**（`assignableAssetsFor`）＝**動画も選択肢に出す**（#512 段3 で差し込み口の動画も映り元の音も
  鳴るようになり、外す理由が消えた。詳しくは下の「この動画の音」）。見た目パターンが見つからない部品では、
  中身の欄の代わりに「次の行動」を出す。
- **「読み上げを置く」**（#633）＝再生位置から音の列へ置く。選ぶと**読み上げる文・声（話者）・「声を作る」**が出る。
  声を作ると**長さが声に合う**（合わせられないときは理由を出し、作った声はそのまま残す）。
  **「この読み上げの字幕を置く」**で、連動つきの字幕を同じ時間に置ける（置ける列が無ければ列を足す）。
  文や声を変えると**作り直しになる**（作成済みの表示に戻らない）。作れなかったときは次の行動を出す。
- **画面は「欄」に分かれ、配置を変えられる**（→ `§3.1 欄の配置`。この画面が持つ欄＝仕上がり確認／並び／選んだ部品／
  素材・文字・図形を置く／見た目パターンを置く／音を置く／読み上げを置く）。**既定は「再生位置」と「選んだ部品」が同時に見える形**
  （中央＝仕上がり確認と再生位置／右＝選んだ部品／下＝並び／左＝置くもの4つ）＝設定を変えないままでも
  「1点置くごとに上下スクロール」が起きない。
  **「選んだ部品」の中は節に分かれ、畳める**（#687＝`§3.1`）。**開いて出す**のは「位置・大きさ」「音」
  「この動画の音」「音量」「読み上げ」「連動する読み上げ」「この見た目パターンの中身」「中身」（写真・文字・図形の
  中身を決める節・#684）、**畳んで出す**のは「切り抜き」「動き」「音量の変化」「字幕の見た目」（細かい調整。
  **ただし設定が入っていれば開く**＝部品を選び直したら見直す〔節に `key` を付ける〕）。
  ⚠️ **字幕の見た目は文字の部品と同じ顔ぶれ**（差分再監査 5巡目 🔴）＝大きさ・色・太さ・揃え・縁取り・
  文字の形・字間・行間・影・背景帯。**同じ関数から出す**（`renderClipTextBasics`／`renderClipTextDecoration`）
  ＝片方だけ足りない、を構造で防ぐ（描画も書き込みも通っているのに入口が影と帯しか無かった）。
  **欄の中では折り返す**＝横スクロールを求めない。**入力欄と選択欄は欄の幅に収める**（長い素材名で欄が横に伸びない）。
  - **見出しをつかんで動かすと、ほかの欄の隣へ移せる**（ADR-0033 段階3）＝指した辺に**線を出して**どこに入るかを見せる
    （分からないまま落とさせない）。**少し動かすまでは掴まない**（押しただけで動き出さない）・**`Escape` でやめられる**・
    **自分の上へ落としても何も起きない**・**いま居る場所へ落とし直しても何も変わらない**（決めた大きさが等分へ戻らない）。
    **左ボタンでだけ掴む**（右クリックはメニュー）・「⋮」の上からは掴み始めない（メニューを開く操作を奪わない）。
    **境界のドラッグも `Escape` で掴む前の大きさへ戻る**（欄のドラッグと同じ意味＝ADR-0026②）。
  - 欄の見出しの「⋮」または**右クリック**で、**上へ／下へ／左へ／右へ**（並べ替え）・**左/真ん中/右/下へ移す**・**この欄を閉じる**。
    **空の領域へはドラッグで入れられない**（線を出す相手がいないため）＝そこは「〈領域〉へ移す」を使う。
  - **閉じた欄は必ず戻せる**（「〈欄の名前〉を表示する」が出る）・**「配置を既定に戻す」はいつでも押せる**（決定6/8＝戻れない状態を作らない）。
  - 配置は**画面ごとに1つ**覚える（**動画ごとには持たない**＝別の動画を開いても崩れない・決定4）。
  - **欄の中身は欄の中でスクロール**する（欄からはみ出さない・決定10）。
- **編集の場所を上から狭めない**（利用者指摘 2026-08-04）＝画面の説明文は出さない（名前だけ）。
  **知らせは欄の下に出す**＝上に積むと、出るたびに編集の場所が押し下げられて狭くなる。
  **答えを求める確認**（バラす・列を消す）は上のまま＝見落とすと操作が進まないため。
- **操作したその場の返事は「操作した欄の中」に出す**（ADR-0034 決定10・#869）＝欄がいくつも並ぶ画面では、
  欄の外の帯に出しても**どの操作が断られたのか読めない**（恒常の警告とも同じ見た目で並んでしまう）。
  返す先は**理由ではなく「操作」で決める**＝同じ「重なっています」でも、置くボタンで出たなら**置く欄**、
  帯を掴んで出たなら**並びの欄**が正しい。決め方は次のとおり（正典＝`src/app/timelinePanels.ts`）。

  | 始め方 | 返す先 |
  |---|---|
  | 欄のボタン・メニュー | **その欄** |
  | キャンバス／並びの帯を掴む | 掴んだ面（仕上がり確認／並び） |
  | キーボードだけの操作 | **欄の外の帯**（押せない見た目が無い＝欄に閉じると気づけない） |
  | 入口が2つ以上ある操作（分ける・バラす・消す） | 始めた所を渡す |

  ⚠️ **画面全体の話になる理由（書き出し中・再生中・対象が無い）は、欄を渡されても帯へ倒す**＝
  入口ごとに「これだけは帯」と書くと、入口が増えたとき片方だけ欄へ押し込まれ、**同じ状況なのに
  出る場所が違う**（ADR-0026②）。規則は1か所（`blockTargetFor`）に置き、**呼ぶ側は素直に自分の欄を渡す**。

  ⚠️ **行き先の欄を閉じているときも帯へ倒す**＝欄の中に出しても見えないので、押した結果が**黙って消える**（§2-5）。
  ⚠️ **恒常の警告と見分ける**＝その場の返事は**次の操作で消える**見た目（貼り付く知らせ）、直すまで残る警告は**欄の外のいつもの位置**。
  同じ文を**帯と欄の両方に出さない**（どちらが今の返事か読めなくなる）。
- **欄の外に残る帯は、欄と同じ囲いの中に閉じる**＝下にある操作の行（「〈欄〉を表示する」「配置を既定に戻す」）を覆わない
  （覆うと閉じた欄を戻せなくなる＝§2-5）。※ 取り消す・動画の一覧へは**見出しの行**へ移した（#774＝上記 `§2` 統一規約9）ので、
  この行にはもう無い。
- **列（並び）の操作は右クリックのメニュー**（ADR-0033 決定9）＝順番（手前へ/奥へ）・動画に出す/出さない・固定・消す。
  **行にボタンを並べない**（帯より文字が目立ち、並びが読めなくなる）。行に出すのは**名前と状態**（出さない・固定中）だけ。
  **同じメニューを開く小さな「⋮」も置く**＝右クリックを知らない・使えないときの逃げ道（§2-5）。項目名は**いまの状態で
  意味が通る言い方**にする（出していない列なら「動画に出す」）。**固定した列では「この列を消す」を押せなくして理由を出す**
  ＝押してから断られる、を作らない（`§2-5`・ADR-0032「固定した列は動かせないだけでなく消せない」）。
- **置くものの一覧は欄の中に収める**（ADR-0033 決定10）＝「見た目パターンを置く」「音を置く」は**縦に並べ**、
  一度に見せるのは**5件ほど**、残りは**欄の中のスクロール**で辿る。**多いときは絞り込み**を出し、見えている数
  （「12件中4件」「全12件（この中をスクロールできます）」）も出す＝**隠れているものがあると分かる**。
  横に並べると数が増えたぶん**欄からはみ出して画面の外へ突き抜ける**（利用者指摘 2026-08-03）。
- **「素材・文字・図形を置く」**（#684）＝この動画が持っている写真を一覧から選ぶ・**文字／図形はボタンで置く**。
  **置き方は2通り**（ADR-0034 決定2）＝**押す**と再生位置へ・**つかんで運ぶ**と落とした所へ。
  掴めない環境・人のために**押すだけの道は必ず残す**（決定19＝ドラッグ専用の操作を作らない）。
  **置いたものはそのまま選ばれる**（続けて中身を直せる）。押して置いたときは**画面の真ん中**＝置いた瞬間に見える。
  ⚠️ **どこへ入るかを見せる**（#771(b)）＝この欄にも**「置く列」**を出す（既定＝いちばん手前の置ける列）。
  以前はここだけ無く、**暗黙にどこかの列**へ入っていた（なぜそこに入ったのか読めない）。
  **落とし先は2つ**＝**仕上がり確認**（動画の中の場所を決める。列は**欄の「置く列」**・時刻はボタンと
  同じ規則でアプリが選ぶ＝利用者が指したのは位置であって列や時間ではない）と**列**（時刻と列を決める。
  **別の場所を探さない**＝そこへ置けなければ断る・決定10）。
  ⚠️ **つかんで置くときの時刻は、帯を運ぶときと同じ吸着**（#771(a)・決定12）＝同じ「時間を決める操作」で
  作法を割らない（片方だけ吸着が無いと、置いた直後に必ず微妙にずれて運び直しになる）。点線も `Ctrl` で
  切れるのも同じ。決定10 の「探さない」は**置けない所から別の場所へ移さない**ことで、近くの端へそろえる
  こととは別。**運んでいる間は影を出し、置けない所では色を変える**。
  **理由の文言は離したときだけ**出す（ドラッグ中に明滅させない）。**落とし先の外で離したら何も置かない**
  （黙って再生位置へ置かない）。置ける／置けないの判定は `clipPlacementIssue` 1つ＝**影の色と結果が食い違わない**。
  ドラッグの作法（少し動かすまで掴まない・`Escape` で中止・左ボタンのみ・掴んだ指だけ見る・
  離したのを取り逃がしたらやめる）は**欄の配置と同じ**（`usePointerDrag`・ADR-0033 段階3 と共有
  ＝掴む場所ごとに書き分けない）。**列の上では「どこに・何秒ぶん」入るかを実寸で見せる**
  （欄の配置が線で示すのと同じ流儀＝どこに入るか分からないまま落とさせない）。
  **スクロールで欄の外へ出ている列へは落とせない**（見えていない所へ入らない）。
  **置いたら、その時刻へ再生位置が動く**＝押して置いたときも含め**必ず仕上がり確認に現れる**。
  **掴めるものは手を出す前に分かる**（`grabbable`＝欄の見出し・帯と同じ見た目）。
  指で押したときは離した時点で確定し、`click` は**キーボードのぶんだけ**拾う（`isKeyboardActivation`）
  ＝二重に置かない／中止したのに置かれない／運んだ次の1回が効かない、をまとめて防ぐ。
  **置けるものはすべて掴んで運べる**（#714 項目2）＝素材・文字・図形に加えて**見た目パターン・音・読み上げ**も
  同じ作法（押すだけでも置ける・決定19）。**置ける条件と置いたときの長さは `clipPlacementIssue` /
  `placedDurationSec` の1組**＝運んでいる最中の枠の幅・色と、実際に置いた結果が食い違わない。
  ⚠️ **仕上がり確認へ落とせるのは絵の部品だけ**＝見た目パターン・音・読み上げは**動画の中の場所を持たない**ので、
  落とし先の外と同じ扱い（何も置かない・勝手に再生位置へ置かない）。
  **並べ替え（場面カード・台本表・列）でも端まで運べば送る**（#714 項目5・#802-3）＝置く側・運ぶ側と**同じ部品**
  （`useEdgeAutoScroll`。向きだけ変える＝場面カードの帯は横・台本表の頁と**タイムラインの列**は縦）。
  ⚠️ **見えている範囲へ丸めてから当てる**＝欄からはみ出した位置で当てると、切り取られて**見えていない
  ところ**が落とし先になり、離すとそこへ置かれる。丸めの規則は `clampToVisible` の**1か所**
  （運ぶ側〔場面カード・台本表〕と列の並べ替えが共有）。**測れないときは丸めない**＝実寸を持たない箱で丸めると
  すべての位置が端へ潰れ、**どこへ運んでも先頭**になる。
  ⚠️ **送っている間は指が止まったまま**なので、落とし先の要素からは動きが来ない。**位置からすき間を
  引き直す**（`gapAtPosition`）＝送った分だけ挿入線も追いつく（引き直さないと、離したときに
  **送る前の場所**へ落ちる）。**並びの外へ指が出ても端のすき間を保つ**（線が消えない）。
  ⚠️ 塞がっているとき**置き先を探すのは素材・文字・図形だけ**（見た目パターン・音・読み上げは**探さず**
  理由を出す＝`11 §7.6.3`）。探す側は**いちばん手前の置ける列の、その次に空いている時刻へ置く**（押しても置けない、を続けない）
  ＝**間の空きを飛び越さない**（いちばん後ろの部品の終わりへ飛ばすと、目の前の空きを使わずに遠くへ置かれる
  ＝`firstFreeStart`・#684 レビュー）。**奥の列へは逃がさない**（#722）＝奥の同じ時刻が空いていても、
  手前に画面いっぱいの部品があると**その裏に入って見えない**。**時刻が後ろへずれても「見える」を優先する**。
  **隠した列・固定した列には置かない**（動画に出ない部品を黙って作らない）。
  置ける列が無いときは「**映像の列を足す**」を指す。
- **「写真・動画を取り込む」**（#712）＝この動画へ素材を足す。場面形式の素材画面はこの形式を見ないので、
  そこを指すと**行き止まりの案内**になる（ADR-0034 決定5）＝**この画面で取り込める**。
  **置ける列が無くても取り込める**（列を足すまで素材を用意できない、を作らない）。押し心地は場面形式と同じ
  （アプリの中はネイティブの「開く」・ブラウザはファイル選択）。**選び方の分岐は `useAssetPicker` に1か所**
  ＝素材の画面・はじめの入力・タイムライン編集が同じものを通る（見た目は違ってよい＝はじめの入力は大きな枠なので、
  部品〔`AssetImportButton`〕ではなく**振る舞い**を共有する。部品だけ共有すると見た目の違う入口が取り残される）。
  **取り込み中は押せない**（同じ番号の素材が2つできる）。**取り込めなかったら一覧に足さず**、次の行動を出す
  （幽霊の行を作らない）。**取り消しで一覧から消える**（やり直しで戻る＝`11 §7.6.3` 参照）。
- **置いた部品は「中身」をその場で直せる**（#684）＝文字（文言・大きさ・色・太さ・フォント・揃え）／図形（形・色）／
  写真（素材・枠への収め方）。**形の名前は場面編集と同じ**（同じ形を画面によって別の名で呼ばない）。
  **フォントは「動画全体に合わせる」へ戻せる**（#731・場面編集と同じ）＝戻せないと、一度選んだら
  動画全体の設定を変えても**その部品だけ取り残される**。指定が無いときも**そう表示する**
  （既定の字体名を現在値のように見せない＝動画全体を別の字体にしていると表示と実際が食い違う）。
  **どの欄も、固定した列の部品と書き出しの最中は触れない**（理由を出す＝押してから断らない・#720）。
  **色を選ぶ面をひと撫でしても取り消しは1回ぶん**＝途中の色ひとつひとつが取り消しに積まれると、
  **1回のドラッグで前の操作まで戻れなくなる**（覚えておける件数には上限があるため。場面編集・見た目パターン編集も同じ）。
  **色を選ぶ面の「やめる」も、他の掴みと同じ結末**（#763・場面編集・見た目パターン編集も同じ部品なので同時に効く）
  ＝**撫でている最中の `Escape`／取り上げられたとき（`pointercancel`）／押していない移動で取り逃がしに
  気づいたとき**は、いずれも**撫で始めの色へ戻す**（離したときだけが「選んだ色で確定」）。
  以前は `Escape` が「確定して閉じる」で、同じ画面の中で作法が割れていた。
  **`Escape` で枠は閉じない**＝一度に2段はがさず、2度目の `Escape` で閉じる。
  取り逃がしを拾わないと、掴んだ印が残って**ただの移動で色が書かれ続け**、`Ctrl+Z` も全画面で効かなくなる。
  ⚠️ **採らない作法もある**（掴みの共通作法のうち）＝**少し動かすまで掴まない**は採らない（押した所の色を
  すぐ入れるのがこの面の作法）。**左ボタンのみ**と**掴んだ指だけ見る**は**まだ入っていない**（別途）。
- **「音を置く」**（#634）＝同梱BGM／持っている音の素材を、再生位置から音の列へ置く。
  **どこへ入るかを見せる**（#724）＝「置く列」を出す（既定は**いちばん手前の置ける列**・見た目パターンも同じ）。
  以前は無言でいちばん奥の列に固定しており、列が2本以上あると「なぜここに入ったのか」が読めなかった。
  **読み上げを置くときも同じ**。置ける列の絞り込みは映像側と**同じ規則・同じ向き**（`placeableAudioTracks`）。
  ⚠️ 置く側の「置く列」は**次にどこへ置くかの下書き**なので、書き出し中でも触れる（変えても文書は動かない）。
  塞ぐのは「選んだ部品」の置く列＝そちらは文書を変える。
- **音量と前後のフェードは、鳴る音を持つ部品すべてで変えられる**（#724）＝**読み上げにも出す**。
  下の「音量の変化」（点）は読み上げにも出ているので、出さないと**点は置けるのに基準の音量は直せない**
  という逆さまになる（ADR-0026②）。描く側はどちらの種別も同じように読んでいる。
- **音の部品を選ぶと「鳴らす音・速さ・素材の使い始め」を変えられる**（#634・#695/#723）。
  ⚠️ **速さ・使い始めは読み上げには出さない**（#724）＝読み上げの長さは声を作ったときの実尺に合わせて
  あるので、速さを変えると**しゃべり終わりと部品の終わりがずれ、連動している字幕も合わなくなる**。
  **鳴らす音は選び直せる**＝素材が見つからなくなったときの案内（「鳴らす音で選び直す」）に対応する操作が
  画面にある（無いと行き止まり＝ADR-0034 決定5）。消して置き直すのと違い、**速さ・音量・フェードは残る**。
  いまの音が選ばれていない状態も欄に出す（空欄で固まって見えない、を作らない）。
  ⚠️ **いま指している音が見つからないときは、そう出す**（#734 レビュー）＝一覧に無い値をそのまま
  選択欄へ渡すと**先頭の候補が選ばれているように見える**。「見つかりません」と知らせているのに
  欄では別の曲が入っているように読め、直ったと勘違いする（§2-5・黙って別のものに差し替えない）。
  素材の差し込み口と同じ扱い（名前だけ出して、選び直しはできる）。
  **速さを変えても部品の長さは変わらない**（置いた長さぶんに素材のどれだけを流すかが変わる）ことをその場に書く。
  音量は空欄で「動画全体に合わせる」。**固定した列では変えられない**（欄を押せなくする）。
  ⚠️ **案内の中で名指しするものは、その画面に実在すること**（#723・決定5）＝「別の見た目パターンを選ぶ」
  「音を選び直す」「置く」のように、**その節に無い操作・存在しないボタン名**を書かない。実装していない操作も案内に出さない
  （**分割は land 済み**＝例に使わない。この規則は「いま無いものを名指ししない」ことであって、特定の機能の話ではない）。列の絞り込みが固定と非表示の**両方**を除くなら、案内も両方を言う。
- **音の部品・読み上げには「音量の変化」を置ける**（#512 段4）＝**再生位置にその時の音量を置く**（動きの
  キーフレームと同じ流儀）。違う値を2か所に置くと**その間はなめらかに変わる**こと、**前後のフェードは
  この変化の上に掛かる**ことをその場に書く。置いた点は**動画の時刻**（部品の開始＋点の秒）で一覧に出し、
  「この位置へ」「外す」「すべて外す」を添える。**再生位置が部品の外なら置けない**＝鳴っている時間を示して
  動かし方を案内する（§2-5）。**上限（`VOLUME_POINTS_MAX`）に達したら置かずに理由を出す**（`15 §6`）＝
  置けたのに書き出しで断られる、を作らない。点があるときは**いま何か所置いてあるか**を見せる。
  **絵の部品には出さない**（鳴る音が無いので効かない）・**再生中は押せない**・**固定した列では変えられない**。
  **点があるときは、その部品の「音量」欄（一定の音量）は使われない**ので**押せなくして理由を出す**
  （＝設定したのに音が変わらない、を作らない・ADR-0026①）。戻し方（「音量の変化をすべて外す」）も添える。
  **置けなかったときは入力した値を消さない**（上限などで断られたあと、打ち直しにさせない）。
- **列へ置いた動画には「この動画の音」がある**（#512 段2）＝「この動画に入っている音を流す」と音量。
  **既定は流さない**（既に作った動画の音が黙って変わらない）。空欄で標準の音量（20%）。
  ⚠️ **音が入っていない動画には欄を出さず、その場で理由を出す**（`15 §6` `TIMELINE_VIDEO_NO_AUDIO`）＝
  押せない欄を並べない・押しても何も起きない、を作らない（§2-5）。**音が入っているか確かめられなかった
  ものは断定せず、取り込み直しを案内する**（`TIMELINE_VIDEO_AUDIO_UNKNOWN`＝場面形式と同じ2文の出し分け）。
  ⚠️ **音の部品の「音量」欄とは別**＝音量の変化・前後のフェードは動画の元の音には効かないので**出さない**
  （置けるのに効かない、を作らない）。**固定した列では変えられない**。
  **仕上がり確認で聞こえたものが、そのまま書き出しに出る**（同じ解決を通る＝ADR-0001）。
  ⚠️ **差し込み口に入れた動画も映り、元の音も鳴る**（#512 段3・段3b）＝**動画も選択肢に出し**（規則は
  場面編集と同じ関数）、**その枠ごとに「この動画の音」を出す**（直接置きと同じ形・同じ言い方＝ADR-0026②）。
  音が入っていない／確かめられない枠には、直接置きと同じ2文でその場に理由を出す。
  ⚠️ **立ち絵に入れた動画はまだ静止画**＝置いてあると書き出しの手前で断る。
  ⚠️ **実映像にできないときは、その場で理由を出す**（黙って静止＋無音にしない・§2-5／ADR-0026④）＝
  まとまり全体を薄くしている間・回した部品を切り抜いている間（どちらも書き出しでは動く）に加えて、
  **この画面が再生できない形式**（`.avi`/`.mkv` など＝取り込めるが復号できない）も理由を出す（#816-1）。
  最後のものは**音も出せない**（同じ復号器を通る）ので、鳴らす側からも外して理由だけ出す＝
  「仕上がり確認では無音なのに、書き出した動画には入っている」を黙って作らない。
  ⚠️ ただし**「書き出しには入る」とは約束しない**＝**素材のファイルが見つからない**ときも同じ状態に
  落ちる（再生の失敗の合図は理由を区別しない）ので、そのときは書き出しも失敗する。両方に当たる行動
  （取り込み直す）だけを出す。
  ⚠️ **差し込み口でない場所（背景など）に入れた動画は静止画のまま**＝そのため**バラす前に断る**（#816-4）。
  バラすと直接置きになって**動き出す**＝「動画の見た目は変わりません」という確認の約束が破れる。
- **部品を選ぶと「切り抜き」と「素材の寄せ」ができる**（#634）＝寄せは「枠いっぱいに表示」で**枠に収まらない側を
  どこで切るか**（全体を表示のときは余白の寄せ）。切り抜きは上下左右を%で隠す。
  上下・左右それぞれの合計は99%まで。**素材の差し込み口では「切り抜いたあと」を選べる**＝「隠したままにする
  （中身は動かない）」か「残った部分を枠いっぱいに映す」。後者は**素材の大きさが分かるときだけ**効くので、
  分からないときは**その場に理由を出して**「隠したまま」で描く（黙って別の絵にしない＝§2-5・ADR-0026④）。**音の部品には出さない**（絵が無いので効かない）・**固定した列では変えられない**。
- **置いたキーフレームごとに「ここまでの動き方」を選べる**（#262）＝一定／ゆっくり始まる／ゆっくり終わる／
  両端ゆっくり／**自由なカーブ**。カーブは制御点を数で入れる（始め・終わりの強さと向き）。**「両端ゆっくり」から
  カーブへ変えると動きが少し変わる**ので、変える前にその場に書く（黙って別の動きにしない＝ADR-0026④）。
  横の強さは0〜1（時間が戻らない）・**縦の向きは範囲外も入れられる**（行き過ぎて戻る動き）。
- **部品を選ぶと「動き」を付けられる**（#634）＝再生位置に**「本来の見た目からのずれ」**を置く
  （横のずれ・縦のずれ・大きさの倍・傾きの度・濃さ）。**空欄の項目は動かさない**。2か所に違う値を置くと
  その間はなめらかに変わる。置いた動きは時刻つきで一覧に出し、**その位置へ移動／値を読み込んで直す／外す**が
  できる（まとめて外すも）。**再生位置が部品の外にあるときは置かせない**（どこへ置かれるか分からない操作にしない）。
  **音の部品には出さない**（絵が無いので効かない）。**再生中は押せない**・**固定した列では押せない**・
  **書き出し中は押せない**（いずれも理由を出す＝押してから断らない）。
  **置けなかったときは入力した値を消さない**（音量の変化と同じ規準＝#694。断られたあと打ち直しにさせない）。
  **時刻は丸めて置く**＝再生位置から起点を引いた端数のまま置くと、置き直したつもりで**点が増える**（#702）。
  **その部品が入っている「まとまり」に動きが付いているときも知らせる**（画面では動いているのに「動きは付いて
  いません」と言わない）。
- **字幕の部品を選ぶと「連動する読み上げ」を選べる**（#633）＝連動すると**文言と時間**が読み上げに合う。
  **いま出る文**をその場に見せる（自分の文を入れているときは、そちらが優先されていることも言う）。
  **字幕の文の欄**も出す＝**空にすると読み上げの文に合わせる**（焼き出しで文が焼き付いた字幕も追従へ切り替えられる）。
  連動している字幕は**時間を自分で動かせない**（理由を出す）＝読み上げに合わせているため。列は変えられる。
  **連動する読み上げが見つからない字幕は知らせる**（自分の文で描かれ続けるので、黙って連動が切れたことに
  気づけない）。
- **見た目パターンの部品は「中身をバラす」で1つ1つの部品に分けられる**（#632）。**押す前に断る**＝
  「動画の見た目は変わらないが、写真や文字を入れる場所は無くなる。戻すときは取り消しを押す」（戻せない＝ADR-0032 決定23）。
  バラした部品はまとめて選ばれる（続けて動かせる）。
- **見た目パターンを一覧から置ける**（#632）＝置き先の列を選び、**再生位置から**置く。置いた部品はそのまま選ばれる
  （続けて中身を入れられる）。置けないときは理由を出す。**一覧はこの動画と同じ向きのものだけ**（押せるのに置けない
  ものを並べない）。
- **素材が入っていない差し込み口があることを知らせる**（#632）＝そのままだと灰色の枠が動画に焼き込まれる。
  **入れられる素材が1つも無い差し込み口**（動画専用の枠など）には、何をすればよいかをその場に出す
  （永久に埋まらない枠を黙らせない）。
- **選ぶ作法は1つ**（ADR-0034 決定15・#701）＝帯を押して選ぶ・`Shift` で足す・**何もない所（列の空きと行の余白）を
  押すと解ける**・**`Escape` で解ける**・**`Ctrl+A`（Mac は `Cmd+A`）で全部選べる**。
  **文字を打っている間と日本語の変換中はキーを奪わない**（変換中の `Escape` は「変換をやめる」＝打っている文を消さない。
  **スライダーやチェックボックスは「文字を打つ場所」ではない**ので奪う＝触った直後にキーが黙って効かなくならない）。
  **`Escape` は手前のものから1段ずつはがす**＝メニュー・欄のドラッグ中・確認が開いている間は**選択まで解かない**
  （閉じただけで打ちかけの値が消えない）。受け持っている側が**自分で名乗る**仕組みにする＝画面が数え上げると、
  受け手が増えるたびに数え漏れて同じ穴が開く。**帯には名前と時間帯を添える**（短い帯でも何か分かる・場面形式と同じ書き方）。
  **帯には中身も敷く**（#332）＝音は**波形**、動画は**コマ列**。名前だけだと「どこで何が鳴っているか」が
  帯からは分からない。⚠️ **置いた範囲だけを映す**＝素材まるごとを測って帯へ伸ばすと、末尾だけを置いた帯に
  頭からの絵が出る（切り出しと速さを見る＝`11 §7.6.5` の「トリムと速度も渡す」と同じ筋）。
  ⚠️ **動画には波形を敷かない**＝コマ列と重なってどちらも読めない（音の大小は選んだときの欄で見る）。
  ⚠️ **細い帯には敷かない**（潰れて読めない）。⚠️ **動画の出力には出ない**＝`layoutTimelineAt` を通らない
  ので、プレビュー＝書き出しの一致（ADR-0001）には関わらない。作り置き（`projects/<id>/cache/`）は
  **作り直せる**ので `project.json` には持たず、起動時に古いものから片づける。
  **選ぶ部品を切り替えたら、前の部品への入力（下書き）と、前の操作の返事は残さない**
  ＝打った覚えのない値が入らない／前の理由がいまの部品の返事に見えない。
  **全部選べても、固定した列の部品は消せない**（動かせないのに消せる、を作らない）。
- **押せない理由は押す前に出す**（#703・監査 §2.2-11）＝編集の入口は**押せなくして理由を添える**。
  押してから断ると、断られた入力を残す配慮も手戻りにしかならない。**答えを求める確認は開く前に断る**
  （答えてから断ると、取り返しのつかなさを聞いた意味が無くなる）。**始まってしまった書き出しは、開いている確認を閉じる**。
  理由の順は**欄そのものを触れなくする条件（固定・書き出し中）が先、欄の中身の事情はそのあと**
  （前者が晴れないうちは後者を直しても押せないため）。判定は**1か所から配る**＝入口ごとに条件を書き並べると必ず数え漏れる。
- **文字の欄は、打っている間ずっと画面に反映する**（#708）＝連動する字幕・見た目の中の文字は**打ちながら見える**
  （見えているものがそのまま出る）。**取り消しだけを「欄に入ってから出るまで」で1つにまとめる**
  ＝1文字ごとに積むと上限を文字入力で食い潰し、それ以前の編集（バラすなど＝取り消しでしか戻らない）が戻せなくなる。
  **欄に入っただけでは取り消しを消費しない**（触っただけで履歴が減らない）。
  **打っている間は自動保存を待つ**（打つたびに全部書き直さない）。**欄が入れ替わるときは必ずまとめを閉じる**
  ＝フォーカス中に欄が消えると閉じる合図が来ないので、開いたままだと**以後の取り消しが積まれなくなる**。
  ⚠️ **ただし、閉じるのが掴んでいる最中なら開き直す**（#813）＝キャンバスで**まだ選んでいない**部品を
  掴むと、同じ操作が「選ぶ」→「まとめを開く」の順に走るので、選択が変わったことによる後始末が
  **開いた直後のまとめを畳んでしまう**。以後は動かすたびに1件ずつ積まれ、60回で上限に達して
  **そのドラッグより前の編集が取り消せなくなる**（実測）。素通りではなく**畳んでから開き直す**
  ＝閉じられなかった古いまとめも一緒に片づく。そして**開いた側が閉じる責任を持つ**＝閉じる合図を出すのは
  **部品を掴んだときだけ**で、空白を押しての選択解除・範囲選択・帯のドラッグは出さない。閉じ損ねると
  **以後の編集が履歴に積まれず、自動保存も止まる**（そのまま閉じると編集が消える）。
  ⚠️ 閉じる合図は**終わり方を並べて数えない**（`Escape` でやめたときは合図そのものが出ない）＝
  **「掴んでいるものが無くなったか」の1か所**で閉じる。
  **利用者が打っている以外の完了**（声ができた等）は**このまとめに混ぜない**＝打った文字と一緒に消えない。
- **数値の欄は確定（欄から離れる／Enter）で1回だけ反映する**（#706）＝**1文字ごとに取り消しが積まれない**。
  文字の欄と扱いが違うのは、**打ちかけの数値を画面に出す必要が無い**ため。
  **色コードの欄も同じ**（#752）＝3桁でも有効な色になるので、随時反映だと「1a2b3c」を打つ途中の
  `#1a2` で1件・完成でもう1件と**打ち方で取り消しの件数が変わる**。同じ色を打ち直したときは反映しない。
  ⚠️ **閉じ方に依らず、打った色は捨てない**＝色の枠は外側を押しても `Escape` でも**欄ごと消える**ので
  「欄から離れる」が来ない。閉じるとき・画面から外れるときにも確定する（押せなくなって閉じたときを除く）。
  （**撫でている最中の1度目の `Escape` は閉じない**＝そのときは「やめる」＝上記。ここは打っている場面の話。）
  ⚠️ **開いている最中に外から色が変わったら、面もコード欄も追う**（取り消し・別の欄からの変更）
  ＝古い色のまま残すと**いまの色を偽って見せる**（そのまま撫でると、戻したはずの色を起点に書き直す）。
  **自分が送った色では同期し直さない**（撫でている指と競らない）。
  ⚠️ ただし**送るのは自分で打った色だけ**＝面やパレットで選んだ色は既に送ってあるので、閉じるときに
  送り直すと「選ぶ→取り消す→閉じる」で**戻したはずの色が復活**する（やり直しでも戻せない）。
  ⚠️ **外側を押して閉じるときは、その押下が選び直すより先に確定する**＝色の受け口は「いま選ばれて
  いるもの」を見るので、閉じたあとに確定すると**打った色が新しく選ばれた相手へ入る**。
  ⚠️ **押せなくなって閉じたときは、確定しないだけでなく打ちかけも捨てる**＝印を残すと、そのあと
  画面から外れた回に送られてしまう（受け取れない状況で書き込まない、を経路によって破る）。
  ⚠️ **パレットは同じ色でも送る**（欄と役目が違う）＝呼び出し側の現在色は**未設定のときの解決値**の
  ことがあるので、送らないと「いまの色で固定する」が表現できない。
  打っている途中の値は直さない（桁を打ち切る前に範囲へ丸めない）。範囲外は確定のときに範囲へ収める。
  **空にできる欄**（音量＝動画全体に合わせる／動きの各項目＝動かさない）は、空と 0 を混同しない。
- **置けないときは「次にどうすれば置けるか」を出す**（`15 §6` の `TIMELINE_EDIT_*`）＝勝手に近くへ寄せたり上書きしたりしない。
- **列の操作は「並び」の欄の中で完結する**（#767・利用者要望）＝**列を足す**導線も欄の中に置く
  （欄だけを見ていて列を足せず、欄の外を探しに行く、を作らない）。**同じ操作を2か所に置かない**
  （`§2` 統一規約5 の流儀）ので、画面下部からは外す。
- **列は中身ごと複製できる**（#767）＝空の列だけ増やすなら「列を足す」と同じなので、**中の部品も運ぶ**。
  引き継ぐ／引き継がないは**部品ひとつの複製とは別の規則**（正典＝`11 §7.6.2.3`・#787）：
  - **読み上げの音声は引き継がない**（ここだけ部品ひとつの複製と同じ＝作成済みに見えるのに別の部品の
    音声を指す、を作らない）。
  - **連動している字幕は、元の読み上げを指したまま運ぶ**＝別の列・同じ区間なので重なりに当たらず、
    時間も文言も追従する。⚠️ 以前ここは「一緒に複製されるときだけ結び直す」と書いていたが、
    **編集操作からはそういう文書を作れない**（字幕は映像の列・読み上げは音の列）ので実際には
    **連動が必ず落ち、何も出ない帯ができていた**（#787＝🔴）。
  - **まとまり・動きは複製した部品を指すように張り替える**（部品ひとつの複製は引き継がない）。
  ※ **部品ひとつの複製**は連動を落とす（同じ列の直後＝区間が合わず必ず重なるため）が、
  **落とす前にいま出ている文を焼き付ける**＝何も出ない帯にしない。
  ⚠️ **まとまりが列をまたぐときは断る**＝片側だけ複製すると、まとまりの変形が乗らない複製が**元と違う絵**に
  なる（複製をまとまりへ入れれば、今度は元の絵まで動く）。次の行動は「まとまりを外す」。
  名前は引き継がない（同じ名前の列が2つ並ぶと区別できない＝自動名は種別ごとの連番）。
- ⚠️ **掴んで並べ替えるときの落とし先は「すき間」**（#771(c)・画面ぜんぶで同じ）＝**重なった項目**で
  決めると、**同じ手つきが向きで別の意味**になる（前へ動かすとその手前・後ろへ動かすとその後ろに入る
  ＝利用者は同じ操作をしたのに**結果が1つずれる**）。**挿入線**でそのすき間を見せ、指したとおりの場所へ
  入れる。すき間から実際の位置へ直す計算は1か所（`insertIndexForGap`）＝画面で数え直さない。
  **端まで運べば送る**（#714 項目5・#802-3）＝置く側と同じ部品（`useEdgeAutoScroll`）で、
  **場面カードの帯・台本表の行・列（タイムライン）のすべて**に効く（列は縦・欄の器を送る）。
  ⚠️ **見えている範囲へ丸めてから当てる**のも同じ＝欄からはみ出した位置で**見えていない所**に
  線が決まって、そこで確定する、を作らない。**測れないときは丸めない**（高さの無い矩形で丸めると
  すべてが上端へ潰れる）。丸めの規則は `clampToVisible` の**1か所**。
  ⚠️ **すき間の当て方だけは列が別**＝場面カードと台本表は項目の間に余白があるので「どちらとも
  決めない」が要り、規則を domain（`gapAtPosition`）に置いて共有する。**列は行が隙間なく並ぶ**ので
  画面側（`displayGapAt`）で素朴に走査する＝**共有するのは丸めと送る部品まで**。
  **送っている間は位置からすき間を引き直す**（指が止まっていても線が追いつく・
  **見えている範囲へ丸めてから当てる**ので画面外の項目に線が出ない）。
  対象＝**列**（タイムライン）・**場面カード**（場面編集）・**台本表の行**（たたき台）。
  ⚠️ **掴む作法も同じ**（#714-4）＝**少し動かすまで掴まない**（震えで隣のすき間が確定しない）／
  **`Escape` でやめられる**（やめたら並べ替えない）／**掴んだ指だけ見る**（取り逃がした後の無関係な
  離しでそこへ落ちない）。共通部品（`usePointerDrag`）に乗せる＝並べ替えだけ自前で持たない。
  以前は場面カードと台本表だけ #398 当時の自前実装のままで、この3つがどれも欠けていた
  （同じアプリの中で `Escape` の意味が2つある状態だった）。
  ⚠️ **やめる `Escape` は「掴むのをやめる」だけに効かせる**＝同じキーで**開いている欄まで閉じない**
  （上記「手前のものから1段ずつはがす」）。並べ替えがやめられるようになったぶん、掴んだまま欄が
  開いている組み合わせが新しくできたので、画面側の後始末は**受け持ちがいる間は走らせない**。
  ⚠️ 見るのは「掴んでいるか」ではなく**名簿**（`hasEscapeOwner`）＝欄の中に入れ子で開く色や書体の面は
  **撫でていなくても**開いている間ずっと受け持つので、掴む話に限った判定だと**そこだけ穴が残る**
  （1回のキーで面と欄が同時に閉じる）。名簿には掴みも入るので、判定は画面ごとに1つで足りる。
- **列は掴んで並べ替えられる**（#767）＝帯は掴めるのに列だけメニューの「手前へ／奥へ」しかない、を解消。
  落とし先も掴む作法も**上記（画面横断の項）と同じ**＝ここには書き写さない（片方だけ直る元になる）。
  **落ちる先は線で示す**（どこに入るか分からないまま落とさせない）。**ドラッグ専用にしない**（決定19）
  ＝「手前へ／奥へ」は残す。⚠️ **重ね順は列の並びそのもの**なので、並べ替えると**絵の重なりが変わる**
  （取り消しで戻せる）。
- **列を消すときは、一緒に消える部品の数を出して確認する**（黙って消さない）。**固定した列は消せない**（固定の切替も列ごとに出す＝「固定を外してください」の行き先を作る）。
- **編集は自動保存する**（少し待ってから書く）＝閉じても消えない。書けなかったときは成功に見せない。
  - 共通トップバーの保存ボタンは出さない（ADR-0032＝押すと場面形式の文書を保存してしまう）ので、**保存の結果を出す担い手はこの画面**（#693）。**保存できたことも控えめに出す**（勝手に保存されているのを信じられるようにする）。
  - **書けなかったら理由と「保存し直す」を見出しの行に出す**（`15 §6` の `TIMELINE_SAVE_FAILED`・`§2` 統一規約9）
    ＝欄の下だと、欄が画面の高さを超えたときスクロールしないと見えず、失敗したまま気づけない。**自動では繰り返さない**＝同じ理由で失敗し続ける間ディスクを叩き直しても直らない。次の編集からは自動保存に戻る。
  - **画面を離れるときは、待っている保存を書き切る**（#693）＝待ち時間の途中で一覧やサイドバーへ移っても、直前の変更が無言で消えない。
    ⚠️ **書くかどうかは、欄の後始末より後で決める**（#763）＝画面の後始末は**欄より先**に走るので、
    そこで「保存済み」を見て降りると、その後に欄（色の欄など）が**打ちかけを確定**したぶんを誰も書かない
    ＝開き直すと確定したはずの値が消える。
    「動画の一覧へ」で戻るときは**書き終わるまで待つ**（実行中はラベルを変えて押せなくする＝`§2` 統一規約4）＝書いている途中に離れると、そのあと失敗しても気づけない。
  - **保存できなかったまま画面を移ろうとしたら聞く**（待った結果が失敗のときも同じ）。黙って変更を捨てない。答えを求める確認なので**上に出す**（下だと見落として進んでしまう）。**書き出し中はその確認からも戻さない**。
    **画面内のボタンだけでなく、サイドバーなど別の入口から離れるときも聞く**（#719）＝遷移の入口は
    `App` の `navigate` ひとつなので、そこが**離れたくない側の名乗り**（`navigationGuard`）に聞く。
    画面ごとに遷移を書き換えて回らないので、新しい画面が増えても名乗るだけで関門に乗る（`escapeOwners` と同じ考え方）。
    行き先は**聞いたときのもの**へ移る（一覧に固定しない）。答えた1回だけ通す＝同じ確認が出続けて離れられない、を作らない。
    **離れる流れは同時に1つだけ**（#729 レビュー）＝保存を待つ間（1秒ほど）に別の行き先を押しても、
    **移るのは1回・着地は最後に押した所**。走っている流れに行き先だけを託す
    （放っておくと、待ちが明けたときに流れがそれぞれ移動を撃ち、**一瞬だけ先の行き先を描いてから次へ飛ぶ**）。
    断って画面に残るとき（保存失敗の確認）は目印を片づける＝**そのあと何を押しても無反応**、を作らない。
- **音が見つからない部品があることを知らせる**（その部品は鳴らない＝`15 §6`）。読み上げをまだ作っていない部品も同じ扱い。
  **絵が出せない素材を使っている部品**も同じ形で知らせる（#726 レビュー＝同じ状況なのに絵だけ無言、を作らない）。
- **表示倍率**（#686・ADR-0034 決定13）＝「広げる／縮める」と「**全体を表示**」。**開いた直後は全体表示**
  （以前は尺から自動で決めており、長い動画ほど潰れて手が出せなかった）。段は**場面形式の見わたす画面と同じ**。
  **`Ctrl`＋ホイールでも変えられ、錨点はマウスの位置**（見ていた所が流れない）。素のホイールは横スクロールの
  まま＝奪わない。**倍率は覚えない**（決定14＝動画の中身に依存する状態は覚えない）＝開くたびに全体表示から。
  ⚠️ 位置合わせは**描き直した後**に行う（同時にやると、まだ古い幅なのでスクロールの上限で切り詰められ、
  錨点が流れる）。**あとで欄の幅が変わっても合わせ直さない**（利用者が自分で広げた倍率を奪わない）。
- **時間の目盛りを押すとその時刻へ**（#686）＝シークは**目盛りが受ける**（列で受けると帯の選択・ドラッグと
  取り合いになる）。位置を持つ操作なので読み上げに現在位置が伝わり、**`←`/`→` でフレーム送り**（`Shift` で1秒）・
  `Home`／`End` で端へ行ける。⚠️ 矢印は**目盛り自身が受ける**＝画面のキー操作は「矢印を使う要素」に
  譲るので、受けないと**両方が手を引いて何も起きない**（動く量は画面と同じ入口から採る）。
  名前は下の「再生位置」の欄と**分ける**（同じ名前の操作を2つ作らない）。
  **再生位置の線**を並びの上に出す＝いま何が出ているか分かる（線は押せる相手ではないので操作を奪わない）。
  ⚠️ **掴んだまま動かせる**（#819-1・ADR-0034 決定1＝業界の型）＝押した所へ跳ぶだけだと、
  再生ヘッドに**掴み手の三角**を描いておきながら掴めない＝**掴める合図を出して掴めない**という
  一番わかりにくい壊れ方になる。合図も `pointer`（押せる）ではなく**左右に掴める**にする。
  作法は帯・欄と**同じもの**（`usePointerDrag`／`Escape` で掴む前へ戻す／左ボタンだけ）で、
  **押した瞬間から追いてくる**（つまみを掴む操作なので遊びを作らない）。
  ⚠️ **やめたら、指を離しても戻したまま**（#833-1）＝中止のあとに来る `click` を捨てる印は
  **時間で消さない**。`Escape` は**指を離す前**に走るので、`setTimeout` で自分から落とすと
  実機では**印が消えた後に離しの `click` が来て、離した位置で上書き**される（＝やめられない）。
  印は**次に指で押し始めた時点**（`pointerdown`）で落とす。⚠️ **キーボードで起こした `click` は捨てない**
  ＝帯は `<button>` なので `Tab`→`Enter` でも `click` が来るが `pointerdown` は無い。印が残った回のあと
  次がキーだけだと落とす合図が来ず、**`Enter` の1回目が無言で飲み込まれる**（キーで到達できなくなる＝決定19）。
  見分けは `detail`（押した回数）＝状態を持たずに判る。
  ⚠️ **再生中は「掴ませない」ではなく「掴んだら止まる」**（#833-2）＝ADR-0032 決定21 が再生中に**断る**と
  定めるのは再生ヘッドの**値を読む**操作（「再生位置へ」「ここで分ける」等＝走っていると結果が毎回変わる）。
  目盛りは値を**書く**側で結果は一意＝**断る理由が無い**（決定21 の対象外）。そのうえで決定21-1 の趣旨
  （走らせながら位置を触らせない）に合わせ、押した時点で止める。掴む処理だけを止めると、
  **掴める合図は出たまま線は追いてこず、離した瞬間にそこへ跳ぶ**（＝「掴める合図を出して掴めない」が
  再生中だけ残る）。止めるのは押し始めの1か所＝押すだけと掴むで割れない。
  ⚠️ **止めるのは「掴んだとき」だけ**＝**キーのシークは止めない**（`11 §7.6.2.1`「再生中に位置を動かしたら
  時計を測り直す」が再生を続けたままのシークを想定している）。境界は**目盛りかどうかではなく掴んでいるか**
  ＝**「再生位置」の欄（つまみ）を掴んだときも止める**（#844-6）。止めないと握っている間つまみが
  **指と再生位置の間で往復**する（毎フレームの書き戻しが刻みの丸めに収まらない分だけ跳ねる）
  ＝「掴めるのに言うことを聞かない」。掴む入口は種類で分けない（ADR-0026②）。
  ⚠️ **帯は据え置き**＝帯が再生中に掴めないのは理由が別（下記＝合図そのものを出さない／吸着の寄り先に
  再生位置がある）なので、目盛りに合わせて「掴んだら止まる」へ寄せない。
  ⚠️ **ヘッドが枠の外にあれば見える範囲を送る**（#819-1／#833-3）＝外へ出た時点で「いま何が出ているのか」が
  画面から消える（倍率を上げるほど早く外れる）。送り方は**ページ送り**＝見えている間は動かさず、
  外へ出たときだけヘッドが左端に来るよう送る（毎フレーム中央へ寄せると画面が流れ続けて位置関係が読めない）。
  **再生中だけのものにしない**＝止まっている間に**利用者が位置を動かす操作すべて**（矢印・`Home`/`End`・
  「先頭へ」・「再生位置」の欄・キーフレーム／音量点の「この位置へ」）が同じ入口を通る
  （⚠️ **送りの話**＝再生を止めるかどうかとは別。止めるのは掴んだときだけ＝上記）
  ＝同じ動作なのに入口で追う／追わないが割れない（ADR-0026②＝`Home` キーと「先頭へ」ボタン）。
  **掴んで運んでいる間は帯と同じ端送り**（`autoScroll`）を通す＝枠の外まで運んでも送りが無いと、
  見えない所へ置いて離すことになる（同じ画面の掴む操作で流儀を割らない）。
  ⚠️ 境界は**誰が動かしたか**＝位置が変わっただけ（外から・取り消し）では送らない。「勝手に画面が動かない」は
  利用者が**枠**を動かしたときの話で、利用者が**位置**を動かしたときは追う。
- **吸着の外し方は画面に書く**（#819-3）＝掴むと勝手に隣へ寄るのに切り方が書かれていないと、
  「思った所へ置けない」ままになる（決定12 は `Ctrl` で切れると定めている）。並びの欄の上に一文で置く。
- **同じ言葉を2つの意味で使わない**（#819-3）＝「置く列」は**次に置く先**（置く欄）の意味に限り、
  選んだ部品が載っている列は**「載っている列」**と呼ぶ（読むほうが区別できない、を作らない）。
- **時刻の書き方は1つ**（#819-3・§6）＝`m:ss`（`clockLabel`）＝目盛り・帯のツールチップ・見わたす画面で
  そろえる。**秒の細かさが要る所だけ**「12.0 秒」と数字で出す（再生位置の読み上げ・数値の欄）。
- **「前へ／後ろへ」は動く量を添える**（#819-3）＝名前だけでは刻み（0.5秒）が分からず、押すまで結果が読めない。
- **帯を掴んで動かせる**（#686・ADR-0034 決定9/10）＝本体を掴むと時間を動かし、**端を掴むと長さを変える**
  （端の取っ手は**選んだ帯にだけ**出す＝隣の当たり判定を常時食わない）。作法は欄のドラッグと同じ
  （少し動かすまで掴まない／`Escape` でやめる／左ボタンだけ／掴んだ指だけ見る）。
  **置けない所では寄せない**（決定10）＝掴んでいる間は**色**で知らせ、離したら**元の位置へ戻し、
  理由の文言を出す**（つかんで置く＝#684 と同じ作法。黙って戻すと「勝手に戻った」としか見えない）。
  **固定した列・書き出し中・再生中の帯は掴めない**（掴めそうに見せない＝つかむ処理そのものを始めない）。
  再生中を含めるのは、**吸着の寄り先に再生位置がある**ため＝掴んだ時点の値で止まったまま流れ続け、
  見えている線と寄る先がずれる（置く操作は既に塞いである＝同じ理由なら同じ挙動・#752-4）。
  端の取っ手は**細い帯では出さない**（本体を掴む所が無くなるため。長さは数値の欄で変えられる＝決定19）。
  ⚠️ **選んだ帯の枠は帯の内側に描く**＝外側に描くと、列の高さに対して上下へはみ出し**隣の列へ食い込んで見える**。
  ⚠️ **列の名前の欄はどの帯よりも前面**＝横へ送ったときに帯が名前の欄を突き抜けない（欄は貼り付いたまま動かない）。
  ⚠️ **「⋮」の位置は幅の条件だけで決める**（掴めるかまで見ると、再生の開始・停止のたびに横へ跳ぶ）。
  ⚠️ **取っ手の当たり判定は見た目より広い**（見た目の2倍・#752-7）＝見た目どおりの細さだと、指が乗る前に
  本体を掴む。広げるのは**帯の内側だけ**（外へ広げると隣の帯を食う）、見た目は太くしない。
  **「⋮」が避ける幅も、取っ手を出す最小の帯の幅も、この当たり判定から導く**（見た目の幅を書き写すと、
  広げた当たり判定が「⋮」を覆う）。
  **掴んでいる間は倍率を変えない**（秒は掴んだ時点の倍率で出しているので、変わると帯が指から離れる）
  ＝ホイールも `−`／`＋`／`全体を表示` も同じ（入口をひとつにして関門もひとつ）。
- **掴んだまま端まで来たら送る**（#714・ADR-0034 決定9）＝いま見えている時間帯の外へも運べる
  （**置く**ドラッグと**帯**のドラッグで同じ部品）。端に近いほど速い・**行き止まりで止まる**・
  端の帯から出たら止まる。**送っている間は指が止まっていても落ちる先が動く**（枠が動くので）。
  効くのは**指がタイムラインの上にいる間だけ**（縦の外では送らない＝一覧を掴んだだけで流れない）。
  左の帯は**列の名前の欄の内側**から測る（欄の下に隠れると、どこへ入るか見ながら送れない）。
  ⚠️ **縦（列の並び）の送りはまだ無い**＝見えていない列へ運ぶには「置く列」の欄を使う（#714 に残す）。
- **列をまたいで運べる**（#686 段階4・ADR-0034 決定9）＝運んでいる間から**運び先の列に描く**
  （指と一緒に列をまたぐ。元の列に置いたまま行き先だけ光らせる、にしない）。
  運び先の**列の採り方**は「置く」と同じ規則（見えている列だけ）＝片方だけ規則が違う、を作らない。
  時刻は**掴んだ位置からの差分**（持ち手のずれを保つ＝離した瞬間に先頭がカーソルへ飛ばない）。
  ⚠️ **連動している字幕は横に動かない**（時間は読み上げが決める）＝列だけ運べる。横にも追従させると
  指が1px ぶれただけで断られ、**縦にだけ動かしたときしか列を変えられない**状態になる。
  **列の外で離したら掴んだ列のまま**（勝手に別の列へ飛ばさない）。置けない列では**赤くなり、離すと元へ戻って
  理由が出る**（決定10）。
- **吸着**（#686 段階4・ADR-0034 決定12）＝**他の帯の端・再生位置・0秒**へ寄る。**画面内に見えている
  ものだけ**（見えていない所へ吸い付くと「なぜ止まったか」が読めない）。寄ったら**縦の点線**を出す
  （再生位置は実線＝役割が違うので見た目を分ける）。**`Ctrl` を押している間は切れる**＝あと少しだけ
  ずらせる。運ぶときは**帯の両端**が寄り先を探し、端を縮めるときは**動かしている端だけ**。
  しきい値は px で決めて倍率で秒へ換算する＝**倍率が変わっても指の感覚が同じ**（空間の吸着と同じ値）。
  ⚠️ **連動している字幕は吸着しない**（そもそも時間が動かない）。
  ⚠️ **確定は「最後に見せた値」**＝離した瞬間に計算し直すと、`Ctrl` を先に離したときだけ寄る
  （離す順で結果が変わる）。**キャンバスの吸着も `Ctrl` で切れる**（3つのキャンバスで同じ切り方）。
- **ここで分ける**（#686 段階4・ADR-0034 決定16）＝**再生位置 × 選んだ帯**。ボタン・`Ctrl+K`・
  帯の右クリックが**同じ入口**（キーだけ／ボタンだけの操作を作らない＝決定19）。
  分けたら**後半を選び直す**（続きを触りたい手が自然に繋がる）。**前半は同じ部品のまま**
  （選択や連動の参照が切れない）。
  **種類で意味が違う**＝絵は時間を切るだけ（**動きは切れ目の見た目を両端に焼く**＝切っただけで絵が飛ばない）／
  音は**素材のどこから鳴らすかを進め**、**フェードは前後に残す**（入りは前半・抜けは後半＝真ん中に
  切れ目の音を作らない）／**読み上げと、それに合わせている字幕は切れない**（文と音がずれる・理由を出す）。
  **両側が最小の長さを満たすときだけ**（片方が潰れる切り方をさせない）。
  ⚠️ **再生中は分けられない**（位置を使う操作＝結果が毎回変わる・ADR-0032 決定21）＝**3つの入口すべて**
  （ボタン・`Ctrl+K`・右クリック）で断る。1つでも素通しだと、走っている再生位置で分割が確定する。
  ⚠️ **カーブの付いた動きの途中でも分けられる**（#753）＝動き方は前後へ切り分けて焼く。
  ただし**その形が表せないときは断る**（「両端ゆっくり」など＝`15 §6`）。近い形で置き換えない。
  ⚠️ **全列いっせいのブレード分割は入れない**（決定16）。
- **まとめて選んでいると一緒に動く**（#686 段階4・ADR-0034 決定15）＝掴んだ相手の動いた量を、
  選択ぶんへ**同じだけ**当てる（群の形を崩さない）。**掴んでも選択を潰さない**。
  **1つでも置けなければ全体を動かさない**（一部だけ動いて群が崩れる、を作らない）。
  **列が変わるのは掴んだ相手だけ**（まとめて別の列へ移すと、見ていない帯が知らない列へ飛ぶ）。
  ⚠️ **連動している字幕は「選択の一員としては」動かない**（時間は読み上げが決める）＝選択に混ざって
  いても時間は据え置く（混ざっただけで全体が動かせなくなる、を作らない）。**列は動かせる**。
  ただし**連動先の読み上げが一緒に動くなら、字幕も付いてくる**（掴んでいる間の見せかけも同じ）。
  ⚠️ **動かない相手は「0秒の壁」の計算に数えない**＝据え置く字幕が 0秒に居るだけで群ぜんぶが
  左へ動けなくなる（しかも断り文も出ない）、を作らない。
  ⚠️ 掴んでいる間の色も**群ぜんぶ**で見る＝**一緒に動く相手と重なる**判定で赤くなるのに離すと
  置ける、を作らない。
- **置いた部品の位置・大きさ・向きを数値で触れる**（#685・ADR-0034 決定6）＝「横位置・縦位置・幅・高さ・
  角度」。**言い方と並びは場面編集の自由配置と同じ**（同じ概念を画面で別の言い方にしない）。
  値は**解決した箱**（未指定＝画面いっぱい）を出す＝空欄にして「動かせない」に見せない。
  ⚠️ **重ね順の欄は出さない**（この形式の重ね順は**列の並びだけ**＝出すと嘘になる・決定17）。
  欄は**「位置・大きさ」の節**にまとめる＝時間の欄（開始・長さ）とひと続きに並べると、どれが秒で
  どれが画面の座標か読み取れない（同じ空間の話である「切り抜き」も節）。
  ⚠️ **見た目パターンのクリップには出さない**（枠そのもの＝中の層を動かすには「バラす」・決定8）。
  **欄が消えるだけにせず、その場で「中身をバラす」を名指しする**（黙って消えると壊れて見える）。
  ⚠️ **名指しできるのは、そのボタンが実在するときだけ**（#812）＝見た目パターンが**見つからない**と
  「中身をバラす」は描かれないので、案内だけ残すと**どこにも無いボタンを探させる**うえ、
  「見つかりません」と食い違う2つの案内が並ぶ。未解決のときは見つからない側の案内だけを出す。
  その**見つからない側の案内も「読み込み直す」を名指ししない**（#812）＝見た目パターンを読み直す操作は
  画面のどこにも無く（起動時に一度だけ）、自作のものを消した場合は読み直しても戻らない＝**実行できない／
  効果の無い行動**になる。消して置き直す側だけを出す（書き出しの断り・画面上部の集計も同じ文にそろえる）。
  ⚠️ **ただし「中へ入る」道はある**（#818・ADR-0034 決定8＝(c) ドリルイン＋明示的にバラす）＝
  見た目パターンの上を**二度押しすると中へ入り**、押した所の**差し込み口の欄へ手が移る**
  （素材・文字はそのまま直せる）。**幾何（位置・大きさ）は触らせない**＝触るなら「バラす」。
  **単押しは従来どおり**（選択を解く）＝掴めない箱で全面を覆わない、という除外の理由は保つ。
  当て先は**描いた結果**から引く（テンプレの座標を画面で組み直すと、動き・まとまりの変形とずれる）。
  **入った所には印を出す**（場面編集のドリルインと同じ色・同じ太さ）＝印が無いと ①二度押しできること
  自体が発見できない ②どの層に入ったのか読めない ③抜けたかどうかも読めない。
  ⚠️ **印だけでは①は解けない**（#832）＝印は**入った後**にしか出ないので、二度押しできること自体の
  発見には使えない（②③は印で解ける）。①は「選んだ部品」欄の常時表示の一文（中の位置・大きさは
  「バラす」を使う旨を伝える段）に「中の写真や文字は、その場所を二度押しでも直せます」を添えて解く
  （見た目パターンを選んだ時点で、まだ何も押さずとも読める）。**入れる差し込み口・文字が1つも無い
  見た目パターンでは添えない**（下の「入れ替えられる中身はありません」と同じ条件）＝実行できない
  行動を名指ししない（§2-5）。
  ⚠️ **文字が空の層は二度押しの当て先にならない**（#834-3・**直さないと決めた**）＝空の文字層は
  そもそも描かれない（`layoutScene` が帯を作らない）ので、当たり判定に出てこない。**そのままにする**＝
  当て先にするには**見えていない矩形を押せるようにする**しかなく、「見えないのに押せる」という
  独自の操作を新設することになる（ADR-0034 決定1＝独自の操作を発明しない／「掴める合図」と挙動を
  一致させる原則の裏返し）。⚠️ **決定4「置けるのに直せない、を作らない」に触れないか**＝触れない＝下記のとおり
  欄からは必ず埋められるので、直せない状態にはならない（当て先が1つ減るだけ）。**行き止まりではない**＝「この見た目パターンの中身」の欄は空の層も含めて
  文字の欄を必ず並べるので、空の見出しはそこから埋められる（埋めた後は二度押しでも直せる）。
  抜け方は**空白の単押し・別の部品を選ぶ・`Escape`**（どれでも抜ける）。
  ⚠️ **どの層に入っても同じ抜け方をする**（#832）＝差し込み口（`<select>`）は入力欄扱いされない
  （`shouldIgnoreShortcut`）ので共有の `Escape` 処理へそのまま届くが、文字の層（`<input>`）は入力欄
  扱いで素通りされ、何も起きなかった。**両方とも欄が自分で `Escape` を受け持ち**（`hasEscapeOwner`）、
  1回目＝欄を抜ける（blur）・2回目＝選択解除、で揃える（「1段ずつはがす」と同じ形）。
  ⚠️ **「入っている」は、入ったときの選択のままか**で決める（#828 レビュー）＝選び直しの入口ごとに
  印を落とす形にすると、`Escape`・`Ctrl+A`・範囲選択・**取り消し**など入口を通らない選択更新で
  「触れていないのに入っている表示」が生き返る（入口を足すたびに漏れる）。
  ⚠️ **同じ所へ入り直すと、もう一度手を移す**（#832）＝「当てるのは一度だけ」を`clipId/layerId`の
  **文字列**で覚えると、抜けて同じ所へ入り直したとき前回と同じ文字列になり、手が移らなくなる
  （同じ操作の結果が2通りになる）。二度押しのたびに**新しく作られるオブジェクトそのもの（同一性）**で
  覚えれば、入り直しは必ず移り、文書の別の変更だけで再描画された回（同じ「入った」が続いている）は
  移らない、が両立する。
  ⚠️ **入れるのは「欄のある層」だけ**（差し込み口・文字の層）＝欄の無い所で入ったことにすると、
  二度押しが黙って飲み込まれ、**単押しの解除まで止まる**（画面が1ピクセルも変わらない・§2-5）。
  ⚠️ **欄はあっても、いま押せない／見えないときも飲み込まない**（#832）＝固定した列・「選んだ部品」欄を
  閉じている・「この見た目パターンの中身」の節を畳んでいる、のいずれでも同じ穴が開く（当て先が
  disabled のまま DOM に残る／DOM に無い）。**開けるものは開いて実際に入れる**（閉じた欄は表示する・
  畳んだ節は開く）。**固定した列だけは開いても意味が無い**ので、理由を出して従来の解除（単押しと
  同じ）へ戻す。
  ⚠️ 決定8 は一度**「バラすだけ」に読み替えられて「完了」に化けていた**（経緯は ADR-0034 の
  「結果・影響 > 経緯」）＝**決定を実装しないなら、実装より先に「やらない」と書く**。
- **キャンバスで掴んで動かす**（#685 後半・ADR-0034 決定6/7）＝仕上がり確認の上で**掴んで移動・角で拡縮・
  回転**。**場面編集の自由配置と同じ部品**（`FreeLayoutOverlay`）を流用する＝2つの画面で操作感を割らない。
  ハンドルは**選んだら常に**（決定7）。**1回のドラッグ＝1回の取り消し**（決定20）。
  選択は**帯・キャンバス・「選んだ部品」の欄で1つ**（決定15）＝何もない所を押すと解ける。
  ⚠️ **触れるのは「いま画面に出ている」「箱を自分で持てる」部品だけ**＝見た目パターンのクリップは
  枠そのものなので渡さない（渡すと画面いっぱいの箱が全面を覆い、その下の部品を掴めなくなる）。
  **固定した列の部品は掴めない**（選ぶことはできる＝帯と同じ）。
  ⚠️ **再生中・書き出し中は出さない**（動く絵と設計位置のハンドルがずれる／入らない編集を受け付けない）。
  ⚠️ **キャンバスに「前へ／奥へ」は出さない**（重ね順は列の並びだけ・決定17）＝共有部品の右クリック
  メニューは**渡した操作だけ**を並べる（渡していない操作を出すと、押しても何も起きない項目になる）。
  **掴む作法は帯と同じ**（#685 レビュー 🔴）＝`Escape` でやめると**元の形へ戻す**・やめている間は
  `Escape` を受け持つ（外側の解除まで走らせない）・**掴んでいる間は取り消しを止める**・
  **少し動かすまで掴まない**・**離したのを取り逃がしたらやめる**・**掴んだ指だけ見る**（#752）。
  ⚠️ **止めるのは押した時点から**（動かし始めてからではない）＝押した時点で取り消しのまとめを開けるので、
  ずらすと**まとめが開いている間だけ取り消しが通る**穴になる（戻した文書の上に、押した時点の控えを
  起点にした位置が書き戻る）。しきい値の役目は「まだ位置を書かない」ことだけ。
  ⚠️ **離しは枠の外でも拾う**（指を捕まえる仕掛けが落ちた回に名乗りを残さない＝残ると `Escape`・
  取り消し・倍率が黙って効かなくなる）。**中断（`pointercancel`）は「やめる」**＝掴んだ所に置かない。
  ⚠️ 共有部品（`FreeLayoutOverlay`）はこれを持っていなかったので**共通核として入れた**
  ＝場面編集の自由配置にも同時に効く（片方だけ直すと同じ画面で作法が2つになる）。
  ⚠️ **「掴んでいる」の合図は画面ぜんぶで1つ**（`isPointerDragging`・#752）＝掴む場所が増えるたびに
  写しを足さない。倍率を変えられない関門もこれ1つを見る（帯・部品を運ぶ最中・色の面のすべてで効く）。
  ⚠️ **欄のスライダーもこの数に入る**（#830）＝掴んでいる間は取り消しが効かない（場面編集の声の調整・
  設定・BGM の音量も同じ）。入れないと、掴んだまま取り消しが通って**まとめが畳まれ**、残りの操作が
  1目盛りごとに1件ずつ積まれて**取り消せる件数を1回のドラッグで使い切る**（取り消しでしか戻せない
  編集が押し出される）。入れる場所は**まとめを開く側**なので、場面形式もタイムライン形式も同時に効く。
  ⚠️ **固定が混ざったときの線引きは「時間か空間か」で分ける**（#773・ADR-0034 未解決7 の決着 (a)）：
  - **時間の移動（帯）＝全か無かで断る**＝一部だけ動くと部品どうしの間隔・並びが壊れ、意図から遠い結果になる。
    断り文は**「選んだ中に固定がある」**（「この列は…」だと、まとめて動かしている場面で指す先が外れる）。
  - **空間の移動（キャンバス・矢印）＝固定は混ぜず、残りを動かす**＝要素は独立で、固定した背景が残っても
    寄せた結果はそのまま使える（場面編集と同じ挙動＝覚え直しが要らない）。
    **除外したことは一言知らせる**（黙って一部だけ動かさない）が、**一度だけ**＝見れば分かることなので
    動かすたびには出さない（**選んだ組み合わせが変わったら出し直す**・同じ組み合わせへ戻っても出さない）。
    **全部が固定なら矢印を奪わない**（奪って何も起きない＝行き止まり）。
    ⚠️ **知らせるのは「まとめて動かす」だけでなく「まとめて拡げる／縮める」も**（#788-2）＝同じ理由で同じ
    除外をするのに、操作によって知らせたり黙ったりしない（ADR-0026②）。
    ⚠️ **一言は理由別に出す**（#788-1）＝キャンバスで掴めないのは**固定した列だけではない**
    （動きが効いている／まとまりの変形も掴ませない）。ひとまとめに「固定を外してください」と出すと、
    **動きが原因のときは従っても直らない**案内になる。言い方は単体選択のときと**同じ関数**から採る
    （`canvasHoldMessage`）＝2か所に持つと片方だけ直る。理由が混ざるときは**数えた理由をすべて**出す。
    ⚠️ **固定した列を先に言う**＝固定した列の上に動きの効いた部品があると両方が理由になりうるが、
    動きを先に言うと「下の数値・矢印キーで」と案内してしまう（**その部品はどちらも列の固定で塞がっている**）。
    ⚠️ **示す行き先は「その場面で本当に押せるもの」だけ**（§2-5）＝まとめて動かしたときは2つ以上選んで
    いるので、「位置・大きさ」の欄は「1つだけ選ぶと…」に替わっていて**数値の欄も「動き」も画面に無い**。
    まとめてのときに実在するのは**矢印キー**だけ（そちらは列の固定しか見ない）。
  ⚠️ **仕上がり確認の比は動画の向きに合わせる**＝16:9 固定のままだと縦型で余白が入り、
  重ねた操作レイヤと実際に描かれている矩形がずれる（掴む位置も動かす量もずれる）。
  **右クリックで操作のメニュー**（#746-1）＝**複製・削除**を出す（帯には在るのにキャンバスでは黙る、
  を作らない）。**押せない条件は帯と同じ式**を見る（まとめて選んでいるときの複製など＝押せる見た目で
  無反応、を作らない）。**押せないときも項目は消さずに理由を出す**。
  ⚠️ **同じ操作は同じ言い方**（#763-6）＝キャンバスも帯も**「複製」「削除」**（欄のボタン・列のメニューも同じ）。
  以前はキャンバスが「複製／削除」・帯が「同じものを足す／消す」と割れていた。**一般的な動画編集用語を
  そのまま使う**（ADR-0034 決定21＝分かりやすさ最優先）ので「複製／削除」に寄せ、共有の語（`uiLabels`）から採る。
  「前へ／奥へ」は出さない（重ね順は列の並びだけ・決定17）。
  **文字は二度押しで直せる**（#746-2・他社の型）＝直している間は**下の絵を伏せる**（二重に見えない）。
  枠に出す内容は**描画と同じ変換**を通す（手で作り直すと文字・書体・帯が抜け、編集中だけ見た目が割れる）。
  **固定した列の文字は編集欄に入らない**（入れても打鍵ごとに断られる＝打てない欄を開かない）。
  **打っている間の取り消しは1回ぶん**（欄と同じ作法）＝⚠️ まとめを開くのは**最初の1打**（編集に入った
  時点では、二度押しが選び直しでもあるため、選択の切り替えでまとめが畳まれる）。
  ⚠️ **触れるのは「いま描かれているもの」だけ**（#746-6）＝隠した部品・隠したまとまり・出さない列・
  再生位置の外は枠を出さない（描かれていないものを掴める、を作らない）。**枠の顔ぶれ・並び・場所は
  描画と同じ関数から採る**（#746-4/5）＝自前で並べると重なった所で**奥の部品が掴まれる**（描く重ね順は
  列の並びで、文書の並びとは違う）。**枠に効かせる「固定」は列の固定だけ**（動かす・中身を変える・消すの
  関門と同じ相手を見る）。
  ⚠️ **動きやまとまりの変形が効いている間は、枠を「描かれている場所」に出し、掴ませない**（#746-4）
  ＝掴んだ量は**素の箱**へ書き戻るので、そのぶんだけ絵が飛ぶ。**理由と触れる先を「位置・大きさ」の欄に
  出す**（数値で変えられる＝行き止まりにしない・決定5）。**理由は原因ごとに分ける**＝「動き」の欄では
  外せないものを「動きで調整して」と案内しない（言われたとおりにしても直らない）。
  ⚠️ **固定したものは「まとめて動かす」にも混ぜない**＝掴み始めるのを塞ぐだけでは、別の1つを動かした
  ときに一緒に動く（固定が意味を失う／枠の場所がそのまま保存されて絵が飛ぶ）。
- **帯（部品）の見分けと操作**（#701）＝**色は部品の種類ごと**（列の種類だけで決めると、見た目パターン・
  写真・文字・図形・字幕が全部同じ色になり、並びを見ても何が置いてあるか読めない）。
  **右クリックで操作のメニュー**（複製／中身をバラす／削除）＝列の行と同じ作法。
  **右クリックした帯はその場で選ぶ**（選ばずに開くと、メニューの項目が別の部品に効く）。ただし
  **まとめて選んでいる中の1つ**なら選択は保つ（まとめて消せる）。まとめて選んでいるときは
  **1つにしか効かない項目（複製・バラす）を押せなくして理由を出す**（押しても無反応、を作らない）。
  ⚠️ **「⋮」の逃げ道は、選んだ帯の内側**に置く。帯の外（すぐ右）や全部の帯に出すと、
  **複製した帯は必ず隣接する**ので次の帯の左端を覆い、**狙っていない帯が選ばれて消える**。
  短い帯は丸ごと覆われ、最後の帯では列の枠の外に出て、見た目が空白の所を押すと帯が選ばれる
  （「何もない所を押すと解除」と逆になる）。
  帯にカーソルを当てると**名前と時間帯**が出る（場面形式の見わたす画面と同じ書式）。
- **キー操作**（#721・ADR-0034 決定18）＝**`Space`**（再生／停止）・**`Delete`**（消す）・**`←`/`→`**（1フレームずつ・
  `Shift` で1秒ずつ）・`Escape`（選択を解く）・`Ctrl+A`（全部選ぶ）・`Ctrl+Z`/`Y`（取り消す／やり直す）。
  **入力欄と日本語の変換中は奪わない**。**そのキーで反応する要素に手がかかっているときは譲る**
  ＝`Space` はボタン・セレクト等、**矢印はセレクト・スライダー・数値欄等**（片方だけ譲ると、同じ理由の判断が
  入口で割れる＝ADR-0026②。譲らないと「欄の値が変わらず再生位置だけ動く」）。
  **答えを求める確認・メニュー・色の面が出ている間は、`Ctrl+A` も含めてキーで先へ進めない**
  （通ると「2個消しますか」と聞いて別の数が消える）。キーは**ボタンと同じ入口**を通る（キーだけ関門を素通りしない）。
  ⚠️ **キーで断るときは理由を出す**（#752-3・§2-5）＝ボタンは押せない見た目と説明で伝わるが、
  **キーには押せない見た目が無い**ので、黙って何も起きないと故障と区別できない
  （選んでいないときだけ黙る＝消す相手がそもそも無い）。
  **押せるボタンにはキーの割り当てを添える**（#752-10）＝キーがあることを知らせる
  （「消す（Delete）」「再生（Space）」「ここで分ける（Ctrl+K）」）。
  **矢印はフレーム番号で数える**＝秒を足し込むと誤差が積もり、押しても絵が変わらない回・1枚飛ぶ回ができる。
  **矢印は文脈で分かれる**（決定18・#752-9）＝**キャンバスで箱を持つ部品を選んでいる間**は
  「少しだけ動かす」（1px・`Shift` で 10px・上下も効く）、それ以外は再生位置を送る。
  **まとめて選んでいるときも一緒に動かす**（掴んで動かすのと同じ＝個数で意味を変えない）。
  ⚠️ 対象は**いまキャンバスに出ているもの**だけ（キャンバスの顔ぶれと同じ規則を見る）＝選んでいても
  再生位置の外・出さない列にある部品は動かさない（**画面のどこも変わらないのに文書だけ動いて
  保存される**、を作らない）。出ていないなら矢印は再生位置へ返す。
  ⚠️ **押し続けても取り消しは1回ぶん**（決定20＝掴んで動かすのと同じ）。畳まないと、キーの連続で
  取り消しの上限を数秒で流し切り、**「バラす」の唯一の戻り道**まで消える。手が止まったら閉じる。
  ⚠️ **動かせないときは矢印を奪わない**（固定した列・書き出し中・再生中＝掴めないのと同じ条件／
  箱を持たない読み上げ・音）＝奪ったうえで断ると、部品も動かず再生位置も送れない（行き止まり・決定5）。
  ⚠️ **上下はこの文脈のときだけ**奪う（それ以外は画面送りに返す＝奪って何も起きない、を作らない）。
- **再生**（#630）＝「再生／停止」「先頭へ」。停止の語は**既存画面と同じ「停止」**（§3）。終わりまで来たら自動で止まり、終端で「再生」を押すと先頭から始まる。**何も置いていないときは押せない**（理由を出す）。**書き出し中も始められない**（#752-6＝成果物は壊れないが、
  走っている間だけ音が鳴り出す入口が開くのは、編集・声の作成を塞いでいるのと揃わない）。
  ⚠️ **塞ぐのは「始める」方だけ**＝走っている最中の「停止」は必ず押せる（止められないまま音が流れる、
  を作らない）。**`Space` で断るときも理由を出す**（`Delete`・`Ctrl+K` と同じ＝キーは押せない見た目を持たない）。**編集すると止まる**ので、走っている位置を掴む操作（「再生位置へ」「ここから始める」「ここで終わる」）は**再生中は押せない**（理由を出す）。
- **取り消す／やり直すはキー操作（Ctrl+Z / Ctrl+Y）でも効く**。ただし**この画面の文書**に対して効かせる（場面形式の履歴を巻き戻さない）。
- **書き出し**（#631）＝プレビューの操作列に「動画を書き出す」。押すと**先に保存先を選ぶ**（重く長い処理をしてから「やっぱりやめる」を選ばせない）→ 進み具合（％）と「書き出しを中止」→ 終わったら結果を出す。
  **始められない理由は1か所で見る**（`exportStartBlock`・#718）＝押す前に無効化して出す理由と、押したときに断る理由が**同じ述語**から来る。見るのは**素材の取り込み中／声を作っている最中／別形式の書き出し中／直前の回の後片づけ待ち（#843）／文書の中身の理由／この端末で書き出せない**。とくに**声を作っている最中**は、始めてしまうと合成の着地が撥ねられて**作った声が捨てられる**（その読み上げが無い動画が「保存しました」で終わる）。
  - **書き出せない理由は押す前に見せ、ボタンを押せなくする**（押しても断られるだけ、を作らない＝`15 §6` の `TIMELINE_EXPORT_*`）。
    出し方は**理由の出どころで分ける**（#729 レビュー）＝**文書の中身の理由は一覧で全件**（直せるものを取りこぼさない）、
    **いまの事情**（取り込み中・声の作成中・別形式の書き出し中・直前の回の後片づけ待ち・この端末では書き出せない）は**一段の知らせ**。
    **同じ文を二重に出さない**（読み上げも2回になる）。両方当てはまるときは**両方出す**
    （片方だけ直して堂々巡り、を作らない）。どちらに属するかは述語自身が返す＝画面が判定順を推測しない。
  - **再生中は書き出さない**（鳴っている音と重ならない）。押した時点で再生は止まる。
  - **保存先を選んでいる間も「書き出し中」**＝続けて押しても二重に走らない。
  - **書き出し中は一覧へ戻れない・編集も取り消しもできない**（理由を出す）＝描いている途中で別の動画に
    入れ替わったり、動画に入らない編集を受け付けたりしない。
  - 理由は「何も置いていない」「動画の素材がある」「**見た目パターンが見つからない部品がある**」。
  - **クレジット（VOICEVOX）はプレビューにも出す**＝書き出しでは焼き込まれるので、見えていたものと違う動画が出てこない（`13 §4`・ADR-0003）。しゃべっている声のキャラを出す（掛け合いの場面形式と同じ）。
  - 結果の文言は「保存しました」「書き出せませんでした（もう一度）」「中止しました（もう一度書き出せます）」＝どれも**次の行動**を言う（§2-5）。
- タイムライン形式を開くときは**「保存していない素材や場面は失われます」の確認を出さない**＝別の文書を別の画面で開くだけで、場面形式の編集内容は閉じない（事実と違う確認を出さない）。

## 13. 書き出し画面

### 設定

- 保存先
- 動画サイズ
- 字幕あり/なし
- BGMあり/なし
- ファイル名
- ナレーション音量（**動画全体の既定**＝`11 §6`）。**場面ごとに個別の声量を設定した場面は、そちらが優先**されてこの全体設定では変わらない。
  個別設定を持つ場面が1つでもあれば、その旨の注意を添える（設定できるのに一部に効かない誤認を避ける）。仕上がり確認は「いまの場面」で
  同じ意味の注意を出す＝両画面で同概念・同挙動（ADR-0026②・#547 P3-13）。全体スライダー自体は他の場面に効くので無効化はしない（ADR-0026①）。
- **音の自動調整**（#257/#259・ADR-0032 追補4）＝**書き出し時の処理**なのでここに置く。⚠️ **仕上がり確認では効かないことを画面に書く**（α-6 出口監査 [プ]・§2-5）＝同じ画面の字幕の欄は「仕上がり確認でも同じ設定で表示されます」と明記しているのに、音だけ何も言っていなかった（利用者は「音も確認で確かめられる」と読む）。**実装を確認にも効かせるのは追補4 に反する**ので、言葉で揃える。**プロジェクト単位**（`videoSettings.audioAuto`）で、
  **場面ごとには持たない**（追補4）。⚠️ **技術用語を出さない**（§2-3）＝「ダッキング」「ノーマライズ」「LUFS」は書かず、やることそのものを書く。
  - **「セリフが流れている間はBGMを控えめにする」**＝声が鳴っている区間だけ BGM を下げ、無いところで戻る。
    **どのくらい**（少しだけ/ふつう/しっかり）・**変わり方**（ゆっくり/ふつう/すばやく）を選べる（%や秒は出さない）。
    ⚠️ **戻りきる前に次のセリフが始まるならその間は上げない**＝行間で BGM が上下すると耳障りなので、下げっぱなしにする。
    ⚠️ **セリフが多すぎて音量の変化が持てる数を超えるときは、間の狭いところからまとめる**（下げっぱなしにする方向＝下げ忘れは起きない）。
    まとめたら**書き出しの完了時に知らせる**（§2-5＝黙ってやらない）。
  - **「全体の音量をそろえる」**＝素材ごとの音量差をならし、音が割れないように整える（`loudnorm`＋`alimiter`）。
    ⚠️ **BGM が無いときも効く**＝BGM の有無で効いたり効かなかったりしない（ADR-0026②）。
  - ⚠️ **既に作った動画の音を変えない**＝新しい動画は既定で両方「する」だが、**前の版で作った動画には読込時に「しない」を書き込む**（§2-5）。
  - ⚠️ **タイムライン形式にも同じ設定が効く**（`videoSettings` は共有）。声は下げない（自分で自分を下げない）。

### 進捗表示

```text
動画を書き出しています
場面 3 / 12 を処理中
```

> 進捗は**書き出し画面だけでなく全画面**に出す（#547 P2-1）。書き出し中も他の画面へ移動できるため、
> 進捗が1画面にしか無いと離れた利用者には止まったように見え、二重書き出しを誘発する。編集ロックの
> バナー（`ExportLockBanner`）に同じ数字・同じ説明と「書き出しの画面へ」を添える（`15 §4`）。

- **書き出しを中止**（#380）：進行中はいつでも中止できる（逃げ道を必ず残す）。中止すると変換を止め、すぐにやり直せる。

### 完了時

- 保存先を開く
- 動画を再生
- プロジェクト一覧へ戻る

### 前回の結果を見ているとき（#547 P3-11）

書き出しの実行状態は次の書き出しまで残る（`15 §1`・進捗を全画面に出すため＝上記）。そのため**画面を離れて戻る**と、
終わった結果（保存した／失敗した／中止した）がそのまま出続ける。これを**いま起きたこと**のように見せない：

- 画面に**入った時点で既に終わっていた**結果には「**前回の書き出しは…**」と添え、次の行動（もう一度「動画を保存」）を示す。
  とくに完了は、**そのあとの編集は入っていない**ことが分かるようにする（「100%・保存しました」だけだと最新に見え、
  直したはずの動画が書き出し済みだと誤読させる＝ADR-0026④）。
- **進捗（%・バー・いま何をしているか）は、いま走っている書き出しのものだけ**に出す（前回の完了を100%のバーで再現しない）。
- ただし**保存したファイルへの導線（保存先・保存した場所を開く・動画を再生）とBGMの欠けの案内は残す**
  （前回の結果でも、そのファイルの話としては正しい・#404）。
- 失敗の中身（原因と次の行動）は残すが、入り直すたびに**読み上げへ割り込ませない**（`role="alert"` にしない）。
- この訪問で何かが起きたら（書き出しを始めた・その場で失敗した）「前回の…」は下ろす。
- 「この端末では書き出せない」は**今の事情**であって前回の結果ではないので、過去形にしない。

### 中止時（#380）

- 「書き出しを中止しました。もう一度『動画を保存』を押すと、やり直せます」と示す（エラーではなく中立の案内・§2-5）。
- 中止後は待たされず再実行できる（走行中の変換プロセスは終了済み。書き出し中にアプリを閉じても残留しない）。

## 14. テンプレート管理画面（見た目パターンの作成・編集）

画面表示では「見た目パターン」とする。標準（同梱）は読み取り専用、自分で作った見た目パターンは**作成・編集・削除**できる（ADR-0017・EPIC #214）。**一覧（管理）と編集は画面を分ける**：一覧から「**ゼロから新規作成**／複製して編集／編集」で**専用の編集画面へ遷移**する（#271＝ADR-0017 当初の「新規画面」設計）。

### 機能（一覧画面）

- 標準見た目パターン一覧（読み取り専用＝複製してから編集）
- 追加済み（自作）見た目パターン一覧
- 見本（サンプル表示）・名前・カテゴリ・使用要素の確認
- **ゼロから新規作成**（向き・カテゴリ・名前を決め、空のキャンバス＝背景のみから作成）→ 編集画面へ遷移（ADR-0017「ゼロから作成（フル）」の導線）
- 見た目パターンを**複製して編集**／（自作は）**編集** → 編集画面へ遷移
- 削除（参照中のプロジェクトは標準へ自動置換＝§9 補正）
- テンプレートパック取り込み

### 機能（編集画面・#271）

**欄の配置（`§3.1`）で組み替えられる**（ADR-0033 段階4）。この画面が持つ欄は2つ＝**プレビュー／見た目パターンの編集**。
**既定の並びはこれまでと同じ**（中央＝プレビュー／右＝編集）＝顔ぶれも並びも変わらない（欄の幅は割合で決まるので実寸は少し変わる）。

- 広いプレビュー（キャンバス）＋レイヤー操作オーバーレイ（ドラッグ/リサイズ/吸着）
  ⚠️ **掴む作法は3つのキャンバスで1つ**（#769・場面編集の自由配置／タイムライン編集／ここ）＝
  `Escape` でやめる（元の形へ戻す）・**掴んでいる間は取り消しを止める**・少し動かすまで掴まない・
  掴んだ指だけ見る・離しの取り逃がしを救済する。**共有部品として1か所に置く**（写すと「片方だけ直す」
  が必ず起きる＝実際にここだけ古いまま残っていた）。
  ⚠️ **キーでも動かせる・消せる**（#788-3・決定19＝ドラッグ専用の操作を作らない）＝**矢印で 1px**
  （`Shift` で 10px）・**`Delete` で消す**。まとまりを選んでいるときは**まとまりごと**動く
  （場面編集の自由配置と同じ規準）。**ロック中のまとまりは中身も動かさない**（掴んで動かす方と同じ）。
  **押しっぱなしでも取り消しは1回ぶん**（`§12.1` 決定20 と同じ間合い）。
  ⚠️ **複数選んでいるなら `Delete` はまとめて消す**（#802-4）＝矢印は選択ぜんぶ動くのに `Delete` だけ
  主の1枚、という割れを作らない（ADR-0026②）。確認は場面編集の一括削除と同じ流儀で、
  **消すのは「確認した集合」**＝確認を出したまま選び直しても、確認していないものは消さない。
  ⚠️ **消せないときは確認を出さず、その場に理由を出す**（§2-5）＝確認という約束を出しておいて
  黙って何も起きない、を作らない。**ロック中のまとまりの分は残る**旨も件数のそばに出す
  （黙って件数だけ減らさない）。**1つも消せない選択では `Delete` を奪わない**（上の規準と同じ）。
  ⚠️ **奪うのは受け持てるときだけ**＝選んでいない・答えを求める確認が出ている・最後の1枚（`Delete`）では
  奪わない（奪って何も起きない＝効かないキーを作らない）。
  ⚠️ **譲る相手は3種類**（#788 レビュー）＝打っている最中／変換中／**矢印そのものが効く相手**
  （セレクト・スライダー・数値欄）と、**押せば反応する相手**（`Delete` で中身が消えない）。
  判定はすべて共通のもの（`keyboardShortcut`）を使う＝**共通判定は旧実装より狭い**ので、
  寄せるときは「何を譲っていたか」を数え直す（実際にここで一度落として穴を開けた）。
  以前はここだけ結線が無く、**掴んで動かせるのにキーでは動かせない**画面になっていた。
- レイヤーの追加・削除・配置（整列・吸着/重ね順）＝こだわり編集（①）の操作感を流用
- レイヤーの型別設定（文字＝表示テキスト・大きさ・色・太さ／図形＝形・色／素材＝入れるもの・収め方／背景＝背景色／立ち絵＝収め方・ポーズ ほか）
- **既定の素材を登録（背景/メイン素材/ロゴ）**：画像を選んでテンプレ自身に持たせる。使用時、場面に素材が無ければこれが入る（場面素材が優先＝フォールバック）。グローバル保存・テンプレ削除で素材も掃除（ADR-0021・#293〜296）
- 名前の変更・保存／キャンセル（未保存があれば確認）・削除

自作の見た目パターンは**全プロジェクトで再利用**（共通保存）。AI の自動選択には出さず、手動選択（おまかせ/こだわり）でのみ選べる（ADR-0017）。テンプレートパック取り込みも引き続き可。

## 15. 設定画面

⚠️ **節の並びは 上から AI設定 → 音声設定 → 言葉の読み方 → 文字の形 → 会社の見た目**（α-6 出口監査 🟡26）。**関連するものを隣に置く**＝声↔読み方（声にまつわる設定）／文字の形↔会社の見た目（会社の見た目が文字の形を既定に使う）。実装が別の順に並んで**2組ともが分断されていた**ので、ここを規準にする。

### AI設定

- 使用するAI
- APIキー
- 外部AI送信確認を毎回表示するか

### 音声設定

- VOICEVOX接続先
- 標準の読み上げの声
- 話速・高さ・抑揚
- **声の表記の出し方**（ADR-0025・#359）＝この画面には**出し方の選択を置かない**（動画ごとの設定なので「動画を保存」に置く）。ここは「どこで選べるか」を案内するだけ＝**「常に表示します」と言い切らない**（選べるようになったため）。

### 言葉の読み方（ADR-0037・#350）

会社名・人名など、そのままだと違う読み方をされる言葉を登録する。**正典はアプリが持ち**（`appData/readingdict.json`）、音声ソフト側の辞書へは「映す」だけ（エンジンを入れ替えても、外部エンジンを指しても同じ読みになる）。

- **言葉**（表記）と**読み**（カタカナ）。読みがカタカナでなければ次の行動を出して受け付けない。
- **言い方（聞き比べて選べます）**＝候補を「読みに印を付けた形」（`ウ↓ツノミヤ`）で並べ、1つずつ**聞ける**。⚠️ **「アクセント型」「モーラ」は画面に出さない**（§2-3）＝**耳で選ぶ**もので、数え方は内部の道具。**既定は先頭で下がる形**。聞き比べは**辞書に触らずに鳴らす**（登録前に確かめられる／`audio_query` の下がる位置だけ差し替える）。
- **一覧を書き出す／読み込む**＝別のパソコンやチームで同じ読みにできる。⚠️ **読み込みは「足す」が既定**で、同じ言葉があるとき**黙って上書きしない**（1件ずつ「読み込んだ方にする」を選ぶ）。⚠️ **書き出しに音声ソフト側の id は含めない**（渡した先では通用せず、失敗の原因にしかならない）。
- 反映は**この画面を開いたとき・編集したとき**＋**声を作る直前**（決定2）。⚠️ **画面で映すのは、黙って上書きしなかった語を知らせるため**でもある（知らせる機会が他に無い＝下記）。⚠️ **反映できなかったら黙って声を作らない**（§2-5＝`15 §6` `READING_DICT_SYNC_FAILED`）。ただし**登録が1つも無ければ音声ソフトに触らない**＝この機能を使っていない利用者の書き出しを止めない。
- ⚠️ **外すのは確認を通す**（α-6 出口監査 🟡27）＝同じ画面の素材削除・接続キー削除は必ず確認を通す。とくにフォントは**外すと実体が消え、使っている動画の書き出しが止まる**。
- ⚠️ **外せなかったら「外しました」と言わない**（α-6 出口監査 🟡13・§2-5）＝失敗しても知らせを出すと、赤い理由と並ぶうえ**一覧にもそのまま残る**（何が起きたのか分からない）。取り込みと同じく「できたときだけ」知らせる。
- ⚠️ **控え（エンジンの語との繋がり）は画面のものではない**（α-6 出口監査 🟡22）＝画面が持っているのは**開いた時点**の控えで、その後「そろえる」「こちらの読みにする」がファイルへ書き足している。保存のときは**語だけ**を書き、控えは**ディスクの新しい方**を採る（画面の側を丸ごと書き戻すと控えが巻き戻り、直した読みが音声ソフトへ映らないまま声が作られ、外した語も共有辞書から消えなくなる）。
- ⚠️ **他の VOICEVOX の辞書を壊さない**＝丸ごと入れ替えず、アプリが関与する語だけを足す/直す/消す。利用者が VOICEVOX 本体で入れた読みは**黙って書き換えず知らせる**＝この画面に「音声ソフトに、同じ言葉で違う読み方が登録されています」と出し、**「こちらの読みにする」を押したときだけ**上書きする（`15 §6` `READING_DICT_WORD_CONFLICT`）。⚠️ **「同じ読みで既にあった」だけの語は控えに入れない**＝控えは「消してよい語の名簿」でもあるので、入れるとアプリの一覧から外したときに**本体側の語を消してしまう**（辞書は共有ファイル＝取り戻せない）。

### 文字の形（フォント）（ADR-0038・#261）

手持ちのフォントを足すと、動画の文字に使える（同梱3種に加えて）。

- **足したフォントはこのパソコンの中だけ**（`appData/user_fonts/`）＝**動画のファイルにも焼き出しにも入らない**。
  ⚠️ **アプリが再配布経路にならないようにするため**（`13 §6`）。素材（ADR-0035）がコピーするのは自己完結のためだが、
  フォントは**理由が逆でコピーしない**。
- 受ける形式は **ttf・otf・woff・woff2**（利用者判断 2026-08-26）。それ以外は取り込まず理由を出す
  （読めない字体を一覧に載せない＝「選べるのに描けない」を作らない）。
- ⚠️ **権利の注意文は画面に出さない**（利用者判断）＝アプリが再配布経路にならないので、出しても
  利用者自身の行為への一般的な注意にしかならない。
- 一覧は**その字形で名前を描く**（同梱フォントの選択UIと同じ流儀＝見て選べる）。
- ⚠️ **足したフォントは「文字の形を選ぶところ」すべてに出る**（α-6 出口監査 🔴1）＝動画全体・場面・
  種別ごと・自由配置の文字/字幕・タイムライン形式の文字クリップ・**会社の見た目の既定**（ADR-0038 決定7）。
  当初は取り込み・検査・書き出しだけを配線しており、**どこからも選べない**＝#261 が利用者から見て
  動いていなかった。**一覧は選ぶ部品（`FontPicker`）が自分で持つ**（6か所へ渡し歩くと配り忘れる）。
- ⚠️ **持ち込みフォントも「既知の字体」として扱う**＝同梱だけを既知にしていると、既に入っている
  文書で**実際と違う字体名を見せ**、一度触ると指定が黙って上書きされる。
- ⚠️ **一覧に無い字体は「見つかりません」と示す**（起動直後でまだ読めていない／実体が消えている）＝
  **先頭の同梱へ倒さない**（具体的に間違った名前が出て、押すとその字体で黙って上書きされる）。
  ⚠️ **内部の綴り（`user_font_NNN`）は画面に出さない**（§2-3）＝出すのは種別まで、指している値は
  **指したときの説明**に残す（選び直せるように）。⚠️ **見本に字形も当てない**（描けないので既定へ落ち、
  結局「違う字体を見せる」ことになる）。
- ⚠️ **読み込みは起動時に1回**＝画面ごとに読み込むと、通っていない画面（場面編集・仕上がり確認・
  タイムライン編集）で**プレビューだけ既定の字体**になる（書き出しは実物＝ADR-0001 のパリティが崩れる）。
- **外す**と実体も消える。⚠️ **使っている動画があるかはここでは見ない**＝消したあとに公開前チェックが
  「見つからない文字の形」として**書き出しを止める**（黙って別の字体で書き出さない・`15 §6` `USER_FONT_MISSING`）。

### 会社の見た目（ブランドキット・ADR-0036・#351）

よく使う**文字の形・色・ロゴ**を覚えておくと、**新しい動画に最初から入る**（α-6 は最小形＝この3つだけ）。

- ⚠️ **反映先はどの動画か名指しする**（差分再監査 3巡目→4巡目で改訂・§2-5）＝開いている文書は**2種類ある**（場面形式／タイムライン形式）ので「いま開いている動画」だけでは分からない。⚠️ **塞がずに名指しで解く**（4巡目 🔴）＝両形式は**同時に開いたままにでき、閉じる導線が無い**ので、タイムラインが載っているだけで塞ぐと**一度開いたセッション中ずっと**場面形式の動画にも反映できなくなる（しかも理由は事実と違う）＝解除できない行き止まり。塞ぐのは**場面形式の動画を開いていないとき**だけ。よく使う素材の取り込みも同じで、**取り込み先を知らせで名指しする**。
- ⚠️ **会社の見た目を読めなかったら書かせない**（差分再監査 3巡目）＝空に潰すと直後の書き込みが**覚えていた中身をそのまま上書き**して消える（目録・読み方辞書と同じ流儀）。
- ⚠️ **書き出しに効く設定は、書き出す画面から触れる**（差分再監査 2巡目・§2-5）＝タイムライン形式には音の自動処理の欄が無く、しかも**前の版の文書は読込時に「しない」を書き込まれる**ので**一度 OFF になると戻す手段が無かった**。欄は場面形式と**同じ部品**を使う（文言を2つ持たない＝§6）。
- ⚠️ **新しいタイムライン動画にも会社の見た目を効かせる**（ADR-0036 決定2）＝場面形式は `newProject` が通すのに、こちらは通らず「タイムラインで作る」で作った動画にだけ効かなかった（ADR-0026②）。**文字の形とロゴの両方**＝場面形式もタイムラインも、取り込みは**素材の一覧へ足すだけ**で置き場所は決めない（見た目パターンの差し込み口から選ぶ）。⚠️ **当初「置き場所を決められないから足さない」と書いたが事実と違った**（差分再監査で是正）。⚠️ **入らなくても動画は作る**が、**入らなかったことは言う**（§2-5）。⚠️ **足したロゴの表示先も解く**＝解かないと作った直後はキャンバスに映らないのに書き出すと映る。
- ⚠️ **タイムラインの書き出しの欄には「音・クレジット・文字の形」を置く**（差分再監査 3巡目）＝いずれも**効くのに選べない**状態だった。とくに動画全体の文字の形は、門の案内（「別の文字の形を選び直して」）どおりに操作するために要る（§2-5 の行き止まりを作らない）。
- ⚠️ **タイムラインからも「よく使う素材」を取り込める**（4巡目 🟡）＝入口が無いと「どの動画からでも取り込める」という棚の目的（ADR-0035）が**片方の形式で成立しない**（ADR-0026②）。
- ⚠️ **文字の体裁は #264 の3つをそろえる**（4巡目 🟡）＝影・字間だけだと**背景帯だけ片方でしか編集できない**。字幕クリップ・見た目パターンの部品（文字の形）・場面の体裁欄（`textStyles`）も同じ理由で入口を足した（**効くのに選べない**を残さない）。
- ⚠️ **棚から取り込んだ素材は、棚の名前・種類・タグのまま入る**（差分再監査 5巡目 🔴・ADR-0035 決定3）＝
  ファイル名から作り直すと、棚のファイル名は機械の番号なので**番号が素材名として画面に出て**、種類（ロゴ）も
  タグも黙って落ちる（場面形式は引き継ぐ＝ADR-0026②）。⚠️ **どの欄から置けるかは種類で言い分ける**＝音は
  「素材・文字・図形を置く」の候補に出ないので、1文で言うと**案内どおり探しても見つからない**。
  ⚠️ **入れる先が無いときは押せなくして理由を出す**＝「素材」は動画を開いていなくても開ける画面なので、
  押せると**画面に出ていない空の動画**が作られてそこへ入る。
- ⚠️ **バラせないときは押す前に断る**（差分再監査 5巡目 🟡）＝理由（切り抜き・寄せ・動き・切り出した動画）は
  押す前に分かるのに、**取り返しのつかない操作の顔をした確認に同意させてから**断っていた（同じ画面の「分ける」は
  押す前に断る＝ADR-0026②）。判定は実際に走る関数の**空撃ち**＝「押せるのに何も起きない」も作らない。
- ⚠️ **書き出しを始める直前に持ち込みフォントを取り直す**（差分再監査 5巡目 ℹ️）＝この画面は書き出す欄が
  同じ画面にあるので、開いたまま長く編集すると古い一覧のまま門を通る（場面形式は書き出し直前の画面で取り直す）。
- ⚠️ **見た目パターンが見つからない部品でも、文字の形は直せる**（差分再監査 8巡目 🟡）＝書き出しの門は**見た目の解決に関係なく**数えるので、欄ごと消すと「別の文字の形を選び直してください」が**その部品では実行できない**（同じ状態に断りが2通り）。部品ぜんぶの欄は**無条件**・種別ごとは指定が残っていれば出す（直上の「消して置き直してください」は見た目そのものの次の行動＝役割が違う）。
- ⚠️ **見た目パターンの部品は種別ごとにも文字の形を選べる**（差分再監査 5巡目 🟡）＝焼き出しが書き、書き出しの
  門が数えるのに**直す操作がこの形式に無かった**＝持ち込みフォントが消えると**書き出しが止まったまま解除できない**。
  ⚠️ **いま使っていない種別でも、指定が残っていれば直せる**（6巡目 🟡）＝門は**休眠のぶんも数えて断る**ので、
  欄を「いま使う種別」だけにすると**案内どおりに選び直す先が無い**（数える側は狭めない＝消えたフォントを
  使っていることに変わりはない。場面編集も同じ〔「いまの見た目パターンでは使っていない文字」の欄〕）。
- ⚠️ **「動画を開いているか」は1つの判定から採る**（6巡目 🟡）＝番号（`projectId`）だけで見ると**白紙から作った
  直後**を「開いていません」と言い、しかも一覧に無いので**案内どおりに開き直せない**（嘘の理由＋行き止まり）。
  読み込んだ（番号がある）／白紙から作った（`status` が `idle` でない）／場面がある／**たたき台の入力がある**（会社名・発表テーマ）、の**どれかで開いている**（差分再監査 7巡目で4つ目を追加＝AI で作る主経路は `status` を `idle` のままにするので、3つだけだと**ウィザードの途中**を取りこぼす。守る側〔破棄ガード〕が「作業中」と数えている状態と食い違わせない）。棚からの取り込み・「素材を追加」・会社の
  見た目の反映・サイドバーの「今の動画」が**同じ式**を見る（同じ「取り込み」で断り方を2通りにしない）。
- ⚠️ **場面の体裁欄の「入／切」は、いま描かれているかを出す**（PR #913 レビュー 🟡）＝影・帯は場面の上書きが**まるごと差し替え**で解かれる（`ov?.shadow ?? layer.shadow`）ので、上書きの有無で出すと**見た目パターン側が付けている帯を「切」と偽り**、切っても継承で戻ってきて**切れない**。継承中に1項目だけ触ったときは**残りの設定を引き継ぐ**（引き継がないと色や角丸が既定へ落ちて**黙って別の絵**になる＝§2-5）。見た目パターン側が元から付けていないものを切に戻したときだけ、上書きごと落とす（意味のない上書きを残さない）。
- ⚠️ **切り抜いてある部品はバラせない**（4巡目 🔴）＝切り抜きは**部品の箱ぜんぶ**を切るので、要素ごとに分けると各要素が自分の箱で切られる＝別の絵になる。**写せないものはバラす前に断る**（決定23）。
- ⚠️ **タイムラインの取り込みは音も受ける**＝タイムライン形式は**音そのものが置ける部品**なので、受けないと**よく使う素材に置いた音楽が届かない**（場面形式は写真・動画のまま＝BGM は BGM の導線）。
- ⚠️ **文字の影と字間はタイムラインの文字クリップからも触れる**（ADR-0032 追補3＝共有の語彙）。
- ⚠️ **文字の影と字間は自由配置の文字から触れる**（#264）＝描画・焼き出しまで land しているのに**書き込む入口が1つも無かった**（差分再監査 2巡目）。既定値は `textStyle` から採る（画面と描画がずれない）。
- ⚠️ **「元に戻す」は文字の形だけを戻す**（差分再監査・§2-5）＝履歴が覚えるのは `{meta,parts,scenes}` だけ（ADR-0020＝assets は入れない）ので、**足したロゴは戻らない**。戻らないものはその場で言い、**ロゴを足しただけのときは「元に戻す」を出さない**（押しても何も戻らないボタンを置かない）。
- ⚠️ **「開いているか」の旧記述（`projectId` で見る）は撤回**（差分再監査 7巡目 🟡）＝**1つの条件だけでは足りない**（番号だけだと白紙直後を、状態と場面だけだと番号だけ採った文書を、いずれも取りこぼす）。判定は上の bullet の**共有の1つ**（`hasOpenProject`）を見る＝同じ節に新旧2つの規則を残さない（読んだ次の実装が元へ戻せてしまう）。
- ⚠️ **動画を開いていなくても塊ごと消さない**（α-6 出口監査 ℹ️）＝反映の一式が何も言わずに消えると**そこに何かがあったこと**が分からない。見出しは残し、押せない理由（先に動画を開く）をその場に出す（§2-5）。
- ⚠️ **ロゴが無いときは場所と行き方まで書く**（ℹ️）＝「「よく使う素材」に置くと選べます」だけでは、どこにあるか分からず**次の行動が取れない**。素材の画面への導線を添える。
- ⚠️ **「何がいくつ変わるか」に“変わらないもの”も入れる**（α-6 出口監査 🟡31）＝**場面ごとに文字の形を選んだ場面は変わらない**（場面の指定は動画全体より優先＝`11 §7.1.1`）。数えて「そのままです」と先に見せる（押したあとに自分で気づかせない）。
- ⚠️ **書き出し中は「この動画に反映する」を押せない**（α-6 出口監査 🟡14）＝押す前に理由を出す（§2-5）。中で断るだけだと、押せるのに何も起きない（コメントだけが「押せないようにもしてある」と言っている状態だった）。
- **保存はグローバル**（`appData/brandkit.json`）＝動画の中身ではない。⚠️ **ロゴの実体は「よく使う素材」
  （ADR-0035）に置き、キットは指すだけ**（棚を3つ目に増やさない）。
- **新しい動画へはコピー**（決定2）＝フォントは動画全体の設定へ、ロゴは**取り込みと同じ経路**で入る。
  ⇒ **動画のファイルの形は変わらない**（`project.schema` は不変）。
- ⚠️ **すでに作った動画は自動では変わらない**（決定3・§2-5）＝**「この動画に反映する」を押したときだけ**。
  自動で遡ると、**過去に書き出した動画と、いま書き出す動画が違う絵**になる。
  押す前に**何が変わるかを見せる**（#547「まとめて標準にする」と同型）・**取り消せる**。
  ⚠️ **一部だけ入って失敗することがある**（フォントは入ったがロゴの取り込みで失敗）＝
  **その旨と戻す導線を出す**（理由だけ出すと、変わったまま戻せない・§2-5）。
  ⚠️ **戻す導線はこの知らせの中に置く**（α-6 出口監査 🟡30）＝設定画面には共通の「取り消す」が無い
  （たたき台・公開前チェック・編集のツールバーにしか置いていない）ので、**その場に押すものが無いのに
  「「取り消す」を押してください」と言う**のは、実行できない次の行動を名指しすること（§2-5）。
  ⚠️ **すでにあるロゴは置き換えない**（足すのは持っていないときだけ＝作り込みを消さない）。
- **色は色を選ぶところの候補の先頭に出る**（決定4）＝**既定18色は残す**・重なる色は二重に出さない。
  覚えられるのは数色まで。⚠️ **上限で古い色を黙って捨てない**＝押せない理由を出す。
- ⚠️ **覚えている字体が一覧に無くても、覚えていないようには見せない**（α-6 出口監査の再監査）＝
  「外す」はキットに触らないので、既定にしていた字体を外すと**一致する選択肢が消え**、覚えているのに
  画面は「覚えない（毎回選ぶ）」を見せる（そのまま新しい動画へは焼き込まれる）。**受け皿の選択肢を出す**
  ＝文字の形を選ぶところ（`FontPicker`）と**同じ扱い**にする（片方だけ直すと同じ穴が残る）。
- ⚠️ **ロゴは1つだけ覚える**（決定6）＝「会社の既定として最初から入れておく1枚」の話。
  白抜き版などは「よく使う素材」から取り込む。
- ⚠️ 「ブランドキット」「アセット」は画面に出さない（§2-3）＝見出しは「会社の見た目」。

### 保存設定

- プロジェクト保存先
- 一時ファイル削除

## 16. エラーメッセージ方針

悪い例：

```text
Invalid templateId
```

良い例：

```text
この場面の見た目パターンが見つかりません。
場面編集で選び直すか、「まとめて標準にする」で標準の見た目に変えてください。
```

> **既存の場面は黙って別の見た目に差し替えない**（#547）。作り込んだ配置が中身の減った動画として書き出されるため、
> 標準へ寄せるのは利用者の明示操作にする。**取り込み時**（AI出力→場面への変換）だけは自動補正してよく、その場合は
> 「この場面の見た目パターンが見つからないため、標準を使います」と**何をしたか**を伝える。使い分けの正典は
> [`15_ERROR_STATE_MODEL.md`](15_ERROR_STATE_MODEL.md) §6 の `TEMPLATE_NOT_FOUND`。
