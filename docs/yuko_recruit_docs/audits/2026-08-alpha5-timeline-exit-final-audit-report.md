## 🔴 ブロッカー

### 1. 焼き出しでグループ id が衝突し、絵が変わる

`src/domain/timeline/bake.ts:723` — `newGroupId()` は累積配列を見るのに、入れ子グループは `.map()` の中で id を採り**あとからまとめて push** する。**FREE 場面が `scene.groups` を2つ以上持つと nested 全部が同じ id** になる。

- **実測**（反証エージェントが再現）: 4要素・2グループの場面 → 焼き出し後の id が `["group_001","group_001","group_002"]`。要素A・Bが**2倍の大きさで画面外**（y=-270）へ。原因は `composeGroupGeometry` の `groupById` が Map（後勝ち）／`parentOf` が先勝ちで不整合になるため。
- **動きも混ざる**: `oldToNewGroupId` が2つの旧グループを同じ新 id へ写し、別々のキーフレームが1本へ合流。
- **何も止めない**: schema 適合・`validateTimelineDoc` とも `[]`。グループ id の重複を見る V ルールが無いので `bakeToTimeline` の「未適合なら保存しない」も発火せず、壊れた文書が**保存される**。
- 到達性: 自由配置でグループを2つ作れば足りる（部品を2つ置くだけでも `addFreeComponentAsGroup` が自動で作る）。
- 正しい型が同リポジトリにある: `edit.ts:533` は採番済み id を積んでから次を採っている。
- 根拠: `11 §2.1`（`group_NNN` は project 内一意）／ADR-0032 決定20・決定23。

### 2. 見た目パターンが未解決のとき、存在しないボタンを案内し続ける

`src/app/screens/TimelineProjectScreen.tsx:2735-2739` — テンプレクリップを選ぶと**無条件で**「中の位置や大きさを変えるには『中身をバラす』を使ってください」と出るが、そのボタンは `selectedTemplate` が解決したときだけ描かれる（`:3468`）。右クリックメニューの同項目も同じ条件、キーボード経路も無い＝**到達路がゼロ**。同時に「見た目パターンが見つかりません」という正しい案内が並ぶ。

- 到達性: 自作の見た目パターンを削除しても、`deleteUserTemplate` はタイムライン文書を修復しない（場面形式の `scenes` しか直さない）＝**恒久的な孤児**になる。画面自身が `missingTemplateCount` で警告している状態。
- 根拠: §2-5（次の行動は実在すること）。コード自身のコメントが「行き先は実在するので名指しする」と書いており、その前提が崩れている。

### 3. キャンバスで未選択の部品を掴むと、1移動＝1履歴になる

`src/app/screens/TimelineProjectScreen.tsx:567` — `pointerdown` で `onSelect` → `beginHistoryGroup` の順に呼ばれるが、選択が変わったことで走る effect が `resetHistoryGroup()` でまとめを畳んでしまう。以後の `pointermove` が毎回履歴を積む。

- **実測**: 未選択の部品を pointerdown + 3 move → `past` +3（選択済みなら +1）。567行だけを外すと +1 に戻る（原因の特定）。60回動かすと履歴が上限50に達し、**その前の編集が取り消せなくなる**（実証済み）。
- リポジトリ自身が同じ罠を文字編集の経路で文書化し回避している（`FreeLayoutOverlay.tsx:244-250`）のに、ドラッグ経路には対処が無い。
- 根拠: ADR-0020（1操作1履歴）・ADR-0034 決定6/7。

### 4. 正典が自分自身と矛盾している（資料ドリフト・2件）

- 根拠: §9-3・§0（CLAUDE.md も正典）。

### 5. 閉区間の境界がテストで守られていない（過去に実機で踏んだのと同型）

## 🟡 直すべき

### 動画まわり（#512 の積み残し）

1. **画面で再生できない動画が、静止＋無音なのに書き出しは実映像＋音**（`TimelineProjectScreen.tsx:2078`）。`.avi`/`.mkv` は取り込めるが WebView2 が再生できないため**これは例外ではなく主要ケース**。理由も一切出ない。`held`（まとまりのフェード・回した切り抜き）は「絵は止めても音は鳴らす」と設計されているのに、`!item || !src` の早期 return だけがその配慮から漏れている。**parity と error-state が独立に同じ結論**。
2. **テンプレクリップを分けると後半が巻き戻る**（`split.ts:36`）。`USES_SOURCE_TIME` に `template` が無く、差し込み口の頭出し（`slotClips[layerId].startSec`）が進まない。**絵も音も**前半と同じところから流れ直す。`USES_SOURCE_TIME` は書かれた当時は正しく、段3/段3b が `split.ts` を触らなかったための取り残し。
3. **直接置きの素材差し替えでトリム・速さが残る**（`edit.ts:1140`）。落とすのは `useOriginalAudio`/`originalAudioVolume` の2つだけ。**`setClipAssetRef` のコメントが「直接置きが同じ後始末をしている」と書いているが嘘**。差し込み口側のテスト名が期待される契約を明示している。しかも残った値を画面から直す手段が無い（速さ・使い始めの欄は音の部品だけ）。
4. **背景の層に入れた動画がバラすと動き出す**（`explode.ts:55`）。背景層は動画を受け付ける（`slotAssign`）が置き場所にはならない＝静止画。バラすと直接置きになり実映像として動く。**確認ダイアログは「動画の見た目は変わりません」と約束している**。UI から素直に踏める。
5. **「バラす」の断り（素材既定側）も行き止まり**（`uiLabels.ts:538`）。「素材の画面で切り出す範囲を外して」と案内するが、**素材画面は場面形式専用**でタイムライン文書の `asset.clip` は触れない。**ADR-0034 決定5 に「あの画面は場面形式専用＝行き止まり」と既に記録されている**。
6. **`isDrawnClip` が描く側と条件不一致**（`video.ts:161`）。列の種別を見ないため、V23 に反する文書（警告どまり・書き出しも止まらない）でプレビュー無音／書き出し有音。JSDoc の「描く側と同じ条件」が成り立っていない。到達は手編集に限られる。

### 履歴・並行ガード

7. **まとめが開いたまま取り消すと、次の1手が積まれず `future` も捨てられない**（`timelineStore.ts:1168`）。矢印キーの 600ms 以内に `Ctrl+Z` → 次の編集が**取り消せず**、`Ctrl+Y` で**黙って消える**。実測表で確認済み。**見た目パターン編集にも同じ穴**。場面形式は「まとめを開かない」ため偶然守られているだけ。
8. **`exportLock` が解放されない経路**（`ExportScreen.tsx:189`）。`acquire` が `try` の外にあり、早期 return が `finally` を通らない。以後タイムライン形式の書き出しが**「ほかの動画を書き出しています」で押せなくなる**（走っていないので終わりようがない）。この早期 return は意図して作られテスト済みの経路。タイムライン側は正しく `try/finally` に入っている非対称。

### 操作モデル・文言

9. **再生ヘッドのスクラブが無い**（`TimelineProjectScreen.tsx:2400`）。目盛りは `onClick` のみ。**プレビューで実証**: ヘッドに 7px の三角のつまみが描かれているのに `pointer-events:none`、押下→移動で `aria-valuenow` が動かない（0 のまま）、目盛りのカーソルは `pointer`。観点ファイル22行目が「ドラッグでスクラブ」を要求し、**意図的な見送りの記録も無い**。同じ行の「再生中の追従（ページ送り）」も未実装。
10. **テンプレのドリルインが無い**（`box.ts:37`）。ADR-0034 決定8 は「**ダブルクリックで中へ入り、差し込み口の中身はそのまま直せる**」と明記。**#685 のクローズ時に「バラす＋案内」で決定8 を満たしたと読み替えられ**、ロードマップは「A は全段階 ✅ 完了」。見送りの記録は無い。`06 §12.1` は除外理由だけを引き継ぎ、ドリルインを書いていない（正典どうしの食い違い）。
11. **画面が断り文を手書きしている**（`TimelineProjectScreen.tsx:806, 1944`）。domain に対応コード（`locked`/`hiddenTrack`）があるのに別文言。`:1216`（`Ctrl+K`）と `:1420`（ボタン）で**同じ状況に2通りの文**が出る。`uiLabels.test.ts` の禁止語スキャンの外。**既存テストがずれた文言を固定してしまっている**。
12. **資料ドリフト4件**: `11 §747`「差し込み口は段3 まで出さない」／`11 §1` の版履歴が 1.1 止まり（現行 1.8）／schema の `crop` 説明が「枠いっぱいは将来」（`cropMode:'fill'` は land 済み）／秒の刻みの直書き（`step={0.1}`/`{0.5}`・場面形式は `SEC_STEP` を通している）。
