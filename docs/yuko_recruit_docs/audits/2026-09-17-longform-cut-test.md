## 1. 試験の素材（作り方と、確かめられないこと）

**自前で生成しました**＝権利の判断が要らないものだけを使う、という決めごとのため。

| | |
|---|---|
| 長さ・大きさ | **30分・869MB**（1280×720・30fps・H.264〔`h264_mf`〕＋AAC） |
| 絵 | `testsrc2`（時計と模様＝**どこを切ったか見分けられる**） |
| 音 | **しゃべり20秒／無音10秒**を交互（周波数はかたまりごとに変える） |

⚠️ **第1版は音が 440Hz の一定音**で、**波形が平らで「音を見て切る」が試せません**でした。作り直しています。

⚠️ **人工の素材では確かめられないこと**（限界を明記します）:

- **実写の探しにくさ**（画質・手ブレ・生活音・似た場面の連続）は再現できません。
- **中身で切り所を決める**作業（面白い所を選ぶ）は測れません。
- ここで確かめられるのは**長さと量**＝取り込み・探す・大量カット・書き出しの**重さ**です。

## 2. 通した道

⚠️ **人の操作ではなく、起動の引数（ADR-0042）で通しました**＝`--import` → `--export --out --quit-when-done`。
**人の操作量は別に測る必要があります**（§6）。

作った文書＝**100 カット・6秒ずつ・合計10分**（30分の素材からばらけた位置を拾う）。

## 3. 測った結果

### ✅ 取り込みは速い

| | 実測 |
|---|---|
| 30分・869MB の取り込み（素材のコピー込み・ADR-0024） | **8〜9 秒** |

### 🔴 書き出しが桁で足りない

| | 実測 |
|---|---|
| **10分の動画の書き出し（100カット）** | **75.7 分**（終了コード 0・839MB の正しい MP4） |
| 1秒あたりに作れるコマ | **4.2〜4.3 コマ** |
| 要るコマ数 | **18,000 コマ**（＋素材のコマ出し 100 本ぶん） |
| 1コマの大きさ | **572 KB** |
| 一時ファイル | **7.6 GB**（4,600コマ時点の実測）→ 最後はおよそ **15 GB**（計算） |
| 後片づけ | ⚠️ **ちゃんと消えました**（`.frames_stage/proc_<pid>` は空に） |

**比べると**（同じ機械・同じ日）:

| 形式 | 出来上がりの尺 | 書き出し | 実時間に対して |
|---|---|---|---|
| 場面形式（6場面・アニメ無し） | 85 秒 | **37 秒** | **0.44 倍** |
| タイムライン形式（100カット） | 600 秒 | **4,541 秒** | **7.6 倍** |

⚠️ **17倍の差**は中身の違いではなく**作りの違い**です（下）。

**なぜこうなるか**＝タイムライン形式の書き出しは**全コマを1枚ずつ焼く**
（`buildTimelineFrames`＝`frameCount = 尺 × fps` 回）。場面形式は「動かない場面は静止1枚＋実動画を FFmpeg で重ねる」に倒しています。

⚠️ **これは今日の新しい壊れではありません**＝**ADR-0032 決定22 でそう決めた**ものです
（「条件を作らず、常に全フレーム描く」＝パリティの検査点を増やさないため）。
そして**その決定は再検討の条件を自分で書いていました**：

> **再検討の条件**：実測で許容できない遅さになったとき。そのときは「重なりもアニメも速度変更も無いクリップだけの
> 区間」を静止1枚へ倒す形を、**パリティの検査を足したうえで**入れる。

**今回の実測が、その条件そのものです。**

### 🔴 出来上がりの長さに上限がある（正典の決定）

`videoSettings.targetDurationSec ≤ 300`（5分）／`maxDurationSec ≤ 600`（10分）＝**ADR-0032 決定9**。
⚠️ **実況系の15〜30分は、そもそもデータとして表せません**（今回は上限ぎりぎりの10分で回しました）。

⚠️ **上限を上げる話は、書き出しの費用を下げた後**です＝いまの作りで30分を焼くと**3〜5時間・50GB 前後**になります。

### 🔴 声を入れないまま「成功」で返る

外の AI が**読み上げのセリフを書いた**文書を `--export` すると：

| | 実測 |
|---|---|
| 終了コード | **0**（成功） |
| 出来た動画 | 5秒・音声トラックあり・**−91 dB＝完全な無音** |

⚠️ **ナレーションは一度も鳴っていません**。頼んだ AI には**成功に見えます**。

**なぜこうなるか**＝未生成の読み上げは**書き出しを止めません**（`TIMELINE_EXPORT_AUDIO_UNREADABLE` の対象外＝
「元から鳴らない」扱い）。⚠️ **場面形式も同じ**です（公開前チェックの「読み上げの声」は `severity:"action"` だが
`blocksExport` ではない）＝**形式で割れてはいません**（ADR-0026②）。

**本当の穴は別の所**＝**画面が担っていた役目を、画面を読まない道（ADR-0042 の起動の引数）では誰も担っていない**。
公開前チェックが「要対応」として人に見せていたものが、**人の居ない道では消える**。

⚠️ **あわせて、声を作る口そのものがありません**＝`--import` と `--export` はありますが、
**「声を作る」に当たる引数が無い**ので、外の AI は #1184 の題（作る→**声**→書き出す）の**真ん中を通れません**。
