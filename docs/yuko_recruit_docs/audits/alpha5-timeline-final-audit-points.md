## ux-model-reviewer（操作モデル）

> **この節が最重要**。利用者は動画エディタの実知識を持たない＝**利用者の実機確認では「独特さ」「型からの逸脱」に気づけない**。ここは型（レビュア定義に焼き込み済み）との差分で機械的に照合する。

- [ ] **3手順ウォークスルー**＝完全新規のタイムラインで「素材を置く→長さを詰める→文字と音を足す」が**案内なしで通る**か。詰まる箇所・迷う箇所を記録 — research §4-3 — [プ]（体感の滑らかさは[実]）
- [ ] **行き止まり案内の検出**＝画面の案内文（「◯◯してください」）の指す先が**すべて実在し、その画面で実行可能**か — audit §2.2-12 の再発防止 — [静]
- [ ] **ドラッグ規則の統一**＝帯・キャンバス・欄（ADR-0033）の3つのドラッグが同じ規則（少し動くまで掴まない／Escape 中止／左のみ／ゴースト／置けない表示→元へ戻る）か — ADR-0026② — [静]＋[プ]

- [ ] **キーボード**＝Space/Delete/矢印/Escape/分割キーの実装と、**入力欄フォーカス中・IME 変換中に奪わない**こと・ツールチップにキー併記 — audit §5-K — [静]（IME の実挙動は[実]）

## 実機チェックリストの種（[実] の集約先＝監査時に #352 へ流す）

- ドラッグ・トリムの**体感**（掴みやすさ・吸着の強さ・ゴーストの追従）
- IME 変換中の Space・確定 Enter がショートカットに化けないこと（日本語入力の実機）
- 実素材（大きい写真・長い BGM・多部品）での再生応答・ドラッグ応答
- 書き出した動画とプレビューの目視一致（代表ケース）
- 高 DPI・小さい画面での欄の折り返し・帯の視認性
