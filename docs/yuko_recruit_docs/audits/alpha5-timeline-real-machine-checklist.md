## A. 書き出した MP4 の中身

- [ ] **〔直〕写真を1枚置いたタイムライン動画を書き出す** — MP4 に**写真が写る**こと（監①🔴1）
  <br>※ 表示用の `asset://` を書き出しへ渡していて**写真が抜けた MP4 が「保存しました」として出て**いた。`resolveExportSrcMap` で data URL に解決して修正済み。
- [ ] **〔直〕場面形式から焼き出した動画の場面の切り替え** — ハードカットでなく**クロスフェードになる**こと（監①🔴2）
  <br>※ 焼き出しが同じ対象に動きを2本作り、読む側は1本しか見ていなかった。1本へマージ＋V31（`TIMELINE_ANIMATION_DUPLICATE`）で検知するよう修正済み。
- [ ] **〔直〕焼き出した動画の部品にキーフレームを1つ置く** — 退場の動きが**消えない**こと（監①🔴2 の影響②）
- [ ] **〔直〕音量 120% の音／読み上げ** — 再生と MP4 で**音量差が無い**こと（監①🟡M）
  <br>※ 100%超が**再生では上がらず書き出しだけ上がって**いた（要素の `.volume` は 1.0 が上限）。#724 で `GainNode` を通す共有経路へ寄せて修正済み。
- [ ] **〔感〕長尺・実素材での書き出し時間と一時ファイル量** — コマは**フレームループ前に全部** PNG で吐き切る構造（監②）
- [x] **〔直・環〕`.avi` / `.mkv` の動画を置いたときの見え方** → ✅ **確かめた**（2026-09-01・Tauri 実アプリ）＝同梱 ffmpeg で `.avi` を作って置き、その部品を選ぶと「この動画は、ここでは映像も音も出せません（形式が合わないか、ファイルが見つかりません）。MP4 で取り込み直すと、ここでも確かめられます」が出る。⚠️ **断りは選んだ部品の欄に出る**（画面上部の知らせではないので、`role=alert` だけを見ると見つからない）
  <br>※ WebView2 が再生できない形式で、**画面は静止＋無音なのに書き出しは実映像＋音**になり、理由も出なかった。#816（#512 積み残し6件）で修正済み。実際のコーデックが要るので実機。

- [x] **〔直〕「再生位置」の欄・時間の目盛りを右クリック** → ✅ **確かめた**（2026-08-31・Tauri 実アプリ）＝目盛りには**独自のメニューが出ず**、再生も止まらない（右クリック前 1.2 → その後 3 と進み続けた）
- [x] **〔懸・環〕帯を押したあと `Space` で再生・停止できるか** → ❌ **懸念は当たった**（2026-08-31・Tauri 実アプリ）＝帯は `<button>` なので押すと焦点がそこへ移り、**`Space` がボタンの起動に使われて再生・停止に届かない**（実測：焦点を帯に当てて `Space` を送っても再生位置 4.3 のまま）。焦点が移るかは `pointerdown` の `preventDefault` 次第で、それは `grabbableClip`（`!exporting && !isPlaying && !locked`）が真のときだけ通る＝**まさに「固定した列の帯・再生中の帯」で壊れている**。→ **#948 で起票し、直した**（帯の `pointerdown` で掴めるかに関わらず `preventDefault`＝どの帯でも焦点を移さない）。⚠️ `element.click()` は焦点を移さないので、クリックを模しただけでは再現しない（最初これで「効く」と誤記しかけた＝PR #947 レビューの指摘で判明）

## C. 取り消し・自動保存

- [x] **〔直〕文字の色を面ドラッグで1回撫でる** → ✅ **確かめた**（2026-08-31・Tauri 実アプリ）＝面を撫でると色が連続して変わり（`#222222` → `rgb(204,41,41)` → `rgb(102,61,61)`）、**「取り消す」1回で `rgb(34,34,34)`（撫でる前）へ戻る**。2回目の取り消しではそれ以上戻らない
- [x] **〔直〕保存に失敗した状態でサイドバーから別画面へ** → ✅ **確かめた**（2026-09-01・Tauri 実アプリ）＝フォルダを書けなくして自動保存を失敗させ、サイドバーの「素材」を押すと**画面は移らず**「保存できていない変更があります。このまま画面を移ると、その変更は失われます。移る前に「保存し直す」を試せます」が出る。「やめる」で留まり、権限を戻して「保存し直す」で復帰できることまで確認。⚠️ **関門を名乗るのはタイムライン編集だけ**（場面形式は保存ボタンがあり、画面を移っても編集は残る）
- [x] **〔直〕場面編集でセリフ欄に手を入れたまま欄の配置を組み替える** → ✅ **確かめた**（2026-09-01・Tauri 実アプリ）＝文字の欄に焦点を当てたまま「⋮ → 左へ移す」で欄を移し、その後2回編集して待つと**保存が走り**（`updatedAt` 更新・未保存の印も消える）、取り消しは**1件ずつ**戻る（いちご3→いちご2→いちご1）
  <br>※ フォーカスしたまま要素が消えると `blur` が飛ばず、まとめが開きっぱなしで**自動保存ごと止まる**。#847 で修正済み。
- [x] **〔直・環〕ドリルイン中に `Ctrl+Z`** → ✅ **確かめた**（2026-09-01・Tauri 実アプリ）＝差し込み口へ二度押しで入り、中で素材を変えてから `Ctrl+Z`。**中に居たまま** `Space`（0→1.3）・矢印（1.3→1.4）・`Escape`（1段出る）がすべて効く。⚠️ **履歴が空のまま押しても検査にならない**（取り消しボタンが `disabled`）ので、先に1つ積むこと
