## 読み方（⚠️ 重要）

各レポートの実機項目は**書かれた時点の状態**で期待値を書いている。監①・監② の項目の多くは
**「不具合が出ること」を確かめる文**（起票のための再現手順）だった。**それらはすべて修正・マージ済み**なので、
本ファイルでは**期待値を「直っていること」へ書き直してある**。レポート本文と文言が違うのはそのため。

種別：**〔直〕**＝修正が入ったので直っていることの確認／**〔感〕**＝正誤でなく手応え・見え方の確認／**〔環〕**＝環境依存

## A. 書き出した MP4 の中身

- [ ] **〔直〕写真を1枚置いたタイムライン動画を書き出す** — MP4 に**写真が写る**こと（監①🔴1）
  <br>※ 表示用の `asset://` を書き出しへ渡していて**写真が抜けた MP4 が「保存しました」として出て**いた。`resolveExportSrcMap` で data URL に解決して修正済み。
- [ ] **〔直〕場面形式から焼き出した動画の場面の切り替え** — ハードカットでなく**クロスフェードになる**こと（監①🔴2）
  <br>※ 焼き出しが同じ対象に動きを2本作り、読む側は1本しか見ていなかった。1本へマージ＋V31（`TIMELINE_ANIMATION_DUPLICATE`）で検知するよう修正済み。
- [ ] **〔直〕焼き出した動画の部品にキーフレームを1つ置く** — 退場の動きが**消えない**こと（監①🔴2 の影響②）
- [ ] **〔感〕音量 120% の音／読み上げ** — 再生と MP4 で**音量差を感じないか**（監①🟡M）
- [ ] **〔感〕長尺・実素材での書き出し時間と一時ファイル量** — コマは**フレームループ前に全部** PNG で吐き切る構造（監②）
- [ ] **〔環〕`.avi` / `.mkv` の動画を置いたときの見え方**（監②🟡1）

## B. 再生・キャンバス・帯の手応え

- [ ] **〔感〕再生中の体感 fps** — 毎フレーム SVG を作り直して差し替える構造（監②）
- [ ] **〔感〕取っ手の当たり判定 14px の掴みやすさ** — 「全体を表示」直後に取っ手が出ない帯（幅 58px 未満）がどれくらいあるか（監②）
- [ ] **〔感〕短い帯（1秒未満＝数px）の掴みやすさ・視認性**（監①）
- [ ] **〔感〕端まで運んだときの送りの速さと、送っている間のゴーストの追従**（監②）
- [ ] **〔感〕吸着のしきい値** — 倍率を変えても**同じ指の感覚**か（監②）
- [ ] **〔感〕目盛りを押しながら横へ引いたときの体感**（監②🟡9 の優先度判断の材料）
- [ ] **〔感〕小さいウィンドウで並び欄が潰れたとき、列へ運べるか**（監①・プレビューでは確認済み・体感は実機で）
- [ ] **〔直〕「再生位置」の欄・時間の目盛りを右クリック** — メニューの有無と、**再生が止まらない**こと（再②ℹ️3）
- [ ] **〔環〕帯を押したあと `Space` で再生・停止できるか** — **固定した列の帯・再生中の帯**で必ず（監②）
  <br>※ `<button>` がフォーカスを受けると `Space` が譲られ、止められない恐れ。DOM 実機でないと確かめられない。

## C. 取り消し・自動保存

- [ ] **〔直〕文字の色を面ドラッグで1回撫でる** — 「取り消す」**1回で撫でる前へ戻る**こと（監①🔴5・`startDragBoundary`/`endDragBoundary` で修正済み）
- [ ] **〔直〕保存に失敗した状態でサイドバーから別画面へ** — **確認が出て**、編集が消えないこと（監①🔴4・#698 で修正済み）
- [ ] **〔直〕場面編集でセリフ欄に手を入れたまま欄の配置を組み替える** — その後の編集が取り消しに**1件ずつ積まれる**こと（＝自動保存が止まらないこと・再②）
  <br>※ フォーカスしたまま要素が消えると `blur` が飛ばず、まとめが開きっぱなしで**自動保存ごと止まる**。#847 で修正済み。
- [ ] **〔環〕ドリルイン中に `Ctrl+Z`** — 差し込み口へ二度押しで入った直後に取り消し、以後 `Space` / `Delete` / 矢印 / `Escape` が**効く**こと（再①🔴・#842 で修正済み）
