## 指摘（検証済み・重大度順）

### 🔴 戻した内容が、走っている保存に黙って上書きされる

`restorePointKeeper.ts:76` — 保存の直列化（`saveInFlight`）の外で `project.json` を書いていた。
`_doSave` は「まだ同じ文書か」を**書き込みの後**でしか見ないので、待たずに戻すと**戻す前の内容で上書き**される。
しかも画面の未保存確認は `saveStatus === "saving"` の間 false になるので**確認も出ずに素通り**する。
⚠️ `doRestorePoint` の説明文は**まさにこの上書き**を警戒していたが、防いでいたのは「**次の**保存」だけだった。
→ 直した（PR #971）。

### 🔴 声を作り直す知らせが、一度も描かれない

`HomeScreen.tsx:331` — 開き直すと**この画面が消える**のに、知らせをその**後**に置いていた＝
正常経路では**構造的に一度も出ない**。失敗経路では**読み込み失敗の理由を上書き**して「戻しました」＝
**失敗が成功に見える**。⚠️ テストは `onNavigate={vi.fn()}`（遷移しない）で緑のままだった。
→ 直した（開く前に知らせて、押してもらってから開く）。

### 🔴 案内が、実在しないボタン名を指していた

`uiLabels.ts` の `voicesClearedMessage` — 「その場面の『声を作り直す』から」と言うが、
作成前に戻したあとのボタンは**「声を作成」**（掛け合いには行ごとのボタン自体が無い）。
→ 場所（声の欄）で言う形に直した。

### 🔴 一覧に出ない動画は、復旧の導線に届かない

`lib.rs:304` — 戻す入口は**一覧の行からしか押せない**のに、`list_projects` は
`project.json` が読めない動画を**黙って飛ばして**いた＝**#263 が救おうとした場面がちょうど到達不能**。
→ **戻り先があるなら行を出す**（いまの内容 → 控え → いちばん新しい復元ポイント）。
