- **正典**: ADR-0038 `:118`（画面の約束）・**決定7**「`fontId` が `string` になれば持ち込みを既定にできる」／`06 §15:1203`「手持ちの文字の形を足すと、**動画の文字に使える**」／`15 §6` `USER_FONT_MISSING` は**構造的に一度も発火しない**（`usedUserFontIds` が常に空）

| 件 | 何が起きるか |

| タイムラインにフォントの門が無い | 🔴1 で `FontPicker` が持ち込みフォントを出すようになり、タイムラインの文字クリップにも指定できるのに門が無い＝**黙って別の字体で書き出しが成功**（ADR-0038 が形式で割れる） |

**到達不能だった機能（凍結点から存在）**

- **よく使う素材に「ロゴ」「音楽」を置けない** → **ADR-0036 の「いつものロゴ」がどこからも設定できない**。`detectAssetType` は `image`/`video` しか返さず、ファイル選択も写真・動画だけ＝種類タブの「ロゴ」「音楽」は常に0件、会社の見た目の選択欄は出ないまま「「よく使う素材」に置くと選べます」だけが残る（§2-5・🔴1 と同型）。

**同じ規則の取り残し**

- `meta.projectId` の着地（5か所）と `setAssetImage` が `sameDocGuard` を通っていない／差し替えた絵の大きさを測り直していない
- 採番の入力が**壊れた行の番号を落とす**（🟡8 で塞いだ失敗が再現しうる）
- 目録の書き込みが**非アトミック**（🟡19 の残り）
- 「調べられなかった」が設定画面とライブラリに配線されていない／読めないときに**矛盾する2つの断り**が同時に出る
- 声を作るときの辞書エラーが**設定画面向けの文言**

### 反省点（観点の切り出し）

⚠️ **「直した」と「消えた」は別**＝今回の10件のうち5件は**修正そのものが開けた穴**だった。とくに **🔴1 のように「使えるようにする」修正は、使えるようになった先の門が要る**（タイムラインのフォント）。修正の PR では「この修正で**新しく到達できるようになる経路**はどこか」を必ず数え上げる。

⚠️ **到達不能な機能は「実装済み」に見える**＝ADR-0036 のロゴは、schema もストアも画面も揃っていたのに**入口（種類を選ぶ口）が1つ欠けている**だけで丸ごと使えなかった。🔴1 と同じ形が**2回**起きているので、機能の完成判定は「経路の端から端まで1本つながっているか」で見る。
