## 見つけたこと

- [直した] **台本 05 が古かった**（`docs/tutorials/05-timeline-advanced.json`）＝①「見え方（色・重ね方）」→ 0.5.2 で「見え方（色・重ね方・反転）」に変わっていた ②「範囲を削除して詰める」の後に、10/2 の UI 監査で入った**確認（「削除する」）**に答える段が無かった。どちらも直して 52 段が通った。
- [🟡 判断が要る] **新しく作った動画にゆうこが入らない**＝同梱のゆうこの絵（7 表情・`public/yuko/`）は画面の飾り（「ゆうこからひとこと」）にしか使われず、動画の素材には入らない。素材を入れずに AI で作ると、案が「ゆうこ右」「ゆうこ」の見た目パターンを選んでも**ゆうこが出ず、知らせも無い**（`12 §8.3` の 4＝ゆうこの素材が無く、層が `required=false` なら出さずに黙る＝**仕様どおり**）。最初の 1 本でマスコットが出ないのは、製品の看板として弱い。直し方の候補：(a) 新しい動画に**同梱のゆうこ 7 表情を素材として入れる**（ADR-0024＝取り込み時にコピー）(b) AI の案に「ゆうこ」の見た目が入ったのにゆうこの素材が無いとき**知らせる**。
- [ℹ️] 「声を文字にする」の対象外の理由は画面に出る（「選んだ部品には、文字にできる音がありません。音の入った動画か、音の部品を選んでから…」）＝§2-5 どおり。
