## 🔴（いずれも修正済み・実コードで再現筋を確認）

### 1. 立ち絵に入れた動画がプレビューに配線されていない（parity）

`TimelineProjectScreen` は当てるアイテムを `role === "slot"` で絞っており、立ち絵のアイテムは
`layoutScene` が `role:'character'` で作るので**必ず一致しない**。置き場所ごと落ちるので、
**プレビューは代表フレームで静止・元の音も無音**なのに、**書き出しは実映像＋元の音**になる（ADR-0001 の破れ）。
穴あけ（`videoSceneSplit`）も同じ絞り込みだった。元の音の欄も差し込み口だけに絞っており、
**書き出しにだけ効く設定**になっていた。

→ 「どの置き場所のアイテムか」は `isItemOfPlacement` 1本に委ね、役割で絞らない。

### 2. 取り消しで戻る場面が指す素材を「未使用」と数え、実体ごと消す（resilience）

`unusedAssetIds` は**いま生きている場面だけ**を見る。場面を消す・写真を外すはどちらも取り消せるのに、
その直後に「まとめて消す」を押すと `assets` から外れ、**ファイルも削除される**（`assets` は履歴の外＝ADR-0020）。
取り消すと場面は戻るが素材は戻らず、死んだ参照と灰色の枠だけが残る（取り込み直しても番号が変わる）。
読み上げ音声の剪定（`_doSave`）は**同じ理由で** `past`/`future` を数えている＝素材だけ規則が違った。

→ 履歴スナップショットの場面も「指されている」に数える。

⚠️ **混ぜる（merge）形にはしない**＝`undefined` で**外す**（ロゴ・フォント）ができなくなる。

### 🔴 B. 立ち絵の「元の音」欄は出るのに、押すと毎回断られる

**音は入っているのに事実と違う**。**読む側だけ共有・書く側は別**だった。
→ 素材の解決を**画面が欄を出す条件と同じ述語**（`videoPlacementsOfClip`）へ寄せた。

⚠️ **足したテストが「欄が出る」しか見ていなかったので緑のまま通っていた**＝
**描けることと設定できることは別**。以後、欄を足したら**押した結果**まで固定する。

## [実] 実機チェックリストへ流すもの

1. 立ち絵に動画を入れて、**プレビューで動き・音が出る**こと（今回の🔴1の確認）
2. 場面を消す → 素材画面で「まとめて消す」→ **取り消し**して、素材が残っていること（🔴2）
3. セリフの多い動画を書き出し、**「区間をつないだ」知らせ**が出ること（タイムライン形式）
4. 設定でフォントを外したとき、**会社の見た目の指定も外れた**と知らせが出ること
5. 棚のタグを、種類で絞った状態で押して**0件にならない**こと
6. 破棄確認バナーは画面上部＝一覧を下までスクロールして押したとき視野に入るか
7. 設定画面の最下段（会社の見た目）までのスクロール量
8. 棚の一覧が数十件になったときの読みやすさ（行が名前だけなので伸びる）
9. **立ち絵に入れた動画で「この動画に入っている音を流す」を押し、実際に音が鳴る**こと（修正PR 🔴B）
10. **持ち込みフォントを外したとき、会社の見た目の色とロゴが残っている**こと（修正PR 🔴A）
11. **声を多めに置いた動画で、点を数個だけ置いた読み上げが書き出せる**こと（門の数え方・修正PR 🟡）
12. **会社の見た目のファイルが壊れているとき**、その旨が出て変更できなくなること（覚えた中身が消えない）＋
    **「直らないときは作り直す」で抜け出せる**こと（差分再監査 🟡）
13. **白紙から作る → 場面を足す → 素材を取り込む → 少し待つ → 取り消す → 少し待つ**＝
    一覧に**同じ名前の動画が2つ**できないこと（差分再監査 🔴＝取り消しで番号が巻き戻る）
14. **分けたとき、立ち絵に入れた動画の後半が続きから流れる**こと（前半と同じところから流れ直さない）
15. ⚠️ **「よく使う素材」の一覧に小さな絵が出る**こと（#926）＝`asset://` の許可範囲（`assetProtocol.scope`）に
    `user_assets` を足したが、**その効きは実機でしか確かめられない**（ADR-0021 が `asset://` を避けた理由）。
    出なくても**壊れた画像の印は出ない**（読み込みに失敗したらその絵だけ落とす）ので、
    **「絵が出るか」だけを見る**。出ないなら data URL 経由（ADR-0021 と同じ手）へ倒す
