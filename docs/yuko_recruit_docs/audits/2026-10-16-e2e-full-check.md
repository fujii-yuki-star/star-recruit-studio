## 領域ごとの確かめ

### 場面形式
- 白紙から作る・場面を足す・セリフを打つ・声を作る・素材を足す（窓）・素材を当てる・AI の「短く」「候補を出す」「セリフから作る」・保存・取り消し／やり直し・場面の複製（2→3）・削除（確認「削除する」）
- 掛け合い（＋ セリフを追加・声＝冥鳴ひまり・全部のセリフの声を作成）・仕上がり確認に両方のクレジット・公開前チェック（要対応を声の作成で解消）
- 字幕ファイル（.srt・2件）・MP4（1920×1080・16秒）の書き出し・名前・名前の候補（2件）・BGM
- 縦型（9:16）への切り替え（2件の知らせ）・表示時間 8→6・掛け合いの2行目で「分ける」→3場面／取り消しで2場面
  （「ここで2つに分ける」はナレーションが2文字未満だと押せない＝仕様どおり）
- タイムラインで見る→作る内容を確かめる→この内容で作る→作った動画を開く

### タイムライン形式
- 取り込み（写真・動画・音声を一度に3件）・置く（10件）・文字／図形を置く・文字を打ち替える
- 選んだ部品：速さ2・使い始め1・角度15・明るさ1.3・上を隠す10%・左右反転（選び直しても保持）
- キー：Ctrl+K で分ける・Ctrl+A／Esc・Shift＋クリックで追加選択・Ctrl+C／End／Ctrl+V・Ctrl+D・Delete・M 目印・I／O 作業範囲・Shift+Delete（確認→削除する→1秒詰まる）・Space 再生／停止
- 右クリックのメニュー：この瞬間で絵を止める（速さ2・使い始め1・2秒目→「clip（0:05）」）・声を文字にする（字幕として並べる）・無音を詰める（無音なし／2.5秒の無音→「1か所・合計 2.4 秒」→部品 20.6→9.0＋9.2 秒）
- 字幕ファイルの書き出し（.srt・3件）／読み込み（.vtt・2件→新しい列・取り消し1回で全部消える）
- 表示倍率・全体を表示・列の高さ・列を足す・列のメニュー（固定⇄外す・出さない⇄出す・複製・奥へ／手前へ・**名前を変える（直した）**・2回押しで名前・削除〔確認つき〕）
- 見た目パターンを置く→メイン素材と見出しを入れる→仕上がり確認に写る・再生位置の時刻を打って移る
- 動きのひな形を当てる（0:06.00 と 0:06.18 に2点）・キーフレームを置く（大きさ1.5）・喋っている間の動き（音2・はねる／ゆらゆら／ふくらむ）
- 読み上げを置く→文を打つ→声を作る→この読み上げの字幕を置く（文が連動）
- 大きく見る／Esc・別の窓で見る（本体と同じ時刻・同じ絵）→この窓を閉じる
- 書き出し（軽い 720×1280）→「動画を保存しました」。コマに回転15°・左右反転・上10%隠し・見た目パターンの写真と見出しが写る
- 横の版を作る（「縦横を入れ替えた版を作りました…」・見た目パターンが横向きの同じ種類へ）

### ホーム・素材・見た目パターン・設定
- ホーム：複製（そのまま開く）・名前を変更・前の状態に戻す（時点5つ→ここへ戻す）・削除（「元に戻せません」）

## 道具の誤り（アプリは仕様どおりだったもの）
- 欄を名前の部分一致で探していて、「表示時間」で「字幕（…そのまま表示）」を拾った／畳まれた区画の中の欄は焦点が入らない
- 分けるは **Ctrl+K**（K 単独ではない）・追加選択は **Shift**（Ctrl ではない）・部品を選んでいる間の矢印は**部品を少し動かす**（決定18）
- JS の `click()` では「ファイルを選ぶ」窓は開かない（利用者の操作の印が要る）→実マウスで押す
- 保存の窓は既定の名前が入っているので、全選択してから道を打つ
- 別の窓が開くと DevTools の先頭が別窓になる→本体を url で選ぶ
- スクロールの途中で座標を取ると「マウスの先に別の物がある」になる→スクロールしてから測り直す
- Bash は Claude の MSIX の中なので、%APPDATA% の一部が仮想化の写しに見える→アプリの実データは外側の cmd で扱う
