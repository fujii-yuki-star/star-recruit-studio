# 17. ゆうこ キャラクター / アセット仕様

> 「ゆうこ」は画面上のマスコット（**自社素材**）。声はVOICEVOX（既定ずんだもん）で**別物**であり、その可否は `13 §5` の最優先確認事項。
> 本書は **ゆうこ立ち絵アセットの技術仕様（形式・サイズ・命名・表情セット）** を定義する。**実際の作画・最終表情数・権利・声の確定は事業判断**であり、本書では前提と要件のみ示す（該当箇所に🏢印）。

---

## 1. 役割

- ゆうこは**自社保有のマスコット**（画面上の案内役）。会社紹介・採用動画で登場（`01 §8.1`）。権利はクリア（`13 §8`）。
- ナレーション音声は **VOICEVOX:ずんだもん（ナレーター用途）** で、ゆうこ固有の声とは称さない（[`adr/0003`](adr/0003-narration-voice.md) / `13 §5`）。
- 性格・トーンは `project.toneSettings.yukoPersonality`（例「丁寧で明るい」）に紐づく。
- 🏢 ビジュアルデザイン（造形・配色・世界観）と最終表情数は自社で決定。本書は差し替え可能な**素材の器**を定義する。

---

## 2. 立ち絵アセットの技術仕様

| 項目 | 仕様 |
|---|---|
| 形式 | **透過PNG（RGBA、アルファ必須）**。背景は完全透過 |
| 推奨解像度 | 縦長 **720×1280 目安以上**（高解像度推奨）。テンプレ `character` レイヤーに `fit: contain` で収める（`11 §5` / `04 §11`） |
| カンバス・基準 | **全表情で同一カンバス・同一基準位置**（足元/中心を固定）。差し替え時に位置がズレないこと |
| 縁 | アンチエイリアス処理。背景色の残り・白フチを残さない |
| 色空間 | sRGB |
| 口パク/アニメ | MVPは**静止画のみ**（口パク・表情アニメは将来、`05 §12`）。Live2Dは対象外（`01 §16.2`） |

### 命名規則

- ファイル名・assetId：**`yuko_{tag}_{NNN}`**（`.png`）。両者を一致させる（`11 §2.1`）。
- 例：`yuko_smile_001.png` / `yuko_guide_001.png`
- `assetType = "yuko"`、`tags` に **poseTag を含める**（poseTag解決の鍵、`12 §8.3`）。

---

## 3. 表情・ポーズセット

各 `poseTag` は自由文字列（`11 §3.5`）。AIの `yukoPoseTag`・テンプレ `defaultPoseTag` がこれを指し、`12 §8.3` の規則で `poseAssetId` に解決される。

| poseTag | 用途 | 想定シーン |
|---|---|---|
| `normal` | 標準・つなぎ | 汎用 |
| `smile` | 明るい挨拶 | オープニング・好印象 |
| `guide` | 案内・説明 | 写真/ポイント紹介 |
| `bow` | お辞儀・お礼 | クロージング・応募メッセージ |
| `surprise` | 驚き・強調 | 数字・意外性の提示 |
| `think` | 考える | 課題提起・問いかけ |
| `cheer` | 元気・応援 | 募集・背中を押す |

（由来：`01 §8.2`）

- **MVP最小セット（推奨）**：`normal` / `smile` / `guide` / `bow` の4点。残りは任意で順次追加。🏢 最終的な表情数は作画コストと相談。
- **既定素材**：1点に `isDefaultYuko: true` を設定（poseTag解決が失敗した場合のフォールバック、`12 §8.3`）。通常は `yuko_normal_001` か `yuko_smile_001`。

---

## 4. メタデータ・登録

`Asset` スキーマ（`11 §7.2` / `project.schema.json`）に準拠。ゆうこ素材の例：

```json
{
  "assetId": "yuko_smile_001",
  "assetType": "yuko",
  "displayName": "ゆうこ_笑顔",
  "filePath": "assets/yuko/yuko_smile.png",
  "tags": ["smile", "opening"],
  "isDefaultYuko": true,
  "metadata": { "width": 720, "height": 1280, "durationSec": null, "hasAudio": false }
}
```

（`fixtures/project.sample.json` の `yuko_smile_001` / `yuko_guide_001` を参照）

---

## 5. 表示ルール

- **常時表示ではない**。表示有無・位置・サイズは**テンプレートが決める**（`character` レイヤーの有無、`04 §11`・要件 `7.3`）。
- レイヤーは `fit: contain`、`required: false`・`allowHidden: true` が基本。
- シーン側でポーズ素材の差し替え可（`character.poseAssetId`）。

---

## 6. 権利・声（決定済み）

- **作画の権利**：ゆうこは**自社保有マスコット**。商用利用・アプリ同梱・エンドユーザー動画への利用権はクリア（`13 §8`）。
- **声**：既定ナレーション音声は **VOICEVOX:ずんだもん（ナレーター用途）**。ゆうこの“固有の声”とは称さない（[`adr/0003`](adr/0003-narration-voice.md)）。将来はゆうこ専用ボイスへ差し替え可（`01 §8.3`）。
- **クレジット**：声を使う限り「VOICEVOX:ずんだもん」表記が必要（`13 §4`）。**常時表示を実装要件**とする。
