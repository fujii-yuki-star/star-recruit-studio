# テスト計画・受け入れ条件

## 1. 目的

本資料は、「すたりお（stario）」のMVP完成判定、手動テスト観点、異常系テスト観点を定義する。

---

## 2. MVP受け入れ条件

### 2.1 基本フロー

- [ ] 新規プロジェクトを作成できる。
- [ ] 会社情報を入力できる。
- [ ] 画像素材を登録できる。
- [ ] 動画素材を登録できる。
- [ ] BGM素材を登録できる。
- [ ] ゆうこ素材を登録できる。
- [ ] 見た目パターンを選択できる。
- [ ] AIで動画のたたき台を作成できる。
- [ ] AI結果をシーンカードとして表示できる。
- [ ] シーンのセリフを編集できる。
- [ ] シーンの字幕を編集できる。
- [ ] シーンの素材を差し替えできる。
- [ ] プレビューできる。
- [ ] MP4を書き出しできる。
- [ ] プロジェクトを保存・再読み込みできる。

---

## 3. AI関連テスト

- [ ] 会社情報と素材説明から動画構成JSONが生成される。
- [ ] 画像サムネイルを送信前確認画面で確認できる。
- [ ] AIが返したJSONを検証できる。
- [ ] 存在しないtemplateIdが返った場合、自動補正または警告できる。
- [ ] 存在しないassetIdが返った場合、候補提示できる。
- [ ] 長すぎる字幕に警告が出る。
- [ ] シーン単位でセリフ再生成できる。
- [ ] AI通信失敗時に手動作成へ進める。

---

## 4. 素材管理テスト

### 画像

- [ ] JPGを登録できる。
- [ ] PNGを登録できる。
- [ ] WEBPを登録できる。
- [ ] サムネイルが生成される。
- [ ] 説明文を編集できる。

### 動画

- [ ] MP4を登録できる。
- [ ] 動画サムネイルが生成される。
- [ ] 開始秒・終了秒を指定できる。
- [ ] 動画内音声をON/OFFできる。
- [ ] 動画内音声音量を変更できる。

### BGM

- [ ] 標準BGMを選択できる。
- [ ] ユーザーBGMを追加できる。
- [ ] BGM音量を変更できる。
- [ ] BGMをループできる。

---

## 5. テンプレートテスト

- [ ] 標準テンプレートが表示される。
- [ ] テンプレートサムネイルが表示される。
- [ ] テンプレートパックを追加できる。
- [ ] 不正なテンプレートはエラー表示される。
- [ ] ゆうこありテンプレートでゆうこが表示される。
- [ ] ゆうこなしテンプレートでゆうこが表示されない。
- [ ] 半透明パネルなどの装飾が表示される。
- [ ] ユーザー登録アセットをテンプレートで利用できる。

---

## 6. プレビューテスト

- [ ] シーン単位でプレビューできる。
- [ ] パート単位でプレビューできる。
- [ ] 全体プレビューできる。
- [ ] セリフ変更がプレビューに反映される。
- [ ] 素材変更がプレビューに反映される。
- [ ] 字幕が指定位置に表示される。
- [ ] 文字あふれ時に警告が出る。

---

## 7. 音声テスト

- [ ] ゆうこの声を生成できる。
- [ ] デフォルト声がずんだもんになっている。
- [ ] 話速を変更できる。
- [ ] 高さを変更できる。
- [ ] 抑揚を変更できる。
- [ ] セリフ変更後、該当シーンだけ再生成できる。
- [ ] VOICEVOX未起動時に分かりやすいエラーが出る。

---

## 8. MP4出力テスト

- [ ] 1920x1080 / 30fps のMP4を書き出せる。
- [ ] 画像素材が出力動画に表示される。
- [ ] 動画素材が出力動画に表示される。
- [ ] 字幕が焼き込まれる。
- [ ] ゆうこ素材が表示される。
- [ ] BGMが入る。
- [ ] ナレーションが入る。
- [ ] 動画元音声ON時に動画音声が入る。
- [ ] 動画元音声OFF時に動画音声が入らない。
- [ ] フェードが適用される。

---

## 9. 長尺動画テスト

- [ ] 3分程度の動画を書き出せる。
- [ ] 5分程度の動画を書き出せる。
- [ ] 将来対応として10分動画の技術検証ができる。
- [ ] 書き出し中に進捗が表示される。
- [ ] 失敗時に失敗シーンが分かる。

---

## 10. 異常系テスト

| ケース | 期待結果 |
|---|---|
| 素材ファイルが削除された | 素材が見つからない旨を表示 |
| AIが壊れたJSONを返す | 修正不能として再生成を促す |
| templateIdが存在しない | 標準テンプレートに置換または選択を促す |
| assetIdが存在しない | 素材選び直しを促す |
| VOICEVOX未起動 | 起動確認メッセージを表示 |
| FFmpeg未配置 | 動画保存機能の準備不足を表示 |
| BGMファイル破損 | BGMなしで続行する選択肢を表示 |
| セリフが空 | 音声生成前に警告 |
| 字幕が長すぎる | 短縮提案を表示 |

---

## 11. 非技術者向け確認

採用担当者相当のユーザーに以下を確認する。

- [ ] 初回起動時に何をすればよいか分かる。
- [ ] JSONや技術用語が出てこない。
- [ ] AIに何を送るか理解できる。
- [ ] セリフを直す場所が分かる。
- [ ] プレビュー方法が分かる。
- [ ] MP4保存方法が分かる。
- [ ] エラー時に次の行動が分かる。

---

## 12. 公開前チェック項目

- [ ] 誤字脱字がない。
- [ ] 会社名が正しい。
- [ ] 採用対象が正しい。
- [ ] 誇大表現がない。
- [ ] 個人情報が含まれていない。
- [ ] 映り込みに問題がない。
- [ ] BGM音量が大きすぎない。
- [ ] ナレーションが聞き取りやすい。
- [ ] 字幕が読みやすい。
