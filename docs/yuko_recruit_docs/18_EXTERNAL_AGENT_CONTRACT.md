# 18. 外の AI が「すたりお」を動かすときの約束（書く側の契約）

> **この文書の相手は、利用者が持ち込む AI**（Claude・Codex など）です。
> 誰に許すかは [`ADR-0041`](adr/0041-external-agent-operability.md)、口の形は [`ADR-0042`](adr/0042-agent-entrypoints.md) にあります。
>
> ⚠️ **同梱の生成（こちらが配る API キーの無料枠で動くもの）はこの文書の相手ではありません。**
> あちらが触れるのは**場面形式まで**です（`CLAUDE.md §2` 絶対原則4・ADR-0032）。

## 18.0 いちばん短い説明

**動画は JSON 1枚と、その隣のファイルだけで出来ています。** だから外の AI は、
**JSON を書いて、ファイルを置いて、アプリを起こす**だけで動画を作れます。

```
<どこかのフォルダ>/
  project.json        ← これが動画そのもの
  assets/             ← 使う写真・動画（相対パスで指す）
  voices/             ← 作った読み上げの音（相対パスで指す）
```

```
stario.exe --import  <そのフォルダ>                       取り込んで開く
stario.exe --export  <動画の番号> --out <保存先.mp4>       書き出す
stario.exe --export  <番号> --out <道> --quit-when-done    書き出して閉じる
```

## 18.1 ⚠️ いちばん大事な約束

**アプリの検証を通ったものしか受け取りません。** 書いた JSON は、取り込みのときに
**正典どおりの形か**を必ず見ます（[`11_SCHEMA_REFERENCE`](11_SCHEMA_REFERENCE.md) / [`11_TIMELINE_REFERENCE`](11_TIMELINE_REFERENCE.md)）。
通らなければ**取り込みません**（フォルダも残しません）。

⚠️ **検証は二段です。**

| いつ | 何を見るか | 通らないと |
|---|---|---|
| **取り込み・読み込み** | **形**（項目・型・値の範囲） | **断る**（取り込まない） |
| **書き出し** | **つながり**（指した素材が居るか・同じ列で重なっていないか等＝`11 §8` V22〜V33） | **書き出しを止める** |

⚠️ **読み込みでは、つながりを見ていません**（`domain/timeline/persistence.ts` の注記で確認）＝
つながりの検査（V22〜V33）は**画面が別に呼ぶ**もので、**読み込み自体は止めません**。
だから「取り込めた＝正しい」ではありません。

→ **形だけ通しても、書き出しで止まることがあります。** 作ったら、**必ず一度書き出してください**。

## 18.2 置き場

| もの | どこ |
|---|---|
| 動画 | `%APPDATA%\jp.star-system.star-recruit-studio\projects\<番号>\` |
| うまくいかないときの記録 | `%APPDATA%\jp.star-system.star-recruit-studio\logs\` |

⚠️ **自分で置き場へ書き込まなくて構いません**＝`--import` を使えば、**どこのフォルダからでも**取り込めます
（中身は手元へコピーされます＝[`ADR-0024`](adr/0024-non-destructive-editing-model.md)＝動画は素材込みで自己完結）。

⚠️ **番号（`projectId`）は自分で決めないでください**＝取り込むときに**アプリが採り直します**
（`project.json` の中の番号も一緒に書き換わります）。フォルダ名も中身も、取り込む前は何でも構いません。

## 18.3 番号の付け方（自分で置き場へ書く場合）

| もの | 形 | 例 |
|---|---|---|
| 動画 | `proj_YYYYMMDD_NNN` | `proj_20260917_001` |
| 素材 | `asset_NNN` | `asset_001` |
| 部品（タイムライン） | `clip_NNN` | `clip_016` |
| 列（タイムライン） | `track_NNN` | `track_003` |
| 動き | `anim_NNN` | `anim_001` |
| まとまり | `group_NNN` | `group_001` |
| 目印 | `marker_NNN` | `marker_001` |
| 場面・部（場面形式） | `scene_NNN` / `part_NNN` | `scene_001` |

⚠️ **その動画の中で重複なし**（`11 §2`）。

⚠️ **「3桁ちょうど」なのは動画の番号だけ**（実物の schema を見て確かめた）：

| | schema の形 | 意味 |
|---|---|---|
| 動画 | `^proj_[0-9]{8}_[0-9]{3}$` | **3桁ちょうど** |
| 部品・列・動き・目印 | `^clip_[0-9]{3,}$` など | **3桁以上**（999 を超えたら4桁でよい） |
| 素材 | `^[a-z0-9_]+$` | ⚠️ **形の上はもっと緩い**＝`asset_NNN` は**採番の決まり**（`11 §2`）であって、schema は縛っていない |

→ **迷ったら `11 §2` の決まり（3桁ゼロ詰め）で書いてください。** schema が緩い所でも、
**決まりから外れた番号はアプリの中の道具が想定していません**。

## 18.4 素材と声の置き方

- **相対パス**で指します（`assets/asset_001.png` / `voices/clip_016.wav`）。
  ⚠️ **絶対パス・`..`・ドライブ付きは受け取りません**（持ち場の外を指せないため）。
- **声は自分で作れます**＝同梱の VOICEVOX（既定 `http://localhost:50021`。`VOICEVOX_URL` で変えられる）へ
  `audio_query` → `synthesis` を投げ、返った WAV を `voices/` へ置き、
  その部品の `voice.status` を `"generated"`、`voice.voicePath` をその相対パスにします。
  ⚠️ **`status` を `"generated"` にし忘れると、書き出しで声が入りません**（作り直しの対象として扱われます）。
  ⚠️ **`status` に書ける値は4つだけ**＝`none` / `pending` / `generated` / `failed`（schema を見て確かめました）。
  ⚠️ **読み上げの部品に必ず要るのは `text` と `status` の2つ**（`speaker` は任意＝未指定なら動画の既定を継ぐ）。
- ⚠️ **相対パスの決まりは、思ったより厳しい**（`is_safe_rel_path`）＝`..` を**部分一致**で弾くので、
  **`写真..png` のような実在しうる名前も落ちます**。落ちたぶんは数で知らせますが、**取り込まれません**。
  `:` を含む名前・`/` や `\` で始まる道・絶対パスも同じく落ちます。

## 18.5 うまくいったかの見分け方

`--quit-when-done` を付けて起こすと、終わったときに**終了コード**で返します。

| 番号 | 意味 | 直し方 |
|---|---|---|
| `0` | できた | — |
| `1` | できなかった | 画面に出た文と、上の記録を見る |
| `2` | **指定が読めない・足りない** | 起動のときの指定（`--export` など）の綴りと、続きの値を直す |

⚠️ **`1` と `2` は直し方が違うので分けています**（やってみて駄目だった／そもそも書き間違い）。

⚠️ **すでにアプリが開いているときは、終了コードで判定できません**（ADR-0042 決定③-2）＝
2つ目の起動は引数だけ渡してすぐ終わるので、**結果に関わらず `0`** で返ります。
**確実に判定したいときは、アプリを開いたままにしないでください。**

⚠️ **開いている動画があると、外から来た頼まれごとは断られます**＝
「いま動画を開いています。閉じてから、もう一度お試しください。」
（**書き出しは保存を伴う**ので、受けると利用者が触っている動画を上書きしうるため）

## 18.5.1 範囲を消して詰める（#1193）

**「ここからここまで要らない」は、1つの操作でできます。**

| 画面 | キー |
|---|---|
| 「ここから（範囲）」「ここまで（範囲）」 | `I` / `O` |
| 「範囲を削除して詰める」 | `Shift+Delete` |
| 「範囲を削除」（詰めない） | — |

⚠️ **詰めると、全部の列が同じだけ前へ寄ります**＝列を選んで詰めることはできません
（片方だけ詰めると、映像と音の時間がずれ、詰めて前へ来た部品が重なるため）。
⚠️ **目印も一緒に寄ります**。消した範囲の中にいた目印は**切れ目へ寄せ**、その数を知らせます。
⚠️ **読み上げと、それに連動する字幕は丸ごと消えます**（半分だけ残すと言いかけの声になるため）。

## 18.6 やってはいけないこと

- ⚠️ **アプリを2つ起こさない**＝起こしても2つ目は開きません（引数だけ渡ります）。
- ⚠️ **`%APPDATA%` の中のファイルを、アプリが動いている最中に書き換えない**＝
  自動保存と競り合って、**どちらかの変更が黙って消えます**。
- ⚠️ **100 回の分割と削除で「範囲を消す」を代用しない**＝**範囲を消して詰める**操作があります
  （[#1193](https://github.com/fujii-yuki-star/star-recruit-studio/issues/1193)）。低い操作を積むと、
  **取り消しがその回数だけ割れ**、途中で失敗した状態も増えます。

## 18.7 できないこと（いまのところ）

| | |
|---|---|
| 画面を出さずに走らせる | **できません**＝絵を作っているのは画面の側（[`ADR-0001`](adr/0001-rendering-parity.md)）。窓は出ますが、**押さなくても進みます** |
| 外へ何かを送る | **アプリはしません**＝素材をどこへ見せるかは、**あなたと利用者の間の話**です（`CLAUDE.md §2` 絶対原則6 は緩めていません） |
| 同梱の生成にタイムラインを書かせる | **できません**＝あちらは場面形式まで（ADR-0041） |
