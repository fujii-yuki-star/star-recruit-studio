## 変異チェック（必須）

```bash
node scripts/mutate.mjs --print-template     # 雛形
node scripts/mutate.mjs <spec.json>          # 実行
```

実行係が構造で守るもの＝**ベースラインが赤いまま回さない／書き換え先が1か所でなければ止める／中断されても戻す**。

⚠️ **生き残った変異は「検査していない振る舞い」**＝検査を足すか、**等価である理由を書く**。

## よく踏むところ

- **空振りのテスト**＝壊しても緑のままになる書き方。実例：
  - 「開いているピッカーの中のタイル」を数える → **畳んでも描き続ける壊し方**を捕まえられない
  - バッジの数を説明文から読む → **バッジを消す**壊し方を捕まえられない
  - 代表1件だけ見る → **残りの枝**を捕まえられない
- **合成イベントで確かめられないこと**＝`click` は焦点を移さない／数値欄は受けない／ドラッグは動かない
- **fixture が実物と形が違う**＝主要経路を素通りする。**実際の型・実際の構築関数から作る**
- **自分がコメントに書いた主張を検査していない**＝主張も変異にする（`CLAUDE.md §7`）
