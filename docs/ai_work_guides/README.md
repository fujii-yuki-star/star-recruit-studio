# AI 作業ガイド（読む資料の入口）

> **これは正典ではありません。** 正典（`CLAUDE.md` / `11` / `12` / `15` / `schemas/`）へ**行き先を示すだけ**の索引です。
> ここに書いてあることと正典が食い違ったら**正典が正しい**（`CLAUDE.md §0`）。食い違いを見つけたら、このファイルを直してください。

## なぜあるか

正典は積み上がって大きくなりました（実測・2026-09-08）。

| 資料 | 文字数 | いつ読まれるか |
|---|---:|---|
| `CLAUDE.md` | 50,916 | **毎セッション自動で全文** |
| `11_SCHEMA_REFERENCE.md` | **49,489**（切り出し前 120,581） | 呼ばれたとき |
| `06_UI_SPEC.md` | 97,871 | 呼ばれたとき |
| `15_ERROR_STATE_MODEL.md` | 58,561 | 呼ばれたとき |
| `adr/*.md`（39本） | 281,937 | 呼ばれたとき |
| 資料ぜんぶ | 946,858 | — |

問題は「長いこと」ではなく、**どこを読めば足りるかが書いていないこと**です。書いていないと、AI は「全部読む」か「読まずに書く」のどちらかに倒れます。前者はトークンを使い切り、**後者は正典違反を生みます**（実際に起きた例は各ガイドの「よく踏むところ」に実数で挙げてあります）。

1. これからやる作業の種類を下の表から選ぶ
2. そのガイドだけを開く
3. ガイドの **必読** を読んでから書き始める

| 作業 | ガイド |
|---|---|
| 画面・文言を変える | [`ui_change.md`](ui_change.md) |
| 保存する形（schema）を変える | [`schema_change.md`](schema_change.md) |
| AI 出力の検証・変換を変える | [`ai_transform.md`](ai_transform.md) |

| 声を作る・音を混ぜる | [`voice_change.md`](voice_change.md) |
| エラー・注意の文言を変える | [`error_message.md`](error_message.md) |

どれにも当てはまらない小さな修正（内部のリファクタ・コメント・依存の更新）は、**`CLAUDE.md` §2・§6・§7 だけ**で足ります。

## 「必読 / 必要なら読む / 読まない」の意味

| 印 | 意味 | 守らないと何が起きるか |
|---|---|---|
| **必読** | 書き始める前に開く。読まずに書いたものは**根拠が無い** | 正典違反・二重実装・文言の割れ |
| **必要なら読む** | 条件つき。条件はガイドに書いてある | 条件に当たっているのに読まないと、既に決まっている判断をやり直す |
| **読まない** | その作業には効かない。読むと**判断が薄まる** | 関係ない制約を持ち込んで、いらない作り込みをする |

⚠️ **「読まない」は「無視してよい」ではありません**＝矛盾に気づいたら止めて確認する、は常に生きています（`CLAUDE.md §9-2`）。

## 全作業に共通で効くもの（ガイドでは繰り返しません）

`CLAUDE.md` は毎セッション自動で読み込まれるので、**改めて開く必要はありません**。ただし次の4つは**どの作業でも必ず通ります**。

- **`CLAUDE.md §2` 絶対原則**（7項目）＝これに反する実装は書かない
- **`CLAUDE.md §7` DoD**（5項目）＋**変異チェック**＝「直した」と書く前に通す
- **`CLAUDE.md §9` 作業方針**＝正典に無いものを推測で埋めない
- **`/canon-check`**＝コミット前に走らせる（判断層の自動点検）

## 大きい資料を開くときの作法

`11` / `06` / `15` は**節ごとに独立**しています。**節を指定して読む**（全文を読まない）。

```bash
# 例：11 §3（enum カタログ）だけを見る
grep -n '^## ' docs/yuko_recruit_docs/11_SCHEMA_REFERENCE.md   # まず節の位置を出す
sed -n '<開始>,<終了>p' docs/yuko_recruit_docs/11_SCHEMA_REFERENCE.md
```
