| [`06_UI_SPEC.md`](../yuko_recruit_docs/06_UI_SPEC.md) | **§3 用語置き換え**（2,297字） | 画面に出してよい言葉／禁止語 |

## 必要なら読む

| 条件 | 読むもの |
|---|---|
| 欄の配置・折りたたみを触る | [`adr/0033`](../yuko_recruit_docs/adr/0033-editor-panel-layout.md)（配置は `localStorage`・**project.schema には入れない**） |
| タイムラインの操作（掴む・置く・吸着）を触る | [`adr/0034`](../yuko_recruit_docs/adr/0034-timeline-interaction-model.md)＋[`timeline_change.md`](timeline_change.md) |
| 文言が「断り」「注意」になる | [`error_message.md`](error_message.md)（`15 §6` の表と機械で突き合わせる門番がある） |
| 場面編集の編集機能を**増やす** | **止まって確認**＝場面形式は凍結（`CLAUDE.md §11` ADR-0032 の線引き） |

## 読まない

- `11_SCHEMA_REFERENCE.md`（保存する形を変えないなら関係ない）
- `12_AI_PROMPT_AND_MAPPING.md`
- `05_RENDERING_SPEC.md`（描画の中身を変えないなら）
- `01`〜`04`・`07`〜`10`（例示・背景。正典ではない）

## よく踏むところ

- **見出しと欄が結ばれていない**＝`<button>` を開く欄にすると、見出しで指すだけでは呼び名にならない。**部品の側で結ぶ**（`FontPicker` / `ThumbPicker` の形）。門番＝`src/test/labelAssociationGuard.test.tsx`
- **同じ文言が画面ごとに割れる**＝`src/app/uiLabels.ts` に1つ置いて共有する。門番＝`src/app/uiMessageScan.test.ts`
- **双子の片方だけ直す**＝場面形式とタイムライン形式は同じ概念を両方が持っている。片方を直したら**もう片方を `grep` で数える**（ADR-0026②）
- **「直した」と書いた行の数を数えていない**＝`CLAUDE.md §7` の末尾。差分の `file:line` を挙げられないものは書かない

## 終わったら

`npm run check:frontend` と変異チェックを通し、**`06` の該当節を同じ PR で直す**（`CLAUDE.md §9-5`）。最後に `/canon-check`。
